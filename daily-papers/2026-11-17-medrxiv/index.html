    澳大利亚健康从业者法庭裁决什么，以及自动化分析遗漏了什么：1999年至2026年2月的3586份裁决 Farquhar, H. L. 2026-11-17 PDF 背景：澳大利亚的医疗从业人员受《医疗从业人员监管国家法》监管，严重的执业行为问题会被提交至州和领地法庭审理。尽管已公布了数千份法庭裁决，但此前尚无研究对该语料库应用计算文本分析。人工编码使以往的研究局限于问题的狭窄切片——通常只涉及一个职业、一个司法管辖区或一种不当行为类型。方法：对澳大利亚全部八个司法管辖区1999年至2026年间的3586份法庭裁决应用了自然语言处理。基于367份标注裁决训练了一个多标签文本分类器（TF-IDF逻辑回归），将不当行为分为七种类型。结果通过基于规则的方法提取。采用卡方检验、Fisher精确检验和Mann-Kendall趋势检验评估关联性和时间趋势。对63项统计检验应用了Benjamini-Hochberg错误发现率校正。在留出测试集（n = 45）上评估了分类器性能，并使用Rogan-Gladen估计量计算了经误差校正的患病率估计值。结果：在3586份裁决中，2428份（67.7%）涉及纪律程序。分类器性能因类别而异（各类别F1为0.47-0.82）。边界违规是最常见的不当行为类型（30.2%），其次是欺诈/不诚实（29.7%）和职业行为违规（28.0%）。谴责是最常见的处理结果（53.0%），其次是注销注册（40.2%）。边界违规（tau = 0.296，p = 0.032）、欺诈/不诚实（tau = 0.564，p < 0.001）、职业行为违规（tau = 0.396，p = 0.004）和沟通失败（tau = 0.667，p < 0.001）均呈现出显著上升的时间趋势。边界违规与更高的注销几率相关（OR = 1.36，p < 0.001）。阿片类药物出现在67%的处方不当行为裁决中。观察到不当行为类型和处理结果均存在显著的司法管辖区差异，两两效应量较大（Cramer's V最高达0.502）。结论：本研究首次对澳大利亚医疗从业人员法庭裁决进行了大规模计算分析，在一个比以往任何人工研究大四倍以上的语料库中识别了时间趋势、司法管辖区差异以及不当行为与处理结果之间的关联。显著的司法管辖区差异引发了关于在国家统一框架下监管结果一致性的疑问。处方不当行为裁决中阿片类药物的集中出现与澳大利亚已记录的处方阿片类药物危害负担相一致。分类器对罕见不当行为类别（欺诈/不诚实、沟通失败）的局限性意味着这些类型的患病率估计值应被视为下限。
