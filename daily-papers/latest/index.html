    针对WhisperX的上下文感知交错批处理

    arXiv / 2026-08-31 / Carlos Bain

    WhisperX通过音频内批处理加速语音转录，但它隔离了音频片段，失去了连贯标点和术语转录所需的历史上下文。相反，标准Whisper按顺序保留上下文，但推理速度慢且易陷入幻觉循环。为兼得两者优势，我们提出上下文感知交错批处理。通过利用基于VAD的片段边界，我们的算法稳定了Whisper的文本条件化，从而在批处理音频片段间安全地维持连续历史上下文。如长音频基准测试所示，该方法降低了词错误率（WER）并改善了专有名词转录，同时保持了高吞吐量的推理速度。

    一般博弈中的恒定个体遗憾

    arXiv / 2026-08-31 / Mingyang Liu

    解耦的无遗憾动态提供了一条去中心化地达到均衡的途径，但先前对个体遗憾的保证仍依赖于时间跨度的多对数项。我们在完全信息反馈下，对每个有限的$N$人正规形式博弈移除了这一依赖。我们引入了\emph{ECHO-OFTRL}：配备用于高阶乐观的EMA级联（ECHO）的乐观跟随正则化领导者（OFTRL），其中EMA指指数移动平均。该算法是确定性的且完全解耦的。若$m_{\max}$表示最大的行动集大小，则对于每个时间跨度$T\geq1$，它同时保证博弈中每位$N$个玩家的遗憾上界为$O(\textrm{poly}(N, \log m_{\max}))$。我们的算法利用了受现代滤波器设计启发的一种新形式的乐观。

    SUN：面向语言接地控制-学习-现实策略的持久程序

    arXiv / 2026-08-31 / Weiqi Wang

    在长时程操作中，将基于模型的控制与学习策略相衔接，一直潜藏着一个未言明的分歧：控制执行明确的目标，学习则将这种行为摊销为反应式策略，然而现有协议丢弃了任务语义，导致奖励需手工设计，行为偏离控制所验证的内容。我们引入了语义统一（SUN）程序，这是一种类型化可执行文件，其中几何和接触关系被定义一次，并编译为对齐的模型预测控制（MPC）成本、满足谓词、强化学习奖励、转换守卫和诊断信息。我们的系统Kuafu，由大型视觉语言系统驱动，能从语言和场景语义中自动合成SUN程序，通过MPC筛选可行性，并在训练阶段条件策略时保留语义。在九项任务中，Kuafu实现了82.03%的宏观成功率，优于稀疏奖励（35.67%）和阶段行为克隆（24.75%）基线。在8192路规模下，它每小时人类遥操作产生的成功轨迹时间是后者的10.57倍。每项任务使用500条轨迹，Kuafu数据训练DP3策略，在模拟中达到46.0%的成功率（对比替代方案的22.4%），在物理Franka和Kinova机器人上达到34.7%。这些结果表明，经模拟筛选的任务语义能有效将控制摊销为稳健策略，无需演示或手动密集奖励，统一了符号规划与数据驱动执行。

    BRF-GS：基于三维高斯泼溅的高光谱双向反射因子建模与图像生成

    arXiv / 2026-08-31 / Yiling Yao

    双向反射因子（BRF）表征了地表的方向性辐射特性。然而，现有的三维（3D）辐射传输模型需要复杂的场景构建和计算密集型的辐射传输求解器，限制了多角度高光谱反射率影像的高效生成。3D高斯泼溅（3DGS）为神经场景表示和新视角合成提供了高效框架，但其低阶球谐函数表示不足以应对复杂的方向性反射，而高光谱数据的高维性和波段间质量差异又带来了额外挑战。为解决这些问题，我们提出了BRF-GS，一种基于3DGS的BRF建模和高光谱反射率影像生成框架。BRF-GS引入了一种混合BRDF驱动核来表示复杂的方向性反射，选择几何可靠的谱段以进行稳健的3D场景初始化，并采用两阶段训练策略，将几何优化与光谱建模解耦。我们进一步构建了AIR-BRF数据集，这是一个包含三个场景、涵盖多样自然和人工目标的多角度高光谱方向性反射率数据集。实验表明，BRF-GS在空间和光谱保真度上表现优异，并能准确再现特征性的视角依赖BRF响应。所提出的框架为遥感场景中的BRF建模和多角度高光谱反射率影像生成提供了一种高效的数据驱动方法。

    具有仿射潜在参数化的神经网络的尖锐逼近率

    arXiv / 2026-08-31 / Shijun Zhang

    许多参数高效方法从低维潜在表示生成大型神经网络的参数。给定一个具有$P_Φ$个参数槽的架构$Φ$，我们写作$\boldsymbolθ_f=\mathcal{G}(\boldsymbolξ_f)$，其中$\mathcal{G}\colon\mathbb{R}^M\to\mathbb{R}^{P_Φ}$是参数生成器，$\boldsymbolξ_f\in\mathbb{R}^M$是目标函数$f$的潜在表示。架构$Φ$和生成器$\mathcal{G}$在整个目标类别中共享，而每个目标$f$由其自身的潜在向量$\boldsymbolξ_f$表示，其中$Φ_{\mathcal{G}(\boldsymbolξ_f)}$近似$f$。这一框架涵盖了超网络、低维参数化、参数高效适应和模型压缩。因此，理解潜在维度$M$与网络预算$P$之间的权衡对于刻画这些方法的表达效率至关重要。我们针对仿射生成器和全连接ReLU架构研究这一权衡。更精确地说，在满足$P_Φ\leq P$的架构$Φ$和仿射生成器$\mathcal{G}:\mathbb{R}^M\to \mathbb{R}^{P_Φ}$上联合优化，我们证明了在$[0,1]^d$上$α$-Hölder函数单位球上的最优最坏情况均匀逼近误差，其中$0<α\leq1$，具有尖锐阶数$ \bigl(P\min\{M,P\}\bigr)^{-α/d} $。特别地，我们的结果表明，即使固定维度的潜在空间也足以随着网络预算的增加实现逼近误差趋于零。

    可配置的语义分块用于检索增强生成中的生物医学信息提取

    arXiv / 2026-08-31 / Riya Ahuja

    BioMedRAG引入了检索增强生成，并配备了一个学习得到的块评分器，用于生物医学信息提取。然而，它依赖于固定大小的分块，这可能会割裂语义证据。我们提出了一种可配置的语义分块框架，通过结合实体保留窗口、触发词中心分块、命题优先提取、分层触发词优先级排序以及层级关系解析来解决这一局限。该框架与BioMedRAG集成时，仅替换分块构建阶段，同时保留嵌入模型、学习得到的块评分器、生成器和评估协议。我们在生物医学关系提取基准（GM-CIHT、DDI、ChemProt）和不良事件分类（ADE）上评估了该框架。在GM-CIHT上，完整的混合配置达到了82.6%的F1分数，在我们的实验设置下，相比固定大小基线（74.2%的F1分数）提高了8.4个百分点。跨数据集分析表明，语义分块改善了具有明确关系线索的提取数据集，如GM-CIHT和DDI，而固定分块在密集生化提取和二元分类设置（如ChemProt和ADE）中仍保持竞争力或更强。通过将分块逻辑外部化到配置文件中，该框架为生物医学RAG流水线提供了一种可解释且可适应的替代方案，以取代僵化的固定大小分块。

    OntoAligner-Ensemble：基于投票的异构本体对齐技术融合

    arXiv / 2026-08-31 / Hamed Babaei Giglou

    本体对齐（OA）已通过多种方法论范式演变，涵盖从词汇和结构对齐器到知识图谱嵌入（KGE）模型，以及最近基于大语言模型（LLM）的方法。尽管现代OA框架为部署这些异构对齐器提供了统一生态系统，但系统性地调和其互补且有时冲突的预测的机制仍相对未被充分探索。我们提出OntoAligner-Ensemble，一个模块化且对齐器无关的框架，通过可配置的两阶段过程组合候选对应关系，该过程包括基于投票的融合策略，随后是融合后选择策略。该框架支持OntoAligner中实现的任何产生候选对应关系的对齐器，从而通过统一决策过程集成多样化的对齐范式。为展示其有效性，我们使用代表性的轻量级字符串对齐器、基于KGE的对齐器以及由开放权重和基于API的LLM驱动的检索增强生成对齐器来实例化该框架。我们在来自五个OAEI轨道的八个基准任务上评估个体对齐器和集成配置，涵盖从生物医学到超越等价性的范围。结果表明，集成融合持续改善精确率和召回率之间的平衡，并经常在多样领域超越独立对齐器。此外，我们的分析揭示集成组成直接影响精确率-召回率权衡：异构跨范式集成通常提高精确率，而同质LLM集成更常实现更高的总体F1分数。这些发现表明，系统性集成学习为OA提供了稳健且可复现的策略，同时为在不同对齐场景下选择集成组成提供实用指导。

    在Template Model Builder（TMB）中实现神经网络混合效应模型

    arXiv / 2026-08-31 / Nan Zheng

    神经网络混合效应模型（NMMs）通过结合人工神经网络的强大表征和预测能力与混合效应建模捕捉复杂相关结构的优势，已获得广泛关注。然而，现有估计方法严重依赖目标函数和梯度的手动推导，这固有地迫使采用简化近似，并严重限制了NMMs的复杂性和准确性。在本工作中，我们引入了一个使用模板模型构建器（TMB）实现NMMs的通用框架。通过利用自动微分和拉普拉斯近似，TMB仅要求用户指定负联合对数似然及任何正则化项。该框架自动积分出随机效应，并评估边际目标函数及其精确梯度，无需手动推导或临时近似。我们通过两个数值示例展示了基于TMB的NMMs的效率、灵活性和统计性能，包括一个应用于单调NMMs的案例。提供了可复现代码以促进更广泛的采用。

    斑马鱼幼体的氮排泄具有灵活性，且对恒河猴糖蛋白缺失具有恢复力。

    bioRxiv / 2026-09-01 / Mes, W.

    含氮废物排泄对鱼类所有发育阶段都至关重要。胚胎鱼排泄尿素，随后转变为皮肤排泄，再后来是鳃部氨排泄。在斑马鱼中，氨排泄涉及角质细胞和离子细胞中的恒河猴糖蛋白Rhbg和Rhcgb，但它们在鳃中出现的确切发育时间尚不清楚。Rhbg和Rhcgb在氨排泄中的潜在冗余性也未充分研究，对低pH响应的差异同样如此。我们假设恒河猴糖蛋白部分冗余，且它们在低pH下的响应不同，因为氨排泄使离子细胞能够交换Na+和H+（Rh-NHE-代谢复合体）。我们预测rhbg或rhcgb的缺失会诱导补偿性反应。我们表征了从0到8天受精后（dpf）从尿素到鳃部氨排泄的转变，以及pH 5.0对对照斑马鱼和rhbg或rhcgb-crispants中恒河猴糖蛋白表达和定位的影响。进一步在rhcgb-crispants中表征了高外部氨（HEA，500 M NH4Cl）和10 mM HEPES缓冲的影响。Rhag和Rhbg在5 dpf时出现在鳃中，而Rhcgb在6 dpf时出现。rhbg或rhcgb的缺失不影响基线N排泄，表明斑马鱼可以在没有完整恒河猴糖蛋白组合的情况下维持氨排泄。我们未观察到恒河猴糖蛋白的补偿性增加，但转运蛋白海马丰富转录本1b的表达增加。暴露于HEA的rhcgb-crispants转向以尿素为主要氮废物。总之，这些发现强调了幼虫在处理含氮废物方面的可塑性。

    跨任务的结构约束内在时间尺度

    bioRxiv / 2026-09-01 / Wu, K.

    内在神经时间尺度（INT）量化了自发神经动力学的持续性，为表征全脑时间组织提供了一种原则性度量。尽管在静息状态下已确立了INT的层级结构，但任务参与如何重构这一组织，以及其如何受结构连接组（SC）约束，仍知之甚少。在此，我们利用人类连接组计划的高分辨率fMRI数据，系统绘制了静息状态及涵盖工作记忆、赌博、运动、语言、社交、关系与情绪领域的七项任务中的全脑INT图谱。任务参与诱导了稳健且区域异质性的INT变化，同时在不同认知状态下大体保留了全脑时间层级。SC-INT耦合保持强健，但在任务期间持续减弱，表明解剖结构仍约束INT，尽管其影响在任务需求下被削弱。为机制性探究这些发现，我们采用了一个多尺度全脑神经元网络模型，该模型揭示INT增加并在广泛的临界类状态内达到峰值。经验观察到的强SC-INT耦合出现在亚临界状态，随网络兴奋性增加而逐渐减弱，并在超临界状态中逆转。这些结果表明，任务参与重构INT同时维持其层级组织，提示静息与任务状态均在共同的亚临界动力学状态内运作。

    bioRxiv / 2026-09-01 / Matsumura, K.

    背景：戒断后寻求可卡因的行为与腹侧苍白球（VP）活性增加相关。这种增加似乎涉及一种阿片肽，它抑制表达D2受体的中型多棘神经元（D2-MSNs）向VP释放GABA，但其身份尚不清楚。我们此前发现，可卡因戒断增加了D2-MSNs中脑啡肽mRNA的表达，且外源性脑啡肽抑制了这些神经元的GABA释放。因此，我们假设可卡因增强的D2-MSNs脑啡肽释放抑制了向VP的GABA释放，从而去抑制VP神经元并促进可卡因寻求。方法：为研究脑啡肽如何改变戒断后的纹状体回路可塑性和可卡因寻求，我们在选择性敲除D2-MSNs中脑啡肽的小鼠（D2-PenkKO）中进行了离体电生理记录和可卡因自我给药实验。记录主要针对D2-MSNs的靶标：VP神经元和表达D1受体的中型多棘神经元（D1-MSNs）。结果：可卡因戒断后，对照组中D2-MSNs向VP神经元的GABA释放减少，但D2-PenkKO中未观察到这一变化。相反，可卡因戒断未改变向D1-MSNs的GABA释放。光遗传学诱发的D2-MSNs GABA释放在盐水戒断对照组和D2-PenkKO中抑制了VP神经元放电，但在可卡因戒断对照组中未产生此效应。雌性（而非雄性）D2-PenkKO在早期获取阶段自我给药的可卡因量较少，且在戒断后线索诱导的可卡因寻求行为减弱。结论：可卡因自我给药后的戒断增加了D2-MSNs脑啡肽表达，导致对VP神经元GABA释放的自身抑制，但不影响D1-MSNs，从而选择性去抑制VP神经元活性。这些发现将脑啡肽确定为可卡因戒断诱导的纹状体-苍白球回路可塑性的关键介质，并提示这种可塑性有助于戒断后的可卡因寻求行为。

    背景：促炎饮食和高环境影响的饮食均威胁人群及地球健康，但这两项目标在不同国家间是协同还是冲突尚未明确。我们检验了基于供给的膳食炎症指数（sDII）是否与温室气体（GHG）、土地和淡水足迹相关联，以及营养可行的重新分配能否同时降低两者。方法：基于FAO食物平衡表，我们构建了sDII（12个炎症加权组分；结构效度r=0.9999）和五项人均足迹，使用三个独立生命周期清单覆盖182个国家食物供给序列。对每个国家，约束优化在等能量、保蛋白质和食物组约束下重新分配13个食物组供给，最小化sDII和GHG（帕累托前沿）。健康负担通过汇总相对风险荟萃分析和2023年世界银行人口数据估算。结果：2023年，sDII与GHG（Spearman rho=0.14）、土地（rho=0.13）和淡水（rho=0.28）仅弱相关。平衡帕累托重新分配在182/182个序列中同时降低了sDII和GHG（100%协同）：人口加权delta sDII=-0.235，GHG -37.5%，土地 -49.3%，水 -17.2%，即每年避免4.28 Gt CO2e。相关的代谢综合征负担减少方向一致但幅度温和（约占患病池的1.1%，约284万例）。结果对三个生命周期清单和三个可行性约束方案均稳健。结论：抗炎和低碳目标呈解耦而非冲突关系，等能量、保蛋白质的重新分配在每个国家均能调和两者。环境收益大且稳健；健康收益方向一致但温和——此为三角验证，而非因果推断。

    淋巴细胞清除可减轻儿童及年轻成人复发或难治性脑肿瘤患者中的抗CAR免疫反应：临床试验结果

    medRxiv / 2026-09-01 / Wang, L. D.

    高级别儿童脑肿瘤患者的预后仍然不佳，但人们对嵌合抗原受体（CAR）T细胞疗法改善预后抱有希望。我们报告了一项I期临床试验结果，该试验将IL13BBz-CAR T细胞每周经脑室内输注给复发或难治性脑肿瘤的儿童和年轻成人患者。试验达到了可行性、安全性和耐受性的主要目标，出现一例剂量限制性毒性。16名可评估疗效的患者中，8名出现影像学肿瘤缩小，与生物活性和抗肿瘤反应一致。两名患者符合方案规定的反应标准。接受淋巴细胞清除的患者中，中线胶质瘤患者自诊断起中位生存期为20.5个月，自治疗起为6.9个月；室管膜瘤患者自诊断起为187个月，自治疗起为7.5个月。重要的是，未接受淋巴细胞清除的患者在脑脊液和外周血中检测到抗CAR体液和细胞免疫反应，而接受淋巴细胞清除的患者在脑脊液中未显示抗CAR免疫证据。综合来看，这些发现证明了局部递送IL13BBz-CAR T细胞对中枢神经系统肿瘤儿童和年轻成人患者的安全性、耐受性和生物活性。此外，我们显示未接受淋巴细胞清除的患者出现抗CAR免疫反应，但接受全身性淋巴细胞清除的患者脑脊液中未出现。在这一患者群体中，进一步研究过继细胞疗法联合免疫抑制是必要的。ClinicalTrials.gov注册号：NCT04510051。

    RUBCN缺失导致伴有年龄依赖性神经退行性变的神经发育障碍中的自噬过度激活

    medRxiv / 2026-09-01 / Efthymiou, S.

    RUBCN基因的致病性变异，其编码Run结构域Beclin-1相互作用及富含半胱氨酸结构域蛋白（Rubicon），已被牵涉于常染色体隐性遗传脊髓小脑共济失调15型（SCAR15）。然而，疾病发病机制背后的分子机制仍知之甚少。在此，我们报告来自15个无亲缘关系家庭的18名个体，携带双等位RUBCN变异，表现为侵袭性神经发育障碍，其特征变异多样，包括癫痫、发育迟缓、智力障碍及运动异常，导致功能退化、进行性脑萎缩和神经退行性特征。通过功能表征，我们证明一组疾病相关的推定截短变异扰乱自噬调控。在秀丽隐杆线虫模型中，功能缺失型RUBCN变异导致自噬通量增加及神经元功能受损，重现人类关键特征。相应地，细胞实验揭示无义和移码RUBCN变异导致自噬抑制缺陷，强调RUBCN作为关键负性自噬调控因子的重要作用。分子动力学模拟按结构效应排序11个错义变异，其中p.Arg813Trp单独在局部和区域水平改变靶蛋白，并位于截短等位基因完全移除的RAB7A结合模块内。我们的发现确立并扩展了RUBCN相关疾病为临床和分子上独特的自噬相关疾病亚型。通过描绘Rubicon功能障碍的遗传景观和细胞后果，本研究增进了我们对自噬相关神经发育障碍的理解，并为未来治疗研究奠定基础。

    面向多部位骨密度测量的负担感知建模与解释的人工科学智能

    medRxiv / 2026-09-01 / Xiang, S.

    Agentic工作流能够协调建模，但在预测性能、测量负担和可重复性之间的平衡尚不明确。我们开发了DXA Agent，一种针对双能X射线吸收测定法（DXA）结果的agentic工作流，整合了规划、特征模型优化、工具、溯源和假设生成性解释。模型在UK Biobank（5,318名参与者）和美国国家健康与营养调查（NHANES；3,777名参与者）中独立开发和测试，采用了成本高效和无限制策略。在20个UK Biobank和3个NHANES骨密度部位中，成本高效模型相比最佳常规对照模型实现了更低的RMSE和更高的R2，中位相对RMSE降低分别为10.9%和9.9%。分类结果依赖于任务：UK Biobank骨质疏松症平均AUROC为0.839，PR-AUC为0.182，而NHANES的表现与常规模型相当。更高负担的特征并未持续改善预测。这些回顾性、队列内部的研究结果将DXA Agent定位为一种可检查、注重测量负担的研究工作流，需进行独立的前瞻性验证。

    东南亚性工作者获得社会保护和HIV预防服务的结构性障碍：2018-2025年固定效应面板数据分析

    medRxiv / 2026-09-01 / Hung, J.

    引言。关于国家结构性政策的存在与低收入和中等收入环境中关键HIV服务提供之间关系的实证证据仍然稀缺。本研究通过量化六个国家结构性政策指标与针对性工作者的HIV预防服务组成部分存在性之间的国内关联，填补了这一研究空白。方法。我们根据联合国艾滋病规划署全球艾滋病监测框架，构建了一个覆盖2018年至2025年八个东南亚国家的平衡面板数据。对于每个国家和年份，面板记录了政府在六个政策指标上的报告状态，即（1）针对性工作者的任何HIV预防服务组成部分，（2）HIV感染者和关键人群在获取社会保护方面的障碍，（3）社会保护与国家艾滋病规划之间的协调，（4）针对性工作者HIV预防计划的国家实施指南，（5）解决无酬照护工作的社会保护政策，以及（6）承认少女和年轻女性为关键受益人的社会保护政策。我们使用了固定效应和随机效应模型，其中固定效应模型被选为统计上更合适的估计方法，并采用一期滞后的解释变量。结果。固定效应模型的主要发现表明，法律或行政障碍的存在与针对性工作者HIV预防服务的存在之间存在统计上显著的正向同期关联（β = 0.8531；p < 0.001）。然而，稳健性检验显示，使用滞后障碍变量时，存在统计上显著的负向关联（β = -0.3540；p = 0.011）。在固定效应模型中，其他指标的系数均无统计显著性。结论。这些障碍随时间持续存在与次年HIV预防服务提供的缺失相关。国家HIV规划必须紧急优先消除关键人群面临的结构性障碍。

    英格兰内镜与影像检查等待时间的近期趋势及地区差异：月度诊断数据分析

    medRxiv / 2026-09-01 / White, B.

    背景 及时诊断性检测对于快速诊断潜在危及生命的疾病至关重要，但英格兰目前缺乏对诊断延迟当前趋势和地理差异的正式评估。方法 我们利用2019年至2026年103个次级综合护理委员会辖区的公共数据，评估了英格兰四种影像学检查和四种内镜检查的近期趋势。我们使用混合效应二项逻辑回归，比较了2026年6月与2025年6月等待超过6周的患者比例。通过随机效应方差量化了超出偶然预期的地理变异变化，并使用条件估计检查了局部趋势。结果 先前延迟的减少在过去一年中停滞，胃肠道内镜和MRI的延迟甚至有所增加。从2025年6月至2026年6月，胃镜检查（24%至29%）、结肠镜检查（26%至31%）、可弯曲乙状结肠镜检查（28%至32%）和MRI（15%至23%）的延迟均有所上升。显著的地理差异持续存在，中间50%的局部地区差异达三至五倍。MRI的局部变异显著增加。局部趋势明显分化，部分区域延迟下降超过50%，而其他区域则翻倍。结论 政策制定者应优先解决胃肠道内镜和MRI等待时间恶化的问题，并识别延迟的局部驱动因素。
