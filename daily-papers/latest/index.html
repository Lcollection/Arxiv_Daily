    FPTR：面向截止时间约束的联合波束与资源分配的可行性保持事务性精化

    arXiv / 2026-11-04 / Minghao Kong

    短间隔无线调度器必须在每次执行截止时间之前返回完整、可行的波束与资源分配方案，迟交或无效的输出在当前控制周期内不产生任何效用。搜索时间更长可能增加传输流量，但也可能错过截止时间，或只留下一个不可行的中间解。我们提出可行性保持的事务式精化方法（Feasibility-Preserving Transactional Refinement，FPTR），它始终保留一个经过验证的可行分配方案，即现任解。每个精化阶段构建一个独立的候选解，并保持现任解不变。候选解只有在完整、在其阶段截止时间之前通过可行性验证器、并且严格改善目标函数时，才会替换现任解；否则被丢弃。四个精化阶段采用该规则：缓冲区感知的资源选择、兼容组（compatibility-group，CG）用户共享、基于剩余需求的波束掩码重建，以及两个资源的联合重新分配。在150个固定合成实例上，完整流水线（Full）相比轻量级波束优先参考方案平均提升流量3.83%，相比其Base构造器提升1.79%。在具有匹配输入的独立测试集中，Full相比六个独立搜索基线（ALNS、禁忌搜索、GA、模拟退火、迭代局部搜索和GRASP）高出6.68–8.35%，其中晚于100 ms的输出获得零效用。内部测试集中全部750次Full运行均返回可行分配，且均未超过100 ms。将强制输出构造与可选精化解耦，使空闲计算时间能够改善分配而不危及现任解。开源实现支持独立复现。

    风险敏感的非参数与核bandits

    arXiv / 2026-11-04 / Devdan Dey

    我们研究非参数 bandit 问题，其中臂的评估采用累积前景理论（Cumulative Prospect Theory, CPT）而非期望奖励。我们考虑具有臂相关噪声的连续动作空间，并提出非参数 CPT Bandit（$\mathtt{NPCB}$），一种将均值估计与基于 CPT 的决策解耦的乐观算法。我们证明 CPT 遗憾界为 $\widetilde{\mathcal O}\bigl(\sqrt{T\,\dim_E(\mathcal F,T^{-2})\,\log N(\mathcal F,T^{-2},\|\cdot\|_\infty)}\bigr)$，其中 $\dim_E$ 是函数类 $\mathcal F$ 的 Eluder 维数，$T$ 是时间跨度，$N$ 是其在 sup 范数下的覆盖数。该结果与经典非参数 bandit 的阶数级遗憾相匹配，表明 CPT 风险敏感性不会带来额外的阶数级遗憾代价。我们将 $\mathtt{NPCB}$ 扩展到未知噪声 CDF 的情形，保留已知 CDF 的均值学习项，并加入由分布 Eluder 维数控制的 CDF 学习代价。我们还研究 Kernel-CPT bandit，并针对一大类核获得基于信息增益的遗憾界，在至多对数因子的意义下与相应的风险中性核速率相匹配。

    模型合并不需要统一的LoRA秩

    arXiv / 2026-11-04 / Zirong Xie

    模型合并将分别微调的专家整合为单一模型而无需重新训练。标准做法是以相同的LoRA秩训练每个专家，这即使每个领域各有其最佳秩，也将秩的选择跨专家耦合在一起。我们表明这种耦合是合并方法的属性，而非合并本身的属性。我们在三个领域（数学、指令遵循、多语言）以四个秩和三种模型规模训练了36个专家，然后以统一秩和每个领域各自的最佳秩用六种方法进行合并。给专家不同的秩对平均法和基于效用的选择法毫无损失，并使其多领域准确率提升最多1.8个百分点，而冲突解决方法则表现不一致，可能损失最多4个百分点。这种分化有一个简单的原因。合并只保留池化谱成分的固定份额，而按大小选择这些成分的方法会丢弃许多本可降低损失的成分。它们还倾向于丢弃同一个专家：指令适配器具有最小的奇异值，因此几乎被完全丢弃，IFEval下降16至25个百分点。相反，按成分对损失的影响来选择成分会保留所有三个专家，并使准确率在8倍秩范围内几乎持平（0.7个百分点，而TIES在4B规模下为6.7个百分点）。因此，只要合并算子不按幅度进行选择，秩就可以按专家分别选择。

    小数据天文图像分类器的对象无关评估：架构、表示与采集捷径

    arXiv / 2026-11-04 / Eraldo Pereira Marinho

    在小天文图像数据集上报告的的性能可能反映对象复用、视场差异、采集设置和目录衍生属性，以及天文形态。我们设计了\dataset{}来测量这些效应，任务为四分类，包括星系、球状星团、星云和疏散星团。该数据集包含370个目录支持的物理对象，每个对象由三个数字化巡天FITS波段表示，并采用组约束划分：222个训练对象、75个验证对象和73个测试对象。我们在自适应全视场表示、共同角视场和两个中心区域掩蔽对照下，使用三个固定种子，将从零开始训练的自定义CNN--Transformer与ImageNet预训练的ResNet-50和ViT-B/16进行比较。在单次对象独立测试中，自适应视图上的平均平衡准确率对于自定义模型、ResNet-50和ViT-B/16分别为$0.773\pm0.014$、$0.874\pm0.054$和$0.866\pm0.023$。经Holm校正后，没有主要架构对比拒绝其原假设；ResNet-50和ViT-B/16相差0.007个平衡准确率点（95\%聚类自助区间$[-0.048,0.062]$）。基于采集和目录元数据的对照达到0.721--0.735，中心区域掩蔽的自适应视图达到0.731--0.800。这些结果证明了对未见物理对象的泛化能力，但也表明图像上下文、采集设置和目录衍生的对象属性携带了大量类别信息。在这种情况下，高准确率不能解释为分类器学习了目标形态的证据，且该比较未将架构与预训练隔离开来。

    多轮强化学习在LLM智能体中究竟真正改进了什么？

    arXiv / 2026-11-04 / Kejian Zhu

    多轮智能体强化学习（RL）在长时程任务上表现优异，但其性能增益对交互约束高度敏感。我们通过 Pass@(K,T) 在采样广度 K 和交互深度 T 上进行评估，结果表明轨迹级 RL 优势依赖于充足的轮次预算，当预算收紧时显著衰减。此外，智能体 RL 并非一致地提升单步决策质量，其优势集中于错误恢复与长时程韧性。为缓解这种预算依赖性带来的部署风险，我们对过程监督信号的收益与局限进行了初步讨论，并引入 BudgetMix RL 作为替代方案，在训练过程中变化交互预算。实验表明，BudgetMix RL 在多样化的执行设置下均能取得稳健性能。项目页面：https://rethinking-agentic-rl.github.io/

    ArcRAG：知识图谱上的智能体组合检索

    arXiv / 2026-11-04 / Jyotin Goel

    基于图的检索增强生成（GraphRAG）通过在一个由语料库构建的知识图谱上进行检索来回答问题。然而，检索策略是围绕其自身构建流程所产生的结构来设计的，而这些策略能否在构建方式改变后依然有效，却鲜有测试。我们研究这种跨构建的可移植性：即一种检索流程，在不依赖特定构建模式的模式、关系名称或重新调参的情况下，当图以不同方式构建时，是否仍能保持有效。我们提出 ArcRAG，它在推理时归纳出一个查询局部的图接口（即从问题所提及实体可达的节点标签、关系描述符和属性键），针对该接口规划多跳遍历，并以 Cypher 形式执行和修复这些遍历。我们将 MuSiQue、HotpotQA 和 TriviaQA 各语料库分别构建为模式引导图（带类型节点、封闭关系集、来源溯源）和开放信息抽取图（无类型节点、自由文本关系），且检索器的配置在两者之间保持固定。我们与一个构建无关的 Direct-Cypher 智能体进行比较，在两种图族上分别针对重试和通过预算对每个阶段进行消融，并与先前 GraphRAG 系统所报告的结果进行比较，这些系统大多将检索与自身的图构建一同设计。在两种构建方式下，我们发现检索无需与图协同设计：查询时接口归纳使得构建无关的检索器在构建方式改变时仍保持有效，尽管构建方式仍然影响绝对准确率。

    arXiv / 2026-11-04 / Ye Yuan

    背景。这是一项实证性刻画研究；我们不提出新方法，也不与替代目标进行对比。我们在结构化财务申报任务上，使用稀疏 LoRA 和长度归一化 DPO 加 SFT 保持项（即 RPO 目标）微调 Qwen3.5-4B，并随着隐式奖励间隔增长至约 7 个 β 缩放单位（nf4 训练；在未量化基座的 fp16 测量下约为 3）跟踪下游能力。问题。间隔增长是均匀地降低各任务能力，还是选择性地降低？发现。在一项预注册研究（8 个种子，冻结时 6 个未见）中，采用工件感知评分和 TOST 等价性检验，对齐税是分级的且具有任务选择性：抽取能力得以保持（Δ= -0.55 分，在 ±5 分处等价），json 损失较小（Δ= -3.52 分，在聚类项目级区间上等价性不成立），router 严重退化（Δ= -30 分）。router 的损失集中在包含瞬态格式中断尖峰的间隔 1-3 损害窗口内。该间隔几乎完全（≥ 96%）由对被拒绝补全的抑制所解释，被选中奖励大致持平，这与保持项对其锚定一致；我们不将行为损害归因于任何单一梯度通道。Gold-logp 通缩具有任务选择性（在 fp16 下，抽取 -0.15、json -1.04、router -1.47 nats/token），并且在抽取任务上，gold 相对于错误对照被选择性保护（8/8 种子）。QLoRA 奖励间隔在 nf4 训练与未量化 fp16 测量之间相差最多 3.4 倍，且存在轴依赖的差距。范围。带 SFT 保持的长度归一化奖励、8/32 层上的稀疏 LoRA、一个 4B 模型、易于分离的合成偏好、三个结构化任务。无保持对照和已测量的格式对齐指标留待未来工作。

    一个统一CT解读与分割的三维基础模型

    arXiv / 2026-11-04 / Yulu Xie

    放射科医生解读计算机断层扫描（CT）时，需要同时判断某个征象代表什么以及它位于三维（3D）解剖结构中的何处。然而，CT模型一直将CT解读与3D分割视为彼此独立的任务，导致文本征象在空间上无法验证，也忽视了临床理解与空间感知之间潜在的协同作用。在此，我们提出HoloCT，这是一个通用的3D基础模型，通过联合建模全容积上下文和细粒度解剖细节，将CT解读与体素级分割统一起来，并提供3D掩码作为证据。我们构建了HoloDATA，包含来自73个公开数据集和六个临床队列的195，921例CT扫描，以及620万条指令对话和280万对CT-掩码配对。在涵盖分割、病灶筛查、视觉问答和报告生成等346项任务（涉及61个内部数据集和12个外部数据集）上，HoloCT优于专科模型和基础模型。在来自五家医院的11，455例临床CT扫描的多中心验证中，HoloCT在病灶分割和报告生成方面分别以18.2分和15.3分优于竞争模型。在筛查甲状腺肿瘤和结肠病灶方面，其平均准确率达到85.1%，在一项回顾性阅片者研究中超过了全部四位参与的放射科医生。进一步分析揭示了双向的语义-空间协同：语言引导的分割能够描绘未见过的解剖结构和病灶以及弥漫性自由文本征象，以22.1分优于领先方法；而提示模型在输出文本的同时生成相应的3D掩码，则显著提升了判读性能。HoloCT表明，临床理解与空间感知可以在单一基础模型内共同学习，并为更准确、更可靠的CT分析提供了一条路径。

    在k维空间中，有多少个排序投影能确定n个点？

    arXiv / 2026-11-04 / Christopher Gorham Lester

    设 $d_1,\dots,d_m$ 为 $\mathbb{R}^k$ 中的方向，其中 $k\ge 2$。一个由 $\mathbb{R}^k$ 中 $n$ 个点构成的多重集 $X$ 投影为 $m$ 个数值多重集 $\{\{x\cdot d_j : x\in X\}\}$，或等价地投影为这些数的 $m$ 个排序列表。要使这些投影确定每一个 $n$ 点的多重集，需要多少个方向？在每个维度上已知两个简单的界：总是需要多于 $(k-1)\log_2 n$ 个方向，而处于一般位置的 $(k-1)n+1$ 个方向总是足够的。在平面中已知的结果要多得多：Matousek、Privetivy 和 Skovron 证明了几乎每一组 $O(\log n \log\log n)$ 个方向的选择都足够。更高维中是否有类似的结果，被 Dym、Wellershoff、Tsoukanis、Levy 和 Balan 留作未解决的问题。我们注意到，Hair 和 Sahai 为随机线性码的列表恢复所证明的两个引理回答了这个问题，并且通过收紧他们的论证，我们证明在每个维度上，几乎每一组 $(4k-2)\ln(2n)\ln(k\log_2 2n)+k+1$ 个方向的选择都足够。对于 $k\le 10$，一旦 $n$ 大于约 100，这就胜过了线性界：例如，对于平面中 1000 个点的多重集，144 个方向就足够，而精确计算将此降低到 133。让他们论证中的一些随机块失败，可以去掉一个因子 $\log k$：几乎每一组 $O(k\log n\log\log n)$ 个方向的选择都足够，且关于 $k$ 和 $n$ 一致。我们还证明 $2k-1$ 个方向永远不能确定三个点，因此对数下界并不紧；平面中每 $m$ 个方向都会在某对大小为 $O(1.78^m)$ 的多重集上失败，改进了 Matousek、Privetivy 和 Skovron 的界 $O(1.80^m)$；并且对于每个 $k$、$m$ 和 $n$，要么几乎每一组 $m$ 个方向的选择都有效，要么几乎没有一个有效。

    以盲法人工智能同行评审审计生物医学文献：同行评审在何处有效、在何处失效，以及如何加强它

    bioRxiv / 2026-11-04 / Kosakovsky Pond, S. L.

    自1991年以来，生物医学出版量增长了十一倍以上，已超出人类同行评审的承载能力。非盲语言模型无法客观审查这些文献，因为它们能从训练记忆中识别出著名作者和期刊。我们构建了BARS（盲审人工智能评审系统），这是一个自动化审稿工具，在按10分制对全文稿件进行评分之前，会剥离标题、作者姓名、机构、期刊页眉和日期，评分涵盖方法、证据、生物学和可重复性。我们使用BARS对1,714篇独特论文生成了1,874份盲审意见。BARS通过了100%的经验证可靠对照，捕获了77%至91%的存在内部缺陷的论文，消除了+0.35分的声望加成，并使人类审稿人的一致性提高了一倍以上。在来自八个领域的320篇近期开放获取文章（2020-2025年）中，54%在核心科学严谨性上不合格（<5.0/10；排除巨型期刊后为41%）。选择性期刊的修订对预印本的改善程度是商业巨型期刊修订的两倍以上（+0.62对+0.30分；基线调整后p = 0.033），并且BARS在100篇开放评审论文中召回了98%的未解决人类审稿人批评意见。在1991年至2025年的915篇日期盲审论文中，随着巨型期刊和模板数据库研究的扩张，平均得分从7.6/10降至5.8/10。两位资深作者对238篇论文进行的盲审自审——以及对本稿件本身的自审——在我们自己的工作中发现了真实的统计、对照和表格错误。每篇论文四美分的成本下，BARS为作者、期刊和读者提供了一种实用的质量检查工具（https://veg.github.io/BARS/）。

    背景慢性肾脏病（CKD）造成持续代谢应激，但在持续肾脏应激下代谢组织能否得以保留仍不清楚。必需微量元素支持氧化还原防御、线粒体功能和中间代谢，其在CKD中稳态受到扰乱；然而，单一元素补充所得结果不一致。我们考察了一种明确配方的多元素制剂能否在CKD中保留代谢韧性。方法在一项随机、双盲、安慰剂对照试验中，80例维持性透析患者仅接受标准治疗（n = 40）或加用微量元素复合制剂（TEX，20 mL/天；n = 40）。采用线性混合效应模型分析纵向轨迹；在部分受试者中分析终点血浆代谢组学和粪便宏基因组学。采用5/6肾切除小鼠模型，通过MALDI成像质谱定量血浆色氨酸通路分支和肾脏空间代谢。结果TEX耐受良好，无治疗相关安全性信号，并与肌酐和eGFR轨迹略为有利相关。补充剂限制而非消除CKD相关代谢位移（中位|Cohens d|，0.25，而疾病效应为2.09），选择性使循环代谢向健康状态重新对齐。宿主犬尿氨酸分支反应最强，而微生物吲哚代谢和肠道群落结构变化很小。肾脏代谢重塑具有区域特异性，保留了部分肾小管和抗氧化特征。结论微量元素补充在CKD中保留了代谢韧性，限制了代谢位移但未完全恢复。代谢组织的保留可能代表CKD治疗反应的一个互补维度。试验注册国际传统医学临床试验注册平台，ITMCTR2026000263（2026年2月3日注册）。

    有限标签下皮肤镜病变分割的自监督预训练：初始化策略的对照比较

    medRxiv / 2026-11-04 / Hamda, H. K. H.

    背景自监督学习在标注数据有限时可能改善分割效果，但其收益可能取决于模型和初始化策略。本研究在有限标注预算下评估了域内掩码重建预训练的效果。方法将国际皮肤成像协作组织（ISIC）2016开发集划分为765张图像用于自监督预训练、94张用于微调、41张用于验证。在379张图像的测试集上评估了五个嵌套标注预算（12-94张图像）和五个随机种子。自定义U-Net比较了随机初始化和域内自监督初始化；ResNet-34 U-Net比较了随机、ImageNet、域内自监督以及ImageNet到自监督的序贯初始化。使用94张标注图像训练的模型在无适配情况下于ISIC 2017上评估。另一项独立实验考察了基于复原的预训练。结果在自定义U-Net中，自监督预训练在所有五个预算下均获得高于随机初始化的平均Dice，包括12个标签时的0.664对0.615，以及94个标签时的0.811对0.768。配对差异的种子级95%置信区间在47和94个标签时排除零，但在其他预算下未排除。在47个标签时，自监督模型的平均Dice为0.789，而随机初始化在94个标签时为0.768。在ResNet-34中，ImageNet初始化在所有五个预算下均获得高于域内自监督预训练的平均Dice，且在ImageNet之后添加自监督预训练在五个预算中的四个降低了平均Dice。所有六种94标签配置在ISIC 2017上的平均Dice均低于ISIC 2016。在复原实验中，随机初始化的平均Dice为0.686，预训练后为0.638-0.642。结论在自定义U-Net中，域内掩码重建预训练相对于随机初始化改善了平均Dice，但在ResNet-34 U-Net中并不一致，其中ImageNet初始化在每个预算下表现更好。在ImageNet之后添加自监督预训练未提供一致的增益。这些发现特定于皮肤镜病变分割实验，并不确立黑色素瘤特异性的诊断或临床性能。

    利用人工智能实现癌症诊断的跨越式发展：对中低收入国家实施决定因素的混合方法评估

    medRxiv / 2026-11-04 / Schoenpflug, L. A.

    引言 低收入和中等收入国家（LMICs）的癌症发病率正在迅速上升，而这些国家的诊断病理能力受到限制。将人工智能应用于常规组织病理学可以增强诊断能力，并在诊断系统建设过程中嵌入人工智能，从而提供跨越式发展的潜力。然而，如果不以实证方式识别LMIC癌症诊断环境中的实施决定因素，人工智能解决方案就可能与当地限制条件匹配不佳，从而限制其影响或加剧现有差距。方法 我们开展了一项探索性混合方法试点研究，分为三个阶段：1）一项结构化调查，描述诊断和技术环境及人工智能优先事项；2）焦点小组讨论（FGDs），以识别实施决定因素；3）第二项调查，对FGD得出的主题进行量化。我们目的性招募了12名医生（9名病理学家、3名妇科医生）（10名来自LMIC，2名来自高收入国家作为参照），并通过叙事三角互证整合研究结果。结果 诊断和人工智能基础设施差异很大，且与国家收入分类并不一致对应。H&E染色在所有机构均可获得，10个机构中有7个的免疫组织化学能力低于WHO推荐的癌症诊断能力，10个机构中有6个的分子检测缺失或极少。全切片成像扫描仪在10个机构中有8个可用，而高效人工智能推理所需的图形处理器仅在10个机构中的4个可用。参与者优先考虑将人工智能用于癌症筛查、诊断以及基于H&E切片的生物标志物预测。识别出六个实施决定因素：人工智能素养、治理框架、资金、证据生成、临床部署和合作。财务限制成为所有决定因素中的主要障碍，而合作则是关键促进因素。结论 人工智能实施准备度在收入组内部差异很大，表明国家收入分类不足以作为机构准备度的替代指标，凸显了进行机构层面评估的必要性。在此背景下实现人工智能的跨越式发展潜力，需要在所有决定因素上协调推进，并以可持续融资和合作作为其他决定因素的促进因素。

    在老年人中平衡镇痛效果与滥用倾向：口服和雾化Δ9-四氢大麻酚的随机安慰剂对照试验

    medRxiv / 2026-11-04 / Costa, G. P. A.

    在美国，大麻使用在老年人中增长最快，而疼痛是他们使用大麻最常见的原因之一。然而，尚无试验在该人群中衡量Δ9-四氢大麻酚（Δ9-THC）的镇痛效应与滥用相关效应之间的权衡。在一项随机、双盲、安慰剂对照试验中，20名65岁及以上成年人按平衡顺序在三次八小时会话中接受口服Δ9-THC（安慰剂、5、10 mg）或吸入Δ9-THC（安慰剂、2、4 mg）。我们使用定量感觉测试评估实验室诱发的疼痛敏感性，使用主观药物效应和强化价值评估滥用倾向，并采样血浆Δ9-THC和11-OH-THC。镇痛和滥用倾向结局在每个会话内重复测量。在疼痛敏感性指数上，口服5 mg相对于安慰剂减轻了疼痛（p=.040），尽管口服组的总体剂量效应不显著（p=.108）；口服10 mg和两种吸入剂量均与安慰剂无差异。主观效应随剂量增加而增强，并在吸入后最强，而强化价值仅在吸入4 mg后增加。口服5 mg后，镇痛在每个评估时间点（60-360分钟）均超过安慰剂，而其愉悦效应在150分钟时达到峰值。吸入Δ9-THC在30分钟内产生愉悦效应，但未显著改变热痛敏感性。滥用倾向与Δ9-THC暴露相关，而镇痛未显示显著关联，所有不良事件均发生在吸入4 mg时。这些发现表明，剂量和给药途径的选择可能有助于最大化Δ9-THC的镇痛效应，同时最小化滥用倾向，这一策略值得在临床人群中评估。

    尼古丁与大麻共同使用与早期精神病中比单独使用任一药物更高的症状负担相关：一项多中心研究的结果

    medRxiv / 2026-11-04 / Smucny, J.

    背景：尽管尼古丁和大麻的使用率较高，且与精神病风险及更早的症状发作年龄相关，但很少有研究考察尼古丁与大麻共同使用与症状之间的关系。本研究考察了早期精神病（EP）个体中症状负担与大麻/尼古丁使用/共同使用之间的关联。方法：这项横断面、多中心队列研究使用了来自早期精神病干预网络（EPI-NET）的738名个体（平均年龄22岁，62%为男性）的数据。采用混合效应模型考察大麻和/或尼古丁使用与使用频率（过去30天期间）及改良科罗拉多症状指数（MCSI）评分之间的关系，以研究站点为随机因素，以年龄、性别和大麻/尼古丁使用情况（均不使用、仅使用尼古丁、仅使用大麻或两者均使用）为固定因素。探索性分析还考察了使用频率（每日使用与非每日使用）的影响。结果：59%的样本既不使用尼古丁也不使用大麻，17%仅使用尼古丁，9%仅使用大麻，16%两者均使用。观察到使用情况对MCSI总分有显著影响（F = 6.69，p < .001），这是由同时使用大麻和尼古丁的个体相对于均不使用、仅使用尼古丁或仅使用大麻的个体症状更严重所驱动的。此外，更频繁的使用与更高的总分相关。结论：这些结果表明，大麻和尼古丁的共同使用与EP中更大的症状负担相关，这可能对治疗策略具有启示意义。本文讨论了可能构成这一关联基础的神经药理学机制。
