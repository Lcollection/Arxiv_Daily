    神经元FICD通过调节多巴胺受体动力学塑造动机行为

    bioRxiv / 2026-10-13 / Weaver, K. J.

    动机行为依赖于多巴胺能信号传导，而后者又取决于受体在内质网中的正确折叠和运输。在内质网中，AMPylase酶FICD通过修饰分子伴侣BiP充当分子变阻器，动态调节该细胞器对折叠扰动和细胞应激的响应能力。虽然FICD的生物化学特性已被充分确立，但其在复杂动物行为中的作用仍知之甚少。在此，我们确定FICD是动机行为产生的一个保守贡献者。在果蝇中，泛神经元敲低dFic显著减少了摄食、自发运动和奖赏寻求行为。这些改变的发生并未破坏昼夜节律结构、运动能力或稳态饥饿，表明动机驱力的特异性丧失。在多巴胺受体表达（Dop1R1）神经元亚群中耗竭dFic可重现这些行为改变。转录组分析显示，dFic耗竭并不诱导经典未折叠蛋白反应，指向特定的转录后改变而非全局性内质网应激。在分子水平上，dFic失调改变了Dop1R1的定位和丰度。最后，我们证明这一调控轴在进化上是保守的，因为FICD的缺失同样减弱了线虫和小鼠的动机行为。总之，这些发现将FICD与动机行为的产生联系起来，并将内质网蛋白质稳态的动态控制与多巴胺受体成熟相关联。

    病毒扩散驱动种群组成变化

    bioRxiv / 2026-10-13 / Holmes, K. E.

    在急性病毒感染中，一个小的种子种群会在几个数量级上迅速扩增，然后下降。这种庞大的种群增长伴随着空间扩张，因为感染会扩散到宿主体内新的解剖部位。进化理论预测，空间扩张的种群比空间上无结构的种群经历更极端的遗传多样性随机丧失。为了在病毒动力学背景下检验这一预测，我们评估了空间扩张对病毒种群遗传结构的影响，并评估了病毒扩散调节因子如何影响这种结构。为此，我们开发了一种在细胞培养中实现甲型流感病毒空间扩张的方法，并将其应用于携带多样化遗传条形码的病毒种群。在这个简化的细胞景观中，我们发现空间扩张产生了由不同病毒亚群组成的拼凑格局。然后，我们评估了两种病毒扩散调节因子对种群结构的后果：细胞外黏度和病毒附着蛋白中的一种常见多态性。物理限制和病毒表型都改变了扩张过程中形成的遗传瓶颈程度和空间异质性，这表明调节扩散的环境特征和病毒性状也会调节病毒种群组成、多样性和进化。

    微生物细胞的可逆固定用于靶向基因组学

    bioRxiv / 2026-10-13 / Engelberts, J. P.

    基于系统发育或活性的微生物荧光标记结合荧光激活细胞分选（FACS）是一种从复杂群落中快速分离目标细胞进行靶向基因组学的强大方法。然而，由于标准的多聚甲醛或乙醇固定程序妨碍了核酸回收和/或长期样品保存，该方法尚未被广泛采用。在此，我们提出二硫代双（琥珀酰亚胺基丙酸酯）（DSP）作为一种可逆的微生物细胞固定剂，能够实现荧光成像以及用于测序的DNA提取和扩增。DSP固定与广泛使用的荧光原位杂交（FISH）方法及生物正交非经典氨基酸标记兼容，并可应用于多种样品类型，其表现始终与多聚甲醛相当。此外，利用FISH-FACS从复杂样品中选择性提取的单个和多个细菌细胞中获得了高质量基因组。因此，DSP是一种用于微生物组成像和测序的双用途固定剂，改进了靶向微生物基因组学。

    出生同步增加了自由放养犬类的异亲哺乳机会

    bioRxiv / 2026-10-13 / Vanderheyden, M.

    50多年前，有人提出假说，认为共同居住的女性通过信息素线索实现月经同步。这一观点作为一种广泛流传的叙事延续至今，并随后被外推到其他动物。确实，繁殖同步有许多潜在益处，包括创造异亲哺乳机会和促进雌性择偶。然而，除了季节性影响之外，几乎没有证据表明雌性脊椎动物会通过社会介导的线索同步其发情。我们分析了自由放养犬的繁殖同步，它们兼具弱的、依赖种群的繁殖季节性和兼性合作繁殖。在控制季节性后，我们发现，在共同居住、母系相关的雌性中，出生同步更高，这表明可能合作的个体之间存在同步。我们的发现支持了这一点：出生同步和母系亲缘关系独立地提高了异亲哺乳的概率和频率。最后，初步证据表明，发情同步降低了雄性垄断。这些发现为关于社会介导繁殖同步的争论作出了贡献，表明它可能主要是因为它促进合作繁殖而进化出来的。

    LLM提议者是否改善了可电离脂质的预算搜索？

    bioRxiv / 2026-10-13 / Singh, H.

    在有限实验预算下进行高效脂质设计是计算化学和药物发现中的核心挑战。我们提出LEAF（脂质进化自适应框架），一种匹配预算协议，用于检验语言模型提议器相对于经典基线是否改善组合分子搜索。该研究使用一个包含30,044个候选物的可电离脂质空间、一个拟合实验效力标签的冻结高斯过程预言机，以及一个独立的主动学习代理模型。四个语言模型在八个随机种子和三种数据划分上评估，相对于遗传算法或随机搜索基线未显示出显著改善。对于Llama 8B，79.1%的采集选择查询重复了先前已评估的档案成员。去除重复可缩小某些划分上的性能差距，但增加提议成本，并可能阻止预算耗尽。更大的模型减少了重复，但未能确立优越性或等价性。探索性评分提示和更严格的新颖性控制相对于遗传算法产生了正的中位数差异，但宽区间和共享种子依赖性阻碍了更强的结论。一项经过验证的单测定再分析在较小的数值尺度上保留了化学型冷启动缺陷，而探索性期望超体积改进并未逆转该结果。后续检查探讨提议器是否真正使用了注入的证据。这些检查包括零样本泄漏探测、仅排名和思维链理由提示、分数打乱扰动、证据冲突探测，以及一个真正的推理模式提议器。它们显示出对提供信息的可测量参与，但没有相应的性能增益。LEAF将提议质量作为实验变量隔离出来，并记录了零样本LLM提议器在受控预算下的一个具体失败模式。

    BioMod：用于单细胞基础建模的生物学模块标记化

    bioRxiv / 2026-10-13 / Meng, L.

    单细胞基础模型通常将细胞表示为单个基因的扁平序列，需要从稀疏表达谱中隐式推断更高阶的生物组织。类似于自然语言处理中从字符级到语义标记化的演变，我们假设细胞状态可以用具有生物学意义的中间单元更高效地表示。在此，我们提出BioMod，一个拥有5000万参数的单细胞基础模型，引入生物模块作为基因与细胞之间的表示单元。BioMod构建了一个包含660个生物模块的重叠词汇表，这些模块来源于精选通路和数据驱动的基因程序，用紧凑的模块表示替代了数千个基因级输入。BioMod在约7300万个人类细胞上预训练，采用高比例模块掩码和非对称解码器，在细胞类型注释、零样本批次整合、扰动响应预测和药物响应预测方面达到了最先进的性能，同时保持紧凑的架构，可在单块GPU上高效推理。模块级分析进一步表明，BioMod能够捕获具有生物学意义的细胞程序并保留通路级组织。

    HERO：一种用于减少和精炼全脑图谱映射细胞数据集的层级感知分析流程

    bioRxiv / 2026-10-13 / Shipman, A. L.

    高通量介观显微成像和基于机器学习的图像分析流程的进展，使无偏全脑成像得以广泛普及。然而，由于数据规模庞大且具有复杂的层级组织，将由此获得并映射到脑图谱的数据集转化为具有生物学意义的结果仍然存在重大障碍。因此，不同研究报告的结构和分析方法差异很大，削弱了严谨性和可重复性。为解决这一问题，我们开发了一种用户友好的数据降维工作流程HERO（层级感知表达区域组织），旨在对全脑细胞检测数据集进行层级感知的选择、精炼、排序和可视化。该工作流程可根据具体需求进行定制，所需编程经验极少，并能输出透明、经过整理的结果。HERO可作为更大规模全脑细胞检测分析流程中的无缝插件，提供高效、无偏的区域选择，以简化后续统计分析和比较评估。尽管HERO是针对小鼠细胞检测数据集开发的，但它可应用于任何包含层级信息的脑图谱映射数据集。在此，我们将HERO流程应用于示例细胞检测数据集，这些数据集包含来自终纹床核（BST）和岛叶皮层（insula）的传入细胞。HERO提供的顶级投射区域与BST（如杏仁核和下丘脑区域）和insula（如躯体感觉、自主和内感受区域）的历史示踪研究一致。此外，HERO的精炼步骤还提供了最初在主要排序输出中被掩盖的额外富集区域，例如与记忆和情绪相关的结构。通过HERO的动态处理，我们能够识别与文献一致的顶级投射区域，并额外发现这些大型数据集中常被掩盖的区域。总之，HERO提供了一种标准化分析流程，用于对全脑细胞检测数据集进行降维，将原始区域细胞计数转化为经过整理的结果，并提升神经科学中全脑成像的有效性、可解释性和可及性。

    关键性相关动力学伴随原代皮层MEA培养物的长期功能衰退

    bioRxiv / 2026-10-13 / Escobar, A.

    原代皮层神经元培养被广泛用于研究网络发育与衰退，但其长期电生理轨迹仍缺乏充分表征。我们使用多电极阵列对Wistar大鼠皮层培养物进行纵向监测，时间长达体外约730天（DIV），并将活动指标与生存分析和临界性指标相结合。各孔共享一个早期发育阶段，平均放电率在DIV 100–150左右达到峰值12–14 Hz，随后分化为两种表型：早期死亡孔，表现为爆发组织进行性丧失、爆发间期延长、爆发持续时间缩短以及活跃电极募集急剧下降；长期存活孔，则维持有组织的爆发和可测量活动远超DIV 400，部分甚至超过DIV 700。采用Cox比例风险模型并对十三项候选特征进行FDR校正后，发现爆发持续时间、爆发间期、同步性、平均放电率、分支比和Kappa指数是网络失效时间的显著预测因子。临界性指标提供了最具机制性的洞见：在早期死亡孔中，随着网络接近沉默，分支比降至趋近于零，而Kappa指数升至趋近其上限。除平均水平外，分支比和Kappa指数随记录的变化率是所有临界性指标中与生存时间相关性最强的指标。神经元雪崩大小和持续时间指数及其标度关系，在网络活跃期间与两种表型中的无标度动力学均保持一致，尽管早期死亡孔中雪崩发生率逐步下降，但作为独立预测因子未达到显著性。这些结果表明，长期网络存活并非仅由放电率决定，而是由保留的爆发组织、持续电极募集和接近临界的传播动力学决定。这项工作提供了迄今为止对啮齿动物皮层培养物最长的电生理表征之一，并确定基于临界性的指标是预测网络衰退和评估干预措施以维持长期神经元功能的有前景工具。

    解析听觉神经祖细胞的干性以实现大规模神经元筛选

    bioRxiv / 2026-10-13 / Rousset, F.

    感音神经性听力损失可由感觉毛细胞、听觉神经元或其突触连接的损伤引起，其中听觉神经病和耳蜗突触病凸显了神经完整性对听力的重要性。哺乳动物耳蜗再生丢失听觉神经元的能力有限。理解维持耳蜗祖细胞扩增和神经发生能力的分子程序，可支持神经元再生，并为听觉药物发现提供可再生的模型。我们此前已确定，WNT激活联合双重SMAD抑制（CHIR-DS）可支持小鼠听觉神经祖细胞（ANPGs）的可规模化扩增和神经元分化。在此，我们表征了与诱导状态相关的转录、染色质和代谢变化。RNA-seq和ATAC-seq发现Id1和Id2表达降低，前神经碱性螺旋-环-螺旋基序处可及性增加，同时翻译、mTOR和葡萄糖代谢程序的转录富集。与生长因子对照相比，CHIR-DS处理的ANPGs在早期传代时糖酵解略有增加。然而，在长期扩增后，糖酵解和线粒体呼吸均显著增强。人胎儿ANPGs也对CHIR-DS作出反应，表现为球体生长增加并保留神经分化能力，提供了超越小鼠系统的概念验证。最后，源自干性诱导ANPGs（siANs）的神经元支持384孔报告基因 assay 和2,560化合物初步筛选，提名了候选神经突生长增强剂。总之，这些发现验证了ANPG干性诱导的通路基础，表征了由此产生的分子和代谢状态，并展示了人类可行性和神经元筛选应用。

    首发精神分裂症谱系精神病中皮层体积变化的对比模式

    medRxiv / 2026-10-13 / Spaniel, F.

    重要性 早期精神病中平均灰质体积（GMV）丢失可能掩盖了具有临床相关性的脑变化差异。目的 识别纵向GMV变化模式、其跨站点对应关系及临床关联。设计、设置和参与者 前瞻性队列，2011-2026年在2个捷克站点获取T1加权MRI；中位随访约13个月。参与者为222例首发精神分裂症谱系精神病患者和178名按站点和基线年龄频数匹配的健康对照。暴露 首发精神病与健康对照状态。主要结局和测量 按站点对图像质量校正后、随后年化的333个皮层分区的GMV变化进行诊断盲法聚类；纵向基于体素的形态测量学（VBM）；全球功能评估和共识5因子阳性与阴性症状量表阴性症状评分。结果 在400名参与者中（平均[SD]年龄，28.2[7.5]岁），208名（52.0%）为男性。每个站点独立产生3个聚类：C1（GMV接近稳定）、C2（显著下降）和C3（增加）。C2和C3在333个分区上的跨站点质心相关性很强（Spearman rho = 0.865和0.861）；C1相关性较弱（rho = 0.138），这符合接近零 profile 且区域变异很小的预期。C2/C3对应关系支持将匹配的站点特异性聚类合并用于事后分析。合并聚类中，C1包含77例患者和125名对照，C2包含66例患者和16名对照，C3包含79例患者和37名对照。后缀-P和-HC标识患者和对照亚组。为将患者变化相对于对照进行定位，事后VBM显示，从C1-HC到C1-P再到C2-P存在一个未预料到的、逐渐更明显的GMV减少梯度，主要涉及联合皮层，并且C3-P存在双侧腹侧颞叶GMV增加（familywise error校正P < .05）。沿此顺序的相反对比显示脑室周围变化，与逐渐加重的脑室扩大一致。C2-P的平均随访功能最低，平均阴性症状严重程度最高（校正omnibus P = .005和.02）；患者组间自基线的临床变化无显著差异。结论与意义 精神病早期GMV变化并非一致，而是包含两个相反方向：一个具有临床相关性、以对照为锚定的模式，表现为逐渐更明显的GMV丢失并涉及默认模式区域；以及一个不同的、方向相反的腹侧颞叶增加。

    美国临床试验中的语言资格标准和入组种族及族裔构成：一项横断面研究

    medRxiv / 2026-10-13 / Tolas, A.

    背景：联邦政策现在要求申办方为临床试验提交多样性行动计划，但与入组构成相关的试验设计可修改特征仍鲜有刻画。英语语言能力要求被写入资格标准，并作为自由文本记录在公共注册库中，使其可见，并且原则上可修改，但其与入组构成的关系仅在单一疾病领域和小样本试验中受到考察。我们研究了这些要求以及有记录的语言便利措施是否与入组参与者的种族和族裔构成相关。方法和发现：我们对在ClinicalTrials.gov注册、至少有一个美国站点并已发布结果的干预性试验进行了横断面研究，使用2026年10月检索的注册库快照。主要队列包括44,487项仅设美国站点的试验，其中21,924项（49.3%）报告了基线种族，17,434项（39.2%）报告了基线族裔，且计数与已发布的分母相符。两项暴露均使用正则表达式从自由文本资格标准中分类，并针对150项试验的独立医生审查进行了验证。对于英语语言要求分类器，敏感性为88.2%，特异性为99.2%。结局为每个类别中入组参与者的试验层面比例，使用广义线性模型分析，并校正干预类别、治疗领域、申办方、分期、入组人数、站点、开始年份、美国人口普查区域以及试验站点所在州的人口构成。英语语言能力要求出现在5,736项试验中（12.9%）；其患病率从2010年开始的试验中的7.4%上升至2023年的26.2%（每十年比值比[OR]为2.91，P<0.001），而有记录的便利措施，即允许以英语以外语言参与的资格声明（在标记试验中99.9%为西班牙语），仍然罕见（788项试验，1.8%）。该要求与亚裔（OR=0.85，95% CI 0.77-0.93，P=0.001）和西班牙裔/拉丁裔参与者（OR=0.85，95% CI 0.79-0.91，P<0.001）入组比例较低相关，未发现与白人参与者相关的证据（OR=0.99，95% CI 0.95-1.04，P=0.75）。有记录的便利措施与西班牙裔/拉丁裔参与者比例较高相关（OR=3.23，95% CI 2.82-3.71，P<0.001）。地理校正未改变该要求相关性的统计学显著性，并减弱了便利措施相关性。主要局限性为横断面设计，无法进行因果推断；入组分析仅限于报告基线人口学特征的试验，而这些试验比未报告者更近；以及自动分类暴露可能存在错误分类。结论：英语语言能力要求在2010年至2023年间变得常见了三倍以上，并与亚裔和西班牙裔/拉丁裔参与者入组比例较低相关。较少见的有记录语言便利措施与西班牙裔/拉丁裔参与者入组比例较高相关。由于这些标准由研究者撰写并公开记录，它们可能是改善入组公平性的一个可处理目标，尽管修改这些标准是否会改变入组人群仍需前瞻性评估。

    背景：童年经历对一生中的健康与福祉都有影响，但来自低收入和中等收入国家的研究大多只关注少数结局，而非成人福祉、行为以及社会和经济状况的更广泛模式。方法：在这项横断面分析中，我们使用了来自全球繁荣研究（GFS）第1波（2023年）的印度全国代表性成人样本（N = 12,765；年龄[≥]18岁），以检验八个回顾性报告的童年经历条目、45个成人结局以及两个综合繁荣指数之间的关联。使用调查加权的线性、逻辑和比例优势模型，并调整年龄、性别、教育和居住环境，采用Bonferroni校正来评估关联以及性别对关联的效应修饰。结果：尽管不同童年经历之间关联的广度和强度不同，但较不利的童年经历总体上与较差的福祉和繁荣、较高的不良健康结局几率以及成年生活中获得资源和安全的机会减少相关。然而，与亲社会行为相关的结局呈现出不同模式：童年虐待（身体或性）与更高的志愿服务几率相关（OR 1.31，95%置信区间或CI [1.13,1.51]），感觉自己在家中像外人的人与更高的捐赠几率相关（OR 1.80，95% CI [1.52,2.13]）、志愿服务几率相关（OR 1.53，95% CI [1.28,1.82]）以及帮助陌生人几率相关（OR 1.49，95% CI [1.27,1.74]）。女性与男性之间的关联大体相似，几乎没有证据表明存在性别差异。解释：童年逆境与成年生活中较差健康和增加亲社会行为的关联，可能反映了未测量的社会、文化或性情因素以及异质性的人生历程反应。尽管如此，这些发现支持在印度加强儿童保护、经济援助项目和心理健康服务。
