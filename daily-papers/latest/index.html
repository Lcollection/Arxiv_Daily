    人类蛋白质稳态网络综述：泛素-蛋白酶体系统

    bioRxiv / 2026-08-30 / Elsasser, S.

    泛素化修饰调控着数千种注定通过蛋白酶体或自噬途径被清除的蛋白质的半衰期，具体取决于泛素修饰的复杂结构。该系统对单个蛋白质、蛋白质复合物和细胞器进行质量控制，并执行无数纯粹调节性功能。在此，我们全面综述了泛素-蛋白酶体系统（UPS），其范围目前界定尚不清晰。UPS，连同涉及泛素样修饰因子的通路，据我们估计在人类中包含超过1430种不同蛋白质，这是一组庞大的活动，其对细胞生物学的集体影响无处不在。UPS是蛋白质稳态网络（PN）的组成部分，该网络的其余部分我们也在近期研究中进行了综述。加上分子伴侣、自噬-溶酶体途径的蛋白质及相关活动，据我们估计，PN总共包含超过3150个组分。对这些通路的全面和系统性定义应支持基因组学、蛋白质组学、生物化学、细胞生物学和疾病研究领域的一系列正在进行的研究。

    神经网络爆发对功能发育的影响

    bioRxiv / 2026-08-30 / Ramstad, O. H.

    网络爆发或同步爆发事件是大多数体外神经网络中常见的活动。网络爆发在发育早期出现，随着网络成熟，活动逐渐由跨越整个网络的爆发所主导。体外这种发育平台期的原因尚不清楚，但绕过它将为体外网络用于计算带来显著优势。由于网络中大多数神经元参与网络爆发，爆发的起始会覆盖任何进行中的活动，从而将短期计算限制在爆发之间的恢复期内。通过评估从体外第4至39天的521次多电极阵列记录，我们发现网络爆发影响连接性，但这种变化与网络爆发的起源仅弱相关。本文讨论了爆发对神经网络功能整合和分离的影响，以及减轻体外网络爆发发展和传播的方法。此外，我们假设爆发起始区或起搏器在控制和储备池背景下是刺激计算的可行靶点。

    汇聚性抑制性皮层环路破坏驱动遗传学上不同的失神发作

    bioRxiv / 2026-08-30 / Song, S.

    儿童失神癫痫是最常见的儿科癫痫之一，其特征为短暂的意识丧失和脑电图上的广泛性棘慢波放电（SWDs）。尽管致病基因列表不断增长，但驱动这种高度刻板SWD表型的核心皮层回路异常仍不明确。利用两种成熟的失神癫痫小鼠模型，它们携带不同基因的点突变，分别改变突触前和突触后传递，即stargazer（Cacng2）和tottering（Cacna1a），我们发现在这两种模型中，一个由第6层皮层丘脑神经元（L6 CT）和一种新型Tac1+ Pvalb中间神经元亚型定义的特定跨层抑制性微回路均受到破坏。这一早期功能缺陷之后，出现了深层生长抑素表达（Sst）中间神经元的继发性显著功能障碍，这与癫痫发作的出生后发育起始时间相吻合。关键的是，我们通过证明在野生型小鼠中仅化学遗传学破坏L6 CT-Tac1+ Pvalb微回路就足以诱导继发性Sst中间神经元功能障碍和SWDs的同时出现，确立了这些级联缺陷的序列因果性。综合来看，这些发现揭示了一种顺序性的跨层突触功能障碍或“多米诺效应”，其中原发性细胞自主缺陷触发更广泛的回路适应，从而允许棘慢波超同步化。因此，我们的结果确定了两种遗传异质性失神癫痫模型中的趋同性、因果性皮层回路病理，突出了一个共同的干预功能靶点。

    使用TrueLAMP抑制LAMP中引物驱动的非特异性扩增

    bioRxiv / 2026-08-30 / Chen, Z.

    环介导等温扩增（LAMP）可实现快速核酸检测，但易受引物驱动的非特异性扩增影响，从而产生假阳性结果。我们开发了TrueLAMP，一种含有抑制剂的比色LAMP配方，该抑制剂可抑制非特异性扩增，同时保留靶标依赖性扩增。这些研究中所有65个无模板对照均保持阴性，对应100%的观察特异性。以SARS-CoV-2为模型，并使用Lamb引物组作为代表性基准，TrueLAMP实现了每反应250拷贝的检测限，检测概率为95%。终点颜色在延长孵育期间保持稳定，减少了对时间关键读数的需求。TrueLAMP与现成的加热设备兼容，包括对流烤箱、水浴锅和温控智能杯。两个外部实验室使用额外引物-模板系统（包括DNA靶标）进行的独立评估进一步支持了非特异性扩增的抑制和序列依赖性靶标检测。综合这些发现，支持TrueLAMP作为一种实用方法，在保持简单等温工作流程的同时提高LAMP检测的可靠性。

    自然植物种群中的昼夜节律同步与门控

    bioRxiv / 2026-08-30 / Paajanen, P.

    昼夜节律钟协调生理、发育和行为与昼夜周期的同步，这有助于生物体的适应性。为实现这一点，昼夜节律钟必须与环境条件的自然每日波动对齐。在此，我们在自然条件下研究了环境线索在调节昼夜节律钟中的作用，以及这如何影响节律输出。通过将自然植物种群中的新型田间实验与全基因组分析和机器学习策略相结合以进行数据解读，我们推断温度线索在自然条件下改变昼夜节律时间。我们推断低温线索可在自然波动条件下改变昼夜节律相位，并且温度对昼夜节律夹带的影响存在季节性变化。我们还识别出田间条件下温度响应的广泛昼夜节律调节。因此，自然条件下昼夜节律时间的可塑性允许节律钟及其输出对环境刺激做出灵活响应。

    绝经后女性心肺适能、多基因风险与乳腺癌：一项前瞻性队列研究

    medRxiv / 2026-08-30 / Tanisawa, K.

    背景：尽管较高的心肺适能（CRF）与较低的乳腺癌风险相关，但CRF是否改变多基因风险与乳腺癌之间的关联尚不清楚。我们研究了心肺适能（CRF）和多基因风险与绝经后女性偶发性乳腺癌的联合关联，以及较高CRF是否与高多基因风险所赋予的额外乳腺癌风险的减弱相关。方法：这项前瞻性队列研究纳入了来自英国生物银行的绝经后女性。CRF通过次极量自行车测力计测试估算，遗传易感性通过乳腺癌多基因风险评分（PRS）评估。使用Cox比例风险模型，以实际年龄作为基础时间尺度，检验CRF和PRS与偶发性乳腺癌的关联。分析总体进行，并按年龄（40-59岁和[≥]60岁）及体重指数（BMI）（<25和[≥]25 kg/m²）分层。评估了乘性和加性交互作用，加性交互作用通过交互作用导致的相对超额风险（RERI）评估。结果：在中位随访10.7年期间，13,907名绝经后女性中识别出500例偶发性乳腺癌病例。较高CRF与乳腺癌发病率降低呈剂量反应关系，而较高PRS与偶发性乳腺癌风险逐渐增加相关。尽管乘性交互作用不显著，但较高CRF与高多基因风险所赋予的额外乳腺癌风险在加性尺度上的减弱相关（RERI -0.88，95% CI -1.57至-0.18）。这种减弱在年龄[≥]60岁及BMI [≥]25 kg/m²的女性中尤为明显。结论：较高CRF与较低的乳腺癌风险及高多基因风险所赋予的额外乳腺癌风险的减弱相关，尤其是在基线风险较高的绝经后女性中。这些发现支持进一步研究CRF作为多基因风险升高女性中潜在可调节因素的作用。

    基于残差门控多模态Transformer的CGM与稀疏膳食日志血糖预测

    medRxiv / 2026-08-30 / Lee, J.

    在自由生活环境中，基于连续血糖监测预测血糖具有挑战性，因为轨迹依赖于内源动态和稀疏记录的进餐信息。我们开发了$\our$，一种多模态变换器，它生成完整的基于CGM的预测，然后添加一个门控、餐食信息驱动的残差校正。该校正由自我报告和CGM衍生的餐食存在证据联合控制，并按预测时间范围缩放，从而在不需餐食记录的情况下利用饮食背景改善预测。我们在弗雷明汉心脏研究的1,752名无糖尿病成人中评估了$\our$。参与者佩戴Dexcom G6 Pro传感器，并完成配对的ASA24饮食回忆。与长短期记忆、变换器和GluFormer模型架构相比，$\our$在预测时间范围、餐食状态分层和血糖范围上实现了最低的平均绝对误差。它还改善了餐后峰值血糖、达峰时间、正向增量曲线下面积以及70--140 mg/dL范围内时间的预测。参与者级别交叉验证确认了对未见参与者的泛化能力。

    可穿戴睡眠分期性能随睡眠呼吸暂停严重程度增加而下降，且在极重度睡眠呼吸暂停中对训练集组成敏感。

    medRxiv / 2026-08-30 / Ogaki, S.

    我们旨在评估可穿戴睡眠分期在不同睡眠呼吸暂停严重程度下的表现，包括定义为呼吸暂停低通气指数（AHI）[≥] 50次/小时的极重度睡眠呼吸暂停，并评估训练集组成如何影响该亚组的表现。我们分析了552份夜间记录：318份来自睡眠实验室数据集，234份来自医院数据集，其中26.5%（N=62）患有极重度睡眠呼吸暂停。一个深度学习模型利用腕戴设备记录的光电容积脉搏波衍生的RR间期和加速度计数据进行睡眠分期。基线性能通过4折交叉验证评估，使用从合并数据集中随机划分的折。我们检查了夜间水平与AHI严重程度的关联。我们还比较了基线模型与消融模型，后者在相同数量的记录上训练，但包含所有睡眠实验室数据集记录和较低AHI的医院数据集记录，并在极重度亚组中评估两者。对于5阶段分类，Cohen's kappa在睡眠实验室数据集中为0.586，在医院数据集中为0.446。在4阶段分期下，差距缩小，kappa值分别为0.632和0.525。在医院数据集中，kappa随AHI严重程度下降，轻度与极重度组之间的中位kappa差异约为0.2。在极重度亚组中，kappa从0.365（基线）降至0.303（消融）。可穿戴睡眠分期性能倾向于随睡眠呼吸暂停严重程度增加而下降。临床实用性可能受益于训练数据覆盖目标严重程度谱，以及分期粒度与预期用途相匹配。

    面向主动学习不确定性采样的新型文档级度量及其性能评估：自动CDSS本体策展的应用案例

    medRxiv / 2026-08-30 / Alluri, S.

    人在回路中的主动学习（AL）能够识别关键短语，以促进生物医学本体开发、维护及其他策展任务。然而，确定哪些文档应由人工标注并非易事。我们探索了新策略，使文档选择过程透明、可重复且有效。我们的AL流程使用PubMed摘要修改了BiLSTM-CRF模型。我们测试了四种新颖的文档级不确定性聚合策略：KPSum、KPAvg、DocSum和DocAvg，这些策略基于标准词级不确定性分数：最小词概率（MTP）、词熵（TE）和边际。所有策略在早期主动学习周期（{theta}至{theta}2）中均显著改善了召回率和F1分数。系统评估显示，KPSum（实际顺序）在召回率和F1上均表现出一致改进。加权F1（{beta} = 5, 10）提供了与原始召回率和F1（{beta} = 1）互补的结果。我们的工作通过引入文档级不确定性聚合推进了不确定性采样，并显示出在自动化本体策展方面的潜力。
