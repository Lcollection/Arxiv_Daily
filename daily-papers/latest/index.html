    无最优臂反馈下的遗憾在奖励依赖延迟中

    arXiv / 2026-11-08 / Zhong Han

    我们研究具有奖励依赖延迟（可能是无限延迟）的随机赌博机，其报告省略了原始轮次。对于每个 $c\in[0,1)$，平衡历史乐观（BHO）具有一个由水平 $1-cΔ_i$ 处最大次优臂分位数控制的延迟项，且不需要最优臂的报告。下界在对数统计区域给出了平方反比松弛代价，并在 $c=1$ 时给出了线性极小极大遗憾。一个 $K$ 增长的族对每个学习器都强制最坏情况遗憾 $Ω(G\log K)$，其中 $G=\max_iΔ_i h_i$ 是最大的间隙加权次优截断。待触发平衡在 $c<1$ 时保持了 BHO 的加权截断界，并在确定性奖励、唯一最优和固定有界延迟下达到了历史贪婪探索系数。间隙加权比较和实验展示了共享等待何时有帮助以及平衡探索的代价。

    通过容量意识学习以最小化医院再入院

    arXiv / 2026-11-08 / Lydia T. Liu

    预测算法越来越多地被用于指导医院出院决策，然而这些模型可能因历史数据不足或过往出院决策而对脆弱患者表现出删失偏差。当有偏的再入院风险预测器被用于指导出院时，由出院决策生成的训练数据在预测器重新训练时可能延续类似的偏差，从而导致恶性循环。我们将基于排队的马尔可夫决策过程扩展用于医院出院，以纳入定期重新训练的再入院风险预测器。我们的关键洞见是，成本最优的“容量感知”运营决策策略能够自然地使观察患者结果所处的住院时长多样化，从而在没有显式公平约束的情况下实现再入院风险的一致估计。我们证明，在良好设定下，出院至多策略下的反复重新训练会收敛到无偏的风险估计。在合成实验和基于合作医院患者级数据校准的模拟中，我们发现，常用的风险阈值策略可能持续存在偏差，而出院至多策略相比现状决策策略（如对风险进行阈值化）将学习误差降低了24%-25%。这些估计上的改进还缓解了某些形式的偏差，将再入院成本差异（经调整人口群体间基线风险差异后）降低了38%-63%。我们的结果表明，容量感知决策策略如何通过解决删失偏差来同时改善预测性能和公平性。

    CallCleaner：基于音频基础模型的轻量级生物声学去噪

    arXiv / 2026-11-08 / Michael Xie

    许多动物发声研究需要干净的录音，但动物通常在野外被录制，伴有来自天气、车辆和其他动物的背景噪声。动物发声降噪面临干净训练数据稀缺和动物发声极端多样性的挑战。经典谱门会留下残余噪声，尤其是在没有语音活动检测（VAD）的情况下，而为生物声学设计的无检测器神经降噪器去除的噪声较少。我们表明，一种通用源分离基础模型 SAM-Audio，在未经训练并使用来自简单动物 VAD 的时间跨度作为提示时，比这两类方法去除更多噪声。为了将这种重型方法转变为实用工具，我们将其蒸馏为 CallCleaner，一个 19M 参数的降噪器，无需检测器，在笔记本电脑 CPU 上运行速度约为实时的 90 倍。我们发现 SI-SDR 在我们的设置中效用有限，因为它惩罚再生输出并将噪声去除与叫声保真度混为一谈，而我们的单独指标揭示了这种权衡。CallCleaner 在叫声周围留下的噪声比 Biodenoising 少 11 dB，后者是具有公开权重的领先神经生物声学降噪器，并且在快速、CPU 可运行的系统当中，它在噪声去除与叫声保真度之间推动了帕累托前沿，且无需检测器。我们发布了 CallCleaner 的代码和权重，这使得无需专用硬件即可对单发声者录音进行快速、私密、本地的降噪。

    THEATRON：评估长时程LLM决策中角色持续性的基准

    arXiv / 2026-11-08 / Yuyan Wang

    通过变分自编码器处理未测量聚类层面协变量的多层次研究因果机器学习

    arXiv / 2026-11-08 / Youmi Suk

    未测量的混杂因素是观察性研究中准确估计处理效应的关键障碍，而在多层次数据中，它们往往出现在聚类层面。灵活的机器学习方法无法直接解决此类未测量的混杂问题。为此，我们提出了变分自编码器增强R-learner（VAE-R），该方法利用变分自编码器（VAE）从结局和处理残差的簇内依赖性中推断未测量的聚类层面协变量，并利用所得的调整来估计条件平均处理效应（CATE）和平均处理效应（ATE）。VAE解码器通过偏移似然来指定，使得潜在变量仅捕获由已测量协变量未能解释的聚类层面变异。VAE-R适用于观察性研究中未测量的聚类层面混杂因素以及多站点随机试验中未测量的聚类层面结局预测因子。我们还提供了数据驱动的策略来选择VAE的两个超参数，即潜在维度大小和Kullback-Leibler权重。我们的模拟研究表明，VAE-R在多层次观察性数据中几乎消除了普通R-learner的CATE和ATE估计的偏差，并在多站点随机试验中提高了其精度。最后，我们用两个数据集来说明VAE-R，一个来自多层次观察性研究，另一个来自多站点随机试验。

    面向分布式非独立同分布生物医学数据分析的一次性分层联邦聚类

    arXiv / 2026-11-08 / Shenghong Cai

    在多机构生物医学数据分析中，全面的疾病画像往往分散在不同的数据孤岛中。此外，本地数据分布通常呈现不同层次的粒度，甚至具有复杂的嵌套结构。尽管层次聚类（HC）是探索此类数据拓扑的有力工具，但其繁琐的递归过程带来高昂的计算开销，并使其极易发生隐私泄露。因此，本文提出一种高效的一次性层次联邦聚类框架，通过从客户端到服务器的单向原型级通信，在客户端（机构）进行分布探索，在服务器端进行分布聚合。尽管所设计的一次性原型传输保证了最小的计算开销并降低了隐私风险，但它不可避免地带来信息损失。为应对这一问题，在服务器端提出一种多粒度竞争学习机制以融合聚类子簇，从而在有限的单向通信约束下有效最大化全局分布拓扑的保留与挖掘。结果表明，跨客户端的复杂聚类分布可以被高效探索，在公开数据集上与最先进方法进行的大量对比实验证明了所提框架在平衡稳健聚类、隐私保护和计算效率方面的优越性。

    超越排名：决策模型是校准的相关性评分器吗？

    arXiv / 2026-11-08 / Shengyao Zhuang

    Jev 等决策模型是一类新型相关性评分器。其类型化评分原语接收一个问题、一组有序的文本相关性等级和一个状态，直接返回每个等级的概率，而非 token 似然或生成的标签。Jev 的供应商承诺这些概率是经过校准的。这促使我们重新审视“Beyond Yes and No”，该工作利用从似然导出的分数在细粒度相关性标签上改进了零样本逐点 LLM 重排序，但将针对人工评估者的校准留作未来工作。在本文中，我们首先在八个 BEIR 集合上复现其开放模型 FLAN-UL2 设置，确认其排序趋势，然后以相同协议运行 Jev 和两个开放权重决策模型。Jev 和 27B pplx-decider 平均而言重排序效果优于 FLAN-UL2 和三个交叉编码器。随后我们将 Jev 的原生概率与人工评估者的标签进行比较，发现其过度自信：在其评分高于 0.9 的 DL21 对上，仅 66% 是相关的。由于这主要是尺度误差，在 2,257 个 DL19 对上拟合的两参数校准消除了大部分误差，并可迁移至 DL21。校准后，Jev 的 DL21 Brier 分数低于 FLAN-UL2 和三个交叉编码器，主要因为它更好地区分相关对与非相关对。最后，借助校准后的概率，通过期望 F1 为每个查询选择截断值无需自身参数，优于固定的 top-10 截断，并与在 DL19 上调优的截断阈值相当。

    基于零知识验证器准入与共识聚合的鲁棒隐私群体学习

    arXiv / 2026-11-08 / Marco Arazzi

    群体学习通过在参与节点间分布模型聚合与验证，提升了韧性并消除了对单一可信协调者的需求。然而，它也将模型更新的验证委托给私有数据可能存在偏差、不具代表性或具有对抗性的对等节点，而现有的群体学习协议通常不对这些数据进行认证，使去中心化验证成为攻击面。我们提出一个稳健、隐私保护的群体学习框架，将可验证的数据质量作为进入学习任务的条件。验证者只有在零知识认证证明参考模型在其私有数据上正确运行且不泄露任何原始样本之后才能加入。经认证的输出还产生无标签的类别画像，因此网络能够从各自偏斜的验证者中组装出一个集体IID的验证者池，其准确度与拥有真实标签的预言机相当（与均匀分布的总变差距离为0.025，预言机为0.021，随机选择为0.21）。获准加入的验证者对客户端更新进行评分，并通过Tendermint风格的拜占庭容错共识，就每次提交的梯度掩码和由质量导出的聚合权重达成一致，以质量感知信号取代数据集大小加权。借鉴拆分学习的切层思想，基于挑战的审计让对等节点能够重新验证掩码是在经认证的数据上计算的，而无需昂贵的端到端零知识证明。在非IID划分下的四个基准测试中，该框架在干净数据上与FedAvg相当；在使FedAvg崩溃至随机水平的梯度缩放攻击下，它在CIFAR-100上保持94%的干净准确率，在FashionMNIST上保持超过99%，而FedAvg仅达到2.1%和11%。其结果为去中心化学习提供了一个私有、稳健且可审计的基础。

    过熟香蕉加工技术对化学成分及对埃及伊蚊和白纹伊蚊引诱性的影响

    bioRxiv / 2026-11-09 / Abuelmaali, S. A.

    由蚊子传播的媒介传染病发病率不断上升，已成为重要的公共卫生问题。蚊子对常规杀虫剂的抗性不断增强，促使人们需要诸如attractive targeted sugar baits (ATSBs)等替代控制策略。虽然基于水果的引诱剂已显示出前景，但不同生产方法对其引诱力的影响仍未得到充分研究。本研究考察过熟香蕉(Musa acuminata)提取物的三种生产技术：液体提取、糖浆浓缩和冷冻干燥，对其化学成分以及对埃及伊蚊(Aedes aegypti)和白纹伊蚊(Aedes albopictus)引诱力的影响。提取物被注入水凝胶珠中，并在双选择嗅觉仪试验中针对蚊媒埃及伊蚊和白纹伊蚊进行测试。通过气相色谱-质谱联用(GC-MS)和酶法糖分析进行化学 profiling。结果表明，所有香蕉提取物均显著比10%蔗糖对照更具引诱力。在各提取物中，糖浆浓缩物表现出最高的引诱力(PI = 0.58 {+/-} 0.17，对埃及伊蚊；0.58 {+/-} 0.14，对白纹伊蚊)，其次是冷冻干燥物(PI = 0.52 {+/-} 0.20；0.54 {+/-} 0.08)和液体提取物(PI = -0.40 {+/-} 0.04；0.49 {+/-} 0.18)。GC-MS分析显示，冷冻干燥粉末保留了最丰富多样和丰度的挥发性有机化合物(VOCs)，尤其是乙酸丁酯和乙酸异戊酯等酯类，这些已知会影响蚊子行为。尽管糖浆浓缩导致VOCs降解，但它也产生了美拉德反应产物，如含硫挥发物，这可能增强嗅觉线索。糖分析表明，糖浆和冷冻干燥提取物均含有较高水平的蔗糖(0.35-0.57 g/100g)、葡萄糖(21.20-28.70 g/100g)、果糖(14.64-17.89 g/100g)和麦芽糖(9.28-15.56 g/100g)，与蚊子偏好一致。总体而言，研究结果表明，生产技术显著影响过熟香蕉提取物的化学成分和引诱潜力，为病媒监测和控制策略中基于水果的蚊虫诱饵的开发提供了宝贵见解。

    背景。低覆盖度血浆游离DNA（cfDNA）测序是一种廉价的癌症检测底物。标准流程会丢弃比对质量低的片段，这些片段主要来源于重复DNA，尽管着丝粒周围卫星重复序列在癌症中常呈低甲基化。我们探究了多比对cfDNA片段的比例在早期癌症与匹配的健康对照之间是否存在差异，以及在严格控制技术因素的条件下，该比例与常规片段组学特征相比如何。方法。我们分析了来自25例I至III期乳腺癌患者和25例健康对照的公开血浆cfDNA全基因组测序数据，对照按年龄、性别、吸烟和饮酒情况1：1匹配，每对样本在同一文库和测序批次中处理；另分析了8例早期肝细胞癌（HCC）病例及8例匹配对照。对每个样本，我们计算了MAPQ<30的常染色体片段比例，以及这些片段位于着丝粒和异染色质细胞带中的份额，并将其与分期、分级和拷贝数偏差（作为肿瘤负荷的替代指标）相关联。分类器在乳腺癌中通过留一对交叉验证进行评估，并仅在乳腺癌上训练后原样应用于HCC。通过折内残差化和片段水平GC加权，检验了对GC含量和测序深度的稳健性。常规片段组学特征（片段长度、末端基序、拷贝数、类DELFI谱和转录起始位点窗口特征）在四种GC处理分析下进行评估。结果。多比对片段比例在乳腺癌中高于匹配对照（中位数5.38%对5.19%；19/25对中更高；配对p=0.0006；交叉验证AUC 0.81，95%CI 0.67-0.94），在I期（9/10对）、II期（7/10）和III期（3/5）疾病中以及每个测序批次中均更高。该超额集中于着丝粒和异染色质带，这些带中多比对片段的份额从22.0%升至23.4%（19/25对；p=0.004）。两种信号在折内校正GC含量和/或深度后持续存在（多比对片段AUC 0.64-0.76，异染色质份额AUC 0.71-0.76），在片段水平GC加权下亦持续存在（18/25对；p=0.003）。多比对差异在I期最大并随分期降低（Spearman ρ=-0.42，p=0.04），两种特征均与分级或拷贝数偏差无关。在公开组织甲基化组中，卫星序列在乳腺肿瘤中的低甲基化程度与其他晚复制DNA相似，但肿瘤低甲基化与cfDNA超额之间的区间水平关联较弱，且可由GC含量解释。在HCC中，预设终点、乳腺癌训练的多比对模型未达到（AUC 0.73；5/8对；符号检验p=0.36）。在一项未预设的探索性分析中，异染色质份额在7/8对HCC中更高（p=0.016；锁定AUC 0.86，95%CI 0.62-1.00）；在包括发现对在内的全部33对中，有26对在癌症病例中更高（事后符号检验p=0.0007）。相比之下，常规片段组学特征仅在没有片段水平GC控制时达到AUC 0.71（乳腺癌）和0.77（HCC）；它们跟随每样本覆盖度的GC依赖性，并在三种GC控制分析中的每一种下均降至随机水平，包括一种保留启动子特异性信号的分析。结论。常规被丢弃的多比对cfDNA片段在早期乳腺癌与批次匹配对照之间存在差异，很大程度上独立于GC含量和测序深度，且在着丝粒和异染色质DNA中呈超额。该信号不随分期缩放，其生物学来源尚未证实，且不能从片段文件中排除读段质量的贡献。它是一个候选标志物，需要在具有原始读段和肿瘤分数估计的更大队列中加以确认。

    medRxiv / 2026-11-09 / Abdulkadir, M.

    摘要重要性。神经性厌食症（AN）是一种严重的精神疾病，其结局异质性强且死亡率升高。刻画严重程度轨迹可能有助于改善早期风险分层和针对性干预。目的。使用基于登记资料的严重程度指数（AN-RSI）识别AN严重程度轨迹，并检验其与多基因评分（PGS）、既往（AN诊断之前）以及后续（AN诊断后5年以上）精神疾病和躯体疾病的关联。设计。基于人群的队列研究。环境。丹麦全国性研究。参与者。1963年至2007年出生且被诊断为AN的个体（N = 9534名个体）。遗传数据可在子样本中获得（N = 5126）。暴露。41项PGS，索引与AN相关的特征，以及AN诊断之前的精神疾病和躯体疾病。主要结局与测量。AN-RSI轨迹、AN诊断后5年以上的精神疾病和躯体疾病。结果。识别出三种轨迹：“低且稳定”（32.6%）、“中等且稳定”（53.5%）和“高且上升”（14.0%）。“低且稳定”组作为所有分析的比较组。AN PGS每增加1个标准差（SD），对应遵循“高且上升”轨迹的几率增加13%。BMI和注意缺陷多动障碍（ADHD）PGS的增加分别对应遵循“高且上升”轨迹的几率降低15%和14%。没有任何既往精神疾病或躯体疾病与轨迹归属显著相关。相比之下，遵循“高且上升”轨迹的个体后续精神疾病和躯体疾病的可能性更高，精神疾病的比值比范围为1.7（ADHD）至3.7（精神活性物质依赖），躯体疾病的比值比范围为1.6（子代胎儿生长不良）至4（小细胞性贫血）。结论与意义。我们的研究结果表明，AN个体遵循不同的严重程度轨迹，这些轨迹与多基因风险和诊断后疾病模式差异相关，但与诊断前精神疾病或躯体疾病无关。随着该领域的发展，在首次就诊时将PGS纳入综合评估，可能有助于对处于更严重疾病轨迹较高风险的个体进行早期识别、个性化干预和资源分配。关键点问题：神经性厌食症患者是否遵循与特定遗传和疾病风险相关的不同严重程度轨迹？发现：在这项基于登记资料的研究中，我们识别出神经性厌食症的三种严重程度轨迹。遵循最严重疾病轨迹者具有更高的较低体重和神经性厌食症遗传易感性，并且发生后续精神疾病和躯体疾病的风险更高。意义：以遗传风险为标志的神经性厌食症疾病严重程度轨迹，可能有助于对严重疾病风险最高者进行早期识别和干预。

    用于改善基因组测序诊断结果的变异过滤框架

    medRxiv / 2026-11-09 / Birnbaum, R.

    罕见遗传病尽管使用了外显子组测序（ES）和基因组测序（GS），仍经常未被诊断。本研究旨在通过引入一个系统性框架来提高诊断率：SMART过滤（系统性、多步骤、自动化、罕见变异优先排序工具），旨在优化GS分析，特别侧重于非编码区域。我们回顾性分析了153例先前ES和GS结果均为阴性的病例。SMART过滤作为注释前过滤步骤应用，整合了保守性指标、等位基因频率阈值和剪接预测评分。随后进行基于表型的优先排序和人工审核。该框架的应用在4.6%的病例中识别出致病性或可能致病性变异，在1.3%的病例中识别出强意义不明确变异（VUS），并在5.2%的病例中识别出额外候选变异。若干深内含子变异通过RNA研究和共分离分析得到确认。该框架能够高效优先排序被标准分析所忽视的非编码和调控变异。总之，SMART过滤提供了一种可重复且可扩展的策略，以提高GS的诊断率，特别是在传统分析方法不足的病例中。将此类框架整合到临床基因组流程中，可以增强变异可解释性和诊断性能，最终带来更好的患者护理结果。
