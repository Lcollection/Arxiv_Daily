    用户嵌入是可解释行为模式的叠加

    arXiv / 2026-11-05 / Jonathan Kozaczuk

    用户嵌入是现代推荐、个性化和行为建模系统的核心组件。尽管这些嵌入能够紧凑地编码丰富的行为信息，但它们本质上是稠密且不透明的，限制了可解释性。为弥补这一不足，我们认为用户嵌入可以被理解为可解释行为模式的稀疏叠加。这一结构在线性嵌入下可由用户行为的生成模型直接预测，并通过叠加假设近似推广到深度学习表示。叠加的模式可以通过稀疏字典学习方法自然恢复，例如稀疏自编码器（SAEs），且恢复的模式可以自动命名并用自然语言进行查询。我们在合成数据上以已知的真实基准验证了模式恢复效果，其中SAEs在恢复模式方面优于经典稀疏基线，包括在Transformer编码的嵌入上。随后我们将该方法应用于来自两个真实世界数据集的经典用户嵌入和基于Transformer的用户嵌入。我们还展示了相应的自然语言标签如何支持对从未在文本上训练过的嵌入进行零样本受众检索和刻画。该框架是事后且模型无关的，无需修改上游嵌入系统。

    你是否怀念我们制作图形的那些夜晚？生成式人工智能时代对预告图与框架图的再思考

    arXiv / 2026-11-05 / Xiaoqi Zhao

    科学图表通过抽象、构图和强调的选择，将研究思想赋予视觉形式。生成式AI为实现这些选择提供了新途径，同时也引发了关于解释清晰度和有目的的视觉表达的问题。我们通过对来自200篇论文的371幅动机图和框架图进行视觉回顾来考察这些问题。该语料库包括一个基于配额的主样本，涵盖四个时间段共160篇论文，以及一个独立的立意性风格对比样本，共40篇论文。由单一多模态评判者对传播与设计的六个维度进行评估，每幅图重复评判三次。我们尝试对所有371幅图进行源约束修订，其中369幅通过了记录的保真度检查。原始图表的评分在各时间段之间未显示出一致性下降。修订使清晰度平均评分提高了0.428分，使美学连贯性平均评分降低了0.111分（五分制）。六个维度平均分的提升在主样本的动机图中大于框架图。案例分析表明，增加解释可以阐明比较关系，但排版层级和视觉经济性仍未得到解决。这些基于模型的发现支持研究者主导的设计，AI辅助探索，作者保留对解释目的、构图和科学关系的责任。随附的图谱和评估记录可在 https://ntu-ai4x.github.io/Rethinking_Figures/index_en.html 获取。

    基于推理的推理在何处以及为何有用？

    arXiv / 2026-11-05 / David Yan

    基于落地的推理，即模型在思维链推理中输出相关位置的文本坐标，是解决复杂视觉推理问题的一种常见策略。然而，落地推理的优势与局限性尚未得到充分研究。我们研究落地推理在何处以及为何最为有用。为此，我们引入一种思维链分析方法，以衡量模型在其思维轨迹中对其输出的落地信息的使用程度，并对一种落地推理训练方案进行详细的消融研究。我们发现，落地推理改善了计数能力，但在广泛的空间推理与感知基准上，相较于无坐标落地的基线并未表现出显著提升。通过若干合成任务，我们表明落地推理在任务需要不可描述指代时最为有用，不可描述指代是难以用语言描述的视觉概念。然而，我们观察到许多现有的视觉推理基准仅凭可描述的文本指代即可解决。为弥补这一差距，我们引入 BrickVision，一个需要不可描述视觉指代才能解决的新基准。

    SwarmEvolve：用于进化发现与优化的潜在智能体集群

    arXiv / 2026-11-05 / Qile Jiang

    LLM引导的进化搜索利用AI智能体，通过迭代优化解并组合高分方法来改进数学与计算问题的程序。然而，这一过程往往较慢，因为LLM在每一轮都会生成冗长的文本思维链，并且必须多次重复这一生成过程以维持种群多样性。我们提出SwarmEvolve，这是一个框架，其中每轮有数百个低成本智能体以群体方式协同工作，在潜在空间中进行推理而无需解码为文本，并通过传递KV缓存来共享信息。每个群体从不同角度研究问题。新颖性过滤器通过直接测量智能体隐藏状态向量之间的距离，保留最具差异性的智能体想法。思想的交叉在潜在空间中自然发生，因为一个总结器智能体接收所有群体成员的组合KV缓存。在数学发现和科学计算中的21个问题上，SwarmEvolve获得了最高的平均得分，并且仅需中位数3到8分钟即可达到其他最先进框架在60分钟内达到的最佳得分。在若干问题上，使用Qwen3 8B的SwarmEvolve改进了AlphaEvolve最初使用前沿LLM找到的解。我们的工作表明，在潜在空间中通信的智能体群体为科学问题的程序搜索提供了一种快速、低成本的方法。

    科学家世界：为AI科学家培育一个研究世界

    arXiv / 2026-11-05 / Taiming Lu

    AI-Scientists已经到来，但一个供它们成长的世界尚未建立。人类科学家对此习以为常——数百年的开放问题与共享思想，静候于科学文献之中。对AI-Scientists而言，那个世界可读却不可运行，因此我们为它们构建了Scientist World：每一篇研究论文都成为一个可执行环境。我们的自主流水线提取每篇论文的开放式研究问题，并将其提出的方法复现为基线；进入环境的AI-Scientist将对照人类作者所取得的成果接受评估。我们发布了首批1,000个经过验证的环境。以这个世界作为评估基准，我们发现前沿AI-Scientists已经能够在74%的情况下超越人类研究者。作为AI如何从事科学研究的记录，它包含6,400小时的研究轨迹，涵盖每一个想法、实验、失败与成功。作为训练场，我们能够将一个小型模型提升（+158%），使其在研究构思方面媲美前沿模型。最终，AI-Scientists自己的世界已经到来，它从科学本身中生长出来，并与科学共同成长。

    EgoGeneralist：通过视频原生建模统一自我中心动作视频任务

    arXiv / 2026-11-05 / Yanlin Jin

    现代视频模型具备强大的视觉先验，但并不能原生地在度量三维空间中表示人类动作。我们提出EgoGeneralist，将预训练视频生成器改造为统一动作条件的第一人称视角视频生成、姿态估计与联合动作-视频生成。我们的角色自适应动作渲染器为多方向动作-视频学习提供视频原生表示，使度量运动既可作为空间控制信号，又可作为可恢复的生成目标。跨流动作-视频耦合通过轻量适配在度量运动与视觉动态之间建立紧密对应，同时保留预训练视觉先验。这些设计共同构建了一个涵盖五项动作-视频任务的通用框架。尽管仅在受控实验室录制数据上进行适配，EgoGeneralist仍能泛化到多样化的未见场景与交互，并具备有效的动作控制与视觉质量，弥合了预训练视觉知识与度量三维人体运动之间的差距。

    XStack：机器学习仓库迁移基准

    arXiv / 2026-11-05 / Linrong Cai

    机器学习代码应当在研究者选择的环境中运行，而不是在它最初被编写的地方运行。如今，机器学习代码主要存在于两个生态系统中：NVIDIA GPU 上的 PyTorch 和 Google TPU 上的 JAX。在这些生态系统之间迁移代码仓库，意味着要跨框架和硬件进行构建与测试。这种迁移（1）是一种实际需求，因为它为研究者解锁了不同的硬件；（2）是一个天然的基准：它涉及不同的框架和硬件，覆盖整个代码仓库，并且是长周期且具有挑战性的。我们推出 XStack，一个评估智能体在这两个生态系统之间迁移机器学习代码仓库的基准。每个智能体收到一个 PyTorch 代码仓库和一台干净的 TPU 机器，并且必须交付一个 JAX 代码仓库。如果其输出满足我们的评分标准，则通过，该标准基于源仓库已发表的结果，并由我们进行认证和校准。智能体进行的迁移仍然不可靠：Claude Opus 5 通过率为 75%，GPT-5.6-sol 为 45%，其他所有智能体至多为 40%。XStack 是朝着将机器学习代码从其生态系统中解放出来迈出的一步。我们发布 XStack，以使跨框架和硬件的可靠迁移取得进展并可被度量。

    相同行为，不同机制：有限实验能就整合信息证明什么

    arXiv / 2026-11-05 / Linqian Wu

    可解释性、AI审计和机器意识评估日益依赖于机制层面的量：系统因果转移律的泛函，这些泛函描述系统如何计算，而非输出什么。实验只能通过有限、部分且含噪的干预来观察该定律。我们追问：这样的量在何种条件下可从实验的访问中辨识、在机制上连续、并能从有限数据中得到认证，并针对一个刻意严苛的案例——整合信息论中的整合信息$\varphi$——在具有已知真值的四单元和五单元随机网络中给出精确回答。行为可以是沉默的：一个循环网络和一个前馈网络在其响应延迟处具有相同的输入-输出律，却分别携带0.28比特和0比特，而内部记录可在4-53次试验内将二者区分。部分访问同样可能盲目：在我们的例子中，被排除在单步记录之外的单元施加了0.30-1.02比特的精度下限，任何样本量都无法降低；而在全但自身奇偶网络中，任意长度的记录只能通过其保真度的乘积来观察若干隐藏单元——这一对称性在精确检验中被一次干预打破。该度量具有尖锐边缘：由于$\varphi$依据一个准则选择划分及其指定的原因与结果，却报告另一个准则，机制在跨越边缘时的无穷小变化会使其改变25-100%，这发生在我们于随机网络中发现的99%的边缘处；而约1%的替代模型虽几乎完美拟合干预数据，却对其误报超过20%。单侧断言仍然成立：同一数据可认证边缘两侧的下界，我们证明$\varphi>1.004$比特在一个64维机制区域内处处成立，并从约$10^7$次受控转移中加以认证，错误认证概率至多为$\alpha$。因此，可测量性是一个具有可计算答案的设计问题。

    走向通过缩放激活反演来解释任何残差流方向

    arXiv / 2026-11-05 / Celeste De Schamphelaere

    要解释语言模型残差流中的某个方向，我们可以寻找能强烈激活该方向的文本。但通过扫描语料库找到的此类文本受限于该语料库所包含的内容。我们开发了最大激活示例元模型（MAEMs），这是一种语言模型，可将主体模型的残差流方向映射到能强烈激活这些方向的文本示例。我们的目标是最大化所给残差流方向与 MAEM 生成文本的激活之间的余弦相似度。这种无标签的强化学习目标有助于在不同来源的残差流方向上扩展 MAEM。在实证中，我们发现所得的元模型能产生有信息量的示例：一个 Qwen3.6-27B MAEM 在反转留出激活方面优于语料库搜索或自然语言自编码器（NLA），在大多数留出语言/领域上优于语料库搜索（1000 万 token），并能激活 89% 的留出 SAE 特征。它识别引导向量背后概念的能力与 NLA 大致相当，比语料库搜索更频繁地恢复 LoRA 后门的载荷，甚至能将某些模型工作区的内部独白言语化。与其他元模型（如 NLA）产生的解释不同，MAEM 示例可以通过对主体模型进行一次前向传播来验证，使 MAEM 目标成为扩展元模型训练的可靠替代方案。

    大步骤对抗训练：隐式偏差、优化与锐度

    arXiv / 2026-11-05 / Yi Feng

    对抗训练（Adversarial Training, AT）是提升模型鲁棒性的重要方法。我们研究了对抗训练中确定性梯度下降（Gradient Descent, GD）的动力学。该方向上现有的大多数工作关注小步长或消失步长情形，此时梯度下降类似于连续时间流。然而，这样的步长会使训练效率低下，在实践中很少使用。本文研究大步长常数步长下梯度下降的对抗训练动力学。我们首先研究对抗线性逻辑回归中的梯度下降，重点关注两个方面：模型参数收敛到哪里（隐式偏差）以及损失下降有多快（优化）。随后我们转向神经网络训练，研究对抗训练过程中损失的锐度如何演化。我们的结果推进了对对抗训练中大步长梯度下降行为的理解，并突出了其与标准训练（Standard Training, ST）行为之间的三个关键差异：（i）对抗训练与标准训练之间的隐式偏差差距此前仅在小步长下建立，该差距在任意大的常数步长下依然存在；（ii）与标准训练不同，对抗训练中优化误差不存在一致的收敛速率；（iii）锐度可能呈现两阶段动力学，不同于标准训练中观察到的稳定性边缘行为。

    人类听觉皮层中先验精度、惊奇度、模型更新与音调适应的时间进程

    bioRxiv / 2026-11-06 / van Haren, J. J. G.

    听觉感知产生于输入声学信号与统计预测的持续整合过程，这一过程由更简单的局部适应加以补充。然而，这些并行机制如何在时间中展开仍研究不足。我们利用脑磁图（MEG）记录参与者聆听具有周期性变化的推断统计特性的随机音调序列，对刺激特异性重复抑制、惊奇度、模型更新和先验精度的时空与频谱动态进行了建模。通过在这一动态听觉环境中同时追踪这些计算参数，我们揭示了支配预测性与适应性加工的一个独特的时间层级结构。反映期望的先验精度状态最早出现，随后是快速且并发的重复抑制与惊奇度——分别反映局部声学衰减和全局失配检测。这些初始动态最终汇聚为额顶网络中随后的分布式模型更新。在频谱上，这些成分映射到不同的振荡特征，从适应过程中的θ-α调制，到惊奇度期间的β抑制，以及精度加权期间的广泛频谱衰减。总之，这些发现表明，大脑通过一系列神经过程在不确定的听觉环境中导航，其中快速的局部感觉门控和失配信号先于内部模型的层级化修正。

    非洲猿类的活动范围与领域性

    bioRxiv / 2026-11-06 / Surbeck, M.

    非洲猿类之间的群体间关系差异显著，只有黑猩猩表现出强烈的、往往致命的领域性。经济可防卫性假说提出，这种行为在家园范围可以被经济地防卫时受到青睐，其指标为每日移动距离与家园范围直径之比。为检验这一观点，我们汇编并分析了每种非人类非洲猿类各一个种群的年度家园范围大小、每日移动距离和可防卫性指数的可比数据，并将这些数据与已发表的可比数据整合。我们发现，倭黑猩猩的家园范围显著大于黑猩猩和大猩猩，每日移动距离也更长，这与倭黑猩猩食物丰度更高或更稳定的主流假设相矛盾。黑猩猩和倭黑猩猩的可防卫性指数高于山地大猩猩，但黑猩猩、倭黑猩猩和西部大猩猩之间无显著差异。总体而言，我们的结果表明，仅凭经济可防卫性无法解释领域性的种间变异，且我们目前对Pan属各种之间生态差异的理解必须修正。塑造邻近群体空间利用的可能额外因素包括群体内的配偶竞争。

    人乳寡糖被进化优势诺如病毒基因群II基因型识别的结构基础

    bioRxiv / 2026-11-06 / Pisapia, L.

    引言：结直肠癌肝转移（CRLM）的治疗策略日益复杂，推动了人们对先进预后工具的关注。需要基于既有临床风险评分的外部验证基准，为新兴模型提供参照背景。然而，现有评分仍难以应用和比较，因为它们提供的是分类风险分层而非个体化概率，且模型参数很少公开发表。在此，我们验证并重新校准了七种既有风险评分，以推导个体化复发概率，供未来评分基准测试使用。方法：纳入来自两个三级中心的初次CRLM切除患者：卡罗林斯卡大学医院（回顾性KaroLiver队列[2013-2021年，随访至2025年，n=709]）和奥斯陆大学医院（OSLO-COMET试验队列[2012-2016年，随访至2022年，n=198]）。以无复发生存作为主要结局，评估GAME、m-CS、Fong、Nordlinger、Nagashima、Konopke和Helsinki评分的性能。结果：在KaroLiver的709例患者中（中位年龄67岁[IQR 59-74]；男性434例[61%]），422例（60%）伴有同时性转移，444例（63%）接受了新辅助化疗。所有评分均能显著分层复发风险（log-rank P<0.001；3年时时间依赖AUC 0.63-0.74），尽管不同时间点的性能存在差异。重新校准的模型显示预测复发与观察复发之间具有良好一致性，并在OSLO-COMET中进行了外部验证，净获益大体相当。模型已实现在在线工具PLATO（Personalised Liver metastases risk AssessmenT in Oncology）中。结论：既有CRLM风险评分可转化为临床相关时间点的个体化概率性复发估计，支持患者沟通、风险适应性监测以及下一代预后模型的透明基准测试。

    目的：我们测试了严重至深度视觉障碍者是否在过街时通过更多的头部扫视和/或在路缘停留更长时间来进行补偿。方法：十名视力正常的对照者，在正常视力下以及使用Bangerter滤光片模拟严重至深度视觉障碍（约20/2000）的条件下接受测试；另有17名患有严重至深度视觉障碍的成年人在头戴式显示器中穿越虚拟街道。四种复杂度水平从空街道到有行人化身的让行车辆不等；只有两个最复杂的水平包含移动车辆。使用混合效应模型分析累积绝对头部偏航角和起步潜伏期，并对潜伏期拟合指数-高斯分布。结果：与正常视力相比，模拟严重至深度视觉障碍下起步潜伏期延长1.57倍，临床严重至深度视觉障碍下延长1.82倍（Bonferroni p < 0.001和p = 0.008）。在严重至深度视觉障碍中，额外的潜伏期可归因于潜伏期分布的慢尾（指数成分{tau}在无移动车辆时延长3.40秒，有移动车辆时延长6.20秒；Bonferroni p = 0.037和0.022）；峰值位置无显著差异。起步前，累积绝对头部偏航角随复杂度增加而增大，F(3, 115.8) = 37.16，p < 0.001，且模拟障碍下比正常视力高1.88倍（Bonferroni p = 0.024）；临床障碍与正常视力之间在起步前或行走期间均无显著差异（Bonferroni p [&ge;] 0.479）。行走期间，其随复杂度的增加取决于观看条件，F(6, 109.3) = 5.23，p < 0.001。结论：严重至深度视觉障碍与更长且更多变的路缘停留时间相关，而累积头部扫视无显著增加，尽管行走期间头部扫视随复杂度的增加有所减弱。路缘停留时间与定向和移动实践及无障碍过街设计相关。

    虚拟物理治疗师主导的肩部外科医生转诊分诊（VIRTUE）照护模式的协同设计：一项研究方案

    medRxiv / 2026-11-06 / Gamble, A. R.

    背景：肩袖相关肩痛占肩痛的比例高达85%。指南建议在考虑手术前先进行6个月的非手术治疗，但许多患者在尝试非手术治疗之前就被转诊至外科医生。澳大利亚公立医院肩部手术诊所的转诊率高，意味着许多患者需要等待1至2年才能见到外科医生，在此期间症状可能变得更加复杂，管理成本也更高。一种有前景的解决方案是VIRTUE（虚拟物理治疗师主导的肩部外科医生转诊分诊）照护模式，即由物理治疗师筛查新转诊患者，判断其适合非手术照护还是手术评估。然而，目前尚无此类模式经过共同设计以纳入虚拟照护，也未经随机对照试验评估。目的：本研究的总体目标是共同设计VIRTUE照护模式，使其能够在澳大利亚公立医院肩部手术诊所开展的随机对照试验中进行评估。具体而言，本研究有两个目标（两个阶段）：i）探讨利益相关者对VIRTUE照护模式的可接受性、可行性和实施情况的看法，该模式面向因肩袖相关肩痛被转诊至公立医院肩部手术诊所的成人患者；ii）共同设计VIRTUE照护模式，使其以用户为中心，并为患者、临床医生和关键利益相关者所接受。方法：第1阶段为定性描述性研究，采用半结构化在线访谈，访谈对象为患者、临床医生和关键利益相关者，通过目的性最大变异抽样招募。访谈将在可接受性理论框架和实施研究整合框架的指导下，探讨当前照护体验、对所提模式的看法以及实施的障碍和促进因素。第2阶段将采用基于经验的共同设计方法，包括三次在线工作坊：分别为患者和临床医生及关键利益相关者举办单独的工作坊，然后举办一次联合工作坊。工作坊将探讨第1阶段的发现、对所提模式的看法以及最终确定该模式所需的改进，数据将映射至适应与修改报告框架扩展版。结论：与患者、临床医生和关键利益相关者共同设计VIRTUE，将确保其以用户为中心、可接受且在澳大利亚公共卫生服务中可行，并准备好接受随机对照试验评估。通过促进及时、公平地获得循证照护，VIRTUE可以改善患者结局，确保最需要的人群能够获得专科服务，并提升卫生系统绩效。

    基因型感染终点分析以理解疟疾单克隆抗体CIS43LS的效力和逃逸潜力

    medRxiv / 2026-11-06 / Schwabl, P.

    在疟疾流行区开展的候选疟疾干预措施早期试验，常以“首次感染时间”作为主要疗效终点。该方法不评估初次感染后的感染风险，且在受试者首次感染后对其进行删失，会随着时间推移使对照组中高风险受试者被剔除的比例高于治疗组，从而引入偏倚。随着风险集规模缩小，疗效估计的精确度也可能下降。在此，我们评估了一项干预试验中对所有感染进行基因分型的效用，以确定每位受试者在整个随访期内的总感染发生率。具体而言，我们对一项先前报道的、在330名马里成年人中开展的抗疟单克隆抗体CIS43LS 2期试验中检测到的所有恶性疟原虫感染进行了基因分型。我们确定了每位受试者的分子感染力（molFOI；新恶性疟原虫株的出现率），并将疗效表示为CIS43LS组相对于安慰剂组的molFOI降低百分比（EffmolFOI）。40 mg/kg和10 mg/kg剂量组的六个月EffmolFOI分别为86.5%（95% CI：80.1-90.8）和70.7%（61.0-78.0）。这些估计值与首次感染时间分析的结果相似，但在按试验月份分析疗效以及按入组时恶性疟原虫感染状态分层时更为精确。入组时已感染的受试者EffmolFOI较低，且在试验中更早获得感染，导致各组间随时间推移的风险构成出现系统性差异。基因分型未显示CIS43LS表位存在逃逸多态性的证据。这些结果表明，基因型终点如何能够更全面地理解候选疟疾干预措施。
