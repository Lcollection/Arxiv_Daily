    阐明语言模型数据归因的设计空间

    arXiv / 2026-10-29 / Steven Yu

    语言模型（LM）的数据归因方法通常通过事实检索等下游任务进行评估。然而，现有评估同时改变多个数据集属性，导致无法准确判断归因算法失败的原因。为诊断这些失败，我们探索了LLM数据归因的设计空间，主要聚焦于评估。我们引入了用于事实追踪的受控归因基准（CATT），在其中我们在完全虚构的知识上微调LLM，为归因提供明确的真实标签。这一合成设置使我们能够系统地一次改变一个数据集配置，例如文档冗余和词汇干扰项。借助这一可配置的评估，我们证明冗余和干扰项会持续降低归因性能。我们没有提出新的估计器，而是考察了两个尚未充分探索的设计选择：用于计算梯度的损失函数，以及如何将逐token归因分数聚合为文档分数。我们发现训练文档中真正的因果证据高度局部化，但标准方法通过对整个文档的归因分数取平均，将这一证据稀释为噪声。我们发现，用负对数几率梯度替换标准交叉熵损失梯度，能够从其他无信息token中凸显关键token。然后我们可以仅聚合排名最高的token分数，在我们的诊断基准上，跨多个基线将真实标签召回率提升35至72个百分点。负对数几率校正还可推广到FTRACE-TREX，在我们测试的每种方法上改善反事实重训练性能，最高提升4.9倍。

    提出-过滤-释放：通过私有过滤将噪声缩放至典型敏感度

    arXiv / 2026-10-29 / Moshe Shenfeld

    一个估计器在典型数据上可能既准确又稳定，却对少数可能的记录敏感。差分隐私机制通常将噪声缩放到单条记录的最坏情况影响，这使得这些记录决定了噪声水平，即使其余数据本可允许远更小的噪声。先移除这些记录可以恢复较小的噪声规模，但移除过程本身必须是隐私的。我们提出\emph{提议-过滤-发布}（PFR），它通过隐私地过滤其输入，将一个保护典型记录增删、且适配剩余数据的机制，转变为在标准意义上对每个输入都满足差分隐私的机制。利用我们新颖的过滤步骤，PFR仅需要一个凹的友好性评分，用以衡量一条记录与数据集的契合程度，以及一个友好差分隐私的发布机制，即在被改变记录与剩余数据契合时满足隐私。对于每个这样的评分和发布机制，它在关于记录数量的公开条件下保证差分隐私，因此它是一种通用的隐私原语，可与提议-测试-发布相媲美，而FriendlyCore可视为其实现之一。我们通过为标量统计量、主子空间估计、用户直方图的KL散度、图的有效电阻以及处理规则选择实例化PFR，来说明其通用性。

    微剪辑：电影中精细剪辑的计算支持

    arXiv / 2026-10-29 / Nhan Tran

    在电影剪辑中，每一帧都至关重要。虽然宏观的内容层面剪辑塑造了电影的高层叙事，但微小的局部剪辑往往控制着节奏并引导视觉注意力。例如，剪辑师可以调整片段的精确时间来控制一段有意义的静默的长度，或者切换到突出某个角色对重要时刻反应的镜头。这些微小而精细的剪辑在标准剪辑工具中制作起来缓慢而繁琐，因为用户必须将高层叙事目标映射到低层的逐帧调整。与此同时，这些我们称之为微剪辑的精细尺度调整可以细腻而富有表现力，不同的选择服务于不同的创作目标。在这项工作中，我们首先与专业剪辑师进行了一项形成性研究，以理解微剪辑的结构及其使用方式。然后，我们推导出该结构的数学形式化表述，以开发利用人工智能和优化来使用户探索微剪辑更简单、更高效的工具。最后，我们在多项用户研究和广泛的视频示例中验证了我们的工具。

    重新思考无权重扰动的神经丛林

    arXiv / 2026-10-29 / Nicolas Dufour

    Neural Thickets 假说认为，预训练语言模型位于权重空间中任务特定专家的密集邻域内，而随机高斯扰动可以揭示这些专家。我们复现了所报告的增益，但表明这些增益并不需要这一几何解释。仅扰动单个解码器块就已能恢复大部分改进，而在模型完全冻结并对其输出 logits 添加随机偏置的情况下，在大多数推理任务上可匹配或超过全权重扰动。这表明一种基于输出多样性、基于验证的选择和投票的替代解释。我们将这一观点形式化为 Perturb-Select-Vote（PSV），一种通用流程：生成受扰动的预测器，在小验证集上选择表现优异的成员，并聚合其预测。这一解释将 Neural Thickets 与既有的推理时方法联系起来，包括采样、自一致性和验证器引导的选择。一阶分析进一步表明，小幅权重扰动主要通过其诱导的 logit 偏移起作用。我们将这一分析扩展到视觉领域，其中 logit PSV 在域偏移下显著提升性能，包括在地球观测任务上，而全权重扰动几乎不提供额外收益。总之，这些结果表明，归因于邻近权重空间专家的增益反而可以通过输出多样性、选择和投票获得。Logit PSV 在完全冻结模型的情况下实现了这些收益，为跨语言和视觉的全权重扰动集成提供了一种简单、无需训练的替代方案。

    阅读、分配、路由：面向像素空间生成式Transformer的角色耦合分词

    arXiv / 2026-10-29 / Jiongfan Yang

    像素空间生成式 Transformer 通常对每个图像块使用一个 token，因此捕捉更精细的细节需要更多 token，并使全局注意力的开销日益增大。我们观察到，更精细的细节并不必然需要更多的全局通信：低频结构受益于全局交换，而高频细节可以在局部建模。基于这一洞见，我们提出 SpecSlot，一种像素空间 rectified-flow Transformer，它将输出细节与全局注意力序列的长度解耦。SpecSlot 将每个空间锚点扩展为多个槽位，每个槽位分配一组不相交的 DCT 系数频带；这将锚点密度与频谱细分分离。每个锚点仅最低频的槽位参与全局注意力，而所有槽位在局部交互。这使得模型能够在不扩大全局序列的情况下增加频谱细节。一个空间头进一步对频谱预测添加局部修正，同时生成状态、目标和损失仍保持在像素空间。在 ImageNet-256 上，SpecSlot 在收敛更快的同时，取得了与 FLOPs 匹配的 JiT 对照模型相当的最终 FID。在 ImageNet-512 上，它以少 3.9% 的 FLOPs 将 FID 相对对照模型提升 2.84，并以低 38.2% 的成本将差距缩小到仅比 JiT-B/16 差 0.69 FID。在文本到图像生成上，SpecSlot 在 DPG-Bench 上以低 40.6% 的前向成本超越 JiT-B/8 达 1.06。

    围绕学习密度模型的自适应场景生成用于KL-DRO

    arXiv / 2026-10-29 / Aron Brenner

    分布鲁棒优化（DRO）为数据驱动的两阶段随机规划提供保障，以抵御从有限记录中估计出的分布存在的误差，而标准歧义集在处理该记录中未出现的实现值时各有不同。围绕经验分布的散度球仅包含对记录的重新加权，而传输球还包含支撑在记录之外的分布，包括在数据生成过程无法产生的实现值上的分布，决策随后也要针对这些分布进行对冲。我们转而提出一个以拟合到该记录的密度模型为中心的Kullback-Leibler（KL）球，即学习到的名义分布，它让对手能够按照模型赋予这些实现值的概率成比例地提高代价高昂的未观测实现值的权重。求解由此产生的问题构成第二个困难，因为它只能容纳少量情景，而该规模的独立样本很可能遗漏最坏情况所集中的稀有实现值。因此，我们自适应地构建情景集，在求解有限问题与从学习到的名义分布中抽取新实现值之间交替进行，抽取过程朝向当前决策下的最坏情况引导，并使用重要性权重将抽取结果校正回该模型。在一个多物品报童问题和一个基于真实电网数据的容量扩展问题上，当记录稀缺且模型类能够捕捉使其外推到记录之外的结构时，将球心设在学习到的名义分布而非记录上，可在分布偏移下降低成本，而分布内成本相当。当记录增长或偏移偏离模型已学习到的结构时，这一优势会减弱。

    行李再识别：面向实际应用策略的研究

    arXiv / 2026-10-29 / Quentin Dhôte

    行李重识别（ReID）是视频监控中的一项关键任务，适用于取证、安全或边境管理（可疑或遗留行李识别）以及行李管理（丢失行李找回）。它能够在机场、火车站和边境口岸等复杂环境中，将同一行李在不相交摄像机视图中的观测进行关联。现有方法主要关注在相对干净条件下基于外观的裁剪图像匹配，而现实场景的特点是频繁遮挡、背景杂乱和场景拥挤，这些会显著降低性能。然而，利用来自不同视频流的多张图像和多视图互补性的策略却被忽视了。本文研究了从多个视频流进行检测和重识别行李的端到端流程策略。我们在真实环境获取的基准数据集上评估了不同变体，以解决如何选择和合并同一行李的不同视图与图像，以及在不同环境数据集上训练以在实际应用中整体提升ReID性能的问题。

    从极端天气到农业后果，借助代理式人工智能

    arXiv / 2026-10-29 / Minghan Yu

    极端天气可提前数天预报，但其对农业的影响仍难以预测：预报只能说明风暴将袭击何处，却无法说明哪些作物会受损、风险有多大，而可提供线索的记录分散在众多来源中。我们提出WxCrop，这是首个通过因果分析检验物理可解释天气指数来判断农业灾害的智能体，也是首个结合天气与农业信息、对过去和预报日期可靠预测作物损失的智能体。我们在佛罗里达州以飓风、冰冻和干热为例进行演示，每种灾害的损失模型均依据保险记录校准，同一流程可推广至其他灾害和地区。三项检验表明其可靠性：飓风指数识别有记录的气旋日，AUC达0.98；在留出年份中，有记录的损失复现误差在2%以内；独立生产记录证实了县排名（秩相关0.63）。用户可向该智能体查询各作物组损失占预期季节产值的比例，每个数字均有来源，从而使政府、种植者和科学家能够快速应对农业灾害。

    SonoWorld4D：通过扩散同步从单段视频生成4D视听场景

    arXiv / 2026-10-29 / Derong Jin

    慢性不可预测应激诱导大鼠产生负性认知偏差，并伴随神经发生和功能连接的性别特异性变化

    bioRxiv / 2026-10-31 / Namchuk, A. B.

    背景：女性比男性更有可能被诊断出重度抑郁症（MDD）。MDD的认知症状包括负性认知偏向，即对模糊情境作负性感知，这种偏向可预测MDD发作的起始与严重程度。MDD与涉及认知、情绪、注意和记忆的脑区之间功能连接的变化有关。方法：本研究考察了慢性不可预测应激（CUS）对雄性（n=18）和雌性（n=22）Sprague-Dawley大鼠负性认知偏向的影响。我们评估了海马神经发生以及面对模糊情境时c-Fos的表达，覆盖额叶皮层、杏仁核、伏隔核和海马的15个区域，包括新生齿状回（DG）神经元，以考察认知偏向测试期间的功能连接。我们进行了基于图的网络分析，并构建线性模型以根据区域激活预测模糊情境中的僵直行为。结果：无论性别，暴露于CUS的大鼠比未暴露于CUS的大鼠在模糊情境中僵直更多。CUS降低了两种性别腹侧DG的神经发生，并且仅在雄性中增加了背侧DG新生神经元的激活。面对模糊情境时，CUS雄性杏仁核中c-Fos表达增加。CUS产生了广泛的、性别特异性的网络重组，降低了雄性而非雌性的全局网络效率。模糊情境中的僵直行为可由新生神经元激活与腹侧CA1的激活共同预测，且两者在不同性别中作用方向相反。结论：这些发现表明，性别特异性通路驱动了CUS诱导的负性认知偏向的表达，凸显了在抑郁症负性认知偏向研究中进行按性别分层的临床前和临床研究的必要性。

    无MRI的OPM-MEG在场景想象中恢复内侧颞叶θ波

    bioRxiv / 2026-10-31 / Thornberry, C.

    光学泵浦磁力计脑磁图（OPM-MEG）为传统低温脑磁图提供了一种可穿戴、耐运动的替代方案，将传感器放置得更靠近头皮，原则上提高了对深部源的敏感性。这对于研究受衰老、障碍和疾病影响的皮层下结构（如海马）具有优势。然而，目前尚不清楚能否用OPM-MEG从中颞叶（MTL）恢复出成熟的活动（例如想象新场景时θ振荡的衰减），以及是否需要个体结构MRI。在此，十五名成年人完成了一项场景想象任务。最初，我们对全样本应用了12参数模板配准核心配准流程。在源重建之后，我们恢复了场景想象相较于计数基线时预期的θ（4-8 Hz）功率衰减，在左侧海马旁回出现了一个显著的活动簇峰值。该簇的质心定位于左侧海马（t = -3.55，p = 0.048，全脑FWE校正），且主要局限于左侧中颞叶。我们进一步通过在有这些扫描数据的六名参与者中使用个体T1加权MRI重建流程来支持我们的发现。两种方法产生了相似的全脑地形图，并将MTL θ效应的峰值定位于左侧海马，颞叶联合质心相距3毫米。这些发现提供了证据，表明场景构建网络的θ衰减可以在组水平上用OPM-MEG恢复，而无需个体MRI。

    性身份与年轻人寻求心理保健：一项全国队列研究

    medRxiv / 2026-10-31 / Khanolkar, A.

    目的：关于性少数群体健康的大多数证据集中于量化心理健康不平等，而关于在获取和接受心理保健方面差异的证据有限。本研究基于一项人群队列研究，考察了性身份与年轻成年人自我报告寻求和接受心理保健之间的关联。方法：研究对象为来自英国全国千禧队列研究的12,782名23岁个体（22%为LGBQ+）。采用多变量逻辑回归，依次调整社会人口学因素（性别/族裔/社会经济地位）、过去（14-17岁）和当前（23岁）心理健康状况、受害经历、孤独感和社会支持，考察17岁时评估的性身份（异性恋[参照类别]、主要为异性恋、男同性恋/女同性恋及其他性身份[LGBQ+]）与寻求心理保健之间的关联。在寻求帮助者中，采用多变量逻辑回归考察性身份与23岁时接受心理保健之间的关联。预测概率由逻辑模型估计以便解释。结果：所有LGBQ+群体寻求心理保健的几率均高于异性恋者。在最低调整模型中，寻求保健的预测概率最低为异性恋者（24%），最高为双性恋者（45%）和男同性恋/女同性恋者（49%）。这些显著差异在完全调整模型中有所减弱但持续存在，异性恋者与LGBQ+群体之间的概率差距从25%缩小至10%。此外，心理健康史独立预测了异性恋者23岁时的求助行为，但在LGBQ+群体中则不然。在寻求支持者中，LGBQ+群体接受保健的几率高于异性恋同龄人，其他性身份群体的基线概率最高（35%对15%）。这些差异在调整后基本保持不变。结论：LGBQ+群体面临显著差异，其寻求和接受心理保健的几率均显著高于异性恋同龄人。关键在于，接受保健的较高比率在完全调整后仍然存在，表明这些不平等在很大程度上独立于下游中介因素和心理健康史。
