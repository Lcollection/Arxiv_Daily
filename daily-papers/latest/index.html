    LIBERO-PeRM：个性化机器人操作基准测试

    arXiv / 2026-10-15 / Zhixu Li

    个性化对于通用机器人进入家庭环境并实现真正的实用性至关重要。尽管通用机器人操作已被广泛研究，但个性化机器人操作（PeRM）缺乏一个受控基准来将任务完成与偏好满足区分开来。我们提出 LIBERO-PeRM，一个用于具身智能体偏好学习的基准。LIBERO-PeRM 研究五个问题：1）策略在零样本设置下如何遵循偏好；2）它们如何从演示中学习单一偏好；3）随着演示增加，它们获取偏好的效率如何；4）学习到的偏好如何跨布局和任务泛化；5）策略如何组合偏好并在冲突下表现。我们提出了仿真中可观测偏好的受控表述与分类体系，涵盖运动、技能和用户画像选择。该表述限于可用语言表达的偏好，这些偏好可在不改变任务目标的情况下在 LIBERO 中实例化、可自动评估，并可跨任务复用。基于 LIBERO，我们的程序化流水线生成带有偏好和不带偏好的配对演示。我们创建了五个任务套件（312 个任务），包含高质量演示、丰富元数据和偏好满足度量。实验表明，当前的 VLA 策略在零样本个性化方面表现不佳，而 SFT 使偏好变得可学习。混合训练比顺序适应具有更好的无偏好保持能力，并且与仅偏好训练相比，在上下文提示下提升了性能，但可能削弱运动偏好的学习；偏好泛化、分解和冲突处理仍然困难。代码、数据集和演示可在项目网站找到：https://libero-perm.github.io/。

    Gen4P：视频生成器是四维感知器

    arXiv / 2026-10-15 / Yitong Xia

    我们提出Gen4P，一个从单目视频中恢复4D几何与运动的统一框架。我们表明，预训练的视频生成器可以被重新用作前馈4D感知器，而无需迭代去噪。基于按需查询，Gen4P在单次编码器前向传播中处理干净的视频潜在表示，并通过轻量级交叉注意力解码器预测所请求的4D属性。按需查询的公式化设计实现了灵活的空间采样，而我们提出的连续时间查询进一步提供了时间灵活性。为增强几何知识，我们提出一种直接的插件式解决方案，将预训练的视频深度LoRA作为冻结的几何先验引入，在不增加额外可训练参数的情况下提升整体性能。Gen4P在3D点跟踪、视频深度和相机位姿估计任务上取得了最先进或有竞争力的性能。在野外视频上的定性结果展示了其在保持精细结构的同时跟踪复杂运动的能力。这些结果共同证明了视频生成预训练在统一4D感知方面的潜力。更多可视化结果见https://gen4p.github.io。

    哪些Token应当合并？面向高效图像生成的扩散动力学

    arXiv / 2026-10-15 / SeungJu Cha

    Token merging已成为一种有效的免训练策略，通过减少冗余token计算来加速扩散模型，同时最小化生成质量下降。一个关键挑战在于确定哪些token可以安全合并，哪些应保留用于后续计算。现有方法通过保留与提示对齐的前景区域来应对这一问题，从而保护语义相关的结构。然而，这种文本相关性准则忽略了背景对象以及提示中未明确提及的局部细节，导致结构连贯性下降。在本工作中，我们提出Dynamics-aware Token Merging（DaTMe），一个免训练框架，将token merging建立在底层扩散动力学之上。我们的关键洞见是，token重要性应反映该token在去噪过程中是否仍未解决，以及它是否携带结构信息。为此，DaTMe从Tweedie去噪估计中构建动力学感知重要性图。该图结合了时间信号——衡量预测干净图像在相邻步骤间的变化——与结构信号——捕捉局部高频内容，如边界和精细细节。利用该图，DaTMe在给定压缩比下自适应地将token分配为合并角色：重要token作为锚点被保留，而同时在时间上趋于稳定且在结构上同质的token被选为安全合并候选。在PixArt-a和FLUX上的实验表明，DaTMe在整个图像上保持视觉保真度，突显了扩散动力学作为高效生成中有效的token级合并决策。我们的代码可在https://github.com/SeungJuCha/DaTMe获取。

    SoftCache：面向扩散Transformer的自适应步长缓存

    arXiv / 2026-10-15 / Shimon Malnick

    扩散模型和流模型通过迭代步骤生成样本，每一步都要完整地通过一个大型网络，而这一过程主导了生成成本。免训练缓存通过复用近期评估中的激活值而非重新计算来加速这些模型。动态缓存方法通过将网络输入的廉价探针累积为陈旧度信号，并在其越过阈值时进行一次新的评估，从而决定何时刷新。它们执行硬缓存：该信号是刷新与复用之间的二元开关，且每一步无论新算还是缓存，都按规定的步长推进。我们观察到，该信号所承载的信息远不止这个开关。它低于阈值的幅度，即其余量，可预测复用所引入的误差。我们提出SoftCache，它执行软缓存：余量不再作为二元开关，而是决定每个缓存步推进多远。在余量较大处，采样器跳过若干个预定节点；随着刷新临近，其步长收缩回原始步长。这些自适应跳跃可能落在预定节点之间，使采样器偏离其固定网格。SoftCache无需训练，也不增加任何逐骨干网络的设置：在图像任务上使用FLUX，在视频任务上使用HunyuanVideo和Wan2.1，在3.5倍至6.9倍的加速下，它在全部四项保真度指标上均领先于所有基线方法。

    价值即记忆：面向通用机器人策略的在线价值引导后训练

    arXiv / 2026-10-15 / Wenye Yu

    通用机器人策略的真实世界后训练面临两个挑战：部分可观测性使动作选择存在歧义，而离线后训练方法延迟了来自部署经验的反馈。我们提出Value as Memory（VaM），一个通过价值缓存和在线真实世界强化学习（RL）应对这些挑战的框架。价值缓存以近期价值预测为条件来生成动作，作为任务进度记忆，而在线更新通过结合离线演示、离策略干预和同策略推演来实现及时的策改进，以实现样本高效的适应。因此，VaM从离线RL预热过渡到具有稀疏奖励的在线自主学习。在涉及可变形物体和接触丰富操作的长时程任务中，VaM通过价值缓存获得平均绝对成功率提升$29.4\%$，而通过在线自主学习相比匹配的离线训练获得$32.8\%$的提升。所评估的在线调度在相同梯度步预算下执行$8\times$的策略迭代，且在并发数据收集和训练下每梯度步记录时间降低超过$2\times$。

    利用大型语言模型发现最先进的量子电路

    arXiv / 2026-10-15 / Andi Gu

    目前，大量工作正致力于实现大规模量子信息处理器，但要想实现有用的量子优势，还需要开发高效的量子算法。尽管对许多实际问题而言，主要的资源成本与一小组计算原语相关，但在量子环境下优化这些原语面临着独特的挑战，其中包括普通经典计算中不存在的可逆性约束。在此，我们引入一个进化框架，其中大语言模型（LLMs）提出电路设计，并由一个独立评估器对其进行验证和评分。我们将该框架应用于涵盖数值计算、化学、优化、量子模拟和数论的任务。在八个任务中的七个里，所发现的电路相较于当前最先进水平显著减少了Toffoli门和量子比特的数量。在第八个任务中，搜索发现了一种用于素数域模逆的新可逆架构。通过以不同方式处理可逆性，该架构使divsteps——一种此前用于可逆整数算术不切实际的经典算法——变得可行，并大幅改善了模逆的Toffoli门与量子比特之间的权衡。这些结果为评估器引导的LLM协同设计量子计算的新算法结构打开了大门。

    T2-z：面向机器人世界模型的环境潜在变量测试时优化

    arXiv / 2026-10-15 / Chenyuan Zhou

    预测世界对某一动作的响应，仅凭可观测信息是不够的：机器人必须考虑既不能直接观测也无法明确指定的环境因素，从摩擦力和质量等物理属性到人类定义的环境规则。我们提出T2-Z用于环境潜变量的测试时优化，它通过可学习的环境潜变量增强机器人世界模型，以条件化世界预测。这一紧凑潜变量在无需监督环境因素存在何种因素或取何值的情况下，捕捉潜在的环境变化。在训练期间，T2-Z在两个阶段之间交替：世界模型优化阶段，固定潜变量并学习跨环境的一般动作条件动力学；以及环境潜变量优化阶段，冻结世界模型并优化条件潜变量，使潜变量结构纯粹通过世界预测涌现。在测试时，世界模型保持冻结，并从一次或多次测试时交互中优化新初始化的环境潜变量，使模型适应先前未见的环境配置。在7个模拟设置和4个真实世界机器人任务中，T2-Z将物体预测误差指标从15.20降至7.00，并将动作成功率从33.73%提升至72.96%。其涌现的潜变量在多样视觉场景中捕捉个体因素和复合因素的结构化表示。消融实验进一步表明，T2-Z能够从仅一次测试时交互轨迹中高效推断环境潜变量。

    感知、预测与规划：一种用于第一人称灵巧操作统一世界动作模型

    arXiv / 2026-10-15 / Zirui Wu

    我们提出P$^{3}$-WAM，一个用于第一视角灵巧操作的统一世界动作模型，通过三种互补模式学习三维感知、动作条件预测和目标导向规划：Perceive，从视频中重建关节手部运动和相机轨迹；Predict，在给定动作下生成视觉未来；Plan，以初始图像、语言指令和可选视觉目标为条件，联合生成动作轨迹及其预期视觉后果。我们的模型通过混合Transformer架构将紧凑的结构化三维动作表示集成到预训练视频扩散Transformer中，该架构具有共享基础权重、模态特定适配和双向视觉-动作注意力。随机化模态可见性使视频和三维动作在三种模式中均可作为条件上下文或预测目标。实验表明，统一训练在全部三项能力上均优于单模式训练，包括在视觉-语言模型评估下规划质量的提升。通过统一训练，我们的模型在四个数据集上的三维手部重建和动作条件视频预测方面优于专用基线，同时生成的目标导向操作视频在指令遵循和动作进展方面优于视频生成基线。项目页面：https://p3-wam.pages.dev/

    将生成式验证建立在3D内容之上

    arXiv / 2026-10-15 / Shuanglin Li

    多模态大语言模型（MLLMs）与3D生成的最新进展拓展了3D理解与合成能力。然而，超越视觉保真度，基于3D证据的任务特定正确性仍是一项重大挑战。我们认为，构建可靠的3D系统不仅需要更强的生成与推理能力，还需要验证反馈来识别未满足的要求并解释其违规之处，从而使系统能够反思并改进其输出。此类反馈必须整合多视角观测，并区分真正的不一致与依赖投影的表观差异。我们做出三项贡献。第一，我们提出3DVerifierBench，一个涵盖10项任务的基准，用于评估决策、拒绝解释以及对规格和候选对象受控变化的响应。一项人类研究揭示了人类与最强测试模型GPT-6 Astra之间存在21.6个百分点的差距，而解释感知分析则暴露了拒绝可靠性方面的弱点。第二，我们跨细粒度事实类别分析验证过程，揭示数值和目标绑定中的错误。我们开发了一条可扩展的流水线，结合多视角事实提取、受控3D编辑和原生标注，生成14,126个训练样本，包含矛盾解释和关联的反事实。第三，我们考察验证如何通过候选选择和递归改进来支持3D生成。在人工标注的十六候选池中，预言机选择将完整事实成功率从26.7%提升至90.0%。在一项独立的八输入研究中，人工引导的递归改进对每个输入均满足全部七项要求，而并行Oracle@8下仅满足三项。总之，我们的基准、分析和数据流水线为模型通过可靠的验证反馈反思3D内容奠定了基础。

    终纹床核中的神经元周围网介导成年雄性小鼠应激诱导的焦虑行为

    bioRxiv / 2026-10-18 / Murrall, K.

    焦虑障碍估计影响全球3.014亿人。然而，它们仍然是最难治疗的疾病之一，只有约一半的患者报告症状减轻50%或以上。因此，发现新颖且更有效的治疗方法需要更好地理解焦虑在回路和细胞层面的潜在机制。应激诱导焦虑回路内各脑区神经元可塑性的异常变化，包括终纹床核（BNST）。突触可塑性调节的一种机制是神经元周围网（PNNs）的组织，这些特化的细胞外基质结构对应激高度敏感。在啮齿动物模型中，应激与边缘区PNN数量减少和/或紫藤多花凝集素（WFA）标记减少相关。然而，BNST内PNNs的发育及其在应激反应性中的作用在很大程度上仍不清楚。在本研究中，我们调查了雄性小鼠BNST内PNNs的时空发育，它们首次出现在P30，并持续成熟至成年期，在P210达到最高表达，且特异性位于前内侧BNST。我们进一步表明，应激诱导的焦虑与PNN数量减少和PNN精细结构的显著变化相关，包括前内侧BNST中泄漏性增加。最重要的是，通过软骨素酶ABC酶促去除小鼠前内侧BNST中的PNNs加剧了对急性应激的行为反应，表现为焦虑样行为增加。总之，这些结果突显了前内侧BNST内PNNs在介导对社会心理应激的健康情绪反应中不可或缺的作用。

    快速广义纵向函数主成分分析及其在群体水平神经元动力学中的应用

    bioRxiv / 2026-10-18 / Duffy, K. A.

    函数型数据在众多领域中被广泛收集。针对重复测量中收集的函数型数据，一种建模方法是纵向函数型主成分分析（LFPCA），它允许在多个层次上对变异性进行分解。然而，现有的LFPCA估计方法对于大型或高维数据集而言计算需求较高。在此，我们提出快速广义LFPCA，这是一种新颖的估计技术，它沿函数域对数据进行分箱，并在每个箱内拟合边际混合模型。模拟结果表明，所提出的方法比现有技术快数个数量级，同时达到相似的精度，使LFPCA能够扩展到观测采样更密集、样本量更大的数据集。我们将所提出的技术应用于建模深部脑刺激（DBS）开启和关闭状态下的神经元放电率数据，以研究该干预如何调节群体水平的神经元活动。我们的结果表明，神经元间变异的绝大部分可以由四个主成分解释，这些主成分与神经元放电的个体差异以及所研究的臂部操作范式有关。我们还发现，DBS显著增加了放电活动的变异性，这可能是由一部分神经元对DBS响应而增加的放电所驱动，这一新见解在以往的分析中未曾获得。实现所提出方法并运行模拟研究的代码包含在补充材料中。

    在空间基因组学中高分辨率地确定细胞系统发育和迁移

    bioRxiv / 2026-10-18 / Zhang, D.

    细胞迁移和肿瘤演化是组织稳态与癌症生物学的核心问题。空间基因组学的快速发展使得利用体细胞突变在人体组织中原位追踪这些过程成为可能。然而，空间基因组学测量中频繁的数据缺失使这一目标的实现面临挑战。在此，我们提出StarTrak（用于体细胞变异识别与追踪的空间谱系重建分析），一个在单像素空间分辨率下进行体细胞变异识别和谱系重建的框架。StarTrak采用神经网络框架，整合突变证据（来自核DNA和线粒体DNA测序读数）、空间邻近性、组织学图像和转录组状态，以识别具有空间信息量的突变模式。它在多种组织类型和空间组学平台上表现稳健（在空间ATAC-seq中尤为成功）。将StarTrak应用于肿瘤切片，我们推断出突变肿瘤细胞向邻近非恶性组织的迁移，并重建了与不同空间区域相关的不同谱系树。值得注意的是，我们识别出转录组状态几乎相同但突变谱不同的肿瘤区域。此外，对于皮肤切片，StarTrak在非恶性表皮中识别出与阳光相关的突变，并有证据表明这些突变表面细胞向更深皮肤层迁移。总体而言，通过将突变识别与空间背景相结合，StarTrak能够实现空间分辨的细胞迁移和细胞系统发育推断。

    早期青少年任务控制网络功能、认知与环境之间的纵向关联

    bioRxiv / 2026-10-18 / Paige, K. J.

    “任务控制”额顶网络和背侧注意网络的神经成熟被认为支持青少年认知和适应功能的发展。此外，理论认为家庭和邻里环境塑造大脑网络的发展。然而，很少有纵向研究考察大脑网络机制与认知和适应功能、或与可能塑造这些机制成熟的环境因素的共同发展。本研究填补了这些空白。我们使用了来自青少年大脑认知发展（ABCD）研究的纵向数据，涵盖从童年晚期（平均年龄=10岁）到青春期早期（平均年龄=12岁）（n=4862）。通过对n-back任务中认知需求的神经反应进行纵向双因子建模，估计了任务控制网络功能的稳定且具有构念效度的神经特征。采用多变量潜在变化分数模型考察该特征与认知效率（扩散模型的漂移率）、教师报告的注意问题、家庭冲突和邻里安全性的共同发展。模型控制了基线家庭收入。研究识别出任务控制激活与认知效率之间稳健的双向关系，且效率与任务控制激活的潜在变化分数呈正相关。认知效率与注意问题之间也观察到类似的双向关联。基线家庭收入预测了任务控制网络功能的变化速率。本研究表明，任务控制网络功能与认知共同发展，进而支持青春期早期注意功能的发展。此外，研究结果凸显了这种任务控制网络功能的神经特征在理解认知发展的神经基础以及环境经历塑造大脑和行为的机制方面的效用。

    一项受解剖学约束的转录组筛查识别出19个基因组合，其在人类躯体感觉系统中具有有序的区域相似性模式

    bioRxiv / 2026-10-18 / Boni, G. A.

    神经解剖学通路连接着特化的脑区，但区域转录组谱是否保留与通路顺序一致的关系仍不清楚。我们从神经解剖学文献中定义了候选通路及其可用的组织代表，随后在基因表达身体指数（BIGE）这一涵盖细胞和组织的人类微阵列资源中筛选了10,262个基因。筛选要求基因在一条通路的每个已定位区域中均有表达，并限制单一区域的主导性。它在三条通路中鉴定出23个具有足够覆盖度的候选基因；其中19个符合背柱-内侧丘系（DCML）代表的标准，并构成固定面板。我们在六名艾伦人脑图谱（AHBA）供体的三个中枢区域代表中评估了该面板：分配给楔束核和薄束核（Cu/Gr）的样本聚合、背侧丘脑内腹侧分部的外侧核群（DTLv）以及中央后回。区域顺序对比比较了解剖序列中相邻配对（Cu/Gr-DTLv和DTLv-中央后回）的平均相似性与Cu/Gr-中央后回的相似性。两个顺序相邻的相关性在全部六名供体中均为正；该对比在五名供体中为正，并达到均值T = 0.345175（精确符号检验，P = 0.109375）。该面板超过了在可比选择约束下生成的50,000个基因集的两个分布（P = 0.027919和P = 0.026579）。在描述性解剖比较中，它在240种组合中排名第三，并在目标及全部16种单区域替换中排名第一。全部50,000次每基因单探针分析均保持T > 0，广泛的神经元表达对比在延髓、丘脑和皮层中均为正。空间支持取决于零模型，在全供体替代模型下的证据（P = 0.003860）强于主要隔室内部模型（P = 0.051179）。这些发现鉴定了一个固定基因面板，其区域相似性与DCML系统所代表的中枢顺序一致，并为在一个独立的、解剖学解析的数据集中进行前瞻性评估定义了一个具体假设。

    全基因组关联荟萃分析中的样本重叠：跨显著性阈值的实际比较

    bioRxiv / 2026-10-18 / Xu, Z.

    Meta分析在全基因组关联研究（GWAS）中被广泛用于整合多项研究的证据，而无需个体水平数据。然而，随着Meta分析纳入的研究数量及其样本量持续增长，同一参与者可能被纳入不止一项研究。这种样本重叠会导致研究间存在依赖性，违背了标准Meta分析方法所依赖的独立性假设。HostSeq是一项加拿大倡议，汇集了15项临床和流行病学研究，包含约10,000名感染SARS-CoV-2病毒的加拿大人的DNA样本。我们在不同参与研究中观察到重复样本。这一观察提出了一个重要的实际问题：样本重叠对关联结果有何影响，何时应关注这种重叠？受这一实际问题的驱动，我们试图比较五种Meta分析方法，并以已知真实样本重叠的参考mega分析为基准评估其性能。我们表明，当样本重叠程度相对较小时，其对关联结果的影响极小，即使在全基因组显著性阈值= 5*10 -8 下也是如此。我们通过大量模拟研究以及在HostSeq内重叠队列中的应用展示了这些发现。

    理解热纤梭菌中的底物运输与代谢以提高生物燃料产量

    bioRxiv / 2026-10-18 / Richardson, I. D.

    作为一种纤维素分解专性微生物，热纤梭菌主要发酵纤维素及其降解产物。然而，其底物范围的完整广度仍知之甚少。在本研究中，我们考察了热纤梭菌转运和代谢多种替代碳底物的能力。我们采用四唑染料测定法评估野生型（WT）热纤梭菌（菌株LL1004）转运和代谢190种不同底物的能力，鉴定出18个阳性命中 and 27个假阳性。这些发现指导我们选择了22种底物，用于野生型在10 g/L替代底物加1 g/L纤维二糖条件下的批式发酵。我们鉴定出八种被完全或部分消耗的底物（纤维二糖、葡萄糖、果糖、山梨醇、熊果苷、松二糖、丙酮酸、葡萄糖-6-磷酸），两种相互转化的底物（苹果酸、富马酸），七种可能转化为未鉴定发酵产物的底物（木糖、山梨糖、塔格糖、半乳糖、甘露糖、鼠李糖、岩藻糖），以及五种未被消耗的底物（甘油、乙酸、乳酸、丙酸、木糖醇）。山梨醇和丙酮酸的还原程度分别高于和低于纤维二糖，因此被选用于进一步分析其对氧化还原平衡和产物形成的影响。在山梨醇和丙酮酸上的批式发酵表明，热纤梭菌的乙醇生产可能部分受限于还原当量的可用性。总体而言，本研究证明了替代碳底物作为调控代谢、氧化还原平衡和发酵产物分布的工具的实用性，有助于进一步理解诸如热纤梭菌等厌氧嗜热细菌在生产生物燃料和目标生物化学品方面的代谢。

    脱卤球菌对六氯丁二烯的微生物还原脱氯

    bioRxiv / 2026-10-18 / Wang, X.

    六氯丁二烯（HCBD）作为一种持久性有机污染物（POP），对生态环境和人类健康构成重大威胁。尽管厌氧微生物转化是一种有前景的修复策略，但所涉及的具体微生物和代谢机制仍知之甚少。本研究证明，以乳酸作为电子供体，成功从河流沉积物中富集到能够转化HCBD的厌氧微生物菌群。在240天内，62.5 mol的HCBD依次经过五氯丁二烯（PCBD）、四氯丁二烯（TeCBD）、三氯丁二烯（TCBD）和二氯丁二烯（DCBD）脱氯，最终转化为氯丁二烯（CBD）。同时添加HCBD和三氯乙烯（TCE）可实现两种化合物的完全去除。16S rRNA基因测序和定量PCR显示Dehalococcoides得到富集，其种群增长与HCBD和TCE的脱氯相关联。本研究表明，在富集培养物中Dehalococcoides的生长与HCBD转化相关，拓宽了我们对Dehalococcoides代谢能力的认识，并鉴定了这一重要环境过程的候选基因，为HCBD污染场地的生物修复提供了有价值的见解。

    可扩展的酶反应检索助力宏基因组生物催化剂发现

    bioRxiv / 2026-10-18 / Luo, D.

    酶催化反应驱动代谢，并在生物技术和可持续合成中实现多种应用，但为未表征酶分配催化功能以及为目标反应寻找酶仍是重大挑战。尽管机器学习近期取得进展，将酶功能预测转化为在庞大未表征蛋白质和生化反应空间中的系统性发现仍具挑战性。本文提出EzHit，一个用于双向酶反应检索的轻量级框架。在酶注释、孤儿反应检索和家族特异性微调基准测试中，EzHit取得了强劲的排名靠前性能，并优于代表性的酶反应匹配基线。我们进一步表明，基于马氏距离的几何置信度提供了比概率推导的不确定性度量或证据学习更有用的可靠性估计，能够对高分候选进行置信度感知的优先排序。得益于其效率，EzHit被应用于近万亿规模的OMG_Prot50与RHEA筛选，在3027万条预测酶序列中产生了82.0亿条保留的酶反应关联。实验验证进一步确认了EzHit优先排序的宏基因组酶候选对稀疏注释反应的活性。总之，这些结果确立了EzHit作为酶注释、反应引导挖掘和生物催化剂发现的可扩展框架。
