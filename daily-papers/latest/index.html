    靶向登革病毒NS3解旋酶：茶树儿茶素的生化与计算评估作为潜在治疗先导化合物

    bioRxiv / 2026-09-03 / Wojciechowski, M. K.

    登革病毒血清型2是一种人类致病性黄病毒，编码非结构蛋白3（DEN2-NS3），属于超家族2病毒解旋酶。DEN2-NS3包含N端蛋白酶结构域和C端RNA解旋酶/核苷5'-三磷酸酶（NTPase）结构域，对病毒复制至关重要。该酶利用NTP水解产生的能量沿双链RNA底物进行3'-至-5'方向转位。鉴于(-)-表没食子儿茶素没食子酸酯（EGCG）对寨卡病毒的高效抑制作用，本研究探讨了三种儿茶素，即EGCG、(-)-表儿茶素没食子酸酯（ECG）和(-)-表没食子儿茶素（EGC），是否可作为DEN2-NS3的有效抑制剂。酶抑制实验表明，催化结构域DEN2-NS3(S171-K618)被没食子酰化儿茶素（EGCG和ECG）强烈抑制，并通过酶偶联验证实验得到确认。相对于NTPase活性的抑制常数（Ki）及提示性抑制模式为：EGCG的Ki = 400 ± 86.6 nM（混合型），ECG的Ki = 550 ± 250 nM（反竞争型），EGC的Ki = 18.3 ± 4.2 μM（混合型）。冠状病毒抑制剂SSYA10-001抑制DEN2-NS3（Ki = 10.2 ± 0.3 μM，混合型）。使用SiteMap的计算流程预测了一个与RNA结合区域相关的可成药口袋，涉及残基ASP290、ARG387、ASP409、MET429、HIS487、ASP541、ARG599和ASP603。通过200纳秒分子动力学模拟分析儿茶素的结合稳定性。计算结果显示，EGCG和ECG保持高稳定性，与ASP603、ARG599、ASP541和ARG387形成高度持久的共享氨基酸接触（>45%占有率）。生化和计算数据支持这些没食子酰化儿茶素先导化合物，提示其可能结合于一个两亲性口袋内。未来的结构优化以形成稳定的前药衍生物，可能产生有前景的抗病毒候选药物。

    肌纤维类型分布对步态生物力学的影响：一项预测性模拟研究

    bioRxiv / 2026-09-03 / Daehlin, T. E.

    肌纤维类型分布影响肌肉的代谢和收缩特性，其对步态生物力学的影响难以在体内直接研究。本研究旨在预测肌纤维类型分布对模拟步态的代谢成本和生物力学的影响。在预测性肌肉骨骼模拟框架中实现了一个独立表示慢肌和快肌纤维的肌肉模型，并用于研究在不同运动速度（1.0 - 4.5 m·s-1）下，纤维类型分布如何影响运输成本、步幅长度、步频以及慢肌和快肌纤维所做的机械功。随着慢肌纤维比例的增加，运输成本降低，而在步行过程中，步幅长度和步频受纤维类型分布的影响最小。在跑步过程中，当速度高于或低于一个阈值速度时，运输成本分别随慢肌纤维比例的增加而降低或升高。在此阈值速度以上，随着慢肌纤维比例的增加，步频降低而步幅长度增加。这些时空特征的转变可能使关键肌肉在其峰值机械效率附近运作。总之，纤维类型分布可能以运动速度依赖的方式影响步态的能量学和生物力学。

    动态恢复中的动力学机制

    bioRxiv / 2026-09-03 / Ciarchi, M.

    生物衰老伴随着表观遗传修饰和染色质组织的系统性变化。衰老效应的逆转，即年轻化，可通过在细胞和生物体中瞬时诱导修饰这些标记的因子在实验上实现。在此，我们表明年轻化实验的关键特征源于动态表观遗传标记与染色质三维构象之间的生物物理相互作用。利用最小场论和分子动力学模拟，我们展示了该系统以三种不同的时间尺度响应。中间阶段满足成功年轻化的必要条件。在该阶段，系统在分界线附近停留，允许高表观遗传可塑性，而染色质构象中保留的记忆则能恢复原始表观遗传相关性。测序数据的分析进一步支持了染色质压缩与表观遗传相关性之间预测的耦合。我们的结果为年轻化如何重塑与年龄相关的表观遗传状态而不不可逆地抹除细胞身份提供了物理解释。我们识别出一种通用机制，通过该机制，存储在慢速结构变量中的记忆允许对较快内部状态进行可逆重塑。

    胰腺导管腺癌中，血管外凝血通过肿瘤内在的PAR1信号稳定促纤维化基质状态

    bioRxiv / 2026-09-03 / Choi, S. R.

    胰腺导管腺癌（PDAC）表现出促结缔组织增生性间质，其具有依赖于情境的肿瘤抑制和肿瘤促进作用，凸显了选择性重编程间质状态的需求。血管外凝血是PDAC肿瘤微环境的一个显著特征，但其是否作为纤维化间质状态的上游调节因子，而非仅仅是肿瘤相关血管功能障碍的副产物，此前尚不清楚。在此，我们确定血管外凝血为一种肿瘤扩增的调节模块，通过肿瘤内在的蛋白酶激活受体-1（PAR1）信号传导稳定促纤维化间质状态。为机制性探究这一轴，我们将人类肿瘤生物信息学与微生理肿瘤-间质（MPTS）模型相结合，该模型在受控凝血暴露下重建肿瘤-间质相互作用，随后在体内进行跨尺度验证。对癌症基因组图谱（TCGA）的分析显示，F2R（PAR1）表达在不同肿瘤中具有异质性，其高表达与纤维化转录程序及生存期缩短相关。一致地，凝血酶在肿瘤细胞和癌症相关成纤维细胞（CAFs）中诱导协调的促纤维化程序，这在MPTS中得到重现，其中肿瘤内在PAR1是细胞外基质沉积扩增和CAF激活所必需的。机制上，PAR1信号传导扩增了肿瘤-间质通讯，部分通过诱导TGF-β1依赖性通路实现，建立了一个强化反馈回路以稳定纤维化重塑。PAR1的药理学抑制选择性抑制了肌成纤维细胞样CAFs内的纤维化转录程序，同时减少了其他CAF亚型的丰度，重编程间质状态并在MPTS和体内模型中减弱肿瘤进展。这些发现确立了凝血-PAR1轴作为PDAC间质结构的上游组织者，并确定药理学PAR1抑制为一种基于机制的选择性重编程促肿瘤间质的策略。

    体外模拟人类造血干细胞定向分化揭示IL-33是巨核细胞生成的调控因子

    bioRxiv / 2026-09-03 / Calderbank-May, E. F.

    特定血液谱系的定向分化事件源于单个造血干细胞（HSCs），并受到应激、炎症和疾病的影响。然而，由于缺乏可操作的体外模型，对这些事件在人类造血中如何调控的理解受到限制。在本研究中，我们引入了一种新型早期祖细胞分化（EPD）检测方法，用于研究人类49+ HSCs的初始谱系定向，该系统忠实再现了体内观察到的细胞状态。结合单细胞组学方法和单细胞功能检测，我们证明IL-33直接作用于人类49f+ HSCs，激活MAPK通路，增强其向巨核细胞-红系-肥大细胞祖细胞及随后的巨核细胞生成的定向分化。这一过程不影响HSC自我更新，通过加速与红系、巨核细胞和肥大细胞谱系相关的染色质程序建立来实现。我们的发现展示了EPD模型在识别人类HSC分化分子调控因子方面的实用性，并揭示了IL-33在造血中的新作用。

    丝状伪足支架多磷酸盐决定细胞黏附与侵袭的选择

    bioRxiv / 2026-09-03 / Rai, A.

    无机多聚磷酸盐（polyP）是一种在所有生命中保守的古老聚合物，在每一个主要细胞区室中发挥细胞类型和位置特异性的功能。然而，它在质膜上的作用——在许多原代细胞中polyP在此积累至峰值水平——在很大程度上仍属未知。在此，我们确定polyP是丝状伪足的稳定组分，丝状伪足是基于肌动蛋白的膜突起，控制细胞粘附、接触抑制和趋化性。提高细胞内的polyP水平可增加丝状伪足的稳定性并增强细胞粘附，而减少polyP则加速丝状伪足的解体并促进细胞迁移。机制上，我们发现polyP作为结构性的丝状伪足支架，招募并组织IRSp53——一种诱导膜弯曲的蛋白质。我们显示，转移性成纤维细胞和乳腺癌类器官相对于其非转化对应物，携带显著减少且细胞内重排的polyP水平。通过脂质纳米颗粒递送恢复内源性polyP可抑制其侵袭性表型，并逆转促转移基因表达特征，提示polyP是一种原始肿瘤抑制因子。

    Rho GTPase激活蛋白SYDE1和SYDE2的功能表征

    bioRxiv / 2026-09-03 / Song, C.

    人类基因组编码超过60种含有Rho GTPase激活蛋白（RhoGAP）结构域的蛋白质，其中许多在其靶标特异性和生物学作用方面仍未得到充分研究。SYDE1和SYDE2是两种此类孤儿RhoGAP，关于它们生化及细胞功能的研究很少，且对其同源GTPase的鉴定存在相互矛盾的报道。我们先前在筛选c-Jun N端激酶底物时识别出SYDE1和SYDE2。在此，我们显示SYDE1和SYDE2相对于其他丝裂原活化蛋白激酶（MAPKs），优先被JNK1磷酸化，磷酸化位点位于激酶对接区域附近。纯化的SYDE1和SYDE2被证明对RhoA、Rac1和Cdc42具有显著的催化性GAP活性。然而，上调或下调SYDE1/2表达均未导致这些GTPase中任何一种的整体GTP负载出现可检测的变化。尽管如此，我们证明SYDE1和SYDE2，在部分依赖GAP活性的情况下，增加细胞铺展和粘着斑数量，并促进HEK293细胞中更具方向持久性的迁移。综合这些发现，确立了SYDE1和SYDE2作为强效JNK底物，对一组Rho GTPase具有催化活性，并揭示了SYDE1和SYDE2在调节细胞形态、粘附和迁移中的基本功能。

    南美洲南部温带雨林中，林下树木经历穿透雨截留降水处理后的生理与解剖叶片适应性。

    bioRxiv / 2026-09-03 / Castro, B.

    水分输入是生态系统的关键组成部分。水分决定了生物群落的功能、组成和结构；因此，其可用性的任何变化都会对生态系统特征产生影响。此外，生态系统水分平衡的改变会影响其持久性以及生化循环，如碳循环和氮循环。森林是利用大量水分构建的生态系统。因此，树木作为最古老的活植物，是这些生态系统中的主要物种，也是这一非生物元素的主要管理者。树木从土壤中吸收水分，将其储存在生物量中，并通过叶片气孔与环境交换水分。它们还用树冠拦截降雨和雾气。所有这些水分也被传递给栖息在这些生态系统中的整个生物多样性。水分输入的任何变化都会影响上述网络。树木改变其解剖结构或生理过程的能力，即适应新气候的能力，在维持生态系统特征方面具有巨大优势。在本研究中，我们利用降水排除实验来揭示耐荫林下树木的适应机制，这些树木未来将成为寒温带雨林的主要组成部分。我们评估了这些物种在水分利用中涉及的不同解剖和生理叶片性状。我们假设，正如类似实验中所观察到的，物种会通过相应调整其功能性状来采取更保守的水分利用策略。与我们的假设相反，我们发现栖息于这一温带生态系统中的林下树种在水分利用上不会变得更加保守。在最小但显著的差异中，大多数研究物种在降水排除处理下表现出的性状被证明是水分消耗型，而非保守型。我们将这些对比性变化归因于根系代谢的缓解，这是由于奇洛埃岛这些森林所栖息的土壤被水淹没所致。

    不同景观要素的土壤在对多种全球变化因子的响应上存在差异。

    bioRxiv / 2026-09-03 / Hu, T.

    全球变化因子（GCFs）已知会影响多种土地利用类型下的陆地生态系统，包括农田、草地和森林。然而，同一区域内不同景观要素对相同全球变化压力的响应是否存在差异仍不清楚。在此，我们利用从共位农田、草地、松林和橡树林采集的四种土壤来研究这一问题，这些土壤代表了同一区域气候条件下不同的景观要素。每种土壤分别暴露于六种单一GCFs（增温、干旱、氮沉降、盐度、微塑料和抗生素）之一，以及所有六种因子组合处理。我们发现，景观要素对相同GCFs表现出强烈分化的响应。在组合胁迫下，土壤功能的影响也因土壤类型而异，其响应根据土壤和响应变量的不同而偏离不同的零模型预测。此外，在多重重叠胁迫下，景观要素特有的响应模式变得更加显著。总体而言，我们的研究结果表明，即使共享气候和地理条件，景观异质性也代表了抵抗和响应全球变化能力的镶嵌体。因此，全球变化评估和生态系统模型应更好地考虑景观层面的异质性，而旨在增强生态系统恢复力的管理策略应针对各景观要素进行定制。

    乌干达卡文佩国家转诊医院妇女紧急流产后护理体验：一项定性描述性研究

    medRxiv / 2026-09-03 / Saad Sessimba, K.

    背景流产后照护（PAC）涵盖紧急治疗、咨询、避孕服务及转诊联系。紧急流产后照护（EPAC）作为PAC中挽救生命的关键组成部分，处理急性流产相关并发症，包括出血、败血症、妊娠物残留及剧烈疼痛。在乌干达，堕胎受到法律限制且社会污名化，女性的照护体验受临床紧迫性、恐惧、道德脆弱性、提供者互动及结构性卫生系统制约的影响。尽管EPAC对孕产妇生存至关重要，但关于女性在乌干达转诊医院环境中如何解读和评价其照护体验的定性证据仍然有限。本研究探讨了女性在卡文佩国家转诊医院（KNRH）接受EPAC的体验，并识别了塑造这些体验的因素。方法采用定性现象学设计。对2026年3月至4月期间在KNRH接受EPAC的16名女性的深度访谈记录进行了归纳主题分析。社会生态模型（SEM）作为解释框架应用。结果识别出六个主题：（1）生存和身体缓解作为优质照护的直接衡量标准；（2）治疗过程中的疼痛、恐惧和情绪困扰；（3）安慰和支持作为对抗脆弱性的缓冲；（4）压力下的尊严：EPAC中的沟通和隐私；（5）照护路径中的结构性障碍；以及（6）出院后的体验：恢复不完整和不确定性。照护常通过生存视角被评价，但这些叙述与剧烈程序性疼痛、隐私受损、延误、经济负担及出院后支持不足并存。KNRH的EPAC被体验为一种复杂遭遇，受身体脆弱性、人际动态和系统层面制约的影响。结论加强EPAC需要以患者为中心的方法，将临床效果与尊重性沟通、疼痛管理、改进分诊及结构化出院后支持相结合。

    在奥密克戎中坚持，然后呢？2018至2022年美国急诊护理人力退出前基线，及其对2026年NSSRN周期的启示

    medRxiv / 2026-09-03 / Squire, K.

    背景美国急诊科作为医疗和社会服务的剩余接入点，服务于包括农村社区、无保险人群、精神健康和成瘾患者以及无家可归者在内的人群。决定科室功能的人力变量（经验密度，即科室劳动力中累积临床判断的集中度）并未在医院会计系统中测量。目的记录美国急诊护理在2018年和2022年全国注册护士抽样调查（NSSRN）周期中劳动力构成的变化，并为2026年周期提出可证伪的预测。方法我们使用扩展自Castner等人（2024）的四重急诊科定义及医院床边限制比较组，分析了NSSRN公共使用文件。方差估计采用2018年的刀切复制权重和2022年的连续差异复制。倦怠通过Norful等人（2023）的离职原因代理指标跨周期操作化，并使用2022年直接倦怠条目进行敏感性分析。结果2008年至2022年的15年轨迹记录了渐进的经验密度压缩：急诊科15年以上资深护士群体在疫情前十年间从41.9%降至28.0%，资深群体损失近三分之一，平均经验密度下降19.6%，随后在资深护士留守疫情急性期后适度回升至33.3%，使急诊科成为所有医院环境中最为年轻的科室。医院非急诊科床边护士在周期之间失去资深任期（平均自首次执照起年限15.65[-&gt;]14.06年；15年以上占比43.5%[-&gt;]38.7%），而急诊科护士保留其资深尾部（平均11.60[-&gt;]12.58）。倦怠认可度在两组人群中急剧上升（非急诊科27.3%[-&gt;]46.0%；急诊科34.2%[-&gt;]61.2%），急诊科与非急诊科差距扩大超过一倍。控制任期后，急诊科状态在2018年与倦怠无独立关联（OR 1.15，95% CI 0.83-1.59），但在2022年强烈相关（OR 1.92，95% CI 1.44-2.55；p<.001）。直接倦怠条目显示平行模式（OR 2.92，95% CI 1.62-5.28）。结论疫情时代出现了一种特定于急诊护理的环境相关倦怠效应，劳动力构成控制无法解释。2022年周期建立了离职前基线，2026年NSSRN将作为后奥密克戎资深护士离职的可证伪测试。护理管道替代滞后超过2026年数据到来前的间隔；不作为的后果落在依赖急诊科剩余接入的人群身上。

    中国亚热带城市甲型和乙型流感阳性率的气象驱动因素：一项整合分布滞后非线性模型与深度学习的六年监测研究

    medRxiv / 2026-09-03 / Xie, L.

    亚热带地区的流感传播受复杂、非线性的气象条件影响，而基于监测的预测在COVID-19期间又因检测强度波动和非药物干预而进一步复杂化。现有方法要么仅刻画滞后环境关联而无预测能力，要么应用深度学习但缺乏清晰的流行病学可解释性。利用中国东南部亚热带沿海城市莆田2018-2023年六年的多站点流感监测数据，我们开发了一个两阶段框架，以刻画气象关联并改进短期预测。流感阳性率作为主要结局指标，以减轻与检测相关的监测偏倚。构建分布式滞后非线性模型（DLNMs）估计气象变量与流感阳性率之间亚型特异性的滞后关联，并开发了集成气象、自回归和社会行为协变量的贝叶斯优化长短期记忆（LSTM）网络，用于预测甲型和乙型流感活动。甲型流感阳性率与较暖条件相关，在15°C时达到峰值（相对风险[RR]=3.01，95%置信区间[CI]：1.03-8.78），且与较窄的昼夜温差相关；而乙型流感阳性率与较冷（8°C；RR=26.12，95% CI：7.79-87.61）、较潮湿（91%；RR=1.52，95% CI：1.00-2.29）和较低辐射条件相关。LSTM在两种亚型上的预测误差均低于协变量匹配的基线模型（多元自回归积分滑动平均[ARIMA]和极端梯度提升[XGBoost]）（甲型流感平均绝对误差[MAE]：0.009对比0.136[ARIMA]和0.138[XGBoost]；乙型流感：0.002对比0.049[ARIMA]和0.070[XGBoost]；甲型流感对称平均绝对百分比误差[SMAPE]：0.521对比1.212和1.081；乙型流感：0.484对比0.810和0.737）。协变量消融和SHapley加性解释（SHAP）分析表明，历史阳性率和检测相关变量在监测变异性下对预测稳定性有实质性贡献。在三明市的外部评估提供了模型可移植性的初步证据。这一整合的DLNM-LSTM框架为刻画亚型特异性气象关联和改进亚热带地区流感预测提供了一种可解释的方法。
