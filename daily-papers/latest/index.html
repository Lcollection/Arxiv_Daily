    可靠的树木识别从稀缺标注中用于森林资源清查扩展

    arXiv / 2026-11-18 / Luiz Fernando Souza Luz

    来自无人机影像的单木树冠（ITC）物种级清单受限于标注成本：在热带森林中，许多物种仅有少量经野外验证的树冠作为代表。我们提出一个可靠的树木招募框架，通过在RGB无人机正射影像上迭代自训练一个多任务DeepLabV3网络来扩大小规模标注清单，该网络将语义分割与树冠距离回归头相结合。在每次迭代中，候选树冠只有在通过基于类别概率和距离图的置信度过滤器以及基于树冠面积和实心度的形态学过滤器后，才能进入训练清单，每个物种最多新增五个树冠，从而使招募样本与参考清单保持一致。我们在两个巴西站点评估该框架：阿克里州的一处亚马逊雨林（17个物种，355个标注树冠，4厘米地面采样距离）和马腊尼昂州塞拉多的一处森林站点（4个物种，51个标注树冠，1.8厘米地面采样距离）。经过20次迭代，保留树冠的数量在阿克里州从约500个增长到960个，在马腊尼昂州从约700个增长到超过3100个，同时树冠级F1超过单任务和多任务DeepLabV3基线（53.5%对50.0%和45.2%；92.2%对79.7%和83.6%）。该框架提供了一条低成本途径，可利用消费级无人机和有限的野外工作来扩展物种清单。

    ScaleBench：一个可扩展且可复现的Kubernetes自动扩缩容研究实验平台

    arXiv / 2026-11-18 / Ze Wang

    自动扩缩容通过在运行时动态调整计算资源，使云原生应用能够满足其SLO。近期研究探索了广泛的先进自动扩缩容方法，包括基于规则、基于优化和基于机器学习的技术，以解决传统资源管理策略在云原生环境中的局限性。尽管取得了显著进展，学术创新与其在真实环境中的实际采用之间仍存在相当大的差距。例如，Kubernetes部署通常依赖反应式的、基于CPU的Horizontal Pod Autoscaler，限制了更先进自动扩缩容方法的采用。近期研究调查了自动扩缩容配置和可复现性能评估等挑战；然而，基于研究的自动扩缩容方案在Kubernetes环境中的实际部署、集成复杂性和运维开销受到的关注有限。为弥补这一差距，我们提出ScaleBench，一个原生Kubernetes实验平台，用于实现可扩展且可复现的自动扩缩容解决方案评估。与现有方法不同，ScaleBench将自动扩缩容方案集成为原生Kubernetes组件，使研究人员不仅能够评估扩缩容性能，还能在真实的云原生环境中评估部署特性和集成需求。我们通过案例研究评估多种自动扩缩容方法，展示了ScaleBench的有效性。结果凸显了其支持对Kubernetes自动扩缩容方法进行系统、可重复且实用评估的能力。

    RSIBench-Infra：智能体能否在生产规模下优化自身的训练与推理基础设施？

    arXiv / 2026-11-18 / Hanlin Wu

    提升训练与推理基础设施的效率是递归自我改进的一个实际组成部分。现有的面向智能体驱动优化的基准主要集中于内核等单个软件层，因而无法明确智能体能否在生产负载下带来端到端性能提升。我们提出 RSIBench-Infra，这是一个包含 20 个训练与推理任务的基准，涵盖多样化的模型家族与模态，部署规模最高达 32 个加速器，运行于 NVIDIA GPU 与昇腾 NPU 之上。智能体从源自官方配方的可运行基线出发，可在引擎、内核与指令层面修改软件栈。OCI 镜像层提交协议可捕获这些改动以实现可复现部署，而独立评估则在任务特定的质量约束下测量端到端性能。在所有任务结果中，66.2% 超过了经校验的 1.10 倍加速。这些结果表明，当前智能体能够提升生产规模的训练与推理性能，但识别有效的优化策略并将局部改进持续转化为端到端收益仍然具有挑战性。

    循环神经网络中的时间秩

    arXiv / 2026-11-18 / Leo Dobson

    循环神经网络（RNN）是时序建模的自然框架，然而因其顺序、不可并行化的计算以及难以捕捉长程依赖（通常归因于梯度消失与爆炸）而常被忽视。我们识别出一个独特且尚未被充分探索的局限性：由秩约束的隐藏状态动力学所引发的信息瓶颈，它限制了随时间可被保留的独立输入方向的数量，这体现在输入到状态映射的秩上。我们证明该约束独立于梯度稳定性而限制时序容量。为解决这一问题，我们引入结构化高维状态动力学，其保持时序可分性并防止输入到状态雅可比矩阵随时间饱和。在受控序列任务上，所得模型尽管严格保持在标准RNN公式之内，却表现出快速学习。我们的结果表明，RNN性能受时序秩的演化与保持所支配，并表明仅缓解梯度病态而不显式维持时序容量是不够的。

    基于基础模型的初始数据选择提升主动学习性能

    arXiv / 2026-11-18 / Mohammad Mirzaee

    在主动目标检测中，选择初始标注池至关重要，尤其是在标注成本高昂且资源预算有限的复杂数据集中。本研究提出了一个主动学习框架，旨在优化目标检测任务中主动学习初始训练周期。我们的方法不同于传统方法，而是利用YOLO-World模型中基于特征的聚类，并基于目标性分数对图像进行精炼，而不是在初始周期依赖不确定性采样。该方法侧重于寻找具有多样特征的样本，并强调在基础模型最有信心的区域进行训练。这样做有助于模型更好地理解不同类型的对象。对于后续周期，我们采用基于一致性的采样技术来保持训练过程的鲁棒性。为了评估我们的方法，我们使用了两个复杂数据集，分别为Aquarium和NWPU VHR-10，它们以对象尺寸多样和条件复杂而闻名。在NWPU数据集上，我们的方法在基于图像的评估中将mAP50平均提高了6.6%。此外，图像精炼方法在基于对象的评估中显示出约11%的提升。结果表明模型性能和标注时间均有所改善，展示了在主动学习早期周期中使用基础模型的优势。算法实现可在https://github.com/Mhrshd-fllh/ALBoost-FM获取。

    多数标签所掩盖的：多方言阿拉伯语性别歧视检测中的标注者分歧与模型错误

    arXiv / 2026-11-18 / Alaa Bazaid

    性别歧视的判断具有主观性，且可能因社群而异，然而性别歧视检测数据集通常将标注者的判断简化为单一的多数标签，从而掩盖了分歧以及模型在有争议案例上的表现。我们推出MuDAS，这是一个包含沙特、埃及和摩洛哥阿拉伯语YouTube评论的数据集，每条评论由其所属方言的三名母语者标注，并保留了个体标注。我们用它来评估以硬标签、软标签和视角主义目标微调的阿拉伯语编码器、GPT-5.6 Terra以及四个以阿拉伯语为中心的大语言模型。模型在标注者存在分歧的评论上错误更为频繁。尽管Macro-F1分数相对接近，GPT-5.6 Terra与微调编码器表现出截然不同的错误模式：GPT-5.6 Terra即便在给定标注者对性别歧视的定义下，仍过度将性别相关内容（如关于端庄的宗教建议）归类为性别歧视，而编码器则漏掉了隐性和规定性的性别歧视。以阿拉伯语为中心的模型同样过度预测性别歧视，且表现低于编码器。分歧感知学习保持了Macro-F1，但软标签以牺牲一致评论为代价改善了对有争议评论与标注者的一致性，且两种范式都无法可靠识别有争议的评论。埃及阿拉伯语上的较低表现（在大语言模型中最为明显）无法完全由所考察的测试集构成和方言性度量来解释。因此，多数标签分数可能掩盖对内容审核至关重要的截然不同的错误模式。

    如何将注意力神经网络转化为可解释的硬逻辑谓词电路：忒修斯之船替换下的真值表谓词提取与状态机合并

    arXiv / 2026-11-18 / Yuchen Li

    我们将一个训练好的注意力网络作为一个整体（包括注意力机制在内）转换为一个硬逻辑谓词电路，由该电路代替原网络运行。电路的每个单元都是关于词元的0/1谓词，谓词之间的每个映射都是最小化后的真值表。短真值表（例如查询码与键码的乘积）被精确最小化，而宽泛的特征到特征转换则通过容噪最小化转化为蕴含规则。各模块按照“忒修斯之船”的方式，从输出端开始逐一替换，每次替换后剩余的软部分会重新适应已冻结的电路。注意力选择有两种形式：对整数分数进行逐行比较（顺序选择）和学习得到的规则（规则选择）。两者都仅在普通训练集上拟合，且仅使用教师分类正确的样本，从而使电路在教师正确之处模仿教师。在TweetEval-emotion上，DistilGPT2的完整电路在三个随机种子下，采用顺序选择达到66.5 ± 1.3%的测试金标准准确率，采用规则选择达到57.4 ± 2.5%，而教师为74.7%，在同一批推文上拟合的词片袋模型为64.0%；BERT-base的完整电路采用顺序选择达到70.0 ± 0.5%，采用规则选择达到63.7 ± 1.2%，而教师为77.8%。该电路不需要乘法器，也不需要权重传输，其导出的硬件描述能够逐位复现该电路。根据基于综合的估计，在FPGA卡上分类一条推文约需1-2 μs（DistilGPT2）和3-5 μs（BERT），在模块功耗为7.5-15 W的掌上型板上约需5-9 μs，比批大小为1时GPU上的网络快两到三个数量级（实测，DistilGPT2包括优化的CUDA图基线为0.9-2.6 ms），代价是综合后的种子0电路的金标准准确率分别下降8.5（DistilGPT2）和8.6（BERT）个百分点。

    扩散Transformer应在何处与其教师相遇？

    arXiv / 2026-11-18 / Zhuoqi Hu

    表示对齐（REPA）通过使用预训练的视觉教师模型引导学生的中间特征，显著加速了扩散Transformer的训练，然而现有方法通常将监督附加到单个固定层上。然而，随着学生表示不断演化，我们发现最适合对齐的层会随训练阶段而变化。为了在不进行昂贵搜索的情况下在线追踪这种不断变化的层适用性，我们测量了流匹配目标与对齐目标之间的梯度兼容性，并提出AdaREPA，一种在线路由框架，可随着训练进展自适应地选择监督层。AdaREPA在平滑后的层兼容性分数上使用softmax分布，以在每个训练步骤中采样一个用于对齐的层。这种概率路由使教师监督适应学生不断变化的学习需求，训练开销极小，且不增加额外推理成本。在ImageNet-256上，AdaREPA加速了收敛，并在不同模型规模上提升了生成质量，同时揭示了最适合监督的层如何随训练而变化。

    MoE-Context：只向模型展示其所需内容

    arXiv / 2026-11-18 / Vedant Navale

    AI智能体在每一步都会读取其全部历史记录。人类并非如此运作：我们保留当下所需的信息，将其余部分作为粗略笔记留存以备回忆。MoE-Context将这一机制应用于语言模型。上下文被分割为多个块。在每一步之前，一次快速的“是/否”判断决定该步骤需要哪些块；其余块保留为一行笔记，可随时调回，且不删除任何内容。在我们构建的版本中，一个模型做出此判断后作答，基于单一键值缓存运行，其中隐藏块被掩蔽而非移除。在搭载Qwen3-1.7B的笔记本电脑上，使用合成查找任务，仅显示所需块将准确率从120次中的93次提升至119次，且被掩蔽的块与已删除的块同样隐蔽。模型自身的挑选是薄弱环节。将监督线性探针写入备用输出行，将其准确率从120次中的80次提升至110次，但简单关键词搜索在此任务上表现完美，且该探针无法迁移至第二项任务。我们公开报告这些结果，以及块切换所支持的两种低成本使用模式：撤销失败尝试和无需新上下文运行子智能体。

    LLM辅助的多保真贝叶斯优化：融合专家知识与数值数据

    arXiv / 2026-11-18 / Dongjun Han

    多保真度贝叶斯优化（MFBO）通过将低成本的低保真度（LF）模型与少量准确的高保真度（HF）评估相结合，并顺序选择待评估的设计，从而降低工程设计成本。然而，当高保真度数据稀缺时，仅凭数值数据难以学习低保真度与高保真度之间的差异，尤其是当低保真度模型中省略的物理因素使其差异依赖于设计时。然而，即使没有足够的数据，领域专家通常也知道低保真度模型省略了哪些物理因素，以及在何种条件下其影响会增大。现有多保真度（MF）模型无法直接利用这类定性知识，但大语言模型（LLM）可以对其进行解释并据此比较设计。所提出的LLM辅助MFBO在传统MF模型的基础上增加了一个知识基：根据专家对省略物理因素的描述，LLM判断两个设计中哪一个需要更大的带符号残差修正，并通过成对高斯过程将这些判断转换为该知识基。高保真度数据用于校准其贡献和符号，因此知识不会被盲目信任。在一个锂离子电池设计问题上，所提出的方法将传统MFBO的曲线下遗憾面积减少了61%。通过一项独立变化两者的对照研究显示，决定搜索是否加速的是知识质量而非LLM的选择。知识层面的消融进一步量化了每条知识陈述的贡献。这些结果表明，LLM解释的专家知识可以作为MFBO中的一种信息源来补充数值数据。

    持久的染色质和转录状态塑造记忆集合的维持

    bioRxiv / 2026-11-18 / Vogel, I. R.

    近期事件的记忆在几分钟内便存储于海马体的神经元集合中。经过数天至数周，这些记忆经历巩固过程，而后续的提取依赖于集合内一部分神经元的再激活。然而，短暂经历如何在海马集合神经元中产生持久的分子和细胞变化仍不清楚。在此，我们在单次情境恐惧条件反射后的多个远端时间点，以单细胞分辨率刻画了海马记忆集合神经元的功能、转录和基因调控状态。我们揭示了学习后长期持续的、细胞类型特异性的染色质和基因表达变化，这些变化与突触可塑性的持续转变相吻合。在齿状回颗粒细胞集合中，我们鉴定出一个持久的染色质转录程序，该程序在部分集合神经元中出现，并以许多突触基因的持续表达为标志。这一转录特征能够预测哪些神经元将在记忆提取时被再激活，提示仅有初始集合神经元中的一部分维持了支持后续再激活的分子状态。与这一持久状态相关的调控元件高度富集AP1基序，即Fos家族转录因子的同源结合位点，尽管FOS蛋白早已降解消失。相反，我们在这些元件上检测到持久的FOSB结合，提示了一种机制，使即刻早期基因驱动的转录效应延伸至初始诱导窗口之外。FOSB在维持持久基因表达变化的集合神经元中尤为富集，提示其在记忆提取时可再激活的神经元中维持染色质可及性和延长的转录。总之，这些发现揭示了海马记忆集合随时间推移的维持、成熟和演化的分子机制。

    重要性：用于预测临床高危精神病（CHR-P）人群发病的结构磁共振成像（MRI）模型很少在新队列中验证，因此其是否以及为何失去准确性尚不清楚。目的：检验结构MRI模型能否在外部队列中预测精神病，并是否在症状评估之外提供增量价值，其准确性是否随参与者特征变化，以及队列间差异的原因。设计：本预后研究应用PRONIA结构MRI模型，在其训练样本（329名参与者；26例转化）中重新估计，未对4个外部队列进行重新拟合。数据分析时间为2025年7月至2026年10月。环境：北美和欧洲的早期识别服务机构。参与者：4个外部队列中的CHR-P人群。暴露：基线MRI风险评分。主要结局与指标：按研究特定标准（症状持续时间1周至1个月）转化为精神病；区分度（曲线下面积[AUC]）、校准、净获益、症状之外的增量价值，以及按参与者特征、站点和结局组划分的区分度。结果：在685名外部参与者中（平均[SD]年龄20.0[5.1]岁；319名[46.6%]女性；106例转化），AUC在NAPLS-3中为0.53，在MUC-FRUE中为0.56，在ZInEP中为0.65，在FePsy中为0.69（合并0.56；95% CI，0.51-0.62），而PRONIA中为0.74。校准斜率为0.17（95% CI，0.01-0.34），没有任何概率给出明确的净获益，将MRI评分加入症状评估使AUC变化0.01（95% CI，-0.02至0.05）。仅阴性症状提示区分度较好，且不稳健（q = .15）。未转化者的评分与PRONIA中相似，而转化者评分较低，因此敏感性从0.92降至0.57，特异性相似（0.52 vs 0.55）。站点内比较、按年龄、性别和症状重新加权以及替代分类器均未能恢复区分度。结论与意义：在其训练队列之外，该MRI模型对精神病的预测效果较差，这种损失仅限于发生精神病的人群，且无法由扫描仪或参与者特征解释。人群可能通过队列间不同的途径达到精神病，其中仅部分途径在脑结构中可见。识别MRI风险评分对哪些人有效（如果有的话），需要更多按共享标准计数的转化病例。

    摘要 癫痫影响全球约5000万人，但目前缺乏能够在临床发作前识别高危个体的生物标志物，且对疾病发病前的分子机制了解甚少。本研究整合了英国生物银行的血浆蛋白质组学、代谢组学和基因组学数据，以刻画癫痫发病前的分子变化，并评估其预测价值和因果相关性。我们在53,000名参与者中定量了2,923种血浆蛋白质，并在癫痫诊断前长达15年的随访中追踪了新发癫痫。Cox比例风险分析识别出116种与新发癫痫相关的蛋白质，其中以神经丝轻链（NEFL；HR=2.03）和生长分化因子15（GDF15；HR=1.73）为首。这些蛋白质富集于细胞外信号传导、免疫调节和细胞死亡通路，并呈现出不同的亚型和年龄特异性特征。由32种蛋白质构成的蛋白质组风险评分可对癫痫风险进行分层，最高五分位个体的风险是最低五分位个体的3.5倍（AUC=0.70）。与此同时，249种循环代谢物中有154种与新发癫痫相关，其中柠檬酸盐的反向关联最强（HR=0.72），而HDL相关代谢物呈正向关联（HR=1.16-1.21），提示能量和脂蛋白代谢失调。代谢组风险评分的区分能力较为有限（AUC=0.63）。整合蛋白质组学、代谢组学、多基因和人口学信息后，对新发癫痫的总体AUC为0.71；在针对早发性癫痫个体的另一项横断面分析中，区分能力达到AUC=0.79。蛋白质组范围的顺式-pQTL孟德尔随机化在错误发现率校正后识别出12种与癫痫相关的蛋白质，主要涉及遗传性全面性癫痫。O-GlcNAcase（OGA）是蛋白质O-GlcNAcylation的调节因子，已知在神经元功能和突触可塑性中发挥作用，其保护性关联最强（OR=0.71，FDR=2.7 e-8）。丝氨酸蛋白酶53（PRSS53）是一种特征尚不明确的丝氨酸蛋白酶，显示出与癫痫可能存在共享因果变异的强证据（共定位PP.H4=0.95）。总之，这些发现表明循环分子改变在癫痫诊断前数年即已出现，并揭示了疾病易感性的互补性蛋白质组、代谢和遗传决定因素，为基于生物学信息的风险分层和治疗靶点优先排序提供了框架。
