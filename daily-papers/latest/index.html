    LIBERO-PeRM：个性化机器人操作基准测试

    arXiv / 2026-10-15 / Zhixu Li

    个性化对于通用机器人进入家庭环境并实现真正的实用性至关重要。尽管通用机器人操作已被广泛研究，但个性化机器人操作（PeRM）缺乏一个受控的基准来将任务完成与偏好满足区分开来。我们提出了 LIBERO-PeRM，一个用于具身智能体偏好学习的基准。LIBERO-PeRM 研究五个问题：1）策略在零样本设置下如何遵循偏好；2）它们如何从演示中学习单一偏好；3）随着演示增加，它们获取偏好的效率如何；4）学习到的偏好如何跨布局和任务泛化；5）策略如何组合偏好并在冲突下表现。我们提出了模拟中可观测偏好的受控表述与分类体系，涵盖动作、技能和用户画像选择。该表述仅限于可用语言表达的偏好，这些偏好可以在不改变任务目标的情况下在 LIBERO 中实例化、自动评估并跨任务复用。基于 LIBERO，我们的程序化流水线生成带有偏好和不带偏好的配对演示。我们创建了五个任务套件（312 个任务），包含高质量演示、丰富的元数据和偏好满足度量。实验表明，当前的 VLA 策略在零样本个性化方面表现不佳，而 SFT 使偏好变得可学习。混合训练在无偏好保持方面优于顺序适应，并且在上下文提示下相比仅偏好训练提升了性能，但可能削弱动作偏好的学习；偏好泛化、分解和冲突处理仍然困难。代码、数据集和演示可在项目网站找到：https://libero-perm.github.io/。

    Gen4P：视频生成器是四维感知器

    arXiv / 2026-10-15 / Yitong Xia

    我们提出Gen4P，一个从单目视频中恢复4D几何与运动的统一框架。我们表明，预训练的视频生成器可以被重新用作前馈4D感知器，而无需迭代去噪。基于按需查询，Gen4P在单次编码器传递中处理干净的视频潜在表示，并通过轻量级交叉注意力解码器预测所请求的4D属性。按需查询公式实现了灵活的空间采样，而我们提出的连续时间查询进一步提供了时间灵活性。为增强几何知识，我们提出一种直接的即插即用方案，将预训练的视频深度LoRA作为冻结的几何先验引入，在不增加额外可训练参数的情况下提升整体性能。Gen4P在3D点跟踪、视频深度和相机位姿估计任务上达到最先进或具有竞争力的性能。在野外视频上的定性结果展示了其在跟踪复杂运动的同时保持精细结构的能力。这些结果共同证明了视频生成预训练在统一4D感知方面的潜力。更多视觉结果见https://gen4p.github.io。

    哪些Token应当合并？面向高效图像生成的扩散动力学

    arXiv / 2026-10-15 / SeungJu Cha

    Token merging已成为一种有效的免训练策略，通过减少冗余token计算来加速扩散模型，同时最小化生成质量下降。一个关键挑战是确定哪些token可以安全合并，哪些应保留用于后续计算。现有方法通过保留与提示对齐的前景区域来应对这一问题，从而保护语义相关的结构。然而，这种文本相关性准则忽略了背景对象以及提示中未明确提及的局部细节，导致结构连贯性下降。在本工作中，我们提出Dynamics-aware Token Merging（DaTMe），一个免训练框架，将token merging建立在底层扩散动力学之上。我们的关键洞见是，token重要性应反映该token在去噪过程中是否仍未确定，以及它是否携带结构信息。为此，DaTMe从Tweedie去噪估计中构建动力学感知重要性图。该图结合了时间信号——衡量预测干净图像在相邻步骤间的变化——与结构信号——捕获局部高频内容，如边界和精细细节。利用该图，DaTMe在给定压缩比下自适应地将token分配为合并角色：重要token作为锚点保留，而时间上已稳定且结构上同质的token被选为安全合并候选。在PixArt-a和FLUX上的实验表明，DaTMe在整个图像上保持视觉保真度，突显了扩散动力学作为高效生成中有效的token级合并决策。我们的代码可在https://github.com/SeungJuCha/DaTMe获取。

    SoftCache：面向扩散Transformer的自适应步长缓存

    arXiv / 2026-10-15 / Shimon Malnick

    扩散模型和流模型通过迭代步骤生成样本，每一步都要完整地通过一个大型网络，而这一过程主导了生成成本。免训练缓存通过复用近期评估中的激活值而非重新计算来加速这些模型。动态缓存方法通过将网络输入的廉价探针累积为陈旧度信号，并在其越过阈值时进行一次新的评估，从而决定何时刷新。它们执行硬缓存：该信号是刷新与复用之间的二元开关，且每一步无论新算还是缓存，都按规定的步长推进。我们观察到，该信号所携带的信息远不止这个开关。它低于阈值的程度，即其余量，可以预测复用所引入的误差。我们提出SoftCache，它执行软缓存：余量不再作为二元开关，而是决定每个缓存步骤推进多远。在余量较大处，采样器跳过若干个预定节点；而当刷新临近时，其步长会收缩回原始步长。这些自适应跳跃可能落在预定节点之间，使采样器偏离其固定网格。SoftCache无需训练，也不增加任何逐骨干网络的设置：在图像任务上使用FLUX，在视频任务上使用HunyuanVideo和Wan2.1，在3.5倍到6.9倍的加速下，它在全部四项保真度指标上均领先于所有基线方法。

    价值即记忆：面向通用机器人策略的在线价值引导后训练

    arXiv / 2026-10-15 / Wenye Yu

    通用机器人策略的真实世界后训练面临两个挑战：部分可观测性使动作选择存在歧义，而离线后训练方法延迟了来自部署经验的反馈。我们提出价值即记忆（Value as Memory，VaM），一个通过价值缓存和在线真实世界强化学习（RL）应对这些挑战的框架。价值缓存以近期价值预测作为任务进度记忆来约束动作，而在线更新通过结合离线演示、离策略干预和同策略 rollout 实现及时的策改进，以实现样本高效的适应。因此，VaM 从离线 RL 预热过渡到具有稀疏奖励的在线自主学习。在涉及可变形物体和接触丰富操作的长时程任务中，VaM 通过价值缓存获得平均绝对成功率提升 $29.4\%$，而在匹配的离线训练基础上通过在线自主学习获得 $32.8\%$ 的提升。所评估的在线调度在相同梯度步预算下执行了 $8\times$ 的策略迭代次数，并且在并发数据收集与训练下，每梯度步记录时间降低超过 $2\times$。

    利用大型语言模型发现最先进的量子电路

    arXiv / 2026-10-15 / Andi Gu

    目前，大量工作正致力于实现大规模量子信息处理器，但要实现有用的量子优势，还需要开发高效的量子算法。尽管对许多实际问题而言，主要的资源成本与一小组计算原语相关，但在量子环境中优化这些原语面临着独特的挑战，其中包括普通经典计算中不存在的可逆性约束。在此，我们引入一个进化框架，其中大语言模型（LLMs）提出电路设计，并由独立的评估器进行验证和评分。我们将该框架应用于涵盖数值计算、化学、优化、量子模拟和数论的任务。在八个任务中的七个里，所发现的电路相较于当前最先进水平显著减少了Toffoli门和量子比特的数量。在第八个任务中，搜索发现了一种用于素数域模逆的新可逆架构。通过以不同方式处理可逆性，该架构使divsteps——一种此前用于可逆整数算术不切实际的经典算法——变得可行，并大幅改善了模逆的Toffoli门与量子比特之间的权衡。这些结果为评估器引导的LLM协同设计量子计算的新算法结构打开了大门。

    T2-z：面向机器人世界模型的环境潜在变量测试时优化

    arXiv / 2026-10-15 / Chenyuan Zhou

    预测世界对某一动作的响应，仅凭可观测信息是不够的：机器人必须考虑既不能直接观测也无法明确指定的环境因素，从摩擦和质量等物理属性到人类定义的环境规则。我们提出T2-Z用于环境隐变量的测试时优化，它为机器人世界模型增加一个可学习的环境隐变量，以条件化世界预测。这一紧凑隐变量在无需监督环境因素存在何种因素或取何值的情况下，捕捉潜在的环境变化。在训练期间，T2-Z在两个阶段之间交替：世界模型优化阶段固定隐变量并学习跨环境的一般动作条件动力学；环境隐变量优化阶段冻结世界模型并优化条件隐变量，使隐变量结构纯粹通过世界预测涌现。在测试时，世界模型保持冻结，新初始化的环境隐变量从一个或多个测试时交互中优化，使模型适应先前未见的环境配置。在7个模拟设置和4个真实世界机器人任务中，T2-Z将物体预测误差指标从15.20降至7.00，并将动作成功率从33.73%提升至72.96%。其涌现的隐变量在多样视觉场景中捕捉到个体因素与复合因素的结构化表示。消融实验进一步表明，T2-Z能够仅从单条测试时交互轨迹中高效推断环境隐变量。

    感知、预测与规划：一种用于第一人称视角灵巧操作的统一世界动作模型

    arXiv / 2026-10-15 / Zirui Wu

    我们提出P$^{3}$-WAM，一个用于自我中心灵巧操作的统一世界动作模型，通过三种互补模式学习三维感知、动作条件预测和目标导向规划：Perceive，从视频中重建关节手部运动和相机轨迹；Predict，在给定动作下生成视觉未来；Plan，以初始图像、语言指令和可选视觉目标为条件，联合生成动作轨迹及其预期视觉后果。我们的模型通过混合Transformer架构将紧凑的结构化三维动作表示集成到预训练视频扩散Transformer中，该架构具有共享基础权重、模态特定适配和双向视觉-动作注意力。随机化模态可见性使视频和三维动作在三种模式中均可作为条件上下文或预测目标。实验表明，统一训练在全部三项能力上均优于单模式训练，包括在视觉语言模型评估下规划质量的提升。通过统一训练，我们的模型在四个数据集上的三维手部重建和动作条件视频预测方面优于专门基线，同时生成的目标导向操作视频在指令遵循和动作进展方面优于视频生成基线。项目页面：https://p3-wam.pages.dev/

    CoDA：数据引擎与行动策略的协同演化

    arXiv / 2026-10-15 / Tianjiao Yu

    生成式仿真可以自动化机器人环境构建，但物理上有效的环境未必对训练有用。挑战在于识别能够针对策略失败的环境，以及帮助策略克服这些失败的监督。我们提出CoDA，一个框架，其中仿真数据引擎与动作策略通过一个共享的异构记忆协同演化，该记忆涵盖环境构建、策略失败和学习进展。该记忆将来自视觉语言批评器的经过验证的诊断编译为生成程序，以重现困难，并编译为帮助策略克服困难的训练程序。我们进一步提出Text2potential，将这些诊断转换为用于动作块价值学习的分阶段势函数，在标准塑形假设下为策略更新提供密集监督，同时保持任务的最优策略。测得的 learning progress 指导进一步的生成和程序改进。在四个操作任务族上，CoDA将分布外成功率从监督微调后的5.3%提升至27.6%，在相同生成预算下超过最强的闭环基线9.5个百分点。在LIBERO-Pro上，15轮生成和训练将位置扰动下的成功率从25%提升至84%，将指令扰动下的成功率从1%提升至76%。

    将生成式验证建立在3D内容之上

    arXiv / 2026-10-15 / Shuanglin Li

    多模态大语言模型（MLLMs）与3D生成的最新进展拓展了3D理解与合成能力。然而，超越视觉保真度，基于3D证据的任务特定正确性仍是一大挑战。我们认为，构建可靠的3D系统不仅需要更强的生成与推理能力，还需要验证反馈来识别未满足的要求并解释其违规之处，从而使系统能够反思并改进其输出。此类反馈必须整合多视角观测，并区分真正的不一致与依赖投影的表观差异。我们做出三项贡献。第一，我们提出3DVerifierBench，一个涵盖10项任务的基准，用于评估决策、拒绝解释以及对规格和候选对象受控变化的响应。一项人类研究显示，人类与测试中最强模型GPT-6 Astra之间存在21.6个百分点的差距，而解释感知分析揭示了拒绝可靠性方面的弱点。第二，我们跨细粒度事实类别分析验证，暴露了数值和目标绑定中的错误。我们开发了一个可扩展的流水线，结合多视角事实提取、受控3D编辑和原生标注，生成14,126个训练样本，包含矛盾解释和关联的反事实。第三，我们考察验证如何通过候选选择和递归改进来支持3D生成。在人工标注的十六候选池中，预言机选择将完整事实成功率从26.7%提升至90.0%。在另一项八输入研究中，人工引导的递归改进对每个输入均满足全部七项要求，而并行Oracle@8下仅满足三项。总之，我们的基准、分析和数据流水线为模型通过可靠验证反馈反思3D内容奠定了基础。

    高级冥想者意识长期停止的神经电生理相关因素：一项多模态脑电图和脑磁图研究

    bioRxiv / 2026-10-17 / Shinozuka, K.

    在一些冥想传统中，“延长的止息”（extended cessation，EC）指的是一种高级冥想状态，冥想者自我报告有意抑制自身意识，并在重新出现时带有深刻的清晰感与平等心。在此，我们呈现首个关于EC的电生理研究，其中五名冥想者同时接受了脑电图（EEG）和脑磁图（MEG）记录。EC显著提高了全部五名参与者的高频全局相干性，但并未在参与者之间一致地影响Lempel-Ziv复杂度或功率。我们的结果为以下观点提供了初步证据：EC的神经特征可能不同于以意识丧失为特征的其他状态，包括深度睡眠和麻醉。EC可能并非简单地“关闭”意识，而是重组了支撑意识的神经动力学。

    筛骨骨髓区域在神经炎症中调节淋巴细胞的激活与分化，并具有独特的髓系特征

    bioRxiv / 2026-10-17 / Laaker, C. J.

    颅骨骨髓轴近年来已成为神经炎症过程中免疫细胞的重要来源，包括在多发性硬化症的小鼠模型——实验性自身免疫性脑脊髓炎（EAE）中。筛板骨髓（cpBM）是小鼠颅骨筛骨的一部分，位于鼻腔区域旁边。在筛板处，嗅神经穿过颅骨，近期证据支持该区域是一个重要的免疫微环境，与脑脊液外流相关并与cpBM存在联系。先前数据支持小鼠筛骨骨髓的细胞组成在神经炎症中发生改变，提示其感知炎症信号，但这些变化的确切性质仍不清楚。本研究利用筛骨骨髓区域的单细胞RNA测序（scRNAseq）和流式细胞术，检测该区域如何响应EAE。此外，我们还比较了cpBM区域与股骨系统性骨髓，以了解区域特异性差异。我们报告神经炎症在这些位点产生调节性反应，并提示cpBM参与控制这些效应。更好地理解筛板微环境可能为神经炎症性疾病提供新的治疗方法。

    结构信息驱动的减数分裂重组机制进化分析

    bioRxiv / 2026-10-17 / Arter, M.

    大型语言模型（LLMs）越来越多地被用于获取健康建议，但它们可能生成流畅却虚假或无依据的陈述，即幻觉，而这种风险在孟加拉语等低资源语言中尚缺乏充分刻画。我们测量了可本地部署的开放权重LLM在孟加拉语糖尿病问答中的幻觉情况，并检验了以孟加拉国《糖尿病国家指南》为基础的检索增强生成（RAG）是否能减少幻觉。40个涵盖六个临床子域的患者问题，在零样本提示下，分别由Qwen3.5-9B、TigerLLM-9B、Qwen3.6-35B-A3B和Gemma-4-26B-A4B各回答两次，并由BanglaDiaRAG回答，后者在Qwen3.5-9B基础上加入了来自经医师审核的孟加拉语指南知识库的混合稠密（BGE-M3）与稀疏（BM25）检索。两名医师对400份去标识化回答以共识方式按0-1量表评定医学准确性、完整性、安全性、可读性和可靠性，准确性低于0.70的回答被归类为幻觉。幻觉率分别为Gemma-4-26B-A4B 2.5%、TigerLLM-9B 3.8%、Qwen3.6-35B-A3B 22.5%和Qwen3.5-9B 77.5%。指南 grounding 将Qwen3.5-9B的幻觉率降至11.3%（差值-66.3个百分点；95% CI -76.3至-55.0），并使每项标准提高0.24至0.38分（Holm校正p < 0.001）。BanglaDiaRAG在全部五项标准上均优于Qwen3.6-35B-A3B，并与TigerLLM-9B持平或超过后者，但在安全性、可读性和可靠性上仍低于Gemma-4-26B-A4B，且其残余错误具体、自信且可能有害。指南 grounding 可将一个较弱的通用模型转变为安全得多的孟加拉语糖尿病助手，但基础模型的选择与检索同样重要，且没有任何配置完全无幻觉，因此在面向患者使用前临床监督仍必不可少。

    2006-22年加拿大某大都市区五种主要菌血症病因的发病率和抗菌药物耐药性趋势：一项基因组和抗菌药物使用队列研究

    medRxiv / 2026-10-17 / Pham, T. M.

    背景 利用加拿大卡尔加里卫生区（CHZ）的基于人群队列，我们将纵向抗菌药物敏感性及处方数据与五种主要病原体的全基因组序列进行整合。旨在评估抗菌药物耐药性（AMR）如何响应处方变化，并确定哪些细菌菌株塑造了这些动态。方法 我们分析了2006-2022年间CHZ地区与菌血症发作相关的7,271株金黄色葡萄球菌、1,609株粪肠球菌、801株屎肠球菌、11,363株大肠埃希菌和2,319株肺炎克雷伯菌分离株的抗生素处方率、临床及基因组数据。使用StrainGST鉴定基因组簇（称为菌株），并将其分配至已知序列型（STs）或克隆复合体（CCs）。按社区发病（入院后≤48小时采集的分离株）和医院发病（入院后>48小时）分层，使用负二项和二项回归对菌株水平发病率、AMR表型和处方率进行建模。使用平均年度百分比变化（AAPC）量化时间趋势。结果 2010-2022年间，氟喹诺酮类处方在社区（AAPC=-6.8% [95% CI -8.1, -5.4]；p<0.0001）和医院环境（AAPC=-5.1% [-6.5, -3.7]；p<0.0001）均下降。与此同时，革兰阳性菌种的氟喹诺酮类耐药性显著降低。具体而言，对临床重要抗生素（氯唑西林、环丙沙星、红霉素和克林霉素）耐药的金黄色葡萄球菌菌血症从2006年至2022年下降，主要见于医院发病病例（AAPC=-16.0%，[-19.3%，-12.7%]，p<0.0001）。在大肠埃希菌中，头孢曲松和环丙沙星耐药性聚集于ST131和新出现的ST1193；后者稳步增加，尤其在社区发病病例中（AAPC=17.7%，[9.0%，30.0%]，p<0.0001）。产CTX-M-27的大肠埃希菌ST131菌株在2008-2022年间增加（AAPC=23.8%，[17.4%，30.5%]，p<0.0001），而产CTX-M-14的大肠埃希菌ST131在2013-2022年间下降（AAPC=-15.9%，[-21.3%，-10.2%]，p<0.0001）。这些趋势与2010-2022年间社区头孢菌素处方增加（AAPC=7.3%，[4.2%，10.5%]，p<0.0001）相平行。对于肺炎克雷伯菌，高毒力ST23最为常见（N=88），2006-2019年间发病率呈上升趋势（AAPC=2.3%，[-4.4%，9.4%]）。结论 革兰阳性与革兰阴性菌种之间相反的耐药趋势凸显了AMR控制工作的复杂性。有效策略需要针对多类药物类别的管理措施、对新出现耐药菌株的基因组监测以及超越医院环境的干预措施。资助 本研究由Genome Canada于2017年颁发的大规模应用研究项目竞赛奖资助，通过Genome Alberta管理。IAL获得Alberta Innovates转化健康讲席和UCalgary研究卓越讲席的支持，并获得加拿大创新基金会（CFI-JELF 34986）和自然科学与工程研究理事会（DG 04547）的额外支持。微生物分离株在Alberta先进诊断中心制备用于分析，该中心由PrairiesCan（000022734）支持。本工作还得到美国国立卫生研究院国家过敏和传染病研究所的联邦资金支持，隶属于卫生与公众服务部，授予Broad研究所的资助编号为U19AI110818。JTS还获得NIH/NIAID F32AI179151的额外支持。

    用人类胎儿心脏调控图谱解读与先天性心脏病相关的变异

    medRxiv / 2026-10-17 / Ma, X. R.

    先天性心脏缺陷(CHD)部分源于改变人类基因组中基因和非编码调控元件的遗传变异。这些变异被认为在胎儿发育期间发挥作用，影响不同心脏结构的形成。然而，由于心脏发育涉及多种细胞类型，以及解读非编码序列的叠加复杂性，识别介导这些效应的基因、通路和细胞类型一直具有挑战性。因此，理解非编码和编码变异的分子功能对于我们对心脏发育和CHD的基本认识仍然至关重要。在此，我们构建了健康人类胎儿心脏跨发育时间的基因调控图谱，并将其应用于解读与CHD和定量心脏性状相关的变异功能。我们从41个胎儿心脏中采集了734,078个单细胞的多组学数据，样本涵盖受孕后第6至22周(PCW)，从而能够在90种心脏细胞类型和状态中构建基因调控图谱，包括心脏传导系统(CCS)细胞类型的稀有群体。我们发现，许多此类风险变异，无论是编码还是非编码的，都映射到瓣膜细胞的基因调控网络上。在对90种心脏细胞类型和状态的无偏分析中，瓣膜间质细胞(VICs)显示出对已知CHD基因最强的富集。九个CHD基因通过VICs中的转录增强子与与其他瓣膜疾病或性状相关的常见非编码变异相关联。CRISPRi实验表明，多个CHD基因在VICs中具有细胞自主效应，包括调控其他CHD基因以及参与细胞迁移和发育模式化的基因的表达。最后，我们表征了一个CHD相关的非编码变异，其活性对心脏内离散结构具有特异性，揭示了此类变异如何影响心脏结构和功能的特定方面。总之，这些结果表明，许多CHD亚型的遗传风险部分受到瓣膜细胞遗传调控的影响，将我们对导致CHD的细胞类型的理解扩展到工作心肌细胞之外。这份人类胎儿心脏调控图谱为理解心脏发育、解读与心脏病相关的遗传变异以及发现细胞类型特异性治疗的靶点提供了基础资源。

    在流感低流行期间，密歇根和香港流感抗体衰减的前瞻性比较队列分析

    medRxiv / 2026-10-17 / Yang, Y.

    背景：COVID-19大流行期间流感传播减少，引发了人们对人群免疫力下降可能导致随后流感传播激增的担忧。我们比较了密歇根和香港两个在COVID-19大流行期间流感传播减少地区的纵向流感抗体滴度。方法：在两项前瞻性队列研究（HIVE，密歇根；EPI-HK，香港）中，我们分析了2020年至2023年从无流感感染或疫苗接种的参与者中收集的纵向血清样本。使用血凝抑制试验（HAI）和微量中和试验（MN）针对疫苗株检测血清。使用针对年龄和基线滴度调整的多变量幂律模型估计滴度的两年倍数变化。结果：我们分析了来自57名HIVE参与者的173份血清和来自60名EPI-HK参与者的259份血清。HIVE的初始HAI几何平均滴度范围为12.3-123.4，EPI-HK为6.3-40.9。在HIVE中基线滴度>1:40的参与者中，倍数变化估计表明H1N1毒株出现下降，包括A/Brisbane（0.70 [95% CI: 0.56,0.86]）、A/Idaho（0.40 [0.32,0.50]）和A/Michigan（0.43 [0.34,0.52]），而H3N2和乙型流感显示最小或无下降。在EPI-HK中，倍数变化估计显示H1N1按毒株呈现异质性模式，以及选定的H3N2毒株出现下降，包括A/Cambodia（0.44 [0.29,0.65]）和A/Singapore（0.48 [0.33,0.69]）。MN结果与HAI发现一致。结论：大流行期间的流感抗体反应显示异质性、毒株特异性变化，而非均匀下降。这些发现表明，尽管病毒传播减少，许多毒株的人群免疫力得以维持，特定毒株出现下降且因人群而异。

    抗阻训练频率与肌肉肥大：容量等同试验的系统综述与荟萃分析

    medRxiv / 2026-10-17 / Boutagy, A. G.

    每周训练量是抗阻训练诱导肌肥大的主要驱动因素，但只有在周训练量相等时，才能分离出训练频率的独立作用。我们量化了每块肌肉每周一至三次训练量相等 sessions 对肌肥大的频率效应。遵循 PRISMA 2020，检索了五个数据库至2026年10月，纳入至少六周、在每块肌肉训练频率之间均衡周训练量并测量肌肉大小的试验。每项试验的一个变化分数标准化均数差（Hedges g；负值有利于较高频率）采用随机效应模型合并，并用 GRADE 评定证据确定性。共合并16项试验（380名参与者）。频率效应微不足道且不显著（g = -0.02；95% CI -0.21至0.16；I{superscript 2} = 0%；预测区间 -0.23至0.18）；该区间最多允许有利于较高频率的小效应。对比特异性估计同样微不足道，且无显著调节因素，尽管调节因素分析仅能检测到大效应。证据确定性为低至极低。在此范围内，数据没有提供依据在固定周训练量下偏好一次、两次或三次 sessions。大多数试验测量肌肉厚度，而肌肉厚度不能可靠反映整块肌肉的生长。
