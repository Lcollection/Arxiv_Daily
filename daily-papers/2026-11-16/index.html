    一种具有步骤的矩阵：面向工具使用智能体与机器人的情景与程序记忆方法 Jürgen Paulhart 2026-11-15 PDF 调用工具的执行体和执行任务的机器人面临两个不足：它们会重复之前失败的做法，并且会从它们自认为成功的运行中学习。我们描述了一种同时解决这两个问题的记忆的构建，该记忆为生产级智能体平台而建。每次运行都被记录为一个片段，只有经过外部检查、测试、工具结果或人员确认的结果才算数；智能体自身的声称永远不算。从片段中学到的内容保存在一个分为两部分的记忆中：一个用delta规则写入的关联矩阵，用于找到适用于某一情境的过程；以及一部分有序、可寻址的步骤记录，用于回答给定步骤之后是什么，其中步骤是智能体的目标，而非动作。由于矩阵对其关联进行求和，它不保留顺序，也无法返回或删除单个关联；它充当查找器，而顺序、结果计数和删除则存在于记录中。我们描述了执行结果如何存储、片段如何被召回并用于解决任务，以及存储该记忆的文件格式。在仿真中，一个自行判断成功并在自认为完成时停止的机器人报告其任务完成率为96%，实际解决了35%；在外部验证下，它解决了79%。在一个包含100000个合成片段（磁盘上457MB）的存储中，最旧的片段仍被最先找到，没有返回来自他人记忆的片段，仅由模型担保的成功从未被召回；一次查找在笔记本电脑上耗时16ms，在服务器节点上耗时40ms（中位数）。任务结果被测量到约10000条确认记录，其中精确记录在首次尝试时就解决了每一次重访。

J. 2026-11-16 PDF 全球卫生项目传统上聚焦于单一疾病。通过整合干预实施存在协同潜力，尤其是在疾病负担地理重叠的地区，但指导整合的方法学发展有限。在此，我们提出一个框架，将多病原监测数据转化为可指导整合项目实施以同时针对多种病原体的汇总指数。我们在三项大规模调查中考虑了多种多样性度量来量化多病原感染或疫苗接种不足：孟加拉国的次区域（90个集群，n=7187）和肯尼亚（89个集群，n=9077），以及柬埔寨的一项全国调查（100个集群，n=2150）。我们发现，以多样性度量——Rao二次指数——为指导的策略在一系列干预组合中始终比其他多病原指数识别出更高效的整合策略。随后我们在每个环境中确定了以免疫为整合骨干的案例研究，发现纳入共现病原体信息仅导致疫苗可预防疾病的效率略有降低，同时为其他病原体带来潜在的大幅收益。与优先针对单一疫苗可预防疾病的策略相比，使用多病原指数进行优先排序在孟加拉国需要针对的空间集群减少4%（95% CI：0-12%）即可覆盖额外四种病原体，在肯尼亚减少10%的集群（95% CI：3-17%），在柬埔寨减少11%（95% CI：5-22%）的集群即可覆盖所有疾病中80%的潜在干预受益人群。在所有环境中，我们观察到多种病原体的地理聚集，孟加拉国（Moran's I = 0.58）、肯尼亚（I = 0.56）和柬埔寨（I = 0.26）具有中到高度的空间自相关，表明更高效、空间集中的整合干预具有潜力。我们还发现多病原指数与多维贫困指数在孟加拉国（Spearman's ρ = 0.25）、肯尼亚（ρ = 0.51）和柬埔寨（ρ = 0.59）显著相关，表明多病原指导的策略可能有效针对公共卫生需求最高的贫困人群。该框架为指导整合项目实施提供了系统方法，为更高效的疾病控制提供了潜力。
    难以阻止：代理驱动的测序预授权工作流中的自动化偏见 Nie, M. 2026-11-16 PDF 目的：外显子组或基因组测序（ES/GS）的事先授权（PA）是一个耗时的过程，阻碍了罕见疾病的及时诊断。基于大语言模型（LLM）的浏览器代理为自动化这些工作流程提供了潜力，但其临床可靠性仍未被表征。方法：我们构建了一个沙盒，其中包含模拟的ES/GS支付方门户和836名患者档案的合成电子健康记录（EHR），包括合规档案和设计有缺陷的缺陷档案。Gemini 3 Pro、Gemini 3 Flash和Claude Opus 4.5在任务完成、表单准确性和适当保留方面进行了评估。在100个档案上进行了两次复制实验，以评估代理性能的逐次运行变异性。结果：Gemini 3 Pro（95.5%）和Claude Opus 4.5（93.7%）完成的任务远多于Gemini 3 Flash（56.1%），且在各次运行中保持一致。在第一次运行中，所有模型都很少因正确原因保留缺陷档案（Gemini 3 Pro 0%，Gemini 3 Flash 17.3%，Claude Opus 4.5 5.2%）。复制实验揭示了显著变异性：Gemini 3 Pro的正确保留率上升至28.8-36.8%，且仅18.0-48.0%的任务在三次运行中产生相同结果。在没有代理脚手架的情况下，Gemini 3 Pro在91.3%的缺陷档案中标记了设计问题，但也在所有合规档案上停止。结论：当前基于LLM的浏览器代理显示出对表单提交的系统性偏向。为安全临床部署，可能需要一种具有人类监督的模块化多代理架构。
