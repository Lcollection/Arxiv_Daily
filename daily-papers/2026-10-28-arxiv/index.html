    蜂窝面元：用于高效场景渲染与重建的紧凑六边形图元 Prakhar Kaushik 2026-10-27 PDF 新视角合成与三维重建在辐射场和泼溅技术的推动下快速发展，但其内存与计算需求限制了在资源受限环境中的应用。我们提出Hexels：新型平面六边形表面元素，配备一阶空间颜色场，用于高效的三维场景与二维图像表示。Hexels利用局部平面区域，其外观平滑变化，使用更少、更大的基元。其六边形支撑提供了面积和边界高效的域，而局部颜色场则捕捉每个基元内的外观变化。在34个场景中，Hexels在多个数据集上将PSNR相较于内存匹配的2DGS提升了4.53-7.38 dB，同时所需训练VRAM更低。我们进一步通过消融实验表明，在单个基元上，Hexels以更低的训练VRAM和2.31倍更快的FPS，性能超过2DGS最多4.74 dB。即使在无约束设置下，Hexels也提供了互补的质量-内存权衡。对于高效三维表面重建，Hexels在15个DTU扫描上相较于内存匹配的2DGS将误差降低了28.9%。在6个Tanks and Temples表面场景上，Hexels在对比方法中取得了最高的平均F1（34.38%，而2DGS为31.72%）。我们进一步还表明，Hexels作为一种通用基元，在二维图像表示上优于Image-GS。Hexels推动了表面对齐基元在质量-效率权衡上的帕累托前沿。
    ThinkWorld：世界想象强化动态链推理 Chaehyun Kim 2026-10-27 PDF 视觉-语言-动作（VLA）模型在机器人操作方面已取得实质性进展，但其泛化能力仍受限于动作标注机器人演示的多样性与覆盖范围。人类视频提供了更为广泛的行为与环境经验，而从中学习面临可扩展数据与显式动作 grounding 之间的根本性权衡。我们提出 ThinkWorld，一个将动作推理建立在世界动态之上并通过世界想象强化学习加以强化的 VLA 学习框架。ThinkWorld 将每个动作思维表示为动态链（Chain-of-Dynamics，CoD），即一系列离散运动 token，捕捉连接当前世界与未来状态的中间动态，并作为跨具身形态的通用动作表示。我们首先用动作标注演示初始化 CoD，然后预测每个 CoD 所诱导的未来，并对预测更匹配观测结果者进行强化。这使无动作标注的视频能够从观测到的状态转移中提供直接监督，从而让人类与机器人经验精炼同一推理空间。仿真与真实机器人实验表明，该方法实现了有效的人到机器人迁移，并对未见任务与环境具有强泛化能力。
    离散标记能否作为视觉信号的语义无损表示？ Jialv Zou 2026-10-27 PDF 离散视觉 token 以类似于语言的离散形式表示视觉，为在共享的下一 token 预测目标下进行多模态建模提供了原生接口。然而，量化误差被广泛认为会造成不可避免的语义损失，从根本上限制了离散视觉 token 的语义保真度，并使连续视觉表示成为内在的上界。我们以多模态理解作为语义保真度的代理指标，重新审视这一假设，发现量化误差并不可靠，因为量化误差大得多的离散表示反而可以实现更好的理解。相反，离散索引的有效比特预算成为下游性能的关键决定因素。然而，现有量化器最终会饱和，因为额外的码本贡献的语义信息逐渐减少。作为缓解这种饱和的一种方法，我们引入了因子化向量量化，它使用对称并行码本对视觉特征的互补、固定维度视图进行量化。它在更大的比特预算下持续改进，最终在多模态理解中与连续视觉表示相匹配。在工业规模多模态数据上训练后，我们的模型在离散表示模型中达到了最先进的性能，在九项指标平均值上分别比 UniAR 和 Emu3-Chat 高出 22.8% 和 59.2%。据我们所知，它也是首个能与 Qwen3-VL 等强连续表示模型竞争的离散表示模型，包括在细粒度 OCR 任务上。我们进一步确定了实现这种竞争力的关键原则和实用方案。这些结果和见解支持离散视觉表示支撑大规模原生多模态基础模型的潜力。代码和模型可在 https://github.com/hustvl/FVQ 获取。
    我们应在何时于测试阶段进行干预？ Jiahao Zhang 2026-10-27 PDF 测试时自适应帮助已部署模型响应变化的输入，但同样的干预可能拯救一个批次却损害下一个批次。例如，更新归一化统计量可以改善损坏图像，但当批次主要包含一个类别时会失败。平均准确率掩盖了这些失败，无法告诉模型何时使用干预。目标标签可以指导这一决策，但它们稀缺，且某些选择已经明确。我们引入PORTAL，一个控制器，选择何时部署干预、标注哪些输入以及何时停止查询。每个可用的预测规则都是一个候选，其预测在当前反馈到达之前就已固定。因此，每个获取的标签都在同一输入上评估所有候选。PORTAL结合这些共享比较，并将查询导向仍可能超越当前领先者的候选。当剩余标签无法改变选择，或可能的准确率增益不再值得另一次查询时，它停止。我们的分析将所需反馈与准确率差距和共享错误联系起来，解释为何某些选择需要少得多的证据。实验表明，这种控制将整体上损失准确率的干预转变为在选定批次上的有用选择。它防止由到达顺序变化引起的严重失败，并在完整损坏流中保持增益。当固定规则已经表现良好时，PORTAL使用少量反馈来保持其性能。定期标签检查揭示过去证据何时需要刷新，并帮助控制器在条件变化时恢复。获取的标签还为未来批次训练更强的候选，选择将几乎所有的准确率增益带入部署。因此，同样的反馈既改善了当前做出的选择，也改善了后续批次可用的预测。
    安全负责人：学习到的注意力门控提升提示注入鲁棒性 Igor Shilov 2026-10-27 PDF 我们提出安全负责人（Heads of Security, HoS），一种提示注入防御方法，通过一小组学习到的逐头注意力门控来强制实现指令与数据的分离。HoS 学习每个注意力头应如何在可信与不可信 token 之间重新分配注意力，使模型能够对不可信内容进行推理而不遵循注入的指令。我们在 Llama-3.3-70B-Instruct 和 GPT-OSS-20B 上评估 HoS。我们将其与 SecAlign++（一种最先进的基于微调的防御方法）以及 ASIDE（一种与我们的方法类似、将指令-数据分离构建到模型架构中的防御方法）进行比较。我们表明，HoS 对自适应攻击具有更强的鲁棒性，在标准效用基准上表现更好，并在标准智能体提示注入基准上达到顶级性能。更具体地说，黑盒 RL-Hammer 攻击对 GPT-OSS-20B 达到 97% 的攻击成功率（ASR），对 SecAlign 达到 85%，但对 HoS 仅达到 10%。Claudini 是一种最先进的白盒攻击，通过自动研究针对 HoS 进行了强化，其在 HoS 上达到相同 ASR 所需的 FLOPs 是在 GPT-OSS-20B 或 SecAlign 上的 3 倍。HoS 在标准多项选择基准和提示设置中保持了基座模型的效用，而 SecAlign 和 ASIDE 在少样本设置下性能下降。在具有静态攻击的智能体基准上，HoS 和 SecAlign 表现相似，并且相较于基座模型大幅改善了安全-效用权衡。ASIDE 在工具使用方面表现不佳，仅达到 10% 的效用。这些结果表明，提示注入的鲁棒性可以通过有针对性的注意力干预来实现和提升。
    注意力作为格点规范理论：关系仅通过威尔逊环相互作用 Aakash Sarkar 2026-10-27 PDF 关系通过它们共享的实体进行复合——Alice是Bob的母亲，Bob是Carol的父亲，因此Alice是Carol的祖母——并且顺序很重要，因为父亲的母亲不是母亲的父亲；验证一个复合关系意味着闭合环路。我们证明，如果每个实体的坐标框架可以独立旋转（逐实体框架自由度），则有三件事随之而来。在纯规范扇区中，不共享任何环路的关系完全无法相互作用。三角形唯一的规范不变评分是其和乐$H = T_{ij} T_{jk} T_{ki}$的类函数——一个Wilson环。而边的唯一等变更新是$U = Ψ(H)\, T_{ij}$，其中$Ψ$是共轭等变的。因此，通过Wilson环进行的边注意力不是众多设计之一，而是对称性所允许的唯一形式。三个社区各自持有这一形式的部分：知识图谱的交换算子嵌入是其阿贝尔（交换）扇区；AlphaFold的三角形更新和Edge Transformer具有其形状——通过第三个顶点更新一条边——但没有其约束；而格点QCD在格点上等变地构建了它。我们在一般关系图上实例化等变子族，称为和乐注意力。在无训练且仅靠复合的情况下，它在稀疏图上以五分之一的边被损坏的条件下，以0.88的准确率推断出未观测到的$S_4$关系，达到或略低于专业同步算法，而每个交换架构的上限为0.083；其和乐评分以AUC 0.99标记损坏的三角形，而交换评分因第二条选择规则上限为0.76，并且它无需标签即可分离聚类。
    KPPax：为大气化学中的机器学习预处理可微分动力学ODE Wenqing Peng 2026-10-27 PDF 大气化学机理通常以动力学预处理器（KPP）的语言发布，该预处理器可生成高效的 Fortran 或 C 代码，但不适用于开发机器学习模型的可微编程框架。我们提出 KPPax，一种动力学预处理器，可从以 KPP 语言编写的机理出发，在 JAX 中生成可微、即时编译且可向量化的化学代码。KPPax 在对数空间中用稀疏运算计算速率定律，从而保持可微性，并使用 \texttt{diffrax} 库的隐式求解器及前向和反向模式伴随来积分刚性系统，因此无需手工推导伴随代码即可获得精确灵敏度。我们以 POLLU 基准机理演示了两个应用。第一个应用中，由自动微分雅可比矩阵计算得到的 Fisher 信息矩阵在任何拟合之前就预测出类流管设计能够识别 25 个速率系数中的哪些，含噪合成估计将九个可识别速率系数的预测不确定性确认到约 30% 以内，同时揭示出仅其比值受到约束的快速反应簇。第二个应用中，排放清单的神经网络校正先基于逐场景 4D-Var 反演离线训练，再通过化学模型在线微调，使生物源校正的误差降低 2.4–5 倍，并恢复了个体反演所丢失的低温排放信息。KPPax 使 KPP 机理可直接用于参数估计和物理–机器学习混合建模。
    推动灵巧性与安全性，实现效果显著优异的手内物体姿态到达 Ian Chuang 2026-10-27 PDF 多指手灵巧操作是机器人学的下一个前沿，然而已学习到的手部技能仍局限于简单抓取或基本重复动作，例如旋转物体。随着机器人尝试更高难度的在手操作，安全性（例如不掉落物体）变得至关重要，但这一点却很少被衡量。我们研究在手物体位姿到达任务，该任务要求多样且困难的抓取：在任意腕部朝向下，通过长序列的连续目标，将物体移动到手指可达范围内的几乎任意位置和朝向。我们提出了一套在仿真中为LEAP手训练此类策略的方案，无需人类数据，该方案建立在多项洞见之上，从通过生成的抓取数据集实现多样化重置与目标，到自适应摩擦课程。通过仔细的系统辨识，策略零样本迁移到真实手，使用动作捕捉或单个腕部安装的深度相机，并展现出显著的能力与鲁棒性。在任务策略之上，我们添加了一个可学习残差安全滤波器，其保守程度可调，使我们能够调节性能与安全之间的平衡，并大幅减少物体掉落。在13.3小时的真实机器人评估中，覆盖4个物体和多样腕部朝向的4800个未见目标，基于状态的策略在2厘米和0.4弧度内达到95.2%的目标，滤波器将其掉落减少75%，同时仍达到91.5%的目标。这些策略还能旋转以任意位姿持有的灯泡，到达分布外目标，承受快速手臂运动和扰动，并且仅需腕部相机即可作为便携技能使用，例如拧入灯泡。我们发布完整方案作为研究高维灵巧系统中性能、可靠性和安全性的平台。视频及更多内容见 https://ian-chuang.github.io/dexsafe/。
    GEPA-Curator：面向自我改进智能体的精选学习 Zack Yu 2026-10-27 PDF 大型语言模型（LLMs）越来越多地用于多轮智能体工作负载，这些负载需要与复杂环境进行持续交互。现有的反思式提示优化器（如GEPA）从失败的 rollout 中学习，但智能体失败也可能源于提示弱点、执行框架限制、随机执行或带噪声的评判器。我们认为此类失败可能无法提供有用的学习信号，甚至可能有害；因此，必须精心筛选提供给提示优化器的任务，以获得更好的性能。我们提出 GEPA-Curator，一个增强提示优化器的框架，用于选择哪些智能体经验应塑造提示优化。具体而言，GEPA-Curator 由两个组件构成：任务筛选，用于过滤掉可能提供噪声或不可靠学习信号的任务；以及先验成功检索，用于选择性地检索某个任务过去的成功轨迹，并将其作为额外上下文提供给提示优化器。我们在 GoBrowse、ALFWorld、AppWorld 和 $τ$-bench 上评估 GEPA-Curator，使用 Gemini 3.1 Pro 和 Claude Opus 5 作为优化器模型。GEPA-Curator 达到或超过两个基线的平均性能，相较 GEPA 提升最高达 20.7%，相较 ACE 提升最高达 21.2%。
    大型语言模型能否通过自由探索揭示隐藏的物理定律？ Zhen Yang 2026-10-27 PDF 科学发现往往始于一个意想不到的观察，进而引出新的研究问题。在一个物理定律被改变的世界中，大型语言模型（LLMs）能否注意到异常行为——例如较重的物体下落得更慢——并在未被告知要研究什么的情况下，通过实验发现该定律？为评估这一能力，我们引入了LongChang，一个自动化框架，用于创建物理规律被改变、其中一条或多条定律不同于普通物理的模拟世界。被评估的LLMs充当探索者，操纵物体并建造工具，以研究自己提出的问题，而无需研究任务或关于这些定律的提示。独立的LLM智能体负责生成和审查场景、审查工具设计，并利用改变后的物理定律和探索记录来评估报告的正确性与实验支持度。这些记录引导场景演化以进行进一步探索，使整个循环无需人工干预即可运行。在12个LLMs中，GPT-6-Astra达到了16.7%的发现率，而其余11个均为0%。探索记录揭示了未被调查的异常现象，以及对改变后的物理定律仅有的部分识别。
