    肠道微生物组与新发动脉粥样硬化性心血管事件：三项瑞典队列的前瞻性分析 Pertiwi, K. 2026-11-16 PDF 背景：在病例对照设计中，肠道微生物组组成的变异与动脉粥样硬化性心血管疾病（ASCVD）相关。我们旨在采用前瞻性设计研究其与新发ASCVD事件的关联，以减少反向因果的影响。方法：我们评估了通过鸟枪法宏基因组测序测定的肠道微生物组特征与新发总体ASCVD、缺血性心脏病（IHD）和缺血性卒中的关联，包括来自三个瑞典人群队列（SCAPIS、SIMPLER和MOS）的17,216名参与者中由登记随访定义的致死性和非致死性事件。对人口学、生活方式因素、用药和现患糖尿病进行调整的Cox比例风险回归模型结果，通过固定效应荟萃分析在各队列间合并，并校正多重检验。这些关联在HUNT和FINRISK研究中进行了重复验证。结果：在中位6-8年随访期间，发生了769例新发ASCVD事件。物种多样性与ASCVD和IHD呈负相关，物种丰富度每增加1个标准差，IHD的风险比为0.86（95% CI：0.79-0.95）。在调整性别和出生国家后，68种常见物种（即在≥30%个体中存在的物种）与新发IHD相关，但在完全调整模型中仅剩8种，包括Ruminococcus_B gnavus。其中，来自Christensenellales目（据报道该目具有丁酸产生能力）的SFEL01 sp004557245和Fimadaptatus sp900553645观察到负相关。Streptococcus mutans和Limosilactobacillus fermentum——先前与冠状动脉粥样硬化相关的口腔相关物种——与新发IHD风险升高相关，且在调整牙齿健康后仍存在。HUNT研究中的重复分析支持了S. mutans的发现。未观察到与缺血性卒中的关联。结论：肠道物种多样性和特定物种丰度与新发IHD相关，提供了支持两种Christensenellales物种的保护作用以及口腔物种和R. gnavus在IHD发展中的不利作用的证据。
    北欧人群中肠道微生物组与新发心血管疾病的关联 Wolford, B. N. 2026-11-16 PDF 背景：肠道微生物组是心血管疾病的新兴危险因素。然而，目前缺乏具有重复验证的大规模宏基因组研究来识别与心血管疾病（CVD）发病相关的肠道微生物特征。方法：我们在一个发现-重复验证框架中，利用四个大型前瞻性北欧队列的粪便样本宏基因组，检验肠道微生物组与CVD的关联。发现队列包含11,604名参与者中的635例CVD发病事件，三个重复验证队列合计包含20,965名参与者中的2,309例CVD发病事件。结果：较高的Shannon多样性指数和物种丰富度始终与较低的CVD发病风险相关。此外，九种物种和十一个细菌功能模块的相对丰度在发现队列以及三个重复验证队列的荟萃分析中均显示出与CVD发病的可重复关联。我们识别出一条女性特异性的肠道微生物群相关通路，涉及常见的口腔-肠道物种Rothia mucilaginosa_A，该物种在义齿使用者中富集，因而可作为长期口腔健康不良的替代指标。孟德尔随机化分析支持义齿使用对Rothia mucilaginosa_A相对丰度增加存在因果效应。该通路通过改变的肠道微生物锰转运、升高的循环咪唑丙酸水平以及升高的全身性炎症生物标志物水平，与CVD风险增加相关联。第二条通路涉及β多样性指标和其余八种物种，所有这些均与代谢综合征的多种标志物以及涉及嘌呤代谢、微生物应激反应、氧化还原平衡改变、抗坏血酸降解和支链氨基酸生物合成的细菌通路强烈相关。结论：这些发现表明，肠道微生物群多样性、特定分类群和功能通路为CVD的潜在生物学机制提供了新的见解。此外，这些发现提示口腔健康不良与心血管疾病之间的关联可能至少部分通过改变的肠道微生物群发挥作用。

    孤独感与15年卒中风险相关：弗雷明汉心脏研究 Ekenze, O. 2026-11-16 PDF 心理社会因素是卒中可改变危险因素的有前景的候选因素。鉴于孤独感在全球范围内日益普遍，其值得关注；然而，孤独感与随后卒中之间的时间关系仍不明确。目的：阐明孤独感的时间性与新发卒中之间的关联。方法：纳入弗雷明汉心脏研究参与者，其无卒中，且在发生新发卒中之前至少进行过两次孤独感评估（在基线检查时，以及在基线前至多15年的既往检查时）。孤独感通过流行病学研究中心抑郁量表“我感到孤独”条目的反应进行评估，定义为过去一周内有3天感到孤独。孤独感的时间近因性定义为既往孤独感（在既往检查时存在）和基线孤独感（在基线检查时存在）。主要分析分别检验既往孤独感与无既往孤独感、基线孤独感与无基线孤独感同新发卒中之间的关联，随访15年。Cox模型调整年龄和性别（模型1），并额外调整血管危险因素（模型2）、抑郁症状（模型3）和体力活动（模型4）。探讨孤独感与年龄和性别之间的交互作用。结果：在4307名参与者中（平均年龄62±10岁，55%为女性），198名（4.5%）在中位6.5年随访期内发生新发卒中。177名（4.1%）报告既往孤独感，226名（5.2%）报告基线孤独感。与无既往孤独感的参与者相比，有既往孤独感的参与者在调整年龄、性别、血管危险因素、抑郁症状和体力活动后，卒中风险增加近3倍（HR=2.85，95%[CI] 1.51-5.39）。该效应主要在<80岁的参与者中观察到（平均年龄60岁。HR=3.21，95% CI 1.69-6.13）。在基线时有孤独感的参与者中未观察到卒中风险增加。结论：我们的研究结果支持将孤独感视为新发卒中的潜在可改变危险因素，尤其是在中年期。

    通过多病原监测指导整合疾病控制措施的框架 Bents, S. J. 2026-11-16 PDF 全球卫生项目传统上聚焦于单一疾病。通过整合干预实施存在协同潜力，尤其是在疾病负担地理重叠的地区，但指导整合的方法学发展有限。在此，我们提出一个框架，将多病原监测数据转化为可指导整合项目实施以同时针对多种病原体的汇总指数。我们在三项大规模调查中考虑了多种多样性度量来量化多病原感染或疫苗接种不足：孟加拉国的次区域（90个集群，n=7187）和肯尼亚（89个集群，n=9077），以及柬埔寨的一项全国调查（100个集群，n=2150）。我们发现，以多样性度量——Rao二次指数——为指导的策略在一系列干预组合中始终比其他多病原指数识别出更高效的整合策略。随后我们在每个环境中确定了以免疫为整合骨干的案例研究，发现纳入共现病原体信息仅导致疫苗可预防疾病的效率略有降低，同时为其他病原体带来潜在的大幅收益。与优先针对单一疫苗可预防疾病的策略相比，使用多病原指数进行优先排序在孟加拉国需要针对的空间集群减少4%（95% CI：0-12%）即可覆盖额外四种病原体，在肯尼亚减少10%的集群（95% CI：3-17%），在柬埔寨减少11%（95% CI：5-22%）的集群即可覆盖所有疾病中80%的潜在干预受益人群。在所有环境中，我们观察到多种病原体的地理聚集，孟加拉国（Moran's I = 0.58）、肯尼亚（I = 0.56）和柬埔寨（I = 0.26）具有中到高度的空间自相关，表明更高效、空间集中的整合干预具有潜力。我们还发现多病原指数与多维贫困指数在孟加拉国（Spearman's ρ = 0.25）、肯尼亚（ρ = 0.51）和柬埔寨（ρ = 0.59）显著相关，表明多病原指导的策略可能有效针对公共卫生需求最高的贫困人群。该框架为指导整合项目实施提供了系统方法，为更高效的疾病控制提供了潜力。
    难以阻止：代理驱动的测序预授权工作流中的自动化偏见 Nie, M. 2026-11-16 PDF 目的：外显子组或基因组测序（ES/GS）的事先授权（PA）是一个耗时的过程，阻碍了罕见疾病的及时诊断。基于大语言模型（LLM）的浏览器代理为自动化这些工作流程提供了潜力，但其临床可靠性仍未被表征。方法：我们构建了一个沙盒，其中包含模拟的ES/GS支付方门户和836名患者档案的合成电子健康记录（EHR），包括合规档案和设计有缺陷的缺陷档案。Gemini 3 Pro、Gemini 3 Flash和Claude Opus 4.5在任务完成、表单准确性和适当保留方面进行了评估。在100个档案上进行了两次复制实验，以评估代理性能的逐次运行变异性。结果：Gemini 3 Pro（95.5%）和Claude Opus 4.5（93.7%）完成的任务远多于Gemini 3 Flash（56.1%），且在各次运行中保持一致。在第一次运行中，所有模型都很少因正确原因保留缺陷档案（Gemini 3 Pro 0%，Gemini 3 Flash 17.3%，Claude Opus 4.5 5.2%）。复制实验揭示了显著变异性：Gemini 3 Pro的正确保留率上升至28.8-36.8%，且仅18.0-48.0%的任务在三次运行中产生相同结果。在没有代理脚手架的情况下，Gemini 3 Pro在91.3%的缺陷档案中标记了设计问题，但也在所有合规档案上停止。结论：当前基于LLM的浏览器代理显示出对表单提交的系统性偏向。为安全临床部署，可能需要一种具有人类监督的模块化多代理架构。
