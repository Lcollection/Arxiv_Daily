    医学图像分割：基础模型适配与任务特定训练 Emre Kutlusan 2026-11-10 PDF 在大型自然图像集合上预训练的基础模型正越来越多地被适配用于医学图像分割，人们期望它们能够取代为每个任务单独训练的模型。然而，大多数比较使用的是来自训练分布的数据以及一个配置很少经过论证的单一任务特定基线，因此对新临床站点性能的证据有限。基础模型需要适配多少以及由什么决定这一点也仍不清楚。我们适配了一个基础模型DINOv2，采用的策略从仅调优其偏置项到完全微调不等，并将其与从头训练的U-Net和ResU-Net进行了比较。实验涵盖结肠镜检查、乳腺超声和皮肤镜检查，并在来自训练来源的留出数据以及其他机构提供的独立数据集上进行测试。适配后的基础模型在每个外部数据集上都泛化得更好。在训练分布内，当训练数据充足时，任务特定模型仍具有竞争力，并且更精确地勾画边界，而基础模型更常遗漏小病灶。基础模型中只有一小部分需要适配，所需容量由成像域而非适配方法决定。还发现一个广泛使用的息肉测试集重复了另一个基准中的图像。因此，在模型必须跨站点工作时，基础模型适配是有必要的，且容量应根据目标域来选择。
    面向通过示例基座进行基础检测模型的EM-DETR研究 Sheethal Bhat 2026-11-10 PDF 基于深度学习的计算机辅助诊断系统在支持临床医生方面展现出巨大潜力，但其性能在很大程度上依赖于大规模、标注良好的数据集的可用性。在医学病灶检测中，全面的标准化标注的稀缺性以及现有数据集的异质性限制了稳健基础模型的发展。在本工作中，我们提出了一种新方法，通过整合针对解剖结构和异常进行标注的多样化医学图像数据集，构建用于病灶检测的多域基础模型。我们首先提出一种学生-教师训练策略，以有效结合具有异质标签空间的数据集，缓解灾难性遗忘并改进特征学习。此外，在我们此前提出的基于示例的EM-DETR框架基础上，我们对其进行了适配，使其能够从多个域特定数据集联合学习，从而实现跨模态的细粒度、示例驱动的检测。我们的模型取得了最先进的结果，在胸部X线片的四个关键发现上，图像级AUC分数超过此前最先进水平1个百分点。我们在胸部X线片和乳腺摄影中取得了领先的mAP50，超过在单一数据集上训练的EM-DETR 2-3个百分点。该方法为医学影像中可扩展的基础模型开辟了道路，这些模型能够利用异质数据，同时保持稳健且可泛化的性能。
    TorchCurves：可微参数曲线 Alex Shtoff 2026-11-10 PDF 我们提出了 TorchCurves，一个 PyTorch 库，将向量值参数曲线视为可学习的基元。其核心操作将批量标量输入映射到以 B 样条或 Legendre 多项式基表示的曲线上的点，并可对输入和系数进行微分。曲线系数可与周围模型联合优化，或由另一个网络生成。该库提供可训练模块、可复用基模块和函数式接口，支持从连续特征嵌入到 Kolmogorov-Arnold 网络和函数回归等应用。其实现将经典求值算法与向量化 PyTorch 操作相结合，强调可读性和可维护性，无需自定义硬件内核。计时实验在不同问题规模下将曲线求值与 NumPy 和 SciPy 进行比较，并将 KAN 训练与 EfficientKAN 进行比较。结果说明了这种通用性在何处仍具有计算实用性，以及在何处开销较大。该库可在 GitHub 上获取，网址为 https://github.com/alexshtf/torchcurves。
    AutoScaffold：面向语言模型强化学习的AI引导式脚手架 Zijian Zhang 2026-11-10 PDF 带可验证奖励的强化学习（RLVR）能产生丰富的训练经验，但结果奖励将每次尝试压缩为单一数值，使其中大部分信息未被利用。训练时脚手架，即在训练期间向提示中加入策略或提示语，为将这些信息转化为指导提供了自然途径，但其设计与适配在很大程度上仍依赖人工，并针对特定领域定制。我们提出 AutoScaffold，一个统一的 AI-for-AI 框架，将学生的训练经验转化为自适应脚手架，仅需极少领域特定信息，且训练过程中无需人工干预。一个冻结的教师模型定期检查这些经验，诊断瓶颈，并以两种形式设计脚手架：（i）跨一类任务共享的策略，以及（ii）针对单个困难任务的提示，随着学生的学习进展调整支持的内容与数量。评估时移除脚手架。我们将同一框架应用于 ALFWorld、基于搜索的问答、数学推理和 GPU 内核生成。在无脚手架评估时，使用 AutoScaffold 训练的学生在全部四个领域均优于使用相应 RL 基线训练的学生，在 ALFWorld 成功率上提升 7.2 分，在问答平均精确匹配上提升 4.0 分。在 GPU 内核生成上，AutoScaffold 将生成正确内核且运行速度快于 PyTorch 参考实现的任务比例最多提升 5.0 分。在数学上，我们的学生以约三分之一的学生训练步数超越了 QuestA 报告的准确率。分析表明，教师模型在每个任务类别中识别出不同的失败，并随着学生的提升将脚手架从分步工作流转向针对性修复，且其修订后的脚手架比保留先前脚手架或不使用脚手架更能帮助学生学
    对比发现：在竞争性解释中进行开放式科学发现 Ziang Liu 2026-11-10 PDF LLM智能体越来越多地被用于开放式的、数据驱动的科学发现，但其中大多数以逐点方式评估假设，仅将经验主张h与其补集¬h进行检验。当证据拒绝h时，智能体得知某一种解释不太可能，却不知道证据支持哪一种替代解释。为恢复该替代解释，我们引入对比发现（Contrastive Discovery），它将单一假设替换为对比集，即一个科学问题配以互斥且完备的竞争性解释。每个实验根据其证据在该集合上重新分配信念的程度进行评分，当信念集中于某一种解释时，问题即得到解决。由于对比集仅改变智能体所提出和评分的单元，现有智能体可以利用它们重新评估已收集的证据或指导其搜索。在六个领域中，信念偏移最大的逐点候选中有89%为拒绝。在相同证据上，对比集将这些候选中的73%解决为某一具体替代解释。当对比集指导搜索时，在相同实验预算下，智能体解决的问题比逐点惊奇度多67%。在一项盲测研究中，38位人类专家在78%的已解决问题上选择了相同的解释，而在逐点智能体拒绝其假设并停止的问题上，这一比例为82%。这些结果共同支持将显式竞争性解释作为发现智能体在相同证据与验证预算下解决更多科学问题的一种方式。
    黄铁矿：构建和基准测试蛋白质-配体姿态排序代理 Megha Srivastava 2026-11-10 PDF 预测配体如何与其靶标结合是小分子药物发现的核心。现代共折叠模型能够生成多样化的候选构象，但可靠地对这些候选进行排序仍然具有挑战性。我们提出 Pyrite，一个成对构象排序基准，包含跨越多样化蛋白质-配体复合物的 1,500 个构象对。配备 3D 可视化工具和基于物理的打分的专家化学家表现接近随机水平，凸显了解读现有化学信号的难度。为研究自动化排序，我们提出 PyriteRep，一种对分子几何、蛋白质-配体相互作用和物理化学打分的结构化表示，并开发了两种基于 LLM 的智能体：PyriteReasoner，通过基于文本的推理直接比较构象；PyriteFeaturizer，生成可执行代码以构建用于逻辑回归的特征，并可选地纳入由 LLM 子调用导出的特征。这些智能体分别达到最高 67% 和 74% 的准确率，超过了观察到的专家表现。LLM 引导的特征发现通常优于直接推理，而组相对策略优化（GRPO）改进了开放权重模型，使其在我们的评估中能够匹配或超越闭源前沿模型。这些结果确立了 Pyrite 作为构象排序能力的一项具有挑战性的测试，并凸显了 LLM 引导的特征发现作为一种解读和整合计算化学工具输出的有前景的方法。
    真实连接何时胜出？用未测量的生理学检验连接组结构-功能主张 Yeyuan Liu 2026-11-10 PDF 连接组约束的模型常被用来论证：实测的接线图优于打乱或重连的接线，因而结构塑造功能。此类比较会将接线与模型的调参方式混为一谈：连接组固定了谁与谁相连，却不决定模型同样需要的兴奋性、增益或可塑性速率，而建模者往往调整这些参数，直到真实接线模型能够工作为止。我们区分了三种估计量：在真实接线上调参并迁移到零模型的生理参数（P1）、每种接线各自调参（P2），以及将P2限制在与独立数据一致的生理参数范围内（P3）。所涉及的偏差在机器学习中已知（欠调基线、继承权重、赢家诅咒）；我们利用合成真值、安慰剂零模型和三个果蝇回路模型，测量这些偏差对生物学结论的影响。有些主张在我们测试的每种方案下都成立：分离的奖赏与惩罚多巴胺改善了学习，头方向拓扑是持续凸起所必需的。其他主张则不然。在蘑菇体中，真实的Kenyon细胞输出接线在P1和P2下以0.09的优势胜过跨亚型身份打乱，但在P3下以0.09的劣势输给它（95%置信区间排除零；留出运行予以确认）。裁决由活跃Kenyon细胞中alpha'beta'细胞所占比例决定，而P1将该比例选得较低；在成像所暗示的比例（约44%）下，真实接线模型无法学习，这暴露的是模型的不充分性，而非果蝇接线的缺陷。在flyvis中，P1对镜像连接组的惩罚大于空间打乱连接组，前者在50个成员中的50个里均如此，其构造解与真实误差的中位数差距在0.07以内；该排序在延长十倍的再训练后依然成立，但在延长五十倍时取决于检查点。可信的结构性主张需要匹配的优化、数据约束的生理参数，以及在该条件下仍然有效的模型。
    持续学习-ARC：衡量整个职业生涯中的技能获取 Daniel Lenton 2026-11-10 PDF Agent harnesses 已成为持续学习的一种有前景的机制，与测试时参数学习并列。然而，当前的基准存在若干局限：它们通常聚焦于单一应用领域，每个实例仅出现一次，且假设单一学习者家族，因此基于记忆和基于权重的系统很少在同一尺度上进行比较。我们提出 Continual-ARC，一个由三个 ARC-AGI 版本构建的终身流，其任务无需领域知识。相同任务在休眠间隔后以新实例返回，同时新任务不断到来。在每个实例上，学习者可以付费获取演示、提交答案或在 harness 内行动，错误提交允许重试，但需付费。每个实例的评分基于所消耗反馈预算的份额。由于学习者可以在实例之间保留任何内容，基于记忆和基于权重的系统在同一尺度上评分。在流结束后，学习者被冻结，并在其遇到过的任务的新实例上测试，以衡量记忆，以及在未见过的任务上测试，以衡量泛化。我们在 Qwen3.5-9B 和 GLM-5.3 Flash 上运行了权重冻结的 agent harness，分别在有持久化和无持久化的情况下，将其与两个提示基线、一种程序归纳方法以及 Qwen3.5-9B 经训练模仿 GLM-5.3 Flash 的权重进行比较。harness 中的持久化通常不会改善记忆，除非提供明确的专家指导。在我们测试的所有模型中，大多数基于 harness 的方法学习效果仍低于一个仅缓存每个任务演示的基线。没有任何基于 harness 的方法在未见过的任务上取得增益，而基于权重的学习显示出显著增益。这为未来基于权重的持续学习打开了大门，这种学习可以教会模型在新领域中驱动 harness。
    分子相互作用基础模型中涌现的生物学能力 Adi Mashiach 2026-11-10 PDF 在大规模无标注语料上训练的基础模型会发展出涌现能力，即超越训练目标的任务能力。我们将这一范式扩展到多模态生物学，提出 Bonbon，这是一个分子相互作用基础模型，基于约 3.2 万亿 token 的配对蛋白质-配体序列训练而成。从单一表示空间出发，Bonbon 在分层分辨率上展现出三种零样本涌现能力：功能层面（作用机制）、残基层面（结合位点定位，包括正构/别构区分）以及键层面（共价与非共价结合）。这三种能力均能泛化到分布外复合物。Bonbon 仅基于蛋白质-配体序列训练，没有任何任务特定监督，也没有结构坐标。我们进行了受控缩放实验，涵盖从 42M 到 1.6B 参数的六个模型规模；在连续指标上，每一项评估的能力都在最大规模处出现急剧跃升，即使预训练损失平滑下降。这表明仅凭基于损失的缩放定律不足以预测零样本涌现能力何时出现。本文报告的能力是在以 1:2,000 的参数- token 比例训练后涌现的，以适应配对生物相互作用数据的稀疏性。相同的冻结表示以比共折叠方法快五个数量级的速度实现了最先进的结合与亲和力预测。在涵盖七个蛋白质家族的九个疾病靶点的前瞻性湿实验验证中，Bonbon 在从头化合物上达到 61.5% 的剂量反应命中率，产生结构新颖的分子，这些分子此前未被报道能抑制这些蛋白质，包括对分布外靶点。
    尼泰罗伊交通选择的空间格局 Sandro Martinelli Reia 2026-11-10 PDF 刻画人们在城市中的移动方式需要空间和时间上精细的数据，而这些数据往往获取成本高且难度大。在此，我们引入一个计算框架，利用宏观的、聚合的、静态的城市数据来构建微观的、动态的、空间详细的城市移动性表征。该框架建立在现有的活动模拟器之上，结合合成人口、建成环境和交通网络来生成日常出行，并分配步行、汽车或公共交通方式。应用于巴西尼泰罗伊约47.5万合成居民，模拟的社区级公交出行模式与实证活动代理指标显示出强关联（Pearson r=0.885）。步行在紧凑的中心区域更为普遍，汽车使用向边缘地区增加，而公共交通使用沿公交走廊保持相对较高。将往返公交站的步行时间减少30%，可使模拟的公共交通与汽车之比提高11.3%，在若干边缘地区公交分担率的增益更大。这些结果揭示了交通选择的空间差异，并识别出改善公交可达性可能产生最大模拟效果的地区。
