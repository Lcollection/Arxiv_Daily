    从记录的赌博机反馈中学习校准的决策头 Ye Yuan 2026-11-11 PDF 一个决策头读取状态和选项列表，并在一次前向传播中返回每个选项的概率。部署后，它通常只能观察到所选选项是否正确：即记录式的赌博机反馈。我们基于该反馈，在 Qwen3-0.6B-Base 和 1.7B-Base 上通过 LoRA 适配这样的决策头，并报告三项结果。第一，采样动作自身概率的 Brier 分数或对数分数不能作为可用的 REINFORCE 奖励：每个错误动作至少获得与正确动作相同的奖励；在均值基线下方，概率最低的错误动作获得最大优势；在两个选项时信号为零；在一次运行中，它将有序尺度问题的准确率从 .636 降至 .111。通过路径导数将概率作为损失进行评分可避免这种崩溃，REINFORCE 奖励 r 和 r 减 p 也是如此。第二，在完整标签下，四种测试的赌博机方案在四个未见标签模式上的平均期望校准误差（ECE）均未超过交叉熵加一个温度参数。第三，仅从记录式反馈出发，Chosen-Action Proper Scoring（CAPS），即在所选动作概率上使用适当评分的直接方法，优于仅在确认答案上微调（后者丢弃负例）：在 Banking77 上准确率高 2.6 个百分点，ECE 低 .053，选择性风险更低（三个种子对一个基线种子）；在记录器经常出错的情绪数据上，单种子下高 21.7 个百分点。在 N 5000 时，CAPS 在 0.6B 上比完整标签训练低 1.5 个百分点，在 1.7B 上低 .6 个百分点（对一个完整标签种子），且倾向权重在此日志上无增益。在已知翻转率的反馈下（每个翻转率一个种子），CAPS 的置信度平均上跟踪噪声信道，反向校正恢复了大部分干净校准，且基于留出记录式结果的早停在所有三次运行中防止了记忆噪声抽样。代码、适配器、日志和逐记录结果均已公开。
    TraceKV：面向推理视觉语言模型的策略保持低秩KV缓存压缩 Ke Li 2026-11-11 PDF 推理视觉语言模型（VLMs）因大规模多模态上下文和不断增长的推理轨迹而面临巨大的KV缓存需求。低秩KV压缩已成为一种有前景的范式，它存储KV状态的低维潜变量，并可与量化结合使用。然而，现有低秩方法在压缩推理KV状态时，往往会导致相对于稠密模型不断增长的预测策略漂移，从而造成推理失败。我们识别出这种性能退化的两个关键原因：静态上下文与在策略推理状态之间的校准状态失配，以及KV状态之间不相等的误差敏感性。为解决这些挑战，我们提出TraceKV，一个免训练的低秩KV压缩框架，在单一策略保持原则下统一了在策略校准、敏感性感知SVD和全局秩分配，大幅降低了推理过程中的策略-KL散度。在多个VLMs和视觉推理基准上的实验展示了更优的精度-内存权衡，与量化结合时在5.64倍KV缓存压缩下实现近乎无损的推理精度。优化的低秩注意力内核进一步带来高达1.83倍的端到端解码加速。代码将发布于https://github.com/AK-DREAM/TraceKV。
    我们能否让大语言模型变笨，还是它只是在装傻？一项关于可信性能节流的实证研究 Chengguang Gan 2026-11-11 PDF 基准分数通常被解读为模型能力的代理指标。我们研究其逆问题：模型能否被驱动至目标分数，其失败是否类似于天然较弱模型的失败？我们从三个维度操作化可信的性能下降：目标校准、项目难度结构，以及与真实弱参考模型的错误分布相似性。我们提出CapLadder，一个经IRT校准的测试套件，包含1,985个项目，涵盖数学、代码、多项选择推理和工具使用。一个简单的弱教师LoRA调节器在推理任务上达到未见过的目标水平，留出校准误差为1.9个百分点，而提示、温度和权重噪声无法结合可比的范围和精度。然而在多项选择上，该调节器收敛到一个答案词元吸引子：其新引入的错误中高达97%落在一个字母上，吸引子在Qwen中从D变化到Llama中的A。Logit干预识别出一个主导的近常数偏移：在留出项目上减去估计的偏移可恢复52%至59%的损失准确率并消除主导吸引子，而选项排列确认该偏差追踪的是词元位置而非选项内容。在标注者间高度一致（κ=0.94）的情况下，人工编码的错误类别分布在推理任务上仍与弱参考模型匹配（JS = 0.00），表明局部合理性与聚合可检测性存在差异。结构化工具调用在Qwen系列中表现出更自然的退化（JS = 0.09），而全局校准的调节器在不同基准之间迁移效果不佳（在两个可用基准上误差为14.2个百分点）。因此，精确的分数控制并不意味着可迁移或可信的技能下降。
    观测漂移，结构留存：面向电磁信号的时间对齐结构预训练 Wenjin Gui 2026-11-11 PDF 电磁信号建模正日益转向对异构I/Q观测的自监督预训练。然而，观测到的波形由信号生成、传播环境和采集过程共同塑造，其中混合了可复用的结构规律与观测特定的变化。现有方法通常对混合观测采用重建目标进行统一预训练。这种异构性为重建预训练带来了两个关键失配：（1）外观失配，由传播相关的波形变化引起；（2）时间失配，由采集相关的采样坐标引起。这些失配使得观测特定的外观和采样坐标比稳定的信号结构更容易被重建，从而诱发观测捷径。我们将这一失效模式识别为观测偏置预训练。为解决这一问题，我们提出了面向异构电磁信号的时间对齐结构预训练。它通过RoPE-fs缓解时间失配，该方法将token位置映射到采样率归一化的物理时间位置，并通过用离散结构单元的掩码预测替代波形重建，减少对外观捷径的依赖。这些单元被组织为原子结构单元和涌现结构单元，后者捕获超越固定patch边界的变长组合模式。在多样化的电磁基准上，我们的方法在全监督和少样本适应方面均优于现有电磁预训练基线，表明当观测在波形外观和时间尺度上发生漂移时，所学表示能更好地保持结构一致性。
    共形选择在CRISPR脱靶设计中能证明什么：基准泄漏、免费基线与有限样本队列要求 Mohammad Malekpouri 2026-11-11 PDF 共形选择承诺对决策错误率进行无分布、有限样本的控制，并已被提出作为机器学习CRISPR引导设计的安全层。我们追问：从现有的已验证脱靶数据中，这样的证书是否可获得。约束是算术性的：共形p值不能低于校准队列规模加一后的倒数，因此Benjamini-Hochberg选择只有在队列规模至少为候选池规模除以容忍错误率时，才能认证单个候选。公共队列提供十个已验证引导，而两千个候选池在百分之十错误率下需要两万个；因此，在超过百分之九十六的划分中，接受集为空。两项基准测试发现解释了为何这一点未被注意到。标准CIRCLE-seq文件在八十个on-target字符串下列出十个引导，因此按序列列进行分组交叉验证会在一 个引导上训练和测试；纠正后，配对级判别和逐引导保真度崩溃。去除该泄漏后，无训练的位置权重评分和近匹配基因组位点的裸计数不会被训练过的oracle击败。我们给出纠正后的协议、新模型必须击败的基线，以及认证流水线所需的队列规模。
    测试跨LLM API的对话保持：一种用于检测静默信息丢失的基于规则的预言机 Xin Liu 2026-11-11 PDF LLM 应用日益依赖翻译器和兼容层来跨 API 迁移对话。然而，一个经过翻译的请求可能被目标 API 接受，却在无声中丢失关于指令角色、工具交互、错误状态或生成控制的信息。我们提出 isloss，一种确定性预言机，用于测试跨 LLM API 翻译的对话信息保持性。它将源请求与回复以及翻译后的请求与回复映射到一个共享中间表示 ConvIR，并应用显式规则来区分合法的表示变更与信息丢失。与模式验证或基于参考的差分测试不同，isloss 既不需要参考翻译，也不需要额外的模型调用。它还能区分可避免的丢失与由目标 API 限制导致的降级。我们使用基于规范的故障注入、人工评审以及在翻译器、网关和客户端库上的实验来评估 isloss。在留出测试中，它检测出 125 个植入故障中的 95 个（76.0%），误报为 2/100（2.0%）。在覆盖五个翻译器代码库六种配置的合成请求套件中，685 个完成的翻译中有 127 个（18.5%）通过了静态目标检查，却在目标 API 本可保留的情况下无声地改变了提示、角色或工具信息。在翻译后的回复中，558 个流中有 203 个（36.4%）在至少一个受测的官方 OpenAI SDK 中导致异常或无声损坏。跨六个模型的有针对性实验表明，当任务依赖受影响的信息时，翻译引起的变化会改变模型行为。这些结果确立了对话保持性作为可靠 LLM 互操作、智能体执行和模型评估的一项独立正确性要求。
    忠实于步骤：通过查询分解提升RAG中的泛化性与引用 Yue Liu 2026-11-11 PDF 检索增强生成是缓解大语言模型幻觉的一种普遍策略。可归因RAG（RAGQ）为其答案生成引文。引文指示哪些输入上下文支持RAG推导出答案，从而增强答案的可验证性和可信度。然而，现有RAGQ在处理需要多跳推理和多模态理解的问题时表现出显著退化，存在过度引用、隐式实体识别失败和泛化能力差等问题。本文提出了一种新颖的RAGQ框架，即QDRAG。QDRAG将输入问题分解为原子子问题以识别隐式实体。然后，重排序器剪枝上下文干扰项以消除下游的过度引用。为促进查询分解，我们提出了两种零样本方法：QD-C和QD-R，分别基于上下文知识和检索奖励引导QD MLLM分解问题。一个有趣的发现是，在QD任务上微调相比直接在下游RAGQ任务上微调展现出更好的泛化能力。在四个多模态问答基准上的实验证明了QDRAG在答案归因和生成忠实引文方面的有效性。该框架在域内和域外测试中均显著优于所有基线，甚至超越了Gemini-Pro。
