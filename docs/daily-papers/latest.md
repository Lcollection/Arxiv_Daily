<h3>从记录的赌博机反馈中学习校准的决策头</h3>
<span class="paper-item__meta">arXiv / 2026-11-11 / Ye Yuan</span>
<p>一个决策头读取状态和选项列表，并在一次前向传播中返回每个选项的概率。部署后，它通常只能观察到所选选项是否正确：即记录式的赌博机反馈。我们基于该反馈，在 Qwen3-0.6B-Base 和 1.7B-Base 上通过 LoRA 适配这样的决策头，并报告三项结果。第一，采样动作自身概率的 Brier 分数或对数分数不能作为可用的 REINFORCE 奖励：每个错误动作至少获得与正确动作相同的奖励；在均值基线下方，概率最低的错误动作获得最大优势；在两个选项时信号为零；在一次运行中，它将有序尺度问题的准确率从 .636 降至 .111。通过路径导数将概率作为损失进行评分可避免这种崩溃，REINFORCE 奖励 r 和 r 减 p 也是如此。第二，在完整标签下，四种测试的赌博机方案在四个未见标签模式上的平均期望校准误差（ECE）均未超过交叉熵加一个温度参数。第三，仅从记录式反馈出发，Chosen-Action Proper Scoring（CAPS），即在所选动作概率上使用适当评分的直接方法，优于仅在确认答案上微调（后者丢弃负例）：在 Banking77 上准确率高 2.6 个百分点，ECE 低 .053，选择性风险更低（三个种子对一个基线种子）；在记录器经常出错的情绪数据上，单种子下高 21.7 个百分点。在 N 5000 时，CAPS 在 0.6B 上比完整标签训练低 1.5 个百分点，在 1.7B 上低 .6 个百分点（对一个完整标签种子），且倾向权重在此日志上无增益。在已知翻转率的反馈下（每个翻转率一个种子），CAPS 的置信度平均上跟踪噪声信道，反向校正恢复了大部分干净校准，且基于留出记录式结果的早停在所有三次运行中防止了记忆噪声抽样。代码、适配器、日志和逐记录结果均已公开。</p>

<h3>TraceKV：面向推理视觉语言模型的策略保持低秩KV缓存压缩</h3>
<span class="paper-item__meta">arXiv / 2026-11-11 / Ke Li</span>
<p>推理视觉语言模型（VLMs）因大规模多模态上下文和不断增长的推理轨迹而面临巨大的KV缓存需求。低秩KV压缩已成为一种有前景的范式，它存储KV状态的低维潜变量，并可与量化结合使用。然而，现有低秩方法在压缩推理KV状态时，往往会导致相对于稠密模型不断增长的预测策略漂移，从而造成推理失败。我们识别出这种性能退化的两个关键原因：静态上下文与在策略推理状态之间的校准状态失配，以及KV状态之间不相等的误差敏感性。为解决这些挑战，我们提出TraceKV，一个免训练的低秩KV压缩框架，在单一策略保持原则下统一了在策略校准、敏感性感知SVD和全局秩分配，大幅降低了推理过程中的策略-KL散度。在多个VLMs和视觉推理基准上的实验展示了更优的精度-内存权衡，与量化结合时在5.64倍KV缓存压缩下实现近乎无损的推理精度。优化的低秩注意力内核进一步带来高达1.83倍的端到端解码加速。代码将发布于https://github.com/AK-DREAM/TraceKV。</p>

<h3>我们能否让大语言模型变笨，还是它只是在装傻？一项关于可信性能节流的实证研究</h3>
<span class="paper-item__meta">arXiv / 2026-11-11 / Chengguang Gan</span>
<p>基准分数通常被解读为模型能力的代理指标。我们研究其逆问题：模型能否被驱动至目标分数，其失败是否类似于天然较弱模型的失败？我们从三个维度操作化可信的性能下降：目标校准、项目难度结构，以及与真实弱参考模型的错误分布相似性。我们提出CapLadder，一个经IRT校准的测试套件，包含1,985个项目，涵盖数学、代码、多项选择推理和工具使用。一个简单的弱教师LoRA调节器在推理任务上达到未见过的目标水平，留出校准误差为1.9个百分点，而提示、温度和权重噪声无法结合可比的范围和精度。然而在多项选择上，该调节器收敛到一个答案词元吸引子：其新引入的错误中高达97%落在一个字母上，吸引子在Qwen中从D变化到Llama中的A。Logit干预识别出一个主导的近常数偏移：在留出项目上减去估计的偏移可恢复52%至59%的损失准确率并消除主导吸引子，而选项排列确认该偏差追踪的是词元位置而非选项内容。在标注者间高度一致（κ=0.94）的情况下，人工编码的错误类别分布在推理任务上仍与弱参考模型匹配（JS = 0.00），表明局部合理性与聚合可检测性存在差异。结构化工具调用在Qwen系列中表现出更自然的退化（JS = 0.09），而全局校准的调节器在不同基准之间迁移效果不佳（在两个可用基准上误差为14.2个百分点）。因此，精确的分数控制并不意味着可迁移或可信的技能下降。</p>

<h3>观测漂移，结构留存：面向电磁信号的时间对齐结构预训练</h3>
<span class="paper-item__meta">arXiv / 2026-11-11 / Wenjin Gui</span>
<p>电磁信号建模正日益转向对异构I/Q观测的自监督预训练。然而，观测到的波形由信号生成、传播环境和采集过程共同塑造，其中混合了可复用的结构规律与观测特定的变化。现有方法通常对混合观测采用重建目标进行统一预训练。这种异构性为重建预训练带来了两个关键失配：（1）外观失配，由传播相关的波形变化引起；（2）时间失配，由采集相关的采样坐标引起。这些失配使得观测特定的外观和采样坐标比稳定的信号结构更容易被重建，从而诱发观测捷径。我们将这一失效模式识别为观测偏置预训练。为解决这一问题，我们提出了面向异构电磁信号的时间对齐结构预训练。它通过RoPE-fs缓解时间失配，该方法将token位置映射到采样率归一化的物理时间位置，并通过用离散结构单元的掩码预测替代波形重建，减少对外观捷径的依赖。这些单元被组织为原子结构单元和涌现结构单元，后者捕获超越固定patch边界的变长组合模式。在多样化的电磁基准上，我们的方法在全监督和少样本适应方面均优于现有电磁预训练基线，表明当观测在波形外观和时间尺度上发生漂移时，所学表示能更好地保持结构一致性。</p>

<h3>共形选择在CRISPR脱靶设计中能证明什么：基准泄漏、免费基线与有限样本队列要求</h3>
<span class="paper-item__meta">arXiv / 2026-11-11 / Mohammad Malekpouri</span>
<p>共形选择承诺对决策错误率进行无分布、有限样本的控制，并已被提出作为机器学习CRISPR引导设计的安全层。我们追问：从现有的已验证脱靶数据中，这样的证书是否可获得。约束是算术性的：共形p值不能低于校准队列规模加一后的倒数，因此Benjamini-Hochberg选择只有在队列规模至少为候选池规模除以容忍错误率时，才能认证单个候选。公共队列提供十个已验证引导，而两千个候选池在百分之十错误率下需要两万个；因此，在超过百分之九十六的划分中，接受集为空。两项基准测试发现解释了为何这一点未被注意到。标准CIRCLE-seq文件在八十个on-target字符串下列出十个引导，因此按序列列进行分组交叉验证会在一 个引导上训练和测试；纠正后，配对级判别和逐引导保真度崩溃。去除该泄漏后，无训练的位置权重评分和近匹配基因组位点的裸计数不会被训练过的oracle击败。我们给出纠正后的协议、新模型必须击败的基线，以及认证流水线所需的队列规模。</p>

<h3>测试跨LLM API的对话保持：一种用于检测静默信息丢失的基于规则的预言机</h3>
<span class="paper-item__meta">arXiv / 2026-11-11 / Xin Liu</span>
<p>LLM 应用日益依赖翻译器和兼容层来跨 API 迁移对话。然而，一个经过翻译的请求可能被目标 API 接受，却在无声中丢失关于指令角色、工具交互、错误状态或生成控制的信息。我们提出 isloss，一种确定性预言机，用于测试跨 LLM API 翻译的对话信息保持性。它将源请求与回复以及翻译后的请求与回复映射到一个共享中间表示 ConvIR，并应用显式规则来区分合法的表示变更与信息丢失。与模式验证或基于参考的差分测试不同，isloss 既不需要参考翻译，也不需要额外的模型调用。它还能区分可避免的丢失与由目标 API 限制导致的降级。我们使用基于规范的故障注入、人工评审以及在翻译器、网关和客户端库上的实验来评估 isloss。在留出测试中，它检测出 125 个植入故障中的 95 个（76.0%），误报为 2/100（2.0%）。在覆盖五个翻译器代码库六种配置的合成请求套件中，685 个完成的翻译中有 127 个（18.5%）通过了静态目标检查，却在目标 API 本可保留的情况下无声地改变了提示、角色或工具信息。在翻译后的回复中，558 个流中有 203 个（36.4%）在至少一个受测的官方 OpenAI SDK 中导致异常或无声损坏。跨六个模型的有针对性实验表明，当任务依赖受影响的信息时，翻译引起的变化会改变模型行为。这些结果确立了对话保持性作为可靠 LLM 互操作、智能体执行和模型评估的一项独立正确性要求。</p>

<h3>忠实于步骤：通过查询分解提升RAG中的泛化性与引用</h3>
<span class="paper-item__meta">arXiv / 2026-11-11 / Yue Liu</span>
<p>检索增强生成是缓解大语言模型幻觉的一种普遍策略。可归因RAG（RAGQ）为其答案生成引文。引文指示哪些输入上下文支持RAG推导出答案，从而增强答案的可验证性和可信度。然而，现有RAGQ在处理需要多跳推理和多模态理解的问题时表现出显著退化，存在过度引用、隐式实体识别失败和泛化能力差等问题。本文提出了一种新颖的RAGQ框架，即QDRAG。QDRAG将输入问题分解为原子子问题以识别隐式实体。然后，重排序器剪枝上下文干扰项以消除下游的过度引用。为促进查询分解，我们提出了两种零样本方法：QD-C和QD-R，分别基于上下文知识和检索奖励引导QD MLLM分解问题。一个有趣的发现是，在QD任务上微调相比直接在下游RAGQ任务上微调展现出更好的泛化能力。在四个多模态问答基准上的实验证明了QDRAG在答案归因和生成忠实引文方面的有效性。该框架在域内和域外测试中均显著优于所有基线，甚至超越了Gemini-Pro。</p>

<span class="paper-item__meta">arXiv / 2026-11-11 / Nils Leutenegger</span>
<p>已有报告称，未经训练的卷积网络作为视觉皮层模型可与训练过的网络相媲美；我们曾报告，在THINGS fMRI的V1区，未训练网络相对于反向传播具有优势，且这种优势依赖于评估分辨率。在预先设定的岭读出下，未训练网络在每个池化网格上的得分都低于训练过的网络（g = 4时r差值中位数为-0.043，5个种子中0个为正），在MSE技能和逐折r上也是如此。在探索性分析中，在单元归一化、距离度量和体素归一化的36种组合（28种不同分析）中，V1对比的方向取决于分析方式（5种不同分析中区间高于0，9种中低于0），而在我们的网络中，原始约定下的分辨率依赖性仅出现在一个单元格中。原始相关-距离表征相似性分析（RSA）与模型和体素模式相对于单位均值轮廓的对齐程度共变（我们的网络间Spearman为0.97，六个ImageNet架构间为0.79）；该优势在正交于均值轮廓的分量中不存在，而仅平行分量也无法解释它。在中心化模式的未加权角度分量上，训练过的网络在V1区领先（我们的网络和6个ImageNet模型中的5个），在LOC区也领先（全部七个）；范数加权角度项未能解释。一个亮度与对比度滤波器组在岭回归下得分高于每个网络（点估计），而在共享惩罚下添加网络特征并未改善预测。区间为三名受试者的刺激自助法区间，且有6项预先声明的预测未得到满足。我们建议报告对两侧所评估刺激上中心化处理的敏感性，分别报告各分量，并纳入一个小型多宇宙分析和简单基线。</p>

<p>在球拍类运动中，下一拍预测需要从具有不同比赛结构、记录属性和标签词汇的事件数据中学习。然而，乒乓球、羽毛球和网球共享一种层级结构，即击球构成回合，回合构成更高层级的计分单元。我们提出MT-HTA，一种层级对齐的多任务Transformer，利用该结构联合预测下一拍的属性。时间Transformer捕捉事件进程，特征令牌路径建模语义字段之间的交互而非沿时间轴的交互，任务特定注意力从层级摘要和球员上下文中检索信息。该架构支持三级和四级层级以及依赖运动项目的任务集。在来自三种运动的四个数据集上，最终的MT-HTA在对比的主要模型中取得了最高的平均任务平均F1。在乒乓球上的消融实验支持层级编码、任务注意力和特征令牌交互的组合。额外模块改变了分类分数与空间误差之间的平衡，而非改善每一项指标。这些结果支持一种可复用的架构，用于异构球拍类运动事件数据。我们发布代码以保证可复现性。https://github.com/gndd1221/For-Sports-event-modeling-with-rally-and-score-hierarchical-A-Multi-Task-Hierarchical-Transformer</p>

<h3>模拟手臂伸展中的读出适应：学习到的补偿及更新停止后的表现</h3>
<span class="paper-item__meta">bioRxiv / 2026-11-12 / Kobayashi, J.</span>
<p>当手臂学会补偿一个使其运动偏转的力时，移除该力会产生相反的偏差，即后效应。我们通过测量后效应、学习到的力矩校正以及权重更新停止后的跟踪性能，来评估控制器保留了哪些信息。我们使用一个模拟的力矩驱动的平面双连杆手臂，在速度相关的侧向力下向八个方向伸展。只有外部线性力矩读出器在线自适应；生成其特征的参数保持固定。特征来自三种闭式连续时间（CfC）网络配置、一个回声状态网络或一个径向基函数层。所有三种CfC配置，包括神经电路策略布线，均训练400个epoch。这五种基于特征的变体使用最小均方（LMS）学习；第六种在密集骨干CfC读出器上使用递归最小二乘（RLS）。学习率在三个模型初始化上选择，并在三个力场下的十个独立初始化上评估。所有六种变体相对于其固定读出基线均改善了跟踪性能，并在每次评估运行中通过了我们的后效应标准。在主力场中相同十个评估初始化（60种条件）上的诊断量化了这一共同决策背后的差异：在共同规定输入上，学习到的输出变化与理想补偿之间的中位数归一化平方残差在不同实现中范围为0.0097至0.383。在更新停止且反馈控制激活的情况下，所有最终读出器均保留了有用的补偿，相对于其预适应版本将跟踪误差降低了40-97%。与最终自适应周期相比，五种LMS变体的中位数固定读出误差比为2.28-5.87，而RLS几乎保持不变。这些测量区分了适应期间达到的性能与最终权重中保留的性能。它们为读出器适应提供了一种具体的评估程序：测量学习到的输出校正，并在更新关闭的情况下测试最终控制器，同时结合行为后效应。该比较表征了此任务中的完整实现；准备和超参数的差异限制了对特征表示或更新规则本身的归因。</p>

<p>情境调节感觉刺激的神经处理。兴奋性神经元的反应通常对符合当前情境特征的刺激受到抑制，而对偏离刺激则增强。这些效应已在基础与临床神经科学中通过oddball范式得到广泛研究，该范式涉及重复标准刺激并插入罕见偏离刺激。对偏离刺激增强的神经反应——被称为偏离检测——在预测编码框架下被解释为预测误差，标志着内部预测与实际感觉输入之间的差异。然而，大多数oddball范式同时改变预测和输入，因此无法检验真正的差异信号。迄今为止，尚无研究表明oddball范式中的神经偏离检测专门编码内部预测与意外感觉输入之间的差异，而非例如一般化的惊讶信号或增强的自下而上信号传递。在此，我们比较了不同oddball范式变体中对听觉刺激的神经反应。在经典oddball范式中，初级听觉皮层（A1）中推测的兴奋性神经元对听觉偏离刺激的反应包含关于近期频率变化的信息，并保留先前刺激情境的记忆痕迹。有趣的是，在固定偏离oddball范式中，当标准刺激（理论预测）在不同组块间改变，但偏离刺激特征保持不变时，神经反应模式编码了标准到偏离的频率差异。总之，这些发现支持这样的解释：A1偏离检测包含一个感觉预测误差，表征预测与感觉输入之间的差异，这是预测编码框架的一个推论。</p>

<h3>将GWAS荟萃分析与人类脑细胞图谱相结合，揭示杏仁核和皮层抑制性中间神经元在耳鸣中的作用</h3>
<span class="paper-item__meta">medRxiv / 2026-11-12 / Schubert, N. M.</span>
<p>目的：耳鸣是一种常见且异质性较高的疾病，其遗传结构仍不明确，且不同研究对其定义存在差异。我们旨在探究哪些常见遗传变异与耳鸣相关，遗传关联在不同耳鸣定义之间的共享程度，以及耳鸣遗传力集中于哪些脑细胞群体。方法：对来自欧洲和美国的19个独立人群队列（以下称为EARGEN）进行全基因组关联荟萃分析，共纳入961，085名欧洲血统成年人（75，584例耳鸣病例和885，501例对照）。耳鸣在17个队列中通过自我报告定义，在2个队列中通过诊断代码定义。基于单核苷酸多态性（SNP）的遗传力和遗传相关性通过连锁不平衡得分回归估计，基因通过基于基因的关联分析结合位置映射和表达数量性状基因座映射进行定位。遗传力富集通过分层连锁不平衡得分回归在来自死后人脑供体的31个脑细胞超级簇及其组成的461个细胞簇中进行检验。富集在百万退伍军人计划（MVP）中通过自我报告定义（114，325例病例，201，343例对照）和诊断代码定义（77，601例病例，310，953例对照）进行重复验证。结果：五个独立位点在2、8、12、13和16号染色体上达到全基因组显著性（p &lt; 5 x 10-8），其中两个位点（rs10877884和rs2147632）此前未见报道。基于SNP的遗传力在观测尺度上为0.0137（SE = 0.0009），在易患性尺度上为0.0535（0.0036）。遗传相关性在听力损失、焦虑障碍、重度抑郁症、慢性疼痛以及另外四个精神、睡眠和前庭性状中显著。三个超级簇在中脑来源的抑制性神经元、杏仁核兴奋性神经元和内侧神经节隆起中间神经元中显示出提示性富集，错误发现率（FDR）为0.067，其中后两者在百万退伍军人计划（MVP）诊断代码定义下达到显著性（0.030和0.006）。在细胞簇分辨率下，杏仁核兴奋性簇被发现显著（z = 4.82，错误发现率 = 3.3 x 10-4），而上升听觉 relay 簇均未发现富集（z [&amp;le；] 1.71，错误发现率 [&amp;ge；] 0.21）。结论：耳鸣相关的常见变异集中于边缘系统和皮层神经元群体，而非上升听觉通路。因此，耳鸣的易感性似乎是中枢性的，且在很大程度上非听觉起源。尽管样本量很大，但获得的全基因组显著关联数量较少，这强调需要更详细和标准化的表型分析，聚焦于耳鸣障碍。</p>

<h3>1999-2023年美国成年人心血管危险因素、疾病管理及预测心血管风险的趋势</h3>
<span class="paper-item__meta">medRxiv / 2026-11-12 / Ahmed, H. M.</span>
<p>背景：美国的心血管危险因素已发生变化，但大流行后时期的患病率、管理和预测风险趋势仍未得到充分描述。方法：我们分析了11个美国国家健康与营养调查（NHANES）周期（1999-2000年至2021-2023年）中60,199名年龄20岁的非妊娠成年人。调查加权回归评估了年龄标准化趋势、亚组差异和测量变化敏感性。我们评估了高血压、血脂异常和糖尿病的知晓率、治疗率和控制率。PREVENT方程估算了无自报心血管疾病（CVD）成年人的10年和30年风险。结果：肥胖率从47.4%上升至57.2%（每十年比值比[OR]为1.23；95% CI，1.16-1.30），III级肥胖增加了一倍以上（4.7%至9.7%）。糖尿病从8.2%上升至12.7%（OR，1.26；95% CI，1.19-1.34），而当前吸烟率从24.4%下降至14.9%（OR，0.76；95% CI，0.71-0.81）。高血压、血脂异常、慢性肾脏病和既往CVD未显示显著的线性趋势，尽管平均收缩压（BP）（124.2至120.2 mm Hg）和总胆固醇（203.6至188.1 mg/dL）下降，同时其他血脂指标也有所改善。高血压和血脂异常的知晓率和治疗率增加，但血压控制率在2013-2014年达到32.5%的峰值后下降至21.5%，而LDL胆固醇控制率从17.0%上升至34.2%。糖尿病知晓率增加，但治疗趋势不显著。血糖控制率在2003-2004年达到51.2%的峰值后下降至41.9%（非线性P&lt;0.001）。预测的10年总CVD风险从5.66%下降至5.28%；动脉粥样硬化性CVD（ASCVD）风险每十年下降0.16个百分点（95% CI，0.22至0.09），而心力衰竭（HF）风险增加0.10（95% CI，0.03-0.17）。其2021-2023年估计值几乎相同（分别为3.20%和3.19%）；30年风险显示出类似的分化。结论：吸烟、血压和血脂的改善与肥胖和糖尿病的上升并存，血压控制率在早期改善后下降，以及预测的ASCVD和HF风险出现分化。</p>

<h3>在严重肥胖中，HbA1c升高与大脑年龄提前相关</h3>
<span class="paper-item__meta">medRxiv / 2026-11-12 / Juhasz, J.</span>
<p>引言：通过结构MRI数据估算的大脑预测年龄是一种反映大脑生物学衰老的机器学习生物标志物。较大的脑龄差（BAG）表明大脑衰老加速，并与认知功能下降和死亡率相关。心脏代谢危险因素，包括血糖升高、体重指数（BMI）、血压和胆固醇升高，会增加衰老过程中认知障碍和痴呆的风险。尽管重度肥胖人群中这些心脏代谢危险因素的患病率增加，但其与BAG的关系仍鲜有明确描述。方法：使用来自97名成年人（BMI 35-73）的T1加权MRI数据，通过ENIGMA和Pyment大脑年龄模型计算BAG。采用多元线性回归和MM估计稳健回归检验BAG与HbA1c、BMI、高血压和高脂血症之间的关联，并校正年龄、性别和种族。事后分析按临床HbA1c截断值（血糖正常、糖尿病前期、糖尿病）对模型进行分层。结果：在线性回归模型中，较高的HbA1c与较大的BAGENIGMA（B = 1.58，p = .014）和BAGPyment（B = 0.93，p = .013）相关。在稳健模型中，HbA1c仍与BAGENIGMA显著相关（B = 1.70，p = .002），但与BAGPyment不相关（B = 0.71，p = .13）。BMI、高血压和高脂血症在线性或稳健模型中均与BAG无关。在处于或高于糖尿病前期水平者中，HbA1c与较大的BAGENIGMA（B = 2.15，p = .01）和BAGPyment（B = 1.21，p = .04）相关；在糖尿病患者中，HbA1c与BAGENIGMA相关（B = 2.49，p = .047）。结论：HbA1c升高与重度肥胖个体的大脑衰老加速相关。BAG与BMI、高血压和高脂血症无关，这可能反映了重度肥胖样本固有的BMI范围受限。</p>
