<h3>蜂窝面元：用于高效场景渲染与重建的紧凑六边形图元</h3>
<span class="paper-item__meta">arXiv / 2026-10-27 / Prakhar Kaushik</span>
<p>新视角合成与三维重建在辐射场和泼溅技术的推动下快速发展，但其内存与计算需求限制了在资源受限环境中的应用。我们提出 Hexels：新型平面六边形表面元素，配备一阶空间颜色场，用于高效的三维场景与二维图像表示。Hexels 利用局部平面区域及平滑变化的外观，使用更少、更大的图元。其六边形支撑提供了面积与边界高效的域，而局部颜色场则捕捉每个图元内的外观变化。在 34 个场景上，Hexels 在多个数据集上将 PSNR 较内存匹配的 2DGS 提升 4.53–7.38 dB，同时所需训练显存更低。我们进一步通过消融实验表明，在单个图元层面，Hexels 较 2DGS 提升最高达 4.74 dB，同时训练显存更低且 FPS 快 2.31 倍。即使在无约束设置下，Hexels 也提供了互补的质量-内存权衡。对于高效三维表面重建，Hexels 在 15 个 DTU 扫描上较内存匹配的 2DGS 将误差降低 28.9%。在 6 个 Tanks and Temples 表面场景上，Hexels 在所比较方法中取得最高平均 F1（34.38%，而 2DGS 为 31.72%）。我们进一步表明，Hexels 作为通用图元，在二维图像表示上优于 Image-GS。Hexels 推动了表面对齐图元在质量-效率权衡上的帕累托前沿。</p>

<h3>ThinkWorld：世界想象强化动态链推理</h3>
<span class="paper-item__meta">arXiv / 2026-10-27 / Chaehyun Kim</span>
<p>视觉-语言-动作（VLA）模型在机器人操作方面已取得实质性进展，但其泛化能力仍受限于动作标注机器人演示的多样性和覆盖范围。人类视频提供了更广泛的行为和环境经验，而从中学习面临可扩展数据与显式动作 grounding 之间的根本性权衡。我们提出 ThinkWorld，一个 VLA 学习框架，将动作推理建立在世界动态之上，并通过世界想象强化学习加以增强。ThinkWorld 将每个动作思维表示为动态链（Chain-of-Dynamics，CoD），即一系列离散运动 token，捕捉连接当前世界与未来状态的中间动态，并作为跨具身形态的通用动作表示。我们首先用动作标注演示初始化 CoD，然后预测每个 CoD 所诱导的未来，并强化那些预测与观测结果更匹配的 CoD。这使得没有动作标注的视频能够从观测到的状态转移中提供直接监督，从而让人类和机器人经验精炼同一推理空间。仿真和真实机器人上的实验证明了有效的人类到机器人迁移，以及对未见任务和环境的强泛化能力。</p>

<h3>离散标记能否作为视觉信号的语义无损表示？</h3>
<span class="paper-item__meta">arXiv / 2026-10-27 / Jialv Zou</span>
<p>离散视觉 token 以类似于语言的离散形式表示视觉，为在共享的下一 token 预测目标下进行多模态建模提供了原生接口。然而，量化误差被广泛认为会导致不可避免的语义损失，从根本上限制了离散视觉 token 的语义保真度，并使连续视觉表示成为内在的上界。我们以多模态理解作为语义保真度的代理指标，重新审视这一假设，发现量化误差并不可靠，因为量化误差大得多的离散表示反而可以实现更好的理解。相反，离散索引的有效比特预算成为下游性能的关键决定因素。然而，现有量化器最终会饱和，因为额外的码本贡献的语义信息逐渐减少。作为缓解这种饱和的一种方法，我们引入因子化向量量化，它使用对称并行码本对视觉特征的互补、固定维度视图进行量化。它在更大的比特预算下持续改进，最终在多模态理解中匹配连续视觉表示。在工业规模多模态数据上训练后，我们的模型在离散表示模型中达到了最先进的性能，在九项指标平均值上分别比 UniAR 和 Emu3-Chat 高出 22.8% 和 59.2%。据我们所知，它也是首个能与 Qwen3-VL 等强连续表示模型竞争的离散表示模型，包括在细粒度 OCR 任务上。我们进一步确定了实现这种竞争力的关键原则和实用方案。这些结果和见解支持离散视觉表示支撑大规模原生多模态基础模型的潜力。代码和模型可在 https://github.com/hustvl/FVQ 获取。</p>

<h3>我们应在何时于测试阶段进行干预？</h3>
<span class="paper-item__meta">arXiv / 2026-10-27 / Jiahao Zhang</span>
<p>测试时自适应帮助已部署模型应对变化的输入，但同样的干预可能挽救一个批次却损害下一个批次。例如，更新归一化统计量可以改善受损图像，但当批次中大多为同一类别时则会失败。平均准确率掩盖了这些失败，也无法告诉模型何时使用干预。目标标签可以指导这一决策，但它们稀缺，且某些选择已经明确。我们提出PORTAL，一个控制器，用于选择何时部署干预、标注哪些输入以及何时停止查询。每个可用的预测规则都是一个候选，其预测在当前反馈到达之前就已固定。因此，每个获取的标签都在同一输入上评估所有候选。PORTAL结合这些共享比较，并将查询引向仍可能超越当前领先者的候选。当剩余标签无法改变选择，或可能的准确率增益不再值得另一次查询时，它便停止。我们的分析将所需反馈与准确率差距和共享错误联系起来，解释为何某些选择需要少得多的证据。实验表明，这种控制将整体上损失准确率的干预转变为在选定批次上的有用选择。它防止了由到达顺序变化引起的严重失败，并在完整的损坏流中保持增益。当固定规则已经表现良好时，PORTAL使用很少的反馈来保持其性能。定期标签检查揭示过去证据何时需要刷新，并帮助控制器在条件变化时恢复。获取的标签还为未来批次训练更强的候选，而选择将几乎所有的准确率增益带入部署。因此，同样的反馈既改善了当前做出的选择，也改善了后续批次可用的预测。</p>

<h3>安全负责人：学习到的注意力门控提升提示注入鲁棒性</h3>
<span class="paper-item__meta">arXiv / 2026-10-27 / Igor Shilov</span>
<p>我们提出安全负责人（Heads of Security, HoS），一种提示注入防御方法，通过一小组学习到的逐头注意力门控来强制实现指令与数据的分离。HoS 学习每个注意力头应如何在可信与不可信 token 之间重新分配注意力，使模型能够对不可信内容进行推理而不遵循注入的指令。我们在 Llama-3.3-70B-Instruct 和 GPT-OSS-20B 上评估 HoS。我们将其与 SecAlign++（一种最先进的基于微调的防御方法）以及 ASIDE（一种与我们的方法类似、将指令-数据分离构建到模型架构中的防御方法）进行比较。我们表明，HoS 对自适应攻击具有更强的鲁棒性，在标准效用基准上表现更好，并在标准智能体提示注入基准上达到顶级性能。更具体地说，黑盒 RL-Hammer 攻击对 GPT-OSS-20B 达到 97% 的攻击成功率（ASR），对 SecAlign 达到 85%，但对 HoS 仅达到 10%。Claudini 是一种最先进的白盒攻击，通过自动化研究针对 HoS 进行了强化，其在 HoS 上达到相同 ASR 所需的 FLOPs 是在 GPT-OSS-20B 或 SecAlign 上的 3 倍。HoS 在标准多项选择基准和提示设置中保持基座模型的效用，而 SecAlign 和 ASIDE 在少样本设置下性能下降。在具有静态攻击的智能体基准上，HoS 和 SecAlign 表现相似，并相较于基座模型大幅改善了安全-效用权衡。ASIDE 在工具使用方面表现不佳，仅达到 10% 的效用。这些结果表明，通过有针对性的注意力干预可以实现并提升提示注入的鲁棒性。</p>

<h3>注意力作为格点规范理论：关系仅通过威尔逊环相互作用</h3>
<span class="paper-item__meta">arXiv / 2026-10-27 / Aakash Sarkar</span>
<p>关系通过它们共享的实体进行复合——Alice是Bob的母亲，Bob是Carol的父亲，因此Alice是Carol的祖母——并且顺序很重要，因为父亲的母亲不是母亲的父亲；验证一个复合关系意味着闭合环路。我们证明，如果每个实体的坐标框架可以独立旋转（逐实体框架自由度），则有三件事随之而来。在纯规范扇区中，不共享任何循环的关系完全无法相互作用。三角形唯一的规范不变分数是其和乐$H = T_{ij} T_{jk} T_{ki}$的类函数——一个Wilson环。而边的唯一等变更新是$U = Ψ(H)\, T_{ij}$，其中$Ψ$是共轭等变的。因此，通过Wilson环进行的边注意力不是众多设计之一，而是对称性所允许的唯一形式。三个社区持有这种形式的部分：知识图谱的交换算子嵌入是其阿贝尔（交换）扇区；AlphaFold的三角形更新和Edge Transformer具有其形状——通过第三个顶点更新一条边——但没有其约束；而格点QCD在格点上等变地构建了它。我们在一般关系图上实例化等变子族作为和乐注意力。在没有训练且仅靠复合的情况下，它在稀疏图上以五分之一的边被损坏的条件下，以0.88的准确率推断出未观测到的$S_4$关系，达到或略低于专业同步算法，而每个交换架构的上限为0.083；其和乐分数以AUC 0.99标记损坏的三角形，而交换分数因第二条选择规则被限制在0.76，并且它无需标签即可分离聚类。</p>

<h3>KPPax：为大气化学中的机器学习预处理可微动力学ODE</h3>
<span class="paper-item__meta">arXiv / 2026-10-27 / Wenqing Peng</span>
<p>大气化学机理通常以动力学预处理器（KPP）的语言发布，该预处理器可生成高效的 Fortran 或 C 代码，但不适用于开发机器学习模型的可微编程框架。我们提出 KPPax，一种动力学预处理器，可从以 KPP 语言编写的机理出发，在 JAX 中生成可微、即时编译且可向量化的化学代码。KPPax 在对数空间中用稀疏运算计算速率定律，从而保持可微性，并用 \texttt{diffrax} 库的隐式求解器及前向和反向模式伴随对刚性系统进行积分，因此无需手工推导伴随代码即可获得精确灵敏度。我们以 POLLU 基准机理演示了两个应用。第一个应用中，由自动微分雅可比计算得到的 Fisher 信息矩阵在任何拟合之前即可预测类流管设计能够识别 25 个速率系数中的哪些，含噪合成估计将九个可识别速率系数的预测不确定度确认至约 30% 以内，同时揭示出仅其比值受到约束的快速反应簇。第二个应用中，排放清单的神经网络校正先基于逐情景 4D-Var 反演进行离线训练，再通过化学模型进行在线微调，使生物源校正的误差降低 2.4–5 倍，并恢复了个体反演所丢失的低温排放信息。KPPax 使 KPP 机理可直接用于参数估计和物理–机器学习混合建模。</p>

<h3>推动灵巧性与安全性的手内物体姿态到达方法，效果显著出色</h3>
<span class="paper-item__meta">arXiv / 2026-10-27 / Ian Chuang</span>
<p>多指灵巧操作是机器人学的下一个前沿，然而已习得的手部技能仍局限于简单抓取或基本重复动作，例如旋转物体。随着机器人尝试更高难度的在手操作，安全性（例如不掉落物体）变得至关重要，但这一点却很少被衡量。我们研究在手物体位姿到达任务，该任务要求多样且困难的抓取：在任意腕部朝向下，通过长序列的连续目标，将物体移动到手指可达范围内的几乎任意位置和朝向。我们提出了一套在仿真中为LEAP手训练此类策略的方案，无需人类数据，该方案建立在多项洞见之上，从通过生成的抓取数据集实现多样化重置与目标，到自适应摩擦课程。通过细致的系统辨识，策略可零样本迁移到真实手部，使用动作捕捉或单个腕部安装的深度相机，并展现出显著的能力与鲁棒性。在任务策略之上，我们添加了一个可学习残差安全滤波器，其保守程度可调，使我们能够调节性能与安全之间的平衡，并大幅减少物体掉落。在13.3小时的真实机器人评估中，覆盖4个物体、多样腕部朝向下的4800个未见目标，基于状态的策略在2厘米和0.4弧度范围内达到95.2%的目标，滤波器将其掉落率降低75%，同时仍达到91.5%的目标。这些策略还能旋转以任意位姿持有的灯泡，到达分布外目标，承受快速手臂运动和扰动，并且仅需一个腕部相机，即可作为便携技能使用，例如拧入灯泡。我们将完整方案作为平台发布，用于研究高维灵巧系统中的性能、可靠性和安全性。视频及更多内容见 https://ian-chuang.github.io/dexsafe/。</p>

<h3>GEPA-Curator：面向自我改进智能体的精选学习</h3>
<span class="paper-item__meta">arXiv / 2026-10-27 / Zack Yu</span>
<p>大型语言模型（LLMs）越来越多地用于多轮智能体工作负载，这些负载需要与复杂环境持续交互。现有的反思式提示优化器（如GEPA）从失败的 rollout 中学习，但智能体失败也可能源于提示弱点、执行框架限制、随机执行或带噪声的评判器。我们认为此类失败可能无法提供有用的学习信号，甚至可能有害；因此，必须筛选提供给提示优化器的任务，以获得更好的性能。我们提出 GEPA-Curator，一个增强提示优化器的框架，用于选择哪些智能体经验应塑造提示优化。具体而言，GEPA-Curator 由两个组件组成：任务筛选，过滤掉可能提供噪声或不可靠学习信号的任务；以及先验成功检索，针对某个任务有选择地检索过去成功的轨迹，并将其作为额外上下文提供给提示优化器。我们在 GoBrowse、ALFWorld、AppWorld 和 $τ$-bench 上评估 GEPA-Curator，使用 Gemini 3.1 Pro 和 Claude Opus 5 作为优化器模型。GEPA-Curator 达到或超过两个基线的平均性能，相较 GEPA 提升最高达 20.7%，相较 ACE 提升最高达 21.2%。</p>

<h3>大型语言模型能否通过自由探索揭示隐藏的物理定律？</h3>
<span class="paper-item__meta">arXiv / 2026-10-27 / Zhen Yang</span>
<p>科学发现往往始于一个意想不到的观察，进而引出新的研究问题。在一个物理定律被改变的世界中，大型语言模型（LLMs）能否注意到异常行为，例如较重的物体下落得更慢，并在未被告知要研究什么的情况下通过实验发现该定律？为了评估这一能力，我们引入了LongChang，一个自动化框架，它创建具有改变后物理规律的模拟世界，其中一个或多个定律与普通物理不同。被评估的LLMs充当探索者，操纵物体并构建工具来研究自己的问题，而没有研究任务或关于这些定律的提示。独立的LLM智能体生成并审查场景、审查工具设计，并利用改变后的物理定律和探索记录来评估报告的正确性和实验支持。这些记录引导场景演化以进行进一步探索，使整个循环无需人工干预即可运行。在12个LLMs中，GPT-6-Astra达到了16.7%的发现率，而其他11个得分为0%。探索记录揭示了未被调查的异常现象以及对改变后物理定律的部分识别。</p>

<span class="paper-item__meta">bioRxiv / 2026-10-27 / Desallais, M.</span>
<p>多样的植物群落通常比单一栽培产生更多的生物量，这一优势随时间增强，主要归因于互补效应——即相对于单一栽培，当物种利用不同资源、共享较少敌人或相互促进时所产生的额外生物量。然而，这一优势究竟只是多样群落的一种趋势，还是每一个持久群落都必须具备的特征，一直未知。在此我们表明，稳定的共存需要正的互补效应，例外极为罕见；并且在四项长期生物多样性实验中，产量不足的群落在两年或采样步骤内失去一个物种的可能性显著更高，失去物种的几率比其他群落高出近三倍。在互补效应被定义以来的二十五年里，生物多样性效应与物种共存之间的联系仅在理论上对两个竞争物种建立过，或仅作为相关性被观察到；我们的理论结果使其成为多物种群落的一般性质，其中互补效应与两个已确立的物种共存稳固程度度量——局部稳定性和结构稳定性——成比例。据我们所知，我们的分析是首次在生物多样性实验中前瞻性地检验一个共存预测——即将发生的物种丧失——仅从一个功能度量出发，将一个关于多样性做什么的度量转变为多样性能否持续的诊断。因此，稳定共存与更高生产力本质上是相互关联的：生物多样性并非仅仅平均而言有益于生态系统生产；持续存在的生物多样性必然通过互补效应有益于它。我们预期这一诊断将把现有的生物多样性实验、播种草地和间作转变为物种丧失的早期预警系统，因为它只需要混合物和单一栽培中每个物种的生物量——这些系统已经收集的数据，且农学家已将其合并为土地当量比——并且它将扩展到森林，通过不断增长的树木多样性实验网络和混合物种人工林，那里进行着相同的测量。</p>

<p>杀伤细胞免疫球蛋白样受体（KIR）基因的高分辨率基因分型仍然具有挑战性，原因在于广泛的序列同源性、拷贝数变异以及复杂的单倍型结构。尽管KIR等位基因变异影响受体表达和功能，常规分型在很大程度上仍局限于基因的存在或缺失。在此，我们评估了一套集成短读长测序系统，该系统结合了四反应、两阶段多重PCR检测（ScisGo-KIR-v3）、集中式云端拷贝感知等位基因分析以及交互式基因型审查。该系统应用于代表1000基因组计划中24个人群的2,298名个体，并配有匹配的高分辨率HLA I类基因型。针对48份样本的完整、定相PacBio KIR序列进行独立验证，在768项基因-样本比较中证明了98.6%的自动化拷贝数一致性和92.8%的拷贝数与等位基因联合一致性。经过桌面审查后，所有评估的判定均与参考序列一致。在涉及311份共享样本的四种计算基因分型方法的单独比较中，自动化Scisco流程与四方法共识的总体不一致率最低（1.62%）。人群分析识别出大量的等位基因多样性以及着丝粒端和端粒端单倍型基序的独特分布。尽管确切的单倍型对经常存在歧义，但结构判定在基序水平上变得越来越可解析，且基序背景表现出特征性的等位基因组成。配对的KIR和HLA分析揭示了被基因内容分型所掩盖的遗传性受体-配体配置。在1,401名KIR3DL1/HLA-B Bw4共携带者中，57名缺乏注释为普通表面表达的等位基因，而在1,175名六种特定HLA-C同种异型的KIR2DS4共携带者中，457名仅携带截短型受体形式。等位基因特异性的KIR2DL1和KIR2DS5分类进一步区分了受体特性及已发表的配体结合注释，这些在不同人群中存在差异。尽管潜在的受体-配体库组成在不同人群间存在差异，但在考虑人群结构和多重检验后，分析并未确立优先的KIR-HLA遗传关联。总之，这些发现表明集成短读长KIR基因分型能够提供可扩展的高分辨率等位基因和拷贝数信息，同时明确保留推断单倍型结构中的不确定性。与现有HLA实验室工作流程的兼容性为将等位基因解析的KIR分析纳入免疫遗传学研究和未来临床研究提供了实用基础。</p>

<h3>比较使用SPARK队列的自闭症退行与无退行自闭症之间的表型和遗传差异</h3>
<span class="paper-item__meta">medRxiv / 2026-10-27 / Yahia, A.</span>
<p>自闭症退行（Autreg）的生物学机制仍知之甚少。我们在SPARK队列的51633名个体中研究了Autreg的表型和遗传景观。我们计算了SPARK中家长报告的语言退行以及影响社交、玩耍、如厕和/或其他发育领域的退行的频率，以及技能退行和恢复的年龄。我们比较了Autreg与无退行自闭症（Autnreg）的发育里程碑、定量发育指标及选定的其他表型。利用基因组测序数据比较了Autreg和Autnreg中的罕见有害编码变异和多基因评分（PGS）。在1107名Autreg和974名Autnreg个体中，使用传递与新生关联（TADA）框架分析罕见变异，随后进行通路富集分析。初步比较了自闭症、注意缺陷/多动障碍、癫痫和精神分裂症的PGS。利用更大规模的SPARK基因分型数据在14001名Autnreg和11638名Autreg个体中进行了PGS验证。我们在43%的自闭症个体中识别出退行。其他退行发生晚于语言退行，60%的技能恢复发生在两年内。Autreg与较低的Vineland-3适应行为综合评分相关（p&lt;0.001），且癫痫和智力障碍的几率增加两倍以上（p&lt;0.001）。发育里程碑和定量指标差异不大。TADA分析突出了参与核苷酸分解代谢、转录和黏着斑的基因，PTEN成为Autreg的强候选基因。精神分裂症PGS解释了自闭症个体退行易感性方差的0.087%。总之，Autreg与神经发育疾病负担增加相关。精神分裂症PGS和罕见变异仅解释了其病因的极小部分。</p>

<h3>里尔大学医院医学上脆弱患者牙周口腔牙源性感染灶（PODFI）的横断面研究</h3>
<span class="paper-item__meta">medRxiv / 2026-10-27 / Ribreux, S.</span>
<p>口腔感染病灶（ODFI），尤其是牙周来源的感染病灶，可触发全身炎症反应，并可能对存在医学合并症的患者造成菌血症。尽管指南建议检出并消除这些病灶，但关于牙周口腔感染病灶（PODFI）风险在这些人群中分布的确切数据仍然匮乏。本研究旨在通过牙周检查与随访表以及近期开发的PODFI风险等级分类，描述存在医学合并症患者的牙周感染来源。这项观察性、回顾性、横断面、单中心研究评估了2024年9月至2025年9月期间在里尔大学医院牙科外科就诊的伴有牙周炎的存在医学合并症患者。牙周炎依据2017年世界研讨会制定的2017年牙周病分类进行诊断。主要结局为PODFI风险等级（中等、高、极高）的分布。次要结局旨在描述特定存在医学合并症患者人群的牙周状况。本研究共纳入39例患者。对PODFI风险的评估（n = 34）显示，以中等风险类型为主（67.6%），高风险类型占相当比例（32.4%）；未观察到低风险或极高风险类型。广泛性牙周炎症非常常见（92%），探诊出血（BOP）位点中位数为26个，菌斑阳性位点中位数为71个，二者呈正相关（R = 0.52，p = 0.002）。重度和活动性牙周炎占主导（n = 39），其中74.4%的病例被分类为III期（28.2%）或IV期（46.2%），B级最常见（56.4%），其次为C级（38.5%）（p = 0.025）。存在医学合并症的患者中重度和活动性牙周炎患病率高，其中近三分之一被归类为感染高风险。近期开发的牙周口腔感染病灶（PODFI）分类为感染风险分层和指导治疗决策提供了一种结构化且具有临床相关性的工具。仍需前瞻性多中心研究以确认这些PODFI风险等级的有效性。</p>
