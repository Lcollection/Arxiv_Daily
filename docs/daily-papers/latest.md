<h3>对立的可塑性机制增强违背其情境的视觉输入</h3>
<span class="paper-item__meta">bioRxiv / 2026-10-22 / Seignette, K.</span>
<p>为了在复杂环境中导航，哺乳动物的视觉系统通过将传入的感觉信号与习得的上下文信息进行比较，优先处理信息量大的输入。虽然这一过程通常被概念化为差异计算，但皮层回路提出了根本性挑战：视觉上下文反馈主要是放大性的，而抑制性回路是否支持选择性减法尚不清楚。在这里，我们展示了小鼠初级视觉皮层第2/3层锥体神经元如何通过可塑性实现这种比较，该可塑性对直接视觉刺激和上下文信号的响应产生相反方向的作用。为了分离这些成分，我们向小鼠呈现完整图像或其中一个象限被遮挡的图像，从而在保留周围上下文信息的同时去除直接视觉刺激，并测量锥体细胞在视觉熟悉化前后对这些刺激的响应。在对非遮挡图像熟悉化之后，对直接视觉输入的响应选择性降低，而对遮挡图像的上下文响应增强。这种增强可推广到自然场景，使上下文输入也能够驱动对新颖遮挡图像的响应，并放大对新颖非遮挡图像的响应。一个计算模型通过减弱前馈输入并增强前馈驱动的抑制和上下文反馈来重现这些变化，这些变化是对重复锥体细胞活动的响应。这种上下文对比机制在小鼠以及先前获得的猴子和人类数据中，对遮挡和非遮挡图像产生了保守的响应结构。总之，这些结果提示了一种显著性赋予机制，该机制利用了皮层锥体神经元的区室组织：它们学习熟悉上下文的广义统计结构，从而能够选择性放大低概率输入或遗漏。</p>

<h3>增强睡眠的皮层电生理特征可克服睡眠剥夺小鼠的内质网应激反应</h3>
<span class="paper-item__meta">bioRxiv / 2026-10-22 / Prius Mengual, J.</span>
<p>睡眠剥夺(SD)会在清醒和睡眠期间触发皮质脑电图(EEG)的特征性变化，并上调神经元活动、突触可塑性和内质网(ER)应激的分子特征。这包括诱导未折叠蛋白反应(UPR)，即ER应激的主要标志物和适应性机制。然而，SD期间皮质神经元活动如何促进这些分子特征的诱导仍不清楚。在此，我们研究在SD期间使用生理性刺激范式(闪烁光刺激，FLS)操纵皮质活动是否会影响UPR的诱导。正如预期，单独SD上调了皮质中活动依赖性和UPR相关基因，并导致随后NREM睡眠期间EEG慢波活动(SWA)增加，这是睡眠需求的电生理特征。然而，在SD期间给予FLS阻止了活动相关和UPR相关基因的上调，同时在随后睡眠期间诱导SWA的额外增加。对神经元放电的进一步分析显示，FLS在刺激期间在清醒动物中诱导了短暂的神经元沉默(OFF)期，从而将皮质活动转向类似睡眠的大脑状态。这些发现表明，在清醒期间对皮质活动进行生理性操纵足以将ER应激的分子特征与睡眠压力的电生理标志物解离。我们提出，整体睡眠-觉醒历史和皮质网络动力学差异性地调节活动依赖性转录和睡眠压力的积累。</p>

<h3>走向自然主义伸手：不确定性下的中间伸手可泛化至行走，但并非必需</h3>
<span class="paper-item__meta">bioRxiv / 2026-10-22 / Seavey, C. V.</span>
<p>高度受控的实验室实验为运动规划提供了重要见解。当人们在不知道目标的情况下向多个刺激之一伸手时，其手部轨迹会介于直接伸向各刺激的路径之间。然而，现实世界中的伸手涉及比典型实验室任务更大的决策空间。我们将“先行动后知晓”范式扩展至类似无约束自然行为的行走伸手任务。参与者朝触摸屏走三步，然后伸向两个刺激之一，目标在行走开始时或伸手开始后才标记。在不确定条件下，出现了中间伸手轨迹，但仅对某些刺激布局和部分参与者成立。个体伸手行为差异很大；许多人直接瞄准一个刺激并在后期修正。伸手开始时的身体位置更多锚定于屏幕而非刺激，且部分处于中间位置。因此，中间运动可推广至实验室之外，但它是多种策略中的一种灵活策略，而非强制性的运动计划平均。</p>

<h3>鉴定一种具有抗分枝杆菌活性的2-取代苯并咪唑衍生物及其与利福平的协同相互作用</h3>
<span class="paper-item__meta">bioRxiv / 2026-10-22 / Thakur, S.</span>
<p>传染病仍然是持续的全球健康负担，其中细菌感染占据了相当大的疾病负担。抗菌药物耐药性的日益普遍强调了开发新型抗菌药物的必要性。在本研究中，评估了新型2-取代苯并咪唑衍生物（NR-1至NR-9）对三种细菌的抗菌活性，即耻垢分枝杆菌、枯草芽孢杆菌和大肠杆菌，采用最低抑菌浓度和最低杀菌浓度的测定方法。其中两种（NR-4和NR-5）对耻垢分枝杆菌表现出抑制活性，而两种（NR-5和NR-7）对枯草芽孢杆菌有活性，MIC范围为62.5至250 μg/mL。值得注意的是，NR-5对耻垢分枝杆菌和枯草芽孢杆菌均表现出抗菌活性，对耻垢分枝杆菌的效力更强（MIC：125 μg/mL vs 62.5 μg/mL），具有杀菌活性，MBC/MIC比值为1，且对Vero细胞毒性低。此外，NR-5表现出浓度依赖性杀菌动力学，并与利福平对耻垢分枝杆菌产生协同相互作用（FICI：0.498）。分子对接分析预测胸苷酸激酶为NR-5的可能靶点，结合能为-6.61 Kcal/mol，分子动力学模拟支持Tmk-NR-5复合物在100 ns模拟过程中的稳定性。因此，基于其效力、低毒性抗分枝杆菌活性以及与利福平的协同作用，NR-5被鉴定为针对耻垢分枝杆菌的初步抗分枝杆菌先导化合物。</p>

<h3>解锁伯克霍尔德菌巨型噬菌体Matilda所利用的成对末端基因组重复序列的秘密</h3>
<span class="paper-item__meta">bioRxiv / 2026-10-22 / Lewis, J. M.</span>
<p>噬菌体是感染细菌的病毒。巨型噬菌体的基因组超过220 kb，能够支撑更强的功能独立性和复杂性。本研究鉴定出vB_BceM_Matilda（{phi}Matilda），一种新型靶向伯克霍尔德菌的巨型噬菌体。在将其基因组注入宿主细菌之前，{phi}Matilda结合到细菌鞭毛上，鞭毛的旋转是驱动有效噬菌体感染所必需的。其线性267 kb双链DNA基因组具有一种此前未描述的三部分架构，带有1.3 kb和25 kb的双向末端元件，分别两侧翼接1.5 kb和18 kb的不同反向重复序列。这些架构元件位于基因组两端。转录组学和蛋白质组学分析追踪了噬菌体感染过程，并证实这些末端元件内的基因在感染期间被转录和翻译。相关巨型噬菌体中双向末端序列的存在表明，这种三部分基因组架构可能是保守的并具有重要功能意义。本研究首次描述了任何生物中的这种基因组架构，拓展了我们对基因组组织的理解，并就巨型噬菌体基因组的复制、包装和演化提出了新的问题。</p>

<h3>采用代表性商业实践免疫程序对蛋鸡粪便微生物群疫苗相关变化的纵向分析</h3>
<span class="paper-item__meta">bioRxiv / 2026-10-22 / Ahmad, A. A.</span>
<p>肠道微生物群对鸡的免疫发育和整体健康至关重要。在商业化生产中，禽类在生命早期通常会接种多种疫苗。虽然已知单个疫苗会影响微生物组成，但家禽行业中使用的复杂多疫苗程序的影响尚不明确。这项初步纵向研究考察了从早期开始在与商业相关的时间点接种多种活疫苗和灭活疫苗对蛋鸡肠道微生物多样性和组成的影响。我们利用16S rRNA基因测序在不同疫苗组的接种前和接种后时间点表征了微生物群谱。总体而言，大多数疫苗的微生物多样性保持稳定，表明肠道微生物群对反复免疫干预具有很强的恢复力。差异丰度分析未发现接种疫苗后分类群发生显著变化。肠道微生物群落在完成疫苗接种程序后也表现出稳定性。这些初步发现强调了鸡肠道生态系统的稳健性，并为未来研究微生物组-疫苗相互作用及其对家禽健康、免疫和生产效率的影响奠定了基础。</p>

<h3>尽管感染外寄生虫仍能生长：性别特异性效应对自由生活鸦科鸟类端粒缩短的影响</h3>
<span class="paper-item__meta">bioRxiv / 2026-10-22 / Perez Badas, E.</span>
<p>已知发育期间的体外寄生虫感染会影响与适合度相关的特征，但其与性别或生长权衡相关的生理代价仍研究不足。在鸟类中，此前在窝水平上的研究发现，吸血性体外寄生虫感染会在分子生物标志物上产生代价（即端粒缩短增加）。然而，感染概率也随年龄、性别或窝内个体而变化。这些代价是否具有年龄或性别依赖性尚不很清楚，而厘清这些效应具有重要意义，因为端粒可能揭示感染的长期影响。在此，我们利用寒鸦雏鸟（Coloeus monedula）为期6年的数据，研究在发育过程中两个中间时间点上蝇类（Carnus hemapterus）感染与雏鸟期端粒动态在个体水平上的关联。我们评估了：（i）Carnus的存在与性别、窝大小操纵、体重和体型的关系；（ii）端粒缩短如何随寄生虫存在和已达到的生长状况而变化。在发育早期（第10天），蝇类在较重的雏鸟上更为常见，而在发育后期（第20天），它们在较小和较轻的雏鸟上更为常见，提示体外寄生虫偏好存在差异。仅在暴露于寄生虫的第20天时，雌性雏鸟的端粒丢失更高；而在雄性中，当它们在发育早期体重较大时端粒丢失更高。总之，感染是一个动态过程，体外寄生虫效应可能取决于感染的时间，并揭示性别特异性的生长与自我维持权衡。我们的研究表明，在评估宿主—寄生虫相互作用和感染的生理代价时，需要在多个发育阶段进行采样。</p>

<h3>野生啮齿动物食物可保存性的口腔手动评估</h3>
<span class="paper-item__meta">bioRxiv / 2026-10-22 / Dumargne, L.</span>
<p>动物会遇到各种各样的食物，必须判断其未来价值和可保存性。由于实验室环境中的动物通常被提供统一的食物，因此关于动物如何评估天然复杂食物的知识十分匮乏。在此，我们剖析了野生刺豚鼠——新热带地区关键的种子传播者——如何决定是食用食物还是将其埋藏于小型贮藏点，即分散贮藏。我们发现，刺豚鼠优先贮藏坚果而非新鲜水果，并且在觅食时经历从进食到分散贮藏的急剧转变。值得注意的是，刺豚鼠分散贮藏了壳完整但空心的坚果，而不贮藏壳破裂但饱满的坚果。这一决策依赖于口-手食物评估，一种生态信息寻求行为。它们利用嘴唇和门齿——一个体感中央凹——在坚果表面导航，最优地积累决策关键的感觉信息。总之，这些发现提供了一种野生啮齿动物可保存性评估的机制性解释，揭示了信息寻求行为如何支持自然环境中的长期价值优化。</p>

<h3>信息素诱导跳蛛的视觉运动唤醒</h3>
<span class="paper-item__meta">bioRxiv / 2026-10-22 / Winsor, A. M.</span>
<p>一种感官模态的知觉可以受到另一模态刺激的影响。这种跨模态效应可能源于多种潜在过程。例如，动物可能因暴露于某一感官模态的线索而启动，并注意另一独立模态中一致的线索。相反，来自某一感官模态的输入可能导致唤醒水平的普遍提高，进而影响行为。跳蛛（Salticidae）是著名的视觉动物，但它们也对信息素作出反应。在此，我们检验信息素是否影响Phidippus跳蛛的视觉注意，以及若如此，我们是否看到对相关刺激启动的证据，或仅仅是唤醒水平的提高。在实验1中，暴露于雌性信息素的雄性蜘蛛在场地中的运动增加，这是与配偶搜寻相关的生理唤醒迹象，而雌性对雄性信息素的反应是运动减少。在实验2中，暴露于雌性信息素的自由活动雄性蜘蛛更可能检测并求偶雌性图像。在实验3中，我们向雄性蜘蛛展示一系列同种个体、蟋蟀和抽象形状的图像，同时使用专用眼动追踪器可视化其主眼的注视方向。当信息素存在时，视网膜运动显著增加，但这种效应不因刺激类别而异。无论是否暴露于信息素，蜘蛛在展示蟋蟀和正面雌性同种个体时的视网膜运动大于展示侧视雄性同种个体时。在实验4中，向蜘蛛展示一系列刺激，但蜘蛛在信息素暴露下并未优先看向同种刺激。然而，在实验4的第二次迭代中，雄性蜘蛛在对照和信息素条件下均接受测试，暴露于信息素的雄性看向正面雌性的时间长于抽象形状。在实验5中，向蜘蛛展示异性同种个体的显著图像。在信息素暴露下，雄性更可能将视线从初始刺激转向一个椭圆形干扰物，而雌性比对照更不可能转移视线，这与实验1中活动性的性别特异性变化相呼应。雄性运动增加可能增强相遇，而雌性运动减少可能促进被发现和评估雄性展示。虽然我们仅发现有限证据表明蜘蛛被启动将注意指向一致刺激，但我们的结果表明信息素影响视觉，具体通过影响蜘蛛移动身体和眼睛的倾向。</p>

<h3>Pose：一个纯NumPy、手性感知的结构引擎，用于构建和操作蛋白质、核酸和小有机分子的分子结构</h3>
<span class="paper-item__meta">bioRxiv / 2026-10-22 / Sabban, S. S.</span>
<p>分子建模流程通常涉及多个程序，每个程序都有自己的格式、约定和安装方式，而且很少有程序能一致地处理D-氨基酸和其他非经典残基。本文介绍Pose，一个仅依赖NumPy作为运行时依赖的Python库。Pose从序列构建多肽（包括六种非经典氨基酸）和核酸双链，通过字母大小写设定每个残基的手性，并将三个力场（OpenFF Sage 2.3.0、AMBER ff19SB和CHARMM36）和两个评分函数（Rosetta REF15和AutoDock Vina）重新实现为可读的数组操作。采用一种手性约定——在取负的扭转角上读取为L残基参数化的表格——应用于旋转异构体库、REF15的统计表和CMAP网格。在相同坐标上，Pose与OpenMM的偏差至多为6.5 x 10- kJ/mol，与AutoDock Vina的偏差至多为0.013 kcal/mol，在30个结构中的25个上与PyRosetta的偏差至多为2 x 10- REU。镜像反射使Pose对全L和全D结构的能量变化至多为4 x 10-12 kJ/mol，并使其评分保持不变，而PyRosetta的REF15变化高达31.4 REU。Pose从二面角重建蛋白质，与PyRosetta的C RMSD在0.0097 Å以内。其动力学、最小化和退火在十个小蛋白质上中位数与参考一致，其侧链堆积恢复{chi}1的频率与PyRosetta相同，其对接在4 Å以内恢复了10个蛋白质-蛋白质复合物中7个的晶体结构，在2 Å以内恢复了10个受体-配体复合物中6个的晶体结构。Pose在Apache 2.0许可下免费提供，网址为https://github.com/sarisabban/Pose。</p>

<span class="paper-item__meta">medRxiv / 2026-10-22 / Chong, A. H. W.</span>
<p>在进行全基因组关联研究时，处理与目标性状相关的用药状态可以防止可能扭曲真实遗传效应估计的偏倚。在此，我们介绍遗传经验用药缩减调整（GEMRA）方法，该方法使用启发式搜索来获得应用于报告用药参与者的表型值的经验调整。通过模拟，我们表明GEMRA方法中的直接遗传效应估计比常见策略（如将用药作为协变量纳入、将样本限制为未用药者或纳入所有样本而不进行调整）表现出更少的偏倚和更大的统计功效。然后，我们应用GEMRA方法，利用来自UK Biobank和Uganda Genome Resource的多群体数据，估计用于低密度脂蛋白（LDL）胆固醇水平分析的他汀类药物用药调整，以及用于收缩压（SBP）和舒张压（DBP）血压分析的反高血压药物用药调整。我们发现，相对调整而非绝对调整能更好地建模药物对LDL胆固醇、SBP和DBP的影响，分别出现40%、10%和10%的缩减效应在不同群体间似乎一致。我们还表明，当效应尺度设定错误时，可能会出现跨群体用药效应的虚假差异。</p>

<h3>APOLLAI，一种多模态人工智能系统，与急救人员相比，在院前检测卒中相关缺陷方面的表现</h3>
<span class="paper-item__meta">medRxiv / 2026-10-22 / Javault, C.</span>
<p>背景与目的：院前卒中识别仍不理想，近三分之一的卒中在到达医院前未被识别，且神经系统评估本质上具有主观性，即使在认证临床医生之间也存在显著的观察者间变异。APOLLAI是一种多模态人工智能系统，旨在从视频和音频记录中检测卒中相关神经功能缺损。我们将APOLLAI与急救医疗服务（EMS）人员的诊断性能与专家共识参考标准进行了比较。方法：在这项前瞻性研究中，于尼姆大学医院（2023年8月至2025年7月）获取了295例疑似卒中患者（平均年龄70.3±13.3岁）的视频记录。五个美国国立卫生研究院卒中量表条目（最佳凝视、面瘫、上肢运动、失语、构音障碍）由七名认证卒中神经科医生独立标注，使用Dawid-Skene算法合并为共识标签，并由EMS人员单独评估（每例患者平均15名评估者）。APOLLAI是一个多模态机器学习框架，结合了计算机视觉、基于音频的深度学习和最终的支持向量机（SVM）融合分类器，使用敏感性、特异性和受试者工作特征曲线下面积（AUC）与EMS进行比较评估。结果：七名神经科医生之间的评估者间一致性总体为中等（平均κ=0.541，范围0.367-0.732），表明神经系统评估存在内在困难。APOLLAI在所有五项神经功能任务和整体评估中均显示出高于EMS的敏感性（78.5%对59.4%），特异性大致相当（整体评估为87.0%对85.9%）。AUC值范围为0.839（面瘫）至0.966（最佳凝视），整体AUC为0.882。结论：APOLLAI在检测卒中相关神经功能缺损方面表现出高于EMS人员的敏感性，同时保持了特异性。这些发现支持其作为院前卒中识别的标准化、可扩展辅助工具的潜力，值得在真实世界EMS条件下进行前瞻性验证。</p>

<h3>未申报的卡痛生物碱和噻奈普汀出现在标为猫爪草的产品中</h3>
<span class="paper-item__meta">medRxiv / 2026-10-22 / Avula, B.</span>
<p>背景：美国食品药品监督管理局将高浓度7-羟基帽柱木碱（7-OH）产品描述为新兴公共卫生问题，2026年8月，美国缉毒局将帽柱木碱假吲哚酚（MP）、MGM-15（二氢-7-羟基帽柱木碱）和MGM-16临时列入附表I。自7月以来，犹他州和田纳西州官员报告了涉及标称为猫爪草（Uncaria tomentosa）的片剂的过量中毒、死亡和实验室发现，猫爪草是一种无已知阿片活性的草药补充剂。此类产品的化学数据稀少，消费者无法从标签判断其含有哪些阿片活性化合物。方法：在一项横断面分析中，我们于2026年9月从在线零售商和密西西比州3家加油站购买了46种标称含猫爪草的咀嚼或单剂量产品。这些产品代表17个品牌。甲醇提取物通过超高效液相色谱-光电二极管阵列检测进行分析，并与经植物学验证的U tomentosa树皮甲醇提取物进行比较。液相色谱四极杆飞行时间质谱鉴定了其他化合物，化合物对照真实参考标准品进行定量。比例报告精确（Clopper-Pearson）95% CI。结果：46种产品均未标示帽柱木碱类生物碱或其衍生物，但全部含有至少一种成分。41种产品（89%；95% CI，76%至96%）定量检出帽柱木碱，35种（76%；95% CI，61%至87%）检出7-OH，24种（52%；95% CI，37%至67%）检出MGM-15，22种（48%；95% CI，33%至63%）检出MP。共39种产品（85%；95% CI，71%至94%）含有MP或MGM-15，二者被临时列入附表I管制。噻奈普汀是一种未在美国获批的抗抑郁药，存在于5种产品中（11%；95% CI，4%至24%），每单位27.9至40.2 mg。7-OH含量范围为每单位0.01至95.4 mg。8种带有“NO KRATOM and No 7-OH”或“NO 7-OH”等声明的产品含有帽柱木碱、7-OH和3-脱氢帽柱木碱。结论：标签未能为消费者提供可靠的暴露指南。临床医生在评估使用猫爪草产品后出现的无法解释的阿片毒性时，应考虑帽柱木碱衍生阿片类和噻奈普汀。监管机构除对单个化合物进行列管外，可能还需要进行产品检测和标签执法。</p>

<h3>常规儿童、常规青少年和运动疫苗接种的标准化国家层面交付单位成本估算：一项更新的建模分析</h3>
<span class="paper-item__meta">medRxiv / 2026-10-22 / Portnoy, A.</span>
<p>背景：可靠的免疫接种服务成本估算对于规划、预算编制和经济评价至关重要。尽管近期已有实证研究，但许多低收入和中等收入国家（LMICs）仍缺乏最新的成本估算，尤其是青少年疫苗接种和运动式疫苗接种方面。本研究在LMICs中按疫苗接种模式生成了标准化的国家层面服务成本估算。方法：利用《免疫接种服务成本目录》2024年更新版中的实证成本研究数据，我们拟合了贝叶斯元回归模型，以估算常规儿童疫苗接种、常规青少年疫苗接种（以人乳头瘤病毒疫苗接种作为代理）和群体性运动的每剂服务成本，不包括疫苗和注射用品成本。模型纳入了国家层面协变量（人均国内生产总值、人口规模、白喉-破伤风-百日咳第三剂覆盖率、城市化率、人口密度和五岁以下儿童死亡率）和研究层面特征（成本类别和成本核算视角）。拟合模型用于生成以2024年美元计的国家特定和人口加权平均每剂经济成本和财务成本。结果：分析纳入常规儿童疫苗接种141个观测值、青少年疫苗接种49个观测值和运动式疫苗接种104个观测值。LMICs中人口加权平均每剂完全经济成本为：常规儿童疫苗接种4.27美元（95%预测区间：1.95-11.58美元），青少年疫苗接种20.56美元（8.56-57.83美元），运动式疫苗接种14.71美元（4.90-86.98美元）。每剂增量经济成本的相应估算分别为16.64美元（7.90-38.22美元）、20.43美元（8.27-47.78美元）和3.53美元（1.70-8.56美元）。在不同国家、接种模式和成本视角之间观察到显著异质性。结论：本研究利用扩展的证据基础和贝叶斯元回归，为136个LMICs提供了跨疫苗接种模式的更新服务成本估算。这些估算为无法获得实证成本数据的分析提供了实用资源。</p>
