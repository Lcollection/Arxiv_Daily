<h3>TaskBridge：通过虚拟任务连接无监督表格异常检测与上下文学习</h3>
<span class="paper-item__meta">arXiv / 2026-09-29 / Doyun Choi</span>
<p>无监督表格异常检测旨在利用正常训练样本识别表格数据中的异常行。传统方法依赖特定数据集的训练和配置搜索，而近期的表格基础模型通过上下文学习实现了对未见数据集的零样本异常检测。然而，大多数基于表格基础模型的方法需要从头进行异常特定的预训练，使检测本质上依赖于合成的表格异常检测特定先验，且更新成本高昂。一些方法转而改造预训练的通用表格基础模型用于表格异常检测以规避这一负担，但依赖于计算开销大且异常归纳偏置受限的公式化方法。在本工作中，我们提出了TaskBridge，一个新框架，通过构建虚拟监督任务，将异常检测直接重新表述为表格基础模型的监督上下文推理，从而高效地改造预训练的通用表格基础模型用于无监督表格异常检测。由此产生的虚拟任务诱导出预测结构，在该结构下，正常查询及其目标对获得高支持度，而异常往往违反所诱导的结构并获得较低支持度，从而提供直接的异常证据。在790个真实世界数据集上，TaskBridge持续优于30个基线方法，包括最先进的基于表格基础模型的方法，且无需异常特定的表格基础模型预训练或数据集特定的模型优化。</p>

<h3>JudgeCast：基于经验信息协变量判断的时间序列预测</h3>
<span class="paper-item__meta">arXiv / 2026-09-29 / Donguk Kwon</span>
<p>协变量效应因情境而异并随时间变化，这要求预测者评估如何在每个预测情境中使用它们。随着预测的推进，早期预测的观测值变得可用，为后续预测中过去协变量的使用提供反馈。然而，当多个协变量共同作用时，预测误差揭示了与观测值之间的数值差异，但并未揭示协变量应如何被使用。我们提出JudgeCast，一种基于经验的时间序列协变量预测框架。遵循判断性调整实践，一个冻结的TSFM提供基础预测，而一个冻结的LLM利用当前情境和相关经验对其进行调整。在调整过程中，评估协变量效应和确定数值调整扮演不同角色，因此JudgeCast首先形成显式的逐协变量判断，然后确定调整量。在观测之后，JudgeCast利用基础预测的观测残差来重构替代判断，并通过其产生的调整来评估原始判断和替代判断。表现最佳的决策被选中并保留为经过验证的经验，用于后续预测。在多样化的真实世界数据集上，JudgeCast优于强基线。消融实验表明，显式的逐协变量判断能够改进预测时的调整，而残差引导的经验构建比将原始决策保留为经验能产生更可靠的预测增益。</p>

<h3>中文-Jev：将系统一模型引入中文任务</h3>
<span class="paper-item__meta">arXiv / 2026-09-29 / Zexiao Wang</span>
<p>System One 模型（如 Jev）为需要决策而非开放式回答的任务提供了一种高效的生成式语言模型替代方案。然而，现有的 Jev 模型在中文决策准确性方面表现有限，限制了其在通用和专业场景中的实用性。本文提出了 Chinese-Jev，一种 System One 模型，通过统一的数据处理和训练流程弥补了这一差距。我们的数据处理协议将异构的中文标注转换为候选选项上的概率目标，从而实现了跨领域和问题格式的共享训练公式。为实现高效推理，Chinese-Jev 采用轻量级的仅编码器骨干网络进行文本编码，并通过面向决策的训练学习对候选答案进行评分。为解决预训练分布与下游中文场景之间的不匹配问题，我们首先在包含 1000 万条样本的通用语料库上训练模型，然后分别针对医学、法律和金融领域进行微调。为评估通用和领域特定中文场景下的决策准确性和校准性，我们提出了 Chinese-Jev Bench（CJ-Bench）。在第一阶段预训练后，Chinese-Jev 在通用领域任务上的准确率超过闭源 Jev 模型 1.24%，同时实现了 20.3 倍的加速。后续的领域特定微调在医学领域相比 Jev 取得了 4.0% 的准确率提升，并在专业领域达到了 Jev 平均准确率的 92%，加速 17 倍，平均每个样本的延迟仅为 15 毫秒。我们进一步展示了 INT8 量化模型在移动设备上的端侧部署，实现了每次决策约 1.0 秒的推理延迟。项目地址为 https://gulucaptain.github.io/Chinese-Jev/。</p>

<h3>大规模多体激发态电子结构的深度学习GW准粒子哈密顿量</h3>
<span class="paper-item__meta">arXiv / 2026-09-29 / Xiaoxun Gong</span>
<p>准确的准粒子电子结构是理解材料激发态性质以及解释光电、量子和输运现象的基础。然而，对于大体系或构型复杂的体系，第一性原理GW计算仍然计算量巨大。在此，我们提出DeepH-GW，一种深度学习框架，可直接从原子结构预测有效的GW准粒子哈密顿量。基于DeepH的局域等变消息传递架构，DeepH-GW通过实空间哈密顿量重构接口，在高保真平面波GW计算上进行训练。该方法将平面波方法的系统精度和广泛化学适用性与线性标度神经网络推断相结合。在所考察的体系中，DeepH-GW再现准粒子能带结构，误差在几meV量级。此外，我们表明，尽管多体相互作用具有内在非局域性，DeepH-GW仍展现出从相对较小的训练结构到显著更大的超胞的强跨尺度可迁移性。我们证明，该框架能够通过在具有热位移的超胞中进行预测，准确捕捉GW级别的电子-声子带隙重整化，展示了该方法的强大能力。因此，DeepH-GW为大规模多体模拟和激发态电子结构基础模型提供了一条实用路径。</p>

<h3>钴：利用专家共激活实现高效分布式MoE训练</h3>
<span class="paper-item__meta">arXiv / 2026-09-29 / Junkang Zhou</span>
<p>专家混合（MoE）已日益成为扩展大语言模型的主流方法，因为它在扩大模型容量的同时保持计算成本几乎不变。训练大规模MoE模型依赖于专家并行（EP），它将专家副本分布到各GPU上，并通过全对全通信交换token。EP的效率通常受限于两个系统瓶颈：跨节点token传输受限于节点间带宽，而专家工作负载倾斜导致GPU间计算不均衡。先前的工作基于每个专家的工作负载统计来缓解这些瓶颈，但忽略了专家可以共享通信这一事实。在这项工作中，我们通过实证观察发现，许多专家对会被单个token频繁共同激活。受此启发，我们提出了Cobalt，一种高效的MoE训练框架，利用专家共同激活来减少跨节点流量和工作负载不均衡。Cobalt采用两阶段专家布局规划器，使专家布局适应不断变化的专家共同激活和工作负载状况。它周期性地将频繁共同激活的专家共置于同一节点上以减少跨节点通信，并执行每步的节点内调整以重新平衡工作负载。随后，我们开发了一种通信感知的任务分配方法，根据当前专家布局将token路由到更少的远程节点。在32块B200 GPU上的实验表明，与现有MoE训练框架相比，Cobalt实现了高达1.53-2.41倍（平均1.28-1.89倍）的加速，同时将跨节点token流量减少了75.74%-99.26%。</p>

<h3>超越可读性：评估任务信息可恢复性</h3>
<span class="paper-item__meta">arXiv / 2026-09-29 / Yiwei Liu</span>
<p>直接视觉可读性与任务信息可恢复性是不同的量。无法从固定观测中解码目标，并不必然意味着无法通过另一条恢复路径获取该目标。我们提出一种评估视角，使观测、查询、目标和可用知识显式化，并度量各路径成功集合之间的重叠。对于在合适成像条件下原始可见表面上可获得的信息，直接光学恢复从图像中读取目标，可选地在恢复之后进行；实体关联恢复利用残余视觉证据识别所描绘的实体，并通过指定知识资源中的实体—属性关系获取其目标。此类获取可以利用存储知识或外部来源。一项受控的书封研究以固定的标题—作者目录实例化外部获取，在分辨率退化条件下比较光学作者恢复与视觉标题解析及确定性查找。实体关联的成功在受测的视觉—语言模型中持续存在，揭示了超出受测直接视觉前沿的信息获取，尽管绝对性能存在显著差异。仍存在一个相当大的纯光学区域。这些互补的结果表明，为何视觉退化应通过沿指定路径和知识资源可获取的任务信息来评估，并与直接可读性并列考量。</p>

<h3>对黑盒大语言模型的受控解码攻击</h3>
<span class="paper-item__meta">arXiv / 2026-09-29 / Jesson Wang</span>
<p>在生成过程中操纵下一词元概率可以绕过大型语言模型的安全对齐。然而，现有方法依赖于对模型权重或数值化词元概率的访问，因此不适用于仅返回采样文本的接口。从采样输出中重建概率提供了一种可能的替代方案，但有限采样会产生稀疏且带噪的估计，而在每个生成步骤重复这一过程会带来大量查询成本。我们的实证观察表明，在成功的越狱轨迹上，大的分布变化集中在少数位置上，这促使我们进行选择性控制。我们提出\method{}，一个通过纯文本续写接口进行越狱的框架，该接口允许重复采样和助手前缀续写。基于采样的分布重建将采样输出与对未观测动作的先验相结合，以获得可用的控制信号。风险门控残差控制利用不断演化的响应前缀来决定何时重建和修改分布，将采样成本集中在选定位置。推测性多词元执行通过验证并接受无需干预的草稿前缀，进一步分摊目标调用。在四个目标端点和三个基准上，\method{}在大多数比较中相对于基线取得了最高平均分。</p>

<h3>Purlin：将集合通信的编排与数据通路分离</h3>
<span class="paper-item__meta">arXiv / 2026-09-29 / Osayamen Jonathan Aimuyo</span>
<p>分布式推理依赖于GPU集合通信，而后者必须跟上不断演进的硬件和专用工作负载。然而，现有的集合通信实现往往将语义、编排（数据在何处以及何时移动）和数据通路（数据如何移动）耦合在一起。这种耦合使得采用新的硬件机制以及为应用定制通信变得代价高昂。我们提出Purlin，一个将上述关注点分离的纵向扩展通信框架。在Purlin的顶层，我们将集合通信指定为输入和输出布局的命名以及复制或归约操作。在中间层，我们引入一种共享编排协议，即Stage, Notify, And Consume（SNAC），它从这些规范中推导出协调逻辑。SNAC之下是一个我们称为Atom的硬件特定数据通路，它为集合通信实现了两个关键的数据移动原语：复制和归约。这种分离使我们能够定制集合通信并采用新的硬件机制，同时通过SNAC复用编排逻辑。我们在A100、H200和B200 GPU上评估Purlin。在七种集合通信上，Purlin相比基线实现了最高5.14倍的延迟加速和最高4.50倍的带宽提升。集成到SGLang后，Purlin将离线LLM服务吞吐量和交互性平均提升1.13倍，最高提升1.37倍。对于在线LLM推理，Purlin将交互性平均提升1.26倍，最高提升2.85倍，其中最大增益出现在过载情况下。对于扩散图像生成，Purlin将端到端延迟最多降低1.13倍。</p>

<h3>冷却采样器，而非学习器：采样温度移动重要性校正GRPO的陈旧性悬崖</h3>
<span class="paper-item__meta">arXiv / 2026-09-29 / Taiheng Pan</span>
<p>语言模型的在线强化学习会让采样器落后于学习器，并用截断的重要性权重来修复由此产生的失配。我们追问在这种校正下采样器可以多久不刷新，并发现了一个悬崖：在 Qwen2.5-Math-1.5B 和 GSM8K 上，每 192 次更新刷新一次的重要性校正 GRPO 在前 180 步学习良好，随后在三个数据种子中都在刷新到来之前严重退化。已发表的针对陈旧性的补救措施作用于更新；我们则作用于采样器。解耦冷却以温度 0.8 采样，而学习器、参考模型和重要性权重保持在温度 1，行为概率从退火分布中记录，因此学习器的目标不变。所有相应的冷却运行都稳定，且更长的间隔保持了短间隔所提供的结果：在相同的更新预算下，每 192 步刷新一次的冷却采样器在训练结束时与每 96 步刷新一次的未冷却采样器相当（两者均为 0.857），并在整个训练过程中平均为 0.79，而将学习率降低到安全值则最终低 3-7 个点。在 Qwen2.5-Math-7B 上，间隔 192 处的退化点预测间隔 144 在不冷却时是致命的，而在冷却时可存活；在两个数据种子上，未冷却的运行在首次刷新前就退化，而冷却的运行通过了它，最终达到 92-93%，而未冷却为 68-81%，其中一个冷却运行在第二个周期后期短暂退化。这种收益有一个窗口：在安全间隔的三倍处以及在高失配的 MATH 设置中，冷却会延迟退化但无法阻止它，更强的冷却并不更好，而没有校正的冷却会崩溃。采样温度是对陈旧性容忍度的控制，温度和刷新间隔应一起选择。</p>

<h3>催产素和加压素免疫反应性在不同社会系统的啮齿动物听觉脑干核团中存在差异</h3>
<span class="paper-item__meta">bioRxiv / 2026-09-29 / Joseph, L.</span>
<p>催产素（OT）和加压素（AVP）是参与调节动物社会行为和广泛生理过程的神经肽激素。尽管它们在前脑和中脑神经内分泌区域的分布已有充分记录，但它们在后脑中的表达仍知之甚少。在此，我们使用免疫组织化学方法，对六种社会性不同的野生捕获啮齿动物物种的三个听觉脑干核团——外侧上橄榄（LSO）、内侧上橄榄（MSO）和斜方体内侧核（MNTB）——中的OT和AVP免疫反应性斑点进行了定量。我们还量化了这些核团的体积，并考察了总脑体积在物种和社会性之间的变异。OT和AVP斑点计数在物种和社会群体之间存在差异。群居物种在LSO和MNTB中的OT和AVP斑点计数高于一夫一妻制物种和独居物种。在MSO中，OT斑点计数在社会群体之间没有差异，而AVP斑点计数在群居物种中高于一夫一妻制物种和独居物种。总脑体积以及MNTB和MSO的体积在物种之间存在差异，但在社会群体之间没有差异，而LSO体积在物种或社会性之间没有差异。这些发现揭示了听觉脑干回路中OT和AVP免疫反应性斑点与社会性相关的变异，并表明早期听觉脑干通路中的神经肽信号传导可能有助于社会和听觉信息的神经整合。</p>

<h3>铁稳态与子宫内膜异位症风险：共享生物学联系的遗传学证据</h3>
<span class="paper-item__meta">medRxiv / 2026-09-29 / Denner, V. A.</span>
<p>研究问题 子宫内膜异位症的遗传易感性是否与铁稳态相关，且这种关系是否具有潜在因果性？摘要回答 遗传学证据表明，全身铁状态降低与子宫内膜异位症风险增加相关，存在8个共享的全基因组显著位点，以及提示性但不一致的因果双向效应证据。已知背景 子宫内膜异位症是一种慢性炎症性疾病，与异位病灶和腹膜腔内局部铁蓄积相关，由经血逆流和铁稳态改变所致。流行病学研究表明，与无子宫内膜异位症的女性相比，子宫内膜异位症女性可能表现出全身铁储备降低，反映为循环铁蛋白浓度较低，尽管研究结果不一致，且可能受到月经失血和炎症的混杂影响。由于观察性研究无法区分因果关系与继发效应或残余混杂，连接铁稳态与子宫内膜异位症风险的潜在遗传基础仍不清楚。研究设计、规模、持续时间 我们利用大规模全基因组关联研究（GWAS）的汇总统计数据进行遗传学分析，涵盖子宫内膜异位症（总体及III/IV期疾病）和五种铁生物标志物（血清铁、铁蛋白、总铁结合力（TIBC）、转铁蛋白饱和度和铁调素）。分析包括使用连锁不平衡评分回归（LDSC）进行全基因组遗传相关性分析，使用多性状GWAS（MTAG）识别共享遗传变异，以及双向孟德尔随机化以评估潜在因果关系。参与者/材料、设置、方法 铁生物标志物汇总统计数据来自一项六队列GWAS荟萃分析（HUNT、MGI、SardiNIA、deCODE、Interval、DBDS；N高达257,953），涵盖血液来源的血清铁、铁蛋白、转铁蛋白饱和度和TIBC（Moksnes等，2022）。子宫内膜异位症汇总统计数据来自一项24项研究GWAS荟萃分析（60,674例病例，701,926例对照；欧洲和东亚血统），其中12项研究具有手术确诊的病例（Rahmioglu等，2023）。使用连锁不平衡评分回归（LDSC）估计铁生物标志物与子宫内膜异位症（总体及III/IV期疾病）之间的全基因组遗传相关性，基于比对至GRCh37参考基因组并限制为HapMap3变异的汇总统计数据。对每种铁生物标志物与子宫内膜异位症联合应用多性状GWAS（MTAG），以增强遗传位点的发现。使用GTEx v8的生殖和铁相关组织以及eQTLGen表达定量性状位点（eQTL）数据的血液对共享位点进行功能注释。使用多个聚类阈值下的全基因组显著变异进行双向孟德尔随机化（MR）分析，以逆方差加权（IVW）为主要方法，敏感性分析包括加权中位数、MR-Egger和MR-PRESSO。主要结果和偶然性的作用 遗传相关性分析提示，子宫内膜异位症的遗传易感性与全身铁可用性较低的谱型相关。具体而言，子宫内膜异位症的遗传易感性与非结合铁结合力（TIBC）较高（rg=0.16，p=4x10-4）相关，同时与转铁蛋白饱和度较低（rg=-0.16，p=0.006）和铁蛋白水平较低（rg=-0.10，p=0.022）相关，这些发现与铁储备减少一致。MTAG识别出8个额外的子宫内膜异位症全基因组显著位点，以及8个与铁生物标志物共享的位点，包括涉及凝血（F5）、先天免疫反应（IL1A）、生殖生物学（WNT4）以及免疫和血管通路（如ABO、STAT6）的区域。孟德尔随机化分析为铁状态与子宫内膜异位症之间的因果关系提供了有限且不一致的证据。尽管逆方差加权（IVW）模型显示铁蛋白水平较高与子宫内膜异位症风险较低之间存在名义关联（OR = 0.85，95% CI 0.76-0.94；p = 0.002），以及子宫内膜异位症遗传易感性与TIBC较高之间存在名义关联（OR = 1.02，95% CI 1.01-1.04；p = 0.006），但这些发现未得到敏感性分析的一致支持。MR-PRESSO识别出少量多效性变异，但去除这些变异并未实质性改变结果。局限性、谨慎原因 铁生物标志物GWAS包括男性和女性，可能掩盖女性特异性效应。数据集可用性将分析限制于欧洲血统，限制了对其他人群的适用性，且仅限于总体和III/IV期子宫内膜异位症，无法评估其他疾病亚型。SNP工具的异质性（由Cochran&#x27;s Q统计量反映）降低了孟德尔随机化估计的精确度。此外，遗传工具仅解释了铁生物标志物约1.0%至18.8%的方差（取决于聚类阈值），这可能限制了检测因果效应的功效。研究结果的更广泛意义 这些发现表明，子宫内膜异位症在遗传上与全身铁可用性降低和铁稳态改变相关。因此，子宫内膜异位症女性中观察到的全身铁状态较低可能不能仅由月经失血或饮食因素解释，而是反映了潜在的遗传易感性。共享遗传位点提示凝血、ABO生物学和免疫通路是连接铁代谢与子宫内膜异位症的潜在机制。尽管孟德尔随机化未提供一致的因果性证据，但这些发现支持共享遗传结构，并值得使用女性特异性GWAS、精细疾病亚型和多组学方法进一步研究。临床上，这些发现提示子宫内膜异位症女性全身铁状态较低可能反映了已确定的铁缺乏原因之外的因素，包括潜在的遗传易感性。</p>

<h3>在健康人群中，没有证据表明木糖醇或赤藓糖醇甜味剂会增加血小板反应性</h3>
<span class="paper-item__meta">medRxiv / 2026-09-29 / Woelnerhanssen, B. K.</span>
<p>背景：赤藓糖醇和木糖醇天然存在于水果和蔬菜中，作为替代甜味剂被广泛使用，对血糖和胰岛素影响极小。两者也可在体内内源性产生，在代谢紊乱和心血管疾病中报道血浆浓度升高。近期，两项干预性研究报告急性口服摄入赤藓糖醇或木糖醇后血小板聚集增强，引发对其潜在促血栓效应的担忧。我们研究了健康个体急性暴露于赤藓糖醇或木糖醇是否会增加血小板反应性。方法：我们开展了一项随机、单盲、交叉研究，纳入14名健康参与者，分别接受赤藓糖醇（50 g）、木糖醇（33.5 g）或水。通过离体方式评估血小板聚集，同时检测循环中血小板活化标志物（P-选择素）、内皮活化标志物（sVCAM-1）和凝血标志物（D-二聚体），以及血浆赤藓糖醇和木糖醇浓度。另采用11名健康参与者的富血小板血浆进行补充性体外实验，暴露于递增浓度的赤藓糖醇或木糖醇，随后评估血小板聚集。结果：尽管口服摄入后循环赤藓糖醇和木糖醇浓度显著升高，但与水相比，赤藓糖醇和木糖醇均未增加离体血小板聚集。一致地，P-选择素、sVCAM-1或D-二聚体浓度均未观察到相关变化。富血小板血浆直接体外暴露于递增浓度的赤藓糖醇或木糖醇同样未增强血小板聚集。结论：在健康个体中，急性口服摄入赤藓糖醇或木糖醇未增加血小板聚集或循环中血小板活化、内皮活化或凝血标志物。这些发现得到体外实验的支持，表明赤藓糖醇或木糖醇对血小板聚集无直接影响。我们的结果不支持在所研究条件下赤藓糖醇或木糖醇具有急性血小板活化效应。注册：网址：https://clinicaltrials.gov/study/NCT04966299；唯一标识符：NCT04966299。</p>

<h3>一种可本地部署的用于临床数据去标识化的智能体框架</h3>
<span class="paper-item__meta">medRxiv / 2026-09-29 / Hirsch, A.</span>
<p>多模态临床数据包含多种格式的标识符。我们开发了多模态匿名化器，这是一个可本地部署的框架，结合了多模态语言模型、专家网络、确定性变换和迭代验证。我们使用自动化评估，在250个构建的MIMIC-IV衍生患者数据包（含合成标识符）上比较了16种编排器配置。选定的本地配置在这些相同数据包上接受了人工评估，并补充了来自无关来源的头部CT扫描、面部图像、手写笔记、音频录音和合成德语临床笔记。单独评估使用了德语GRASCCO语料库和250份Charite产程图。在这个扩展基准上，患者级去标识化灵敏度为98.80%（95% CI，97.20；100），每标识符灵敏度为99.82%（95% CI，99.76；99.88），患者级关键临床保留率为99.60%（95% CI，98.80；100），临床保留评分为99.61%（95% CI，99.51；99.71）。所有产程图均满足研究定义的去标识化标准。这些发现支持可行性，但构建的数据包、合成标识符、有限的自然数据验证以及缺乏组件消融限制了泛化能力。</p>

<h3>2019-2024年COVID-19大流行及后续恢复期尼泊尔结核病通报的时空聚集性：一项全国时空扫描分析</h3>
<span class="paper-item__meta">medRxiv / 2026-09-29 / Bisht, N.</span>
<p>COVID-19大流行严重扰乱了全球结核病（TB）的预防、诊断和治疗服务。尽管尼泊尔在大流行后恢复期结核病通报数有所增加，但通报的地理分布和时间聚集性仍知之甚少。本研究考察了COVID-19恢复期尼泊尔全国结核病通报的时空模式。我们对尼泊尔全部77个区从2019/20财年至2023/24财年的区级结核病通报进行了全国性回顾性生态学分析。使用SaTScan中的离散泊松模型进行了时空、纯空间和纯时间扫描统计。采用999次重复的蒙特卡洛模拟评估统计显著性。研究期间共通报172,155例结核病病例。结核病通报率从2019/20财年的每10万人口92例上升至2023/24财年的139例，增幅为51%。共识别出四个具有统计学显著性的高通报时空聚集区（均p &lt; 0.001）。主要聚集区包括加德满都、拉利特普尔、巴克塔普尔、马克万普尔、巴拉和帕尔萨各区，时间为2021/22财年至2023/24财年（RR = 1.60）。其他聚集区位于尼泊尔西部、东部特莱平原和鲁潘德希区。纯时间分析显示，2022/23财年至2023/24财年全国通报数增加（RR = 1.26，p = 0.001）。尼泊尔大流行后恢复期结核病通报数大幅增加，且具有明显的地理和时间异质性。整合空间和时间监测可能有助于识别需要采取地理靶向结核病控制策略的地区。</p>

<h3>刚果民主共和国金佩塞卫生区城乡小学儿童血吸虫病高感染率</h3>
<span class="paper-item__meta">medRxiv / 2026-09-29 / Karume, K. L.</span>
<p>背景 血吸虫病是一种由称为血吸虫的扁形动物引起的寄生虫病。感染循环始于人们通过粪便或尿液排出虫卵。幼虫感染淡水螺，随后在水上活动期间通过皮肤感染人类。血吸虫病通常与农村地区相关。在本研究中，我们希望了解血吸虫病在农村和城市地区的分布是否存在差异，以及与血吸虫病分布相关的潜在风险因素。方法 从Kimpese卫生区城市和农村地区的1，699名学龄儿童（5-15岁）中采集新鲜尿液样本。分别使用尿液沉淀法和即时检测循环阴极抗原试验测定埃及血吸虫和曼氏血吸虫血吸虫病的患病率，并通过RDT-Reader获得感染强度的定量估计。对收集的风险因素与血吸虫感染及其强度之间的关联进行了检验。结果 城市和农村地区血吸虫病的总体患病率分别为75%和82%，其中农村学校曼氏血吸虫患病率较高，城市学校埃及血吸虫患病率较高。城市和农村地区学校之间的总患病率差异显著，X2（1，N = 1699）= 13.03，p = .0003。农村儿童曼氏血吸虫感染强度也高于城市地区儿童（均值 = 162 mV 对 均值 = 76 mV）（p &lt; 2e-16）。男性、在河中洗碗和游泳与城市地区血吸虫病相关。年龄、泉水和河流是农村地区的重要因素。年龄、河流和在河中洗碗是与感染强度相关的因素。结论 我们的结果显示，农村和城市地区的患病率都非常高，这意味着控制项目应以同等重视程度考虑这两个地区，并且还应修订控制策略。</p>
