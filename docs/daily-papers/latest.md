<h3>基于能量的推理器：你的循环推理器应该是一个基于能量的模型</h3>
<span class="paper-item__meta">arXiv / 2026-11-06 / William Xingxu Chen</span>
<p>循环是一种强大的归纳偏置，可用于推理。通过反复迭代一个循环块，循环模型能够扩展其有效深度，并在潜在空间中实现多步推理。然而，现有的循环模型本身并不受显式进展度量的引导，这使得难以确定何时停止循环以及如何改进当前状态。为实现这一点，我们引入了基于能量的推理器（Energy-Based Reasoners, EBRs），它学习潜在推理状态上的能量函数，并将循环更新表述为对该能量的梯度下降。能量对潜在状态进行评分，而其梯度引导细化并提供停止信号。为了有效训练EBRs，我们进一步引入了基于探索的训练，以发现额外的模式，并在更广泛的状态集合上更好地塑造能量景观。在四个算法推理基准上，EBRs匹配或超越了先前的循环推理模型，在Sudoku-Extreme上达到99.9%的准确率，同时推理计算量比次优模型少345倍，并保持可比的训练计算量。在所有多解基准上，EBRs在保持接近100%单样本准确率的同时，实现了对 distinct 有效解的最先进覆盖。这些结果表明，基于能量的模型是实现强推理性能的一种有前景的方法。</p>

<h3>Refer-CityFlow与M3Track：面向语言驱动的多目标多摄像头跟踪的基准数据集与参考框架</h3>
<span class="paper-item__meta">arXiv / 2026-11-06 / Phuong T. Nguyen</span>
<p>指称多目标跟踪使用户能够通过自然语言指定目标，但现有的Refer-MOT基准主要集中于单摄像头设置。我们形式化了指称多目标多摄像头跟踪（Refer-MTMCT），其中自由形式的查询指定了需要在由顺序、稀疏重叠的摄像头组成的网络中恢复的身份一致轨迹。我们引入了Refer-CityFlow，这是一个基于CityFlow的全局跨摄像头身份标注构建的基准，并增加了需要联合语言 grounding、跨摄像头关联和时空推理的语言查询。Refer-CityFlow涵盖来自40个路侧摄像头的96个视频，包含660多条身份一致的跨摄像头轨迹、4,362条轨迹级描述和7,699条查询，其中包括从50名参与者收集的1,699条真实用户查询。在四摄像头场景02上的参考实验表明，单摄像头指称跟踪器在真实用户查询上达到14.95-18.28 HOTA，而所评估的跨视角方法在直接迁移中仅达到约0.05 HOTA。为建立参考性能，我们提供了M3Track，这是一个模块化多模态指称框架，其中基于大语言模型（LLM）的智能体协调可互换的检测、跟踪和跨摄像头关联模块。M3Track在同一真实用户查询集上达到44.10 HOTA和65.40 IDF1。项目仓库见https://github.com/phuongnguyen194/Refer-CityFlow-and--M3Track。</p>

<h3>超越截断？蕴涵许可的省略与LLM解码中语义保持的限度</h3>
<span class="paper-item__meta">arXiv / 2026-11-06 / Mahmoud Alyosify</span>
<p>指令微调的大语言模型（LLM）回答长度超出请求所需。我们探究解码循环内一个免训练的控制器能否在保留内容的同时去除这一冗余，并以最简单的基线——将模型自身答案截断至相同长度——作为评判标准。一个熵门控的 logits 处理器在 MT-Bench 开发问题上移除了 25.5–34.9% 的 token，在密封测试集上移除了 19.9–34.2%，均处于预先注册的 BERTScore 非劣效性边际之内，但我们证明并经审计确认，其输出始终是未修改答案的前缀：所节省的即为截断。对 23 个免训练机制家族的调查发现，在没有 oracle 标签的情况下，没有一个能比截断更好地选择内容。因此我们引入 Entailment-Licensed In-Decoding Elision（ELIDE），它在每个句子边界处，仅当自然语言推理模型判定某段文本已被先前展示的文本所蕴含时，才向读者隐去该段，同时保持模型的生成不变。ELIDE 在三个模型家族上优于等长截断，但阅读其在 670 个公开提示上的 936 处省略后发现，59% 损害了答案，这一失败没有任何自动指标能检测到。将许可范围限定至其话语单元后，在两项全新测试中，有害比例降至约每十处省略一处。</p>

<h3>幻影共识：测量多智能体大语言模型决策中的社会推理</h3>
<span class="paper-item__meta">arXiv / 2026-11-06 / Disha Sheshanarayana</span>
<p>多智能体大语言模型系统日益聚合跨模型实例的判断，但关于其他智能体的推理本身可能引入失败。我们研究一种设定：大语言模型在观察到模糊社会信号后改变其公开决策，同时报告对其他智能体私下判断的不准确估计，即使群体记录的私下判断并不支持表面的共识。我们将这一失败称为幻影共识，并将其作为受控大语言模型集体中一种多元无知式模式加以研究。为测量这一现象，我们引入PHANTOM-Bench，一个将孤立私下判断、模糊社会信号后的公开决策、对群体私下判断的诱导估计、基于透明度的恢复，以及对中性公开文本和显式投票跟随的控制条件分离开来的基准。在九个闭源和开源权重模型上，模糊公开信号持续降低决策质量，并可将正确的私下群体判断转变为错误的公开集体结果。公开准确率下降幅度高达47.8个百分点，在最易受影响的设定中集体理性失败率达到47.3%。我们观察到所报告的群体私下信念存在大量错误，同时伴随公开阶段的失败，而控制条件揭示了模型在易受模糊同伴信号和显式同伴信号影响方面的差异。揭示智能体记录的私下决策可在不揭示金标准标签的情况下修复许多失败，尽管恢复程度因模型而异。我们的结果表明，评估多智能体大语言模型系统不仅需要测量最终一致性，还需要测量该一致性反映的是独立测量的私下判断还是表面共识。</p>

<h3>PhysioWave-T：面向生物信号的令牌高效小波基础模型</h3>
<span class="paper-item__meta">arXiv / 2026-11-06 / Yanlong Chen</span>
<p>我们提出PhysioWave-T，一个面向EEG、ECG和sEMG的token高效小波基础模型系列。动态尺度折叠在token化之前重新组合J+1个小波子带，将序列长度从(J+1)CS压缩至CS个token，其中J为层级数、C为通道数、S为时间片段数。路由特定的前端与学习的通道名称嵌入使每种模态的一个Transformer能够处理多样的导联布局与采样率，而未见过的设置则通过轻量适配器复用主干。我们在超过1500万个窗口（19–128通道）上预训练了一个3000万参数的EEG模型，并同时训练了ECG（3000万）和sEMG（1200万）编码器。在四条EEG路由上，尺度折叠相比尺度扩展将Transformer延迟降低4.0–7.2倍、峰值内存降低6.8–12.7倍，且无精度损失。我们的EEG编码器在9项指标中的8项上领先于BENDR、BIOT、LaBraM和EEGPT，并在可穿戴癫痫检测上以更少参数超越LUNA-L。可靠性感知潜在融合（RALF）进一步通过样本自适应权重整合来自独立预训练编码器的摘要token。在SeizeIT2上，RALF在每小时11次误报下将事件灵敏度从61.4%提升至74.4%，并将窗口AUPRC从0.321提升至0.399，优于最佳单模态基线，并在所有变体上优于加权logit融合与拼接融合。PhysioWave-T还在sEMG上取得最先进准确率，并在PTB-XL Super和Chapman-Shaoxing上取得最高宏F1。代码与模型：https://github.com/ForeverBlue816/PhysioWave。</p>

<h3>使用大型语言模型处理尼泊尔语推文命名实体识别中的困难案例</h3>
<span class="paper-item__meta">arXiv / 2026-11-06 / Claire Wang</span>
<p>命名实体识别（NER）对低资源语言的社交媒体数据而言具有挑战性。大型语言模型（LLM）在NER性能上往往落后于预训练语言模型（PLM），但它们在处理PLM难以应对的情况时展现出潜力。我们使用一个尼泊尔语推文数据集，利用微调后的预训练语言模型（PLM）的token概率将测试集划分为“简单”和“困难”两类案例。随后，我们使用16种不同的提示配置在困难测试案例上评估了一个LLM。我们发现，基于语义相似度选择示例并增加示例数量，可使F1分数较基线配置提升近10个点。尽管该LLM在完整测试集和简单测试集上表现不及PLM，但它在困难测试集上超越了PLM，从而在两种模型结合时带来了分数的提升。</p>

<h3>一致最优的连续音乐情感估计：方差分解、双分支时间融合与共形预测区间</h3>
<span class="paper-item__meta">arXiv / 2026-11-06 / Mohammad Faraz Akhtar</span>
<p>连续音乐情绪识别（MER）估计一首歌曲内唤醒度（Arousal）与效价（Valence）如何演变，然而该领域的标准指标——池化帧级相关——被歌曲间差异所主导，无法区分一个追踪情绪动态的模型与一个仅按歌曲平均水平对歌曲排序的模型。我们将标注方差分解为歌曲间与歌曲内成分，并表明均方误差（MSE）针对前者，而窗化Lin一致性相关系数（CCC = $r \cdot C_b$）通过惩罚MSE引起的方差压缩来针对后者。单一权重$λ$控制这一权衡：在1,764首DEAM歌曲上，将$λ$从0提高到1会使池化唤醒度$r$从0.843降至0.810，同时使歌曲内平均$r$从0.204升至0.368。基于这一目标，我们提出MMAS（多模态音乐分析系统），一个开源模型，每0.5秒从原始音频预测唤醒度与效价。它通过带跨模态注意力的双分支时间卷积网络，将冻结的MERT-v1-95M嵌入与来自自动转录的十个符号特征融合。由于两个分支均源自音频，一个模型无需域条件即可在DEAM和PMEmo上联合训练。在按歌曲分组的5折交叉验证（2,531首歌曲）下，池化$r$在DEAM上达到0.801/0.685（唤醒度/效价），在PMEmo上达到0.742/0.746。在相同特征上与岭回归基线相比，歌曲内唤醒度$r$大约增至三倍（0.344对0.125；$n = 353$首歌曲，Wilcoxon $p = 1.7 \times 10^{-21}$，$d = 0.56$）。完全转录失败最多损失0.04的池化$r$。分割共形区间在95%目标下达到93.7%（唤醒度）和90.0%（效价）的边际覆盖率，其不足可追溯至歌曲内依赖性。MMAS以可通过pip安装的软件包形式发布。</p>

<h3>面向医学图像分割的区域感知错误分诊：基于分组共形风险控制</h3>
<span class="paper-item__meta">arXiv / 2026-11-06 / Nishi Kanta Paul</span>
<p>分割掩膜正日益被复核而非重绘，这需要知道掩膜可能在何处出错。学习到的误差图按风险对像素排序，但需要警告的像素数量是凭经验选择的，且在所有误差像素上校准单一警告阈值可能会使远离预测轮廓的误差未被充分标记。我们提出RACE-Triage，一种事后误差分诊框架，保持分割掩膜不变。风险网络在与骨干无关的输入所产生的外折预测上训练。预测轮廓将每幅图像划分为边界带和非边界区域，并在每个区域分别应用保形风险控制，以约束该区域存在误差的病例中漏检误差的期望比例。在ISIC 2018皮肤镜和BUSI乳腺超声（患者标识不可用，因此假定图像间独立）上，合并控制达到了其总体目标，但平均漏检了31.8%和36.4%的非边界误差。区域控制将这些比例降至19.3%和20.9%，并将经尺寸过滤的假阴性成分的召回率从0.722提升至0.818、从0.611提升至0.763。平均警告面积增加了1.6和4.9个百分点，其95百分位数达到23.5%和38.5%。该效应在三个随机种子和第二个骨干上保持稳定，且面积匹配的启发式方法未能复现该效应。在外部PH$^2$数据集上，冻结阈值超过了两个目标，而用100幅本地图像重新校准使重复划分的平均值降至目标以下。区域校准以可测量的警告面积增加为代价，改善了非边界误差的覆盖。</p>

<h3>准确性并非价值：依据学生所继承的内容选择弱监督者</h3>
<span class="paper-item__meta">arXiv / 2026-11-06 / Romano Li</span>
<p>弱监督者通常以其自身的错误来评判，但真正重要的是学生从中学到了什么。对于平方损失和所有监督者共享的任意线性学习器，我们证明监督者的价值由其在通过学生学习算子之后的错误决定。因此，监督者原始错误的内积可以与学生学习风险的每一个可行值相容，而按这些内积对监督者加权，在相对超额风险上可能任意劣于最优加权。这种学生相对价值无法从无标签数据中辨识，但缺失的部分很小：目标的一个有限维投影决定在弱聚合上训练是否有帮助，另一个投影决定如何对监督者加权。已知的教师训练规则，或以学生相对形式陈述的标签模型条件，会进一步缩小它。干净标签以由未解决方向的几何而非学生表示的维度所设定的代价弥合剩余差距，并具有匹配的最坏情况下界。在高斯设计中，我们还量化了精确教师结构何时优于普通堆叠，以及弱监督者结合干净标签何时优于仅使用干净标签的每一种方法。这些保证可推广到拟合岭学生和有限无标签数据。</p>

<h3>MetricPose：利用深度与几何线索的灵活三维人体姿态估计</h3>
<span class="paper-item__meta">arXiv / 2026-11-06 / Shifan Zhu</span>
<p>在本文中，我们提出了一种3D人体姿态估计器，能够在相机坐标系中预测具有度量精度的人体关节位置。该任务需要恢复身体关节的配置、尺度以及度量相机局部放置。在单目图像中，身体尺寸与相机距离通过透视投影耦合在一起，因此无法仅从图像中唯一确定。这种歧义可以通过结合三种互补的信息来源来减少：学习到的RGB先验、直接深度测量以及来自环境的几何约束（例如地面接触）。我们扩展了一个预训练的全身体估计器，增加了可选的度量深度和几何处理模块，在保留仅RGB操作的同时改进了相机距离估计和深度引导的身体细化。由此得到的统一模型使用共享的学习参数支持RGB、RGB-Ground和RGB-D。与骨盆相对误差不同，相机局部误差还衡量相对于相机的放置。与现有的基础模型SAM 3D Body相比，我们的方法在RGB、RGB-Ground和RGB-D模式下分别将相机局部关节位置误差降低了12.16%、31.00%和54.61%。</p>

<h3>过去一年按性身份划分的毒品使用不平等持续存在：英格兰2007、2014和2024年成人精神疾病发病率调查的趋势</h3>
<span class="paper-item__meta">medRxiv / 2026-11-08 / Wu, Y.</span>
<p>引言 性少数群体遭受不成比例的歧视与少数群体压力，导致其健康状况和健康相关行为（包括药物使用）更差。药物效力增强和掺假可能加剧相关危害。英国关于药物使用中性身份不平等的证据已过时，且不平等是否随时间变化尚不清楚。方法 2007年（N=7403）、2014年（N=7546）和2024年（N=6912）的成人精神病发病率调查提供了英格兰家庭人口的重复横断面概率样本。按性身份、性别和年龄分析过去一年药物使用的加权患病率。逻辑回归模型调整了年龄、性别和地区剥夺程度。趋势分析聚焦于16-64岁人群。结果 2024年，16岁及以上成年人过去一年药物使用报告率为：异性恋9.1%、男同性恋/女同性恋18.3%、双性恋26.8%、其他身份成年人28.3%。在16-64岁人群中，性少数成年人的药物使用（2007年=22.9%，2014年=27.5%，2024年=24.9%）仍至少是异性恋成年人（2007年=10.3%，2014年=9.9%，2024年=11.6%）的两倍，调整后比值比分别为2.4（95% CI：1.7-3.2，2007年）、3.2（2.2-4.8，2014年）和2.2（1.4-3.4，2024年）。性少数女性与异性恋女性之间的差距似乎有所扩大，但置信区间较宽。结论 在英格兰，药物使用中的性身份不平等持续了17年。预防、治疗和政策应解决这些不平等及其社会决定因素，包括歧视和排斥。常规药物统计数据应按性身份报告。健康调查应收集性别认同信息，并具备足够大的样本量以支持对性和性别认同进行分层分析。</p>

<h3>从纵向废水测序数据推断病毒变异株和适应性优势</h3>
<span class="paper-item__meta">medRxiv / 2026-11-08 / Rimaite, A.</span>
<p>在SARS-CoV-2大流行期间，基于废水的流行病学成为监测感染动态的有效工具。然而，废水代表了来自污水处理厂集水区多个个体的不完整病毒基因组片段的混合样本，无法组装出完整的病毒基因组。因此，现有的计算流程在检测临床测序数据中不存在的新变异方面存在局限。我们开发了FitNMF，一种整合的病毒动力学与非负矩阵分解模型，利用废水测序数据的时间结构和潜在的变异竞争，直接从废水下一代测序数据中联合推断突变特征、相对丰度以及循环变异的适应度优势。利用模拟数据以及2021年至2024年间在瑞士六家污水处理厂收集的废水时间序列数据，我们展示了FitNMF从头识别和量化新出现变异的能力，为临床测序有限的环境中的实时变异监测提供了强大工具。</p>
