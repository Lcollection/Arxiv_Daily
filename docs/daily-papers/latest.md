<h3>自然观影中惊奇度和语义距离的神经追踪</h3>
<span class="paper-item__meta">bioRxiv / 2026-09-13 / O&#x27;Leary, R. M.</span>
<p>理解言语需要听者将输入信息与先前的语言和主题知识相结合以获取意义，而预测在很大程度上促进了这一任务。惊奇度及相关现象（例如下一个词预测）往往与听音过程中语言脑区的广泛激活有关。解释惊奇度神经相关物的一个主要挑战在于，词汇预期同时受到句法和语义信息的约束。相比之下，语义距离更能提供一种纯粹的度量，衡量一个语言成分（如词、短语、n元组）与高维语义空间中另一个成分之间的关联程度。我们在自然化的视听语言理解过程中，对连续语篇中的惊奇度和语义距离进行了对比。我们分析了20名英语母语成人在观看全长电影《和莎莫的500天》时的fMRI扫描数据。我们的关注点是大脑对惊奇度或语义距离在逐词展开的语言加工中的敏感性。为此，我们实现了一系列分层体素级编码模型。在控制了低级听觉和视觉特征之后，加入惊奇度或语义距离均改善了双侧颞上回、左侧额下回和右侧小脑的预测。关键的是，在控制另一方之后，语义距离和惊奇度均能解释双侧颞叶皮层的独特变异。这些结果支持了大脑同时追踪广泛的概率预测和语义整合这一观点。更一般地说，这些发现扩展了以往仅针对听觉言语的研究，表明即使在丰富的视听情境中，惊奇度和语义距离也能预测有意义的神经变异。</p>

<h3>从几何到层级：通过发展描绘人类皮层功能的主导模式</h3>
<span class="paper-item__meta">bioRxiv / 2026-09-13 / Holmes, A.</span>
<p>人类皮层的皮层功能沿宏观信息处理层级在空间上呈现模式化分布。该层级沿一条感觉-联合轴排列，一端以单模态感觉区为锚点，另一端以跨模态联合区为锚点。脑动力学的生物物理模型提示，该轴应与皮层解剖和几何的主导共振模式相一致，但事实并非如此。相反，主导的解剖模式对应于沿吻-尾、内-外和背-腹轴延伸的简单空间梯度。皮层解剖模式与功能模式之间的这种分歧是如何产生的？在此，我们使用四个独立的磁共振成像数据集，涵盖从婴儿期到青年期（n=1,512，年龄0-21岁），表明这种空间分歧可归因于长程皮层-皮层区域间功能耦合的成熟。具体而言，我们发现，在生命最初3至4年中，人类皮层的主导功能模式与皮层几何的吻-尾模式高度相似，随后在4至6岁之间转变为一种初步的类感觉-联合模式，并最终在13岁时成熟为一种典型的感觉-联合模式。在婴儿期和幼儿期，从皮层几何模式预测主导功能模式拓扑的线性模型显著优于依赖成人感觉-联合模式的模型，而在发育后期则相反。此外，有针对性地移除长程连接会使成人功能模式从感觉-联合拓扑退化为婴儿样的吻-尾模式。我们的发现表明，长程皮层-皮层耦合的成熟支持皮层功能层级模式从最初由几何约束主导的组织中逐渐涌现。</p>

<h3>关联学习过程中上丘的奖赏预期信号</h3>
<span class="paper-item__meta">bioRxiv / 2026-09-13 / Mutlu, S.</span>
<p>预测未来奖励使中性感觉线索能够获得动机意义，并引导旨在最大化奖励获取的目标导向行为。当结果与预期不同时，这些奖励预测会被更新，从而产生预测误差。中脑多巴胺神经元提供了奖励预测误差信号的经典神经相关物，该信号被广播到多个脑区。这些习得的奖励预测最终影响神经过程，使动物能够选择、准备并执行朝向预期奖励的动作。奖励预期信号已在感觉和运动回路中被观察到，它们可以在其中调节感觉处理以及动作选择和活力。这引出了一个问题：整合性感觉运动回路如何在与驱动奖励寻求动作的感觉和运动变量并存的情况下，表征关于奖励预期的信息。上丘（SC）是中脑的一个感觉运动区域，传统上与定向和动作选择相关，并受到奖励情境的强烈影响。预期奖励调节视觉和前运动活动，习得的客体价值塑造感觉反应，而近期奖励改变小鼠SC中的视觉处理。SC还向中脑多巴胺神经元提供输入，并且能够传递或获得影响多巴胺能活动的条件性感觉反应。然而，SC投射也可以驱动定向运动而不支持强化，这提高了这样一种可能性：线索相关活动反映的是显著性或多动准备，而不是奖励预测本身。在这里，我们使用一项联想学习任务，其中听觉线索预测不同的奖励概率，并结合对整个学习过程中中间SC群体活动的纵向监测，来探究SC是否获得与奖励概率相关的信号，这些信号是否可以与预期性舔舐分离，以及结果反应是否表现出奖励预测误差的标志性特征。我们发现，线索诱发的SC活动在学习过程中逐渐区分奖励概率，并且线索相关的奖励概率在预期性舔舐之外解释了神经活动。因此，中间SC携带一种习得的奖励预期信号，该信号与运动准备多重并存，但不能还原为运动准备。相比之下，结果反应并未表现出一致的群体水平奖励预测误差特征。总之，这些发现将SC确定为在联想学习过程中预测奖励与预期性动作被整合的位点。</p>

<h3>ESCRT-I抑制可保护精神分裂症细胞模型中的NMDAR功能低下并恢复突触稳态</h3>
<span class="paper-item__meta">bioRxiv / 2026-09-13 / Shalaby, M.</span>
<p>N-甲基-D-天冬氨酸受体（NMDAR）功能低下是精神分裂症的核心病理生理机制，然而直接增强NMDAR的临床获益有限，这可能是因为它未能解决受体转运和表面稳定性方面的缺陷。转运所需内体分选复合体（ESCRT）机制调控内化膜蛋白的溶酶体命运，但其在谷氨酸能功能障碍期间突触受体稳态中的作用仍不清楚。苯环己哌啶（PCP）是一种非竞争性NMDAR拮抗剂，被广泛用于模拟NMDAR功能低下和精神分裂症样表型。在此，我们表明亚慢性PCP暴露在原代海马神经元中诱导了持续性NMDAR功能低下、GABA能传递受损以及兴奋/抑制（E/I）平衡崩溃。对ESCRT-I组分TSG101的遗传抑制阻止了这些缺陷，使PCP洗脱后功能恢复成为可能，并增加了功能性NMDAR和GABAA受体的表面表达，而不改变受体药理学或生物物理特性。在网络层面，TSG101敲低恢复了抑制性张力，使兴奋性活动正常化，并稳定了E/I平衡。此外，TSG101敲低挽救了PCP诱导的PSD-95和BDNF减少，恢复了ERK1/2信号传导，并重建了Fos样（Fos-L）的活动依赖性核转位，这与转录可塑性的重新激活一致。这些发现将ESCRT-I确定为突触稳定性的调节因子，将内体分选通路定位为精神分裂症的潜在治疗靶点。</p>

<h3>Ancestree：在给定或推断的谱系下对祖先等位基因进行统一似然推断</h3>
<span class="paper-item__meta">bioRxiv / 2026-09-13 / Sendrowski, J.</span>
<p>推断祖先状态——即在每个多态位点上确定哪个等位基因是祖先型、哪个是衍生型——是许多下游群体遗传学分析的基础，从选择扫描和未折叠位点频率谱到人口统计学推断。然而，现有工具无法统一支持所有相关输入类型：普通变异数据或祖先重组图（ARGs），无论有无外群，同时还要处理多等位基因和反复突变位点。在此我们提出 Ancestree，一个基于似然的引擎，在单一框架内统一这些输入，并返回每个位点四种核苷酸状态的完整后验分布。它以三种模式运行：固定树模式，假设所有位点共享单一拓扑结构，并通过最大似然联合推断各分支的替换率；ARG 模式，直接从提供的祖先重组图中读取每个位点不同的局部树；以及局部树模式，通过成对溯祖 HMM 从基因型数据中采样这些局部树，无需预先存在的 ARG。在模拟数据上，基于谱系的模式（ARG 和局部树）更准确且扩展性更好，并且在违反固定树假设的外群配置下仍保持稳健。外群本身仍然难以替代：在没有外群的情况下，内群多态位点的单位点推断准确性显著受限，而加入单个外群后准确性大幅提升。最困难的位点是那些在内群中固定为衍生等位基因的位点，它们不携带内群内信号，因此需要多个足够深的外群才能恢复，但这些位点在下游分析中信息量极高，携带着选择和适应分析常常依赖的高频分歧信号。Ancestree 可在 github.com/Sendrowski/Ancestree 获取。</p>

<h3>从正反实验证据重建人类相互作用组</h3>
<span class="paper-item__meta">bioRxiv / 2026-09-13 / As, J.</span>
<p>蛋白质-蛋白质相互作用已被检测和报道了数百万次，尽管它们被用于许多不同的情境中以更好地理解健康和疾病中的细胞过程，但关于人类蛋白质-蛋白质相互作用网络的知识远未完整，其中包含许多假阳性测量结果且高度偏倚。无论是为了描绘这些问题的范围还是解决它们，不仅需要了解高置信度的阳性相互作用，还需要了解可能不相互作用的蛋白质对。然而，这类信息在蛋白质-蛋白质相互作用研究中通常未被报道。我们开发了一种方法，从现有的蛋白质-蛋白质相互作用数据中重建这些知识。我们重建了已执行蛋白质-蛋白质相互作用筛选的实验搜索空间，然后创建了一个模型，用以说明给定某个蛋白质-蛋白质相互作用的测试频率和观测频率时，它为真的可能性有多大。我们认为，阴性蛋白质对使我们能够估计实验和计算筛选的错误率。我们展示了如何将这些知识纳入校准。最后，我们评估了一种用于蛋白质-蛋白质相互作用预测的简单机器学习方法，并提出如何利用这类阴性数据而非随机蛋白质对进行训练。总之，我们的结果表明，重建实验搜索空间从现有蛋白质-蛋白质相互作用数据中恢复了一个在很大程度上被忽视的信息层，这有助于指导更准确、更完整地绘制人类相互作用组图谱。</p>

<h3>Delta节律与声音熟悉度组织婴儿大脑中的神经夹带</h3>
<span class="paper-item__meta">bioRxiv / 2026-09-13 / Rambosson, I.</span>
<p>delta频段（约0.5-3.5 Hz）代表了一种在系统发育上保守的生物交流节律，而神经对该时间尺度的夹带将是大脑产生时间预测的关键机制。尽管不同层次的夹带已在成人中得到表征，但听觉时间预测的机制在发育轨迹中仍研究不足，尤其是刺激节律性、频率特异性和声音熟悉度的作用。我们使用高密度脑电图，考察了30名6个月大婴儿在暴露于由其母亲或陌生人产生的delta（2 Hz）或theta（4 Hz）节律性语音音节以及非节律性对照时的神经夹带。听觉时间规律性引发了广泛的额颞夹带反应。关键的是，delta频段夹带在额叶和颞叶集群中具有频率特异性，右额叶选择性在整个夹带期间逐渐增强，这符合该区域主动细化输入的时间模型而非被动对其共振的预期；未观察到显著的theta频段特异性。夹带还进一步受到声音熟悉度的塑造：左侧颞叶皮层选择性地对母亲的声音产生夹带，而右侧额叶集群则选择性地对陌生人的声音作出反应。这与一种实现方式一致，即颞中叶语言相关区域内基于熟悉度的加工与对新异性敏感的额叶机制相互作用，并反映了内部预测模型的持续更新而非被动的感觉登记。频率特异性delta夹带与经验依赖的半球不对称性的共同出现，揭示了一个用于层级时间预测的神经功能网络，该网络由早期听觉经验塑造，并已在6个月时形成。</p>

<p>高频伽马和涟漪频率振荡参与记忆痕迹的编码与提取。跨时间及多种任务追踪特定痕迹及其特征性神经活动仍是一项重大挑战。利用癫痫患者的颅内电极记录，我们在连续几天重复的两个不同任务中，检测到对观看和记忆相同普通名词产生的高频振荡爆发。我们发现，视觉感觉区域的最低词汇反应选择性约为40%，而在更前部的联合区域选择性逐渐增高。在筛选任务中被确定为偏好的相同词汇集，在同一会话中无感觉刺激的视觉呈现或自由回忆期间，以及次日，均引发了另一任务中的选择性反应。我们证明，特定概念所依赖的大规模神经元集群的持续再激活，反映为人类皮层中高频振荡的爆发。</p>

<h3>英国生物银行中大脑与心理健康关联的最新路线图</h3>
<span class="paper-item__meta">bioRxiv / 2026-09-13 / Li, X.</span>
<p>英国生物银行提供了在大规模上研究脑影像与心理健康之间关联的前所未有的机会，但其效应量和可重复性仍不清楚。我们在8，415名参与者中，将七种MRI模态的17，580个影像衍生表型与309个心理健康表型进行相关分析，并分为发现子集和验证子集。关联通常较小（中位|r| = 0.018；前1%为0.108），且可重复性较差：在发现集中显著的关联中，仅9.0%在验证集中显著。进食障碍在所有精神障碍中显示出最大的效应，但仅在6.0%的案例中可重复，而物质使用显示出最高的可重复性（14.5%）。磁敏感加权成像产生的影像关联最可重复。脑与心理健康指标的纵向变化之间关系微弱。我们提供了一个交互式仪表板，可返回任何心理健康类别与影像模态组合的效应量和可重复性基准，支持英国生物银行研究中的变量选择和研究设计。</p>

<p>皮肤温度和床微气候是已确立的人类睡眠调节因素，但此前大多数研究依赖于被动热材料。我们使用一种能够加热或冷却微气候的智能床，研究六种温度设置如何影响睡眠结构、自主神经活动和脑电图活动。18名成年人（9名男性，9名女性；平均年龄44.5岁）完成了两次整夜多导睡眠监测，床温通过拉丁方平衡分配，覆盖三个小时的高冷却、中冷却、低冷却、关闭、低加热和中加热时段。混合效应回归模型评估了对诱导热变化的操纵检验、睡眠与觉醒的概率，以及各睡眠阶段（N1、N2、N3、REM）的概率，二次分析评估了睡眠加深、心率和脑电频谱功率。温度操纵显著影响了睡眠和生理结果。与关闭相比，所有五种主动设置均使睡眠向更深程度转变，增加了慢波睡眠的比值比（比值比1.21至3.65，高冷却最大），并降低了浅非快速眼动睡眠的比值比。与冷却相比，加热加速了早期睡眠加深，但未显著改变入睡潜伏期，而冷却则产生了心率的分级降低。脑电分析揭示了加热和冷却条件下不同的皮层特征。这些发现表明，主动床微气候调节可调控睡眠期间的睡眠结构、自主神经活动和皮层活动。效应的非线性模式提示存在热“最佳点”，其可能随夜间时段和个体而变化，支持开发用于睡眠优化的个体化可编程温度调节策略。</p>

<h3>中国社交媒体上青少年对生殖健康视频的参与度和情感倾向：一项横断面内容分析</h3>
<span class="paper-item__meta">medRxiv / 2026-09-13 / Zhang, X.</span>
<p>背景 青少年越来越多地在社交媒体平台上寻求青少年生殖健康信息，但在中国，此类内容的范围、可信度和情感接受度仍不明确。本研究考察了青少年如何在Bilibili（一个视频分享网站，月活跃用户约3.41亿，其中大多数为24岁或以下）上与生殖健康视频互动，以识别信息缺口和塑造在线讨论的因素。方法 使用18个关键词查询，我们检索了2016年9月至2024年6月期间发布的743个Bilibili视频的元数据和用户生成文本。该数据集包含4.868亿次观看、1230万次点赞和约76万条文本条目（评论加弹幕）。在去除重复和中文分词后，我们对互动指标进行了描述性和Pearson相关分析，并应用了一个由大语言模型（Qwen2.5-32B）驱动的三分类情感分类器，对所有评论和弹幕进行分析。上传者的医学背景经人工核实，以确认其专业资质。结果 观看量与点赞（r = 0.7）、收藏（r = 0.74）和分享（r = 0.74）呈强正相关；收藏与分享几乎呈线性关系（r = 0.9）。较少涉及的主题，如绝育手术（占视频的3.0%）和基于生育意识的方法（2.3%），吸引了不成比例的高点赞、分享和评论率。只有17%的上传者确认接受过医学培训，而在关于新型避孕方法或自然流产的视频中，未识别出任何具有医学培训背景的上传者。情感分析显示，对人工流产（52.2%负面）和新型避孕药（52.1%负面）主要呈负面反应，而关于应对自然流产的内容引发了最高比例的正向情感（24.2%）。负面情感与较大的评论量呈中度相关（r = 0.32），但与点赞（r = -0.38）和虚拟币投币（r = -0.51）呈负相关。结论 在Bilibili上，青少年的参与集中在基础避孕方面，但小众或有争议的话题推动了更多互动和两极化的情绪，且往往缺乏专业监督。需要医疗服务提供者、教育工作者和有影响力的上传者协同努力，提供准确且富有同理心的内容，以满足未满足的信息需求。调整信息的情感框架可以进一步增强传播效果，并促进关于敏感生殖健康问题的建设性讨论。</p>

<h3>轻量级频率门控增强的nnU-Net提升鼻窦CT分割中的数据效率</h3>
<span class="paper-item__meta">medRxiv / 2026-09-13 / Chen, Y.-C.</span>
<p>背景与目标：从CT中自动分割鼻腔和鼻旁窦有助于诊断和手术规划，但该领域的临床数据集仍然很小，这可能影响训练稳定性和评估有效性。本研究探讨自适应频率-空间双流网络（AFS-DSN）的频率域机制能否以轻量形式迁移到自配置nnU-Net框架中，以及由此产生的性能提升能否经受严格的统计验证。我们将AFS-DSN的频率分支和跨域注意力机制集成到nnU-Net中，并修正了原始设计中零初始化门控死锁问题，使用修正后的模型（v2）作为共同基础。在此基础之上，我们评估了三种变体：X1，一种应用于24个小波子带的输入条件可学习频谱门；X2，增加了边界距离训练目标；X3，结合X1和X2。实验使用了130卷NasalSeg CT数据集，采用完整的91/19/20方案以及重建的真正3折交叉验证，其中每折的训练集减少约19%，从91例降至73-74例。在完整方案下，所有变体均显示出相对于匹配的nnU-Net基线小幅但统计上可检测的改善。X3的Dice分数为95.78%，而基线为95.59%，提高了0.19个百分点（95% CI [0.09, 0.29]；Holm校正p = 0.004），X3还将平均表面距离（ASD）从0.252 mm降至0.235 mm。X3在±0.10个百分点的裕度内与任一单独组件统计等效，表明存在共享的性能上限而非互补增益。在训练数据减少的情况下，基线Dice下降了2.71个百分点（95.59%至92.88%），而X3基本保持不变（95.78%至95.75%），跨折优势为+2.88个百分点（折级95% CI [0.80, 4.96]），该优势在所有20个测试病例中均成立（符号检验，p = 1.9e-6），并得到平均表面距离的佐证。这种组合方法的实际价值主要在于分布内数据效率，而非最大化峰值分割精度。</p>
