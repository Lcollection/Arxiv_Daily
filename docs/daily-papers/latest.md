<h3>AnyCam：任何事物皆可表征视频生成中的相机</h3>
<span class="paper-item__meta">arXiv / 2026-11-25 / Weijie Lyu</span>
<p>相机控制的视频生成沿目标相机轨迹重新渲染视频，然而围绕物体移动相机——这是改变以物体为中心场景视角的最自然方式——仍然困难。现有方法要么以相机参数为条件，而相机参数在单目视频中具有尺度歧义，要么以显式几何如变形点云或深度为条件，而后者在大视角变化下会失效。我们提出AnyCam，一种以场景中的锚定物体来表示相机的方法：我们在3D中重建该物体并沿目标轨迹渲染它，这是一种尺度感知、视角完整且易于相对于物体指定的相机信号。视频扩散模型将源视频的内容和动态迁移到新视角。其H-Concat布局在时间上对齐源帧和目标帧，因此该模型可以蒸馏为AnyCam-AR，一种用于即时相机控制的流式少步生成器。两个模型均在配对的视频上训练，这些视频带有来自多相机视频和静态场景采集的像素对齐锚定渲染。在不同数据集和轨迹上的实验表明，AnyCam在相机控制和视觉质量方面优于相机控制的视频生成和3D重建方法。</p>

<h3>用智能体视觉推理跟踪任意点</h3>
<span class="paper-item__meta">arXiv / 2026-11-25 / Xuweiyi Chen</span>
<p>通用视觉-语言模型（VLM）在目标检测、视频识别等诸多领域已超越专家视觉模型。然而，点对应关系对VLM而言颇具挑战，因为它超越了目标级识别：它要求在观测之间对同一物理表面点进行像素级定位，即便外观发生变化或该点消失后又重新出现。本文提出AgenTAP，一个基于VLM的智能体，直接预测点坐标与可见性，并对视频进行主动推理。该智能体从自身估计出发，自主选择要检查的内容，并利用由此获得的证据验证点的身份并精化其预测。在GPT-6 Astra上，它在点定位与可见性预测两方面均超越专家视觉模型，且无需针对对应关系进行微调。我们进一步利用AgenTAP在点消失后重新识别物理点并重新连接碎片化轨迹，构建了EgoTAP-4D，一个长时真实世界第一人称视频中的3D点轨迹数据集。在采样的重新出现的点上，其预测接近人类一致性，且将EgoTAP-4D加入D4RT训练可提升平均3D跟踪性能。</p>

<h3>AI原生自编码器通信的频谱自适应与迁移学习</h3>
<span class="paper-item__meta">arXiv / 2026-11-25 / Yalin E. Sagduyu</span>
<p>端到端物理层学习用自编码器（AE）取代了独立的调制、编码和检测操作，该自编码器由发射机和接收机处联合训练的编码器-解码器对组成。本文研究了基于自编码器的AI原生通信，并量化了其对信道模型中训练-测试失配的敏感性。仅在AWGN信道上训练的模型在匹配条件下可实现低误码率（BER），但在存在实际前端损伤的瑞利衰落信道上性能严重退化。为减少适应新信道条件所需的时间和能量，我们提出一种低延迟迁移学习流程，该流程从AWGN预训练系统出发，仅微调发射机和接收机层的一小部分子集，同时冻结其余部分。我们进一步将层选择建模为预算约束优化问题，以识别适应过程中最具信息量的待更新参数。这在适应轻量前端以应对衰落和损伤引起的混合的同时，保持了已学习的信号几何结构和深层判决结构。对于自编码器通信，我们表明部分更新可消除失配引起的误码率底限，并接近完全重训练模型的BER。我们提供了逐层研究并量化了资源-性能权衡，表明适度的适应可大幅降低BER，同时减少训练时间、乘累加（MAC）操作、能耗以及更新参数的比例，从而实现资源高效的实现。</p>

<h3>在没有视频的情况下改进和扩展视频编辑能力</h3>
<span class="paper-item__meta">arXiv / 2026-11-25 / Ji Xie</span>
<p>图像编辑模型能够遵循广泛的指令，但视频编辑模型仍然落后，部分原因是难以收集成对的源视频和编辑后视频。是否有可能在没有新配对视频的情况下，将先进的图像编辑能力迁移到视频编辑器？我们提出图像到视频迁移（I2VT），该方法利用图像编辑器改进预训练视频编辑器，并将其扩展到新的编辑任务。它能够实现高效的后训练，无需架构更改，也无需新视频，仅使用单张图像。我们的核心思想是让视频编辑器扮演图像编辑器的角色：它将图像作为单帧视频进行编辑，由图像编辑器在每个去噪步骤中引导视频编辑器的预测。尽管视频编辑器在训练期间只看到单张图像，但在测试时，它将改进和扩展的能力应用于整个视频片段，同时保持时间一致性。为推进视频编辑的边界，我们提出OpenVE++，这是OpenVE-Bench的扩展，增加了四个对视频制作有用的新编辑任务，包括动作变化、表情变化、身体运动和场景重光照。我们在三种不同视频编辑器上的实验表明，I2VT提升了现有编辑能力并将其扩展到新任务，我们的模型在OpenVE-Bench和OpenVE++上均达到了最先进（SOTA）性能。</p>

<h3>每一刻的网格</h3>
<span class="paper-item__meta">arXiv / 2026-11-25 / Roy Or-El</span>
<p>我们提出MEMO（a Mesh for Every MOment），一种重建完整动态场景几何的方法，该场景由多台同步相机捕获，并在每一帧提取网格。现有的动态高斯泼溅方法要么仅建模外观，要么针对由前景掩码分割出的孤立物体，并且它们都通过TSDF融合或泊松重建来恢复网格，其固定网格限制了所能捕获的细节。MEMO的核心是一种受高斯过程启发的逐高斯运动模型，它将每个高斯的位置和旋转随时间表示为时间高斯核的组合。该模型在整个序列中保持每个高斯为有效的表面元素，并携带动态几何的隐式表示，因此可以在任何时刻从高斯定义的场中导出网格。尽管在真实捕获中很常见，但大幅度快速运动构成了动态高斯泼溅方法通常忽视的挑战。为了解决这一问题，我们设计了一种基于轨迹的初始化方案，以闭式形式将每个高斯的初始轨迹拟合到点轨迹。我们在Blender-Moments（一个包含九个动画场景、每帧均有真值网格的新基准）和两个真实世界数据集上评估了MEMO。MEMO在最先进方法中重建出最准确的几何，并在新视角合成和训练时间方面保持竞争力。项目页面：https://memo-4d.github.io</p>

<h3>攻击策略选择可能误导监控评估者</h3>
<span class="paper-item__meta">arXiv / 2026-11-25 / Charlie Griffin</span>
<p>AI监控器——即标记AI智能体危险行为的分类器——通常使用由攻击策略生成的对话记录进行评估，这些攻击策略充当部署中危险行为的代理。我们以一个已投产的OpenAI监控器作为案例研究进行评估，发现测得的假阴性率对生成攻击策略的方法以及该方法内部所施加的优化程度都高度敏感。在单一方法（强化学习）的不同优化水平下，该比率从0.5%到20.8%不等；在各方法最佳观测优化水平下（优化提示词 vs. 对话记录编辑），该比率从6.4%到23.0%不等。每个攻击策略都仅针对代理监控器开发：所有报告的结果均显示攻击能够迁移到留出的GPT-5.4目标监控器上。我们的结果表明，监控器规避评估很容易产生误导：仅使用基本攻击方法的评估可能会让人错误地确信监控器足够强大。对攻击策略选择的敏感性带来了一个问题：要将任何特定结果解释为关于部署性能的证据，需要提供正当性论证。攻击策略生成的对话记录是监控器在部署中必须标记的危险行为的代理。这些代理可能引入可见的人为痕迹，例如对监控器所见的指令中并不存在的“侧任务”进行推理，从而影响监控器的判断。鉴于上述敏感性，代理的选择可能改变评估的结论。因此，要将这些结果解读为关于部署的证据，需要单独提供合法性论证，说明这些代理为何具有信息量，包括对保守性的任何正当性说明。给出令人信服的论证仍是一个未解决的问题。</p>

<h3>DynMF2：基于期望最大化的刚体运动分解用于单目4D重建与运动分割</h3>
<span class="paper-item__meta">arXiv / 2026-11-25 / Agelos Kratimenos</span>
<p>单段随意拍摄的视频会使动态场景欠定：从每个位置仅观测一次的点可以沿朝向或远离相机的方向滑动，却仍与每一帧匹配。我们利用运动本身的结构来约束重建。基于 DynMF，我们将场景运动建模为少量 SE(3) 轨迹，每条轨迹均为刚性，并让每个点仅跟随其中一条轨迹，绝不混合。DynMF2 通过期望最大化（EM）直接从 3D 点轨迹计算这一分解，无需渲染。其 M 步以闭式解将每条刚性运动拟合到分配给它的点，其 E 步将每个点重新分配给解释误差最小的运动。背景只是又一条运动——相机的运动，因此无需掩码。随后三种工具修正该分解：requery 在渲染显示跟踪器遗漏部分的位置添加轨迹，merge 合并一起运动的运动，split 分离不一起运动的运动。因此运动数量随场景而定。无需掩码，DynMF2 在 iPhone 和 NVIDIA 上的视图合成以及 iPhone 上的 3D 跟踪中明显优于基于掩码的基线。它恢复了掩码遗漏的内容，从细小部件和细节到背景深处的小型运动物体。其运动对 MOVi-F 和 iTACO 场景中运动部分的分割具有竞争力，尽管 DynMF2 从未被训练用于分割。场景中什么在运动并非预先决定：它从刚性运动本身中涌现。</p>

<h3>ESCRT-III依赖的膜弯曲方向源于双分子层不对称性</h3>
<span class="paper-item__meta">bioRxiv / 2026-11-26 / Tran, J.</span>
<p>ESCRT-III是细胞执行反向拓扑膜剪切、从内部切割膜颈的主要机器。然而，纯化的ESCRT-III主要组装在膜的外侧，并向相反方向弯曲膜。一种聚合物如何选择其方向，是一个长期存在的悖论。在此，我们表明ESCRT-III提供力，但双分子层不对称决定方向。在芽殖酵母中，鞘脂不对称是高效腔内囊泡形成所必需的：缺乏它时，货物分选受损，内体中间体积累。在重构膜中，施加脂质或蛋白质跨双分子层的不对称足以定向ESCRT-III驱动的形变。小叶分辨的荧光寿命成像揭示，两者通过单一机制起作用：小叶之间不等的脂质堆积产生差异拉伸应力，从而决定膜向哪个方向弯曲。重构膜通常是 symmetric 的；细胞膜则不是。这解决了反向拓扑悖论，并将双分子层不对称识别为任何膜重塑机器都可利用的方向线索。</p>

<h3>动态基因体染色质可及性与裂殖酵母孢子萌发过程中阶段依赖性转录上调相关</h3>

<p>背景 遗传性癌症约占恶性肿瘤的5%至10%，在早发性疾病或具有显著家族史的个体中更常发现遗传易感性。然而，来自印度及更广泛南亚人群的跨多种肿瘤类型的种系癌症易感性大规模研究仍然有限。方法 我们回顾性分析了2016年至2025年间在印度班加罗尔MedGenome Labs Ltd.接受种系遗传性癌症检测的24,320名个体。检测主要使用经过临床验证的多基因靶向下一代测序（NGS） panel（N = 22,773），其中一部分病例使用多重连接依赖探针扩增（MLPA）进行分析（N = 4,524）。此外，对1,547份样本仅进行了MLPA确认检测。分析的主要癌症亚组为乳腺癌（N = 10,292）、卵巢癌（N = 3,935）、结直肠癌（N = 1,267）、前列腺癌（N = 762）和子宫内膜癌（N = 539），另有2,764名具有阳性家族史的无症状个体。结果 总体诊断率为23.9%，最高见于结直肠癌（42.1%），其次为卵巢癌（31.6%）、子宫内膜癌（22.3%）、乳腺癌（20.3%）和前列腺癌（8.7%）。相应癌症的家族史与大多数主要癌症类型中更高的诊断率相关，而前列腺癌在报告有其他癌症家族史的个体中显示出更高的检出率。乳腺癌、结直肠癌、卵巢癌和子宫内膜癌的诊断率通常随年龄增长而下降，但前列腺癌则随年龄增长而上升。BRCA1和BRCA2在乳腺癌和卵巢癌中占主导，错配修复基因在结直肠癌和子宫内膜癌中占主导，BRCA2在前列腺癌中占主导。复发性BRCA1 c.68_69delAG（p.Glu23ValfsTer17）变异在351名个体中被识别。所识别的BRCA1基因突变与已发表的诱变研究的功能后果数据相关。在乳腺癌病例中，ER-/HER2-亚型显示出最高的诊断率（25.5%）。使用autoACMG分类器对VUS重新分析后经人工审核，确认443份样本中的277份（62.5%）为致病性/可能致病性（P/LP）。在剩余VUS中，3.2%使用VUS-Grader工具被分类为VUS-High。此外，对74份被分类为VUS的CNV阳性样本进行人工审核，导致41份（55.4%）被重新分类为可能致病性，使诊断率提高了1.4个百分点。在4,524名接受NGS和MLPA联合检测的个体中，251名（5.5%）发现了CNV，其中59例由MLPA检测到但NGS未检测到。结论 本回顾性研究是南亚地区跨主要癌症类型遗传性癌症易感性的最大规模特征描述，涵盖24,320份样本。研究结果支持全面的多基因检测和适应当地人群的检测策略，以改善遗传性癌症风险评估和精准肿瘤学。</p>

<h3>精神病学障碍中可能具有因果关系的血浆蛋白：一项蛋白质基因组学评估</h3>
<span class="paper-item__meta">medRxiv / 2026-11-26 / Margelyte, R.</span>
<p>重要性：大规模血浆蛋白质组学研究已将数百种蛋白质与精神疾病联系起来，但尚不清楚哪些反映因果生物学而非混杂因素或疾病后果。目的：确定哪些与抑郁、焦虑、双相障碍和精神病性障碍相关的血浆蛋白质具有因果作用的遗传学证据。设计、设置和参与者：本蛋白质基因组学研究将遗传分析与英国生物银行（UKB）队列（N=52,615）中的横断面和纵向分析相结合。使用两样本孟德尔随机化（MR）和遗传共定位，对2,923种血浆蛋白质与来自英国生物银行制药蛋白质组学项目（N=34,557）的常见变异蛋白质数量性状位点（pQTL）的关联进行了检验。研究结果通过基于规则的框架进行评估，该框架结合了工具变量有效性与使用血液和脑表达数量性状位点（eQTL）及罕见变异MR的遗传分析。暴露：测量的和遗传代理的血浆蛋白质水平。主要结局和指标：抑郁、焦虑、双相障碍和精神病性障碍的现患和新发诊断；抑郁、焦虑、双相障碍和精神分裂症的全基因组关联研究（GWAS）汇总统计数据。结果：多重检验校正后，UKB中有1,685种蛋白质涉及蛋白质-障碍关联，其中26种蛋白质（32个蛋白质-障碍配对）同时满足MR和共定位标准（MR错误发现率&lt;0.05且共定位后验概率≥0.8）。经过独立遗传验证后，涉及7种蛋白质（CD40、ADAM22、CDHR1、PDIA3、SEMA3F、DSG3和DDR1）的9个障碍-蛋白质配对符合可信因果证据标准，其中以免疫信号受体CD40对精神分裂症和双相障碍的作用为首。具体而言，遗传预测的CD40水平较高与精神分裂症风险较低（比值比[OR] 0.90；95%CI 0.85-0.95）和双相障碍风险较低（OR 0.89；95%CI 0.84-0.95）相关，并得到方向一致的共定位脑eQTL和罕见变异MR证据的支持。结论与意义：与主要精神疾病相关的血浆蛋白质关联中，很少有具有可信的因果遗传学支持，这表明在提名蛋白质组学靶点之前，需要在分子层面、组织和遗传变异类别上进行多层评估。CD40是一种正在临床开发中被药物靶向的免疫受体，在精神分裂症和双相障碍中显示出稳健的保护性遗传学支持，值得进行有针对性的机制和治疗研究。</p>

<p>由于生殖支原体在临床样本中的细菌载量低，直接对其进行基因组测序具有挑战性。我们开发并比较了两种DNA富集策略——基于扩增子的方法和基于杂交捕获的方法——并结合下一代测序技术，评估了DNA捕获在全基因组测序和高分辨率分子分型中的适用性。富集方法包括RNA探针杂交和靶向序列扩增，并与Illumina iSeq 100平台上的双端测序相结合。在89份生殖支原体阳性样本中，针对五个基因组位点评估了方法性能：23S和16S rRNA，以及分别用于大环内酯类、四环素类和氟喹诺酮类耐药性的parC和gyrA，还有用于系统发育分析的mgpB。关于抗微生物药物耐药性决定因素，多重扩增子测序方法表现出最高的灵敏度，为93.3%至98.9%。尽管使用DNA捕获仅对不足50%的样本进行了表征，但两种方法之间的一致性极好。使用DNA捕获时，24.7%的样本在1倍深度下达到了95%的最低覆盖度。测序成功率与人类DNA污染和低质量读数的存在呈负相关。全基因组单核苷酸多态性分析提供了比多位点序列分型方案更高的分辨能力，并证实了属于mgpB基因型159的多重耐药生殖支原体菌株的克隆性。总之，基于靶向扩增子的富集是专注于抗微生物药物耐药性和mgpB分型的流行病学研究中最准确和可靠的方法，而DNA捕获对于从选定的生殖支原体阳性样本中生成全面的基因组数据具有重要价值。</p>

<h3>应用斑马鱼胚胎对不育男性中鉴定出的NANOS蛋白变异体进行功能分析</h3>
<span class="paper-item__meta">medRxiv / 2026-11-26 / Madiwale, S.</span>
<p>研究问题：脊椎动物NANOS蛋白是否与人类生育力相关，能否建立一种斑马鱼快速体内试验来评估人类NANOS变异的生物学活性？简要回答：结合我们开发的用于Nanos蛋白活性的快速体内试验和患者来源的遗传数据，我们鉴定出可能贡献于男性不育的NANOS变异。已知情况：男性不育影响约17%的人群，但将特定基因变异与该病症联系起来仍然具有挑战性。NANOS蛋白是不同模式生物中生殖细胞发育的关键调控因子；然而，目前缺乏一种快速且稳健的体内试验来评估其在人类男性不育背景下的活性。研究设计、规模、持续时间：本研究检查了男性生殖基因组学（MERGE）队列中3,338名男性的外显子组/基因组数据。其中，2038名男性表现出严重受损的精子发生，但在其他方面健康。96名精子发生完整的男性作为对照纳入研究。此外，该研究还包括对IMIGC队列中44名患者的NANOS变异进行靶向分析。参与者/材料、环境、方法：对外显子组/基因组数据筛查NANOS1、NANOS2和NANOS3中的罕见无义突变、移码、剪接位点以及错义变异。在斑马鱼蛋白的相应位置引入人类氨基酸替换。在斑马鱼胚胎中异位共表达野生型Dnd1和Nanos3可诱导体细胞产生生殖细胞样命运，导致严重发育缺陷和胚胎致死。基于这一原理，我们建立了一种快速体内试验，在活体斑马鱼胚胎中将野生型Dnd1与野生型或变异型Nanos2和Nanos3蛋白共表达，预期如果变异蛋白具有功能，则会导致早期胚胎死亡。该试验用于评估在不育男性中鉴定的NANOS2和NANOS3变异的活性。主要结果和机会的作用：在人类外显子组/基因组测序数据中，我们鉴定了NANOS2中的一个杂合错义变异和NANOS3中的两个杂合错义变异。使用我们开发的体内试验在斑马鱼中检查了这些变异的功能。将野生型Dnd1与从不育男性中选出的Nanos2或Nanos3变异共表达，导致生殖细胞样表型诱导缺陷，证明了该生物学读数在评估患者来源变异对NANOS蛋白活性潜在影响方面的效力。总之，我们的分析使得能够评估单核苷酸变异，这些变异对蛋白功能的影响难以预测，并使我们能够区分对蛋白功能影响很小或没有影响的变异与强烈降低活性并可能潜在贡献于不育的变异。局限性、谨慎的原因：该试验需要获取斑马鱼胚胎和基础成像设备。尽管先前研究支持NANOS蛋白在斑马鱼和人类之间的功能保守性，但物种特异性差异可能影响蛋白活性。因此，斑马鱼试验应被视为评估NANOS变异作为不育贡献因素的更广泛框架的一个组成部分。发现的更广泛意义：以NANOS2和NANOS3为例，我们证明将临床遗传数据与功能细胞和发育生物学相结合，有助于建立候选疾病基因与人类生育力之间的联系。该策略可能适用于其他生殖系特异性基因，其异位表达在斑马鱼胚胎中产生可测量的发育表型。研究资助/竞争利益：我们感谢西班牙卫生部Instituto Carlos III-FIS FONDOS FEDER（资助号PI23/00425）、德国研究基金会（DFG）对E.R.的资助（RA 863/17-1、RA 863/18-1）、对E.R.、C.F.和F.T.的资助（男性生殖细胞临床研究单元，CRU 326，项目号329621271）、对S.K.、C.F.和F.T.的资助（合作研究中心Reproduction.MS，SFB 1748，项目号549467913）、联邦研究、技术和空间部（BMFTR）青年科学家研究中心ReproTrack.MS对S.K.和F.T.的资助（项目号01GR2303），以及明斯特大学医学院的资助。作者声明无竞争利益。试验注册号：不适用。</p>

<h3>正常压力脑积水恢复的脑脊液代谢特征</h3>
<span class="paper-item__meta">medRxiv / 2026-11-26 / Duan, L.</span>
<p>理解神经功能恢复的生物学决定因素仍然是一项重大挑战。正常压力脑积水（NPH）以尿失禁、步态障碍和认知功能下降为特征。值得注意的是，脑脊液（CSF）引流可以显著改善症状，使NPH成为少数可能可逆的痴呆病因之一。然而，术后获益在患者之间差异相当大，且缺乏可靠的术前预测指标，使患者暴露于侵入性干预之下而临床获益的可能性不确定。因此，我们提出术前CSF代谢谱是否能捕捉与神经功能恢复相关的生物学状态。我们研究了一个单中心NPH患者队列，共86例（平均年龄74.7岁，范围59-90；男44例，女42例）。我们通过半靶向（n = 42）和靶向（n = 55）质谱分析接受分流手术患者的脑室CSF，并额外分析腰椎CSF（n = 29）和血浆（n = 33）。在发现队列中鉴定的通路被归纳为指数，并在锁定数据集上以预设的统计分析方案在靶向队列中进行检验。一个一碳/氧化还原指数，结合转硫途径和胆碱代谢物，与3个月时改善的症状域数量相关（每标准差比值比0.49，95% CI 0.24-0.92；错误发现率0.051），其中与认知的相关性最强，较低的指数值伴随改善。同一患者CSF细胞外囊泡中一碳通路的转录本向相同方向变化（置换检验p = 0.023；校正后不显著）。在嵌套交叉验证下，一个稀疏代谢物模型能够区分认知改善的患者，无论是在我们初始流程的留一法实现中（AUC 0.79；置换检验p = 0.028），还是在锁定的重复5折方案中（AUC 0.70；模型选择校正后p = 0.046），并且将预设指数加入临床协变量改善了认知预测；预设的全代谢组模型以及步态和泌尿结局的模型未超过随机水平。这些结果指向一碳和胆碱代谢作为分流手术后认知恢复的候选生物学相关因素，有待在前瞻性验证研究中检验。</p>

<h3>将临床事件标注适配于荷兰初级保健：针对急性感染后综合征的事件标注框架</h3>
<span class="paper-item__meta">medRxiv / 2026-11-26 / Mazzucato, S.</span>
<p>临床自然语言处理（NLP）依赖于特定语言的语料库，而荷兰初级保健领域的此类语料库仍然稀缺。这限制了使用NLP研究急性感染后综合征（PAIS），如新冠感染后状况，因为相关症状及其时间背景通常记录在全科医生（GP）的自由文本记录中，而非结构化编码中。COVID-19标注临床文本（CACT）框架的开发旨在识别英文临床记录中的COVID-19诊断及相关症状，每个症状表示为一个事件：一个文本片段及其关联的上下文，如否定、时间和确定性。我们翻译并改编了CACT以适用于荷兰初级保健，将其范围从COVID-19扩展到PAIS及其他相关感染和诊断，并针对荷兰全科医生记录的四部分（SOEP：主观、客观、评估、计划）定制了标注规则。修订后的框架区分症状、急性感染、PAIS及其他相关诊断，并捕获11类支持性诊断证据，包括实验室检查或体格检查。它还将不确定的诊断（“可能新冠后”）与提及但未断言的状况（例如患者对长新冠的恐惧）区分开来。在由两名标注者独立标注200份全科医生记录的试点中，六个核心类别（症状、诊断、否定、证据、时间和生命体征）的总体片段级一致性为F1 = 0.51（95% CI [0.47, 0.55]）。当仅限于两名标注者均标记的文本片段时，一致性提高至F1 = 0.78 [0.75, 0.80]，表明分歧主要在于某提及是否被标注，而非其被归入哪个类别。未来研究应评估修订框架的哪些部分可推广至荷兰初级保健和PAIS之外的领域。</p>

<h3>用于登革热预测的神经网络：一项系统综述</h3>
<span class="paper-item__meta">medRxiv / 2026-11-26 / Piva, L. L. d. S.</span>
<p>背景：早期登革热预测是疾病缓解的重要工具，神经网络（NNs）是强大的预测模型，已在公共卫生的许多领域做出贡献。我们综述了登革热预测文献中的神经网络应用，以为未来研究的模型设计提供参考。方法：遵循PRISMA指南，我们系统检索了Web of Science/Knowledge、Scopus、PubMed和Science Direct截至2025年9月的文献，以查找使用神经网络预测人群登革热的研究，共检索到628条记录。去除重复后，应用四项纳入标准和两项排除标准：文章须为英文，实施神经网络或深度学习技术，预测登革热发病率或风险，并明确说明数据来源、处理步骤、网络参数和架构。结果：共纳入62篇论文，并按神经网络与对照模型的相对性能、架构与超参数、输入特征选择、地理分布和模型透明度进行总结。大多数研究（62项中的35项）实施了浅层前馈神经网络，使用历史登革热发病率和气候变量作为最常见的输入特征，共出现43次。目标变量为登革热病例、严重程度和热点以及暴发风险，模型选择和评估方法不统一。大多数研究（25项）使用城市或其分区层面的精细观测数据，同时也常用每周测量数据（62项中的35项）。神经网络相对于对照模型（如基于树的监督模型）的性能因研究背景而异。我们发现63%的研究在基线中纳入了此类模型；其中约一半发现神经网络优于基线，尽管大多数未包括统计比较。结论：这些研究表明，神经网络虽然在特定场景中有用，但并未一致发现其优于更简单的预测模型，尤其是基于树的机器学习方法。</p>
