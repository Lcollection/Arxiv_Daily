<h3>基于可变粒度的图像到三维部件生成统一框架</h3>
<span class="paper-item__meta">arXiv / 2026-10-22 / Qiwen Gu</span>
<p>可控三维部件生成对数字资产生成至关重要，然而现有方法缺乏灵活性，难以适应需要不同控制程度的多样化用户工作流。本文提出FlexPart，一个统一的图像到三维部件生成框架，在单一模型中支持可变粒度的几何条件。通过门控自适应调制无缝集成从稀疏点到密集边界框和掩码的异构输入，FlexPart实现了强大的跨模态协同。我们还提出了一种非对称几何引导机制，利用强空间先验来对齐跨粒度的表示，提升几何一致性并促进任务间协同。在PartVerseXL上以掩码为条件时，FlexPart相较于TripoSG + SAM3D将部件CD降低了16.6%，相较于OmniPart降低了10.5%，同时保持具有竞争力的整体网格质量。代码可在https://github.com/Gucci233/FlexPart获取。</p>

<h3>感觉运动对齐：具身策略成功的柏拉图式代理</h3>
<span class="paper-item__meta">arXiv / 2026-10-22 / Yunfei Xie</span>
<p>机器人基础模型通常通过昂贵的闭环部署进行评估，这促使人们寻求廉价的离线代理指标来衡量模型能力。柏拉图表示假说（PRH）表明，随着表示能力的提升，视觉和语言等不同模态会趋同于一个共享的现实统计模型。我们追问运动轨迹是否构成另一种此类模态：随着具身模型能力增强，其感官表示是否应向物理运动的结构收敛？为考察这一问题，我们提出感觉运动对齐（$S^2$），一种无需训练的离线指标，用于衡量模型的感官表示与物理运动几何结构的对齐程度。我们发现，$S^2$ 在各类具身模型家族中与下游机器人任务成功率呈正相关，使其成为在闭环评估之前优先筛选模型的低成本离线代理指标。$S^2$ 还能在昂贵的视觉-语言-动作模型（VLA）微调之前，识别出有前景的视觉-语言模型（VLM）骨干网络。除相关性之外，$S^2$ 还为 VLA 和世界动作模型（WAM）中观察到的现象提供了表示层面的解释。借助 $S^2$，我们将 PRH 扩展到具身模型，并使感觉运动对齐在经验上可测量，为理解具身模型为何能超越其闭环成功率而取得成功提供了洞见。</p>

<h3>面向思维剪枝的直接Pass@$k$优化：在测试时推理中平衡质量与多样性</h3>
<span class="paper-item__meta">arXiv / 2026-10-22 / Mahdi Salmani</span>
<p>测试时扩展已成为推理模型的一种关键推理策略，模型通过生成大量候选解，以期至少找到其中一个正确解。将所有候选解运行至完成可能在计算上代价高昂，因此近期工作在仅生成较短前缀后便对候选池进行剪枝，只对存活的候选继续投入计算。现有剪枝策略大致分为两类：基于质量的方法为每个部分解分配分数，并丢弃那些被预测最终会导致错误最终解的候选；而基于多样性的方法则选择遵循不同推理轨迹、因而可能覆盖不同最终解的部分解。这两个目标之间的张力是探索与利用的一个实例，然而此前几乎没有剪枝工作直接揭示这一权衡，更不用说对其进行优化。本文中，我们引入一种剪枝流程，通过优化所选解池上的 pass@$k$ 来直接处理这一权衡。具体而言，它选择解池以最大化如下概率：其中至少一个部分解在继续至完成后产生正确答案。由于该目标同时奖励高质量部分解并惩罚它们之间的冗余，质量与多样性由该准则本身自然平衡，而非通过单独的临时设计选择来实现。在八个开放权重推理模型上，我们的方法优于现有的基于质量和基于多样性的剪枝策略。当剪枝流程保留中等数量的部分解用于继续生成时，增益尤为显著，凸显了在剪枝过程中直接平衡质量与多样性的价值。</p>

<h3>从随机特征到完全可训练网络的相变</h3>
<span class="paper-item__meta">arXiv / 2026-10-22 / Xin He</span>
<p>构造精确且计算上可行的近似空间是科学计算中的一项基本任务。部分可训练神经网络将固定随机特征与完全自适应表示相结合。本文量化了近似界中的相变模式，并在训练误差中观察到类似行为：初始阶段快速但平滑的改善，随后收益递减，且在初始化失配更大时转变更为急剧。在谱衰减指数为 $α&gt;1$ 的多项式谱衰减和杠杆兼容性条件下，我们为宽度为 $m$、可训练比例为 $P$ 的两层网络建立了平方 $L_2$ 近似速率 $\mathcal{O}((κ_P\log(m/δ)/m)^α)$，其中 $κ_P=(P/κ_1^*+(1-P)/κ_0^*)^{-1}$。该界在再生核希尔伯特空间（RKHS）的单位球上一致成立，概率至少为 $1-δ$。常数 $κ_0^*$ 和 $κ_1^*$ 量化了固定组和可训练组相对于目标 RKHS 的采样失配。对于维度为 $d$ 的球面偏置 ReLU 特征，我们在初始化尺度 $τ\ge1$ 下以 $α=(d+2)/(d-1)$ 和 $κ_0^*=4\sqrt{2}τ(d+1)/d$ 验证了这些假设，并在岭杠杆采样下得到 $κ_1^*=1$。对于 $d=5$ 和 $τ=10$，约 $4.1\%$ 的可训练比例即可捕获从 $P=0$ 到 $P=1$ 近似界缩减量的 $90\%$。一个结构化的三层示例说明了少量可训练的第一层神经元如何通过非线性复合利用固定的下游模块。在包括多达 15 层网络在内的多种设置下的数值实验，在训练误差中表现出类似的相变。</p>

<h3>通过选择性审计实现可靠的AI辅助决策</h3>
<span class="paper-item__meta">arXiv / 2026-10-22 / Isaac Gibbs</span>
<p>我们考虑对一个产生一系列决策的AI系统进行在线监测。在每一轮中，系统输出一个建议决策以及一个估计该决策可信度的置信分数。决策和置信分数不必由同一模型产生：例如，一个智能体可以提出决策，而另一个独立的验证器智能体对其进行评估并输出正确性或安全性分数。基于这些信息，我们必须决定是自动接受AI决策，还是咨询专家，例如人工审核员，由其审查该建议并接受或纠正它。我们将此任务形式化为一个在线约束优化问题，其目标是在保证未经审核的AI错误比例保持在用户定义阈值以下的同时，最小化专家审核的频率。我们推导出一族具有可证明错误控制保证且无需任何假设的算法，其中包括一种最优高效的方法：对于对抗性和独立同分布数据流，它渐近地达到可实现的最佳审核率。在筛选对大型语言模型的有害请求、定性文本标注和数据标注上的实验表明，我们的方法在实践中实现了有效的错误控制，同时与基线相比大幅减少了人工审核的需求。</p>

<h3>SpectralCanary：用于T2I数据集使用审计的极其简单的低频痕迹</h3>
<span class="paper-item__meta">arXiv / 2026-10-22 / Sy-Tuyen Ho</span>
<p>审计一个文本到图像（T2I）模型是否在特定图像集合上进行了微调是困难的：模型可以吸收集合级别的视觉特征，而不复制训练图像。主动式数据集使用审计在数据集发布前植入一个共享信号，随后检查该信号是否出现在可疑模型的生成输出中。现有方法往往在可验证性、保真度、鲁棒性和可部署性之间权衡。我们提出$\textbf{SpectralCanary}$，它使用平滑的低通掩码将固定的金丝雀图像混合到每张集合图像中，同时保持caption不变，且既不需要辅助生成也不需要逐图像优化。一个轻量级验证器在可疑模型的输出中检测迁移的信号。在Pokemon数据集上的八项测试和三种真实数据变换中，跨越两个架构家族，SpectralCanary在所评估的方法中取得了最高的平均逐代TPR@$1\%$ FPR（$91.1\%$）以及使用30次生成的固定阈值模型级准确率（$94.8\%$）。在涵盖艺术、医学、卫星和时尚领域的五个数据集上使用SD3.5，SpectralCanary平均达到$92.4\%$的逐代TPR@$1\%$ FPR，同时保持发布图像的质量（SSIM $0.989$，LPIPS $0.022$），各数据集的平均变化FID接近零（平均$Δ$FID $0.05$）。在Pokemon和ROCOv2上的匹配能量消融支持了我们的设计选择，低频放置相比中/高频放置能更可靠地迁移。在所评估的自适应攻击下，最有效的移除需要激进的修改并产生超过$25$个$Δ$FID点。这些结果确认了低频视觉信号作为集合级T2I审计痕迹的有效载体。</p>

<h3>基于LLM的IT工单分类中的成本感知弃权机制</h3>
<span class="paper-item__meta">arXiv / 2026-10-22 / Sachin Gupta</span>
<p>IT支持工单的错误自动路由可能比人工分诊代价更高。我们将成本感知弃权评估为一种离线、成本条件化的就绪性评估：在显式成本下于校准数据上选择路由策略，然后在留出测试数据上对该冻结策略进行一次评估。在一个包含47,837张工单、八个类别的公开语料库上，我们在零样本和少样本提示下比较了四个训练过的非LLM分类器与四个大语言模型。在示例性成本模型(c_ok, c_triage, c_wrong) = (0, 1, 5)下，TF-IDF配合逻辑回归以及在校准集上选定的0.60阈值将测试成本从0.763降至0.472，相对降低38.1%（配对比率自助法95% CI [35.7%, 40.4%]），同时将错误路由从15.3%降至3.5%。在事后成本参数分析中，冻结的校准选定策略在16种设置中的14种里于留出测试数据上同时优于始终路由和始终延迟。最强的提示配置在分层1,000张工单测试子集上达到0.477准确率，而同一批工单上微调DistilBERT为0.879。等渗回归降低了期望校准误差，但未可靠改善区分度：GPT-4o-mini少样本在校准前后各只有一个置信度值，正确性AUROC为0.500。因此，我们在报告ECE的同时报告正确性AUROC和并列感知的风险-覆盖率面积。在解析推导的盈亏平衡概率0.80处，七个提示配置延迟所有工单；Haiku少样本仅路由19/1,000。仅LLM一致性对照和边际/熵拒绝基线进一步将校准与区分度分开。研究结果受限于该数据集、提示设计、模型端点和示例性成本；本工作是评估框架，而非新的弃权算法或通用部署认证。</p>

<h3>METTA：面向元强化学习的记忆增强测试时适应</h3>
<span class="paper-item__meta">arXiv / 2026-10-22 / Ali Najar</span>
<p>元强化学习旨在训练智能体能够从有限交互中快速适应未见任务，但这需要在长交互历史中表征任务证据。经典循环智能体将经验压缩为隐状态，而基于Transformer的智能体则以二次方的内存和计算成本从过去轨迹中检索。在本工作中，我们提出面向元强化学习的内存增强测试时适应（METTA）。它将快速适应阶段分解为两个时间尺度：因果神经内存以线性序列复杂度执行细粒度的回合内适应，而紧凑的回合级摘要支持长程跨回合任务推断，无需关注完整交互历史。此外，为智能体配备神经内存提供了充分的表达能力和测试时训练能力，使其能够在元测试时有效适应未见的留出任务和任务族。在未见的留出Meta-World ML10/45测试环境中，METTA在保持低训练预算和短实际运行时间的同时，成功率超过50%。在长上下文稀疏奖励PointMaze任务上，它通过表现出更有结构的探索行为而优于基于Transformer的基线。这些结果表明，METTA为更具适应性和可扩展性的长上下文元强化学习提供了一条高效路径。</p>

<h3>BrickWright：物理可行积木搭建的智能体式创作</h3>
<span class="paper-item__meta">arXiv / 2026-10-22 / Ava Pun</span>
<p>前沿编码智能体在3D建模方面正变得越来越熟练。然而，在构建需要在物理世界中组装的物体时，它们仍面临挑战，常常生成无效的装配体，出现悬浮、碰撞或断开的部分。我们认为，为智能体提供用于组装构建和验证其物理可行性的工具，就足以让它们生成物理上有效且仍符合输入提示的装配体。聚焦于乐高积木构建领域，我们提出了BrickWright，一个利用预训练智能体从文本或图像提示生成物理可行积木构建的框架，其中构建在仅使用真实零件、没有碰撞或悬浮零件、并在可能时形成连通结构的情况下是物理可行的。BrickWright引导智能体通过使用BrickLayer编写代码来创建构建，BrickLayer是一个Python工具包，包含两个主要组件：一个符合人体工程学的积木组装API，与在原始LDraw中工作相比可将推理成本减半；以及一个提供物理可行性反馈的验证器。基线智能体的物理有效性率仅从9%（GPT-6 Luna）到69%（GPT-6 Astra）不等，而BrickWright引导的智能体在512个提示样本上达到100%的有效性，同时改善了轻量级智能体的提示遵循度，并保持了较强智能体的提示遵循度。此外，它们在文本到积木任务上优于专用模型。代码可在我们的项目页面获取：https://avalovelace1.github.io/brickwright/</p>

<span class="paper-item__meta">medRxiv / 2026-10-23 / Buggiotti, L.</span>
<p>杂交捕获方法可直接从临床样本中检测广谱病原体，灵敏度高于非靶向方法。临床采用一直受限于周转时间长、工作流程复杂以及被认为成本高昂。我们基于Illumina的RPIP方案（标准工作流程）迭代开发并验证了一种快速杂交捕获工作流程。Rapid-RPIP v1将湿实验时间从约11.4小时缩短至约7.3小时，周转时间（TAT）&lt;15小时。Rapid-RPIP v2进一步将湿实验时间缩短约0.7小时，并使用Illumina Turbo测序将测序时间从约5.5小时缩短至约2.5小时，从而在不影响灵敏度的情况下实现&lt;10小时的TAT，并且对RNA病毒产生的RPKM高于标准工作流程。该方法可 readily 适用于广泛的临床和公共卫生应用。</p>

<h3>心血管波形信号波形流形上的通用坐标用于动态量化和跨受试者比较</h3>
<span class="paper-item__meta">medRxiv / 2026-10-23 / Wu, H.-T.</span>
<p>目的：从非平稳时间序列中量化生理动力学以支持临床决策具有挑战性，尤其是在比较不同受试者的数据时。我们提出一种解决方案，并使用两个真实手术数据库进行验证，重点关注未被充分利用的动脉血压（ABP）信号。方法：我们应用流形学习算法动态扩散映射（DDMap），结合新颖的通用坐标（UC）算法，从非平稳时间序列中量化动力学。该方法使用ABP信号进行演示，并通过肝移植和心血管手术数据库进行验证，两者均包含临床结局。进行了敏感性分析以评估稳健性并确定最佳参数。结果：UC应用通过衍生指标与临床结局之间的显著相关性得到验证。敏感性分析确认了算法的稳定性并有助于优化参数。结论：DDMap结合UC能够实现ABP信号的动态量化及跨受试者比较。该技术重新利用了手术室中通常被丢弃的ABP信号，在医院和家庭护理环境中对其他非平稳生物医学信号具有潜在应用价值。</p>

<h3>证据三角互证的定量方法：构建一个兼顾严谨性与相关性的框架</h3>

<p>三角互证是一种通过整合多来源证据来强化因果推断的方法。多数使用三角互证的研究仅定性考察不同研究是否在因果效应的存在性上一致，而非通过定量整合结果来估计效应。在此，我们开发了一个定量三角互证的框架。我们首先处理如何将各研究特定研究问题与总体目标因果问题相关联（相关性），然后评估每项研究中偏倚的方向和幅度（严谨性），之后在调整偏倚的荟萃分析中合并结果。我们通过三角互证随机对照试验、孟德尔随机化和传统多变量回归的证据来估计β-胡萝卜素对冠心病和心血管疾病的影响，以说明我们的框架。五项随机对照试验和一项孟德尔随机化研究几乎未显示β-胡萝卜素与冠心病之间存在因果关系的证据（相对风险分别为1.00，95%置信区间0.98至1.01；以及1.02，95%置信区间0.98至1.07）。十三项多变量回归研究表明，高摄入β-胡萝卜素可降低冠心病风险（相对风险0.83，95%置信区间0.76至0.91）。应用我们的框架后，三种研究设计一致认为，没有强有力的证据反对β-胡萝卜素摄入不影响冠心病风险的零假设（相对风险0.99，95%置信区间0.82至1.21）。心血管疾病的研究结果类似。我们的框架展示了在三角互证不同研究设计的证据时，如何定量处理严谨性和相关性问题。我们强调了明确定义目标研究问题和各研究特定研究问题的重要性。我们的框架展示了在三角互证不同研究设计的证据时，如何定量处理严谨性和相关性问题。我们强调了明确定义目标研究问题和各研究特定研究问题的重要性。</p>

<h3>精神分裂症中具有不同时空轨迹和生物学特征的三类小脑影像亚型</h3>
<span class="paper-item__meta">medRxiv / 2026-10-23 / Liu, Z.</span>
<p>小脑在精神分裂症病理生理学中的潜在作用相对而言未得到足够关注。既往研究主要在组水平上刻画小脑异常，未充分考虑疾病的异质性。本研究采用机器学习方法（亚型与分期推断，SuStaIn）对横断面小脑三维容积MRI进行分析，纳入来自全球34个中心的3,550例精神分裂症患者（1,423例女性；平均年龄：32.3 +/- 12.0岁）和5,771名健康对照（HC）（2,861例女性；平均年龄：32.5 +/- 12.9岁）。SuStaIn识别出小脑灰质体积减少的三种不同时空轨迹，分别起源于小叶X（亚型1）、小叶III（亚型2）和小叶VIIb（亚型3），其中亚型1和亚型3对应后叶，亚型2对应前叶。这些轨迹在1,588例精神分裂症患者中被横断面推断，并分别在另外1,334例和628例患者的独立样本中得到重复验证。利用神经影像、转录组和行为数据的多模态分析揭示了亚型特异性的生物学特征，涉及脑形态模式、小脑-皮层连接、基因表达和临床症状。具体而言，亚型相关基因在亚型1和亚型2中分别富集于代谢相关过程和免疫相关过程；亚型3表现出更严重的脑异常和更差的认知症状。来自381例患者、随访长达12个月的治疗数据显示，亚型2和亚型3对抗精神病药物治疗的反应较差，而亚型1对经颅磁刺激的反应较好，且其情绪相关症状更差。综上，本研究对小脑在精神分裂症中病理生理进展的异质性提供了全面刻画，可能有助于未来制定临床分层和靶向干预策略。</p>

<h3>Rett综合征的EEG生物标志物：机器学习与深度学习及可解释AI的比较分析</h3>
<span class="paper-item__meta">medRxiv / 2026-10-23 / Gupta, M.</span>
<p>Rett综合征（RTT）是一种罕见的神经发育障碍，其特征是皮层活动异常，可通过脑电图（EEG）捕捉。尽管机器学习（ML）在诊断多种神经系统疾病方面已显示出前景，但针对RTT的经典机器学习与深度学习（DL）方法的综合评估，以及具有生理学意义的解释，仍然有限。本研究使用基于功率谱密度（PSD）的机器学习和端到端深度学习框架，分析了RTT患者和健康对照者的静息态闭眼脑电图记录。经典机器学习模型，包括支持向量机、随机森林和XGBoost，在PSD特征上进行训练，而脑电图专用的深度学习架构，包括ShallowConvNet、DeepConvNet、EEGNet和EEG Conformer，则直接在预处理后的脑电信号上进行训练。采用按受试者划分的交叉验证以避免数据泄漏，并以平衡准确率作为主要性能指标，因为它同等考虑敏感性和特异性。随机森林在经典机器学习模型中取得了最佳性能，而EEGNet取得了最高的深度学习性能。消融研究表明，4秒的脑电片段在模型性能与稳健性之间提供了最佳权衡。模型可解释性通过随机森林的SHAP和EEGNet的遮挡敏感性分析进行研究。两种方法一致地将delta和theta振荡以及中央-额叶脑区识别为RTT分类的关键贡献因素。这些发现表明，基于PSD的机器学习和端到端深度学习方法均能可靠地识别RTT，并揭示了共同的神经生理生物标志物，为基于脑电图的Rett综合征诊断和生物标志物发现提供了一个可解释的框架。</p>

<p>目的 估计日本员工居家办公（WFH）频率与心理困扰之间的关联，区分个体间差异与个体内差异，并按性别和家庭状况检验该关联。方法 我们使用了全国性日本COVID-19与社会互联网调查（JACSIS）的五个年度波次（2021-2025年），纳入39,773名年龄≥18岁且在过去一个月内工作过的员工（78,498人-波次）。暴露变量为过去一个月内居家办公的频率（七个类别）。结局变量为Kessler 6（K6）评分（0-24）、K6≥5和K6≥13。我们采用个体内-个体间线性回归，分别进行总体分析以及按第一波次的性别和家庭状况分层分析。结果 与不居家办公相比，每月居家办公2-3次、每周一次和每周2-3次与K6评分在个体间分别高出1.99、1.80和0.67分相关，在个体内分别高出0.53（95% CI 0.28, 0.77）、0.45（0.20, 0.69）和0.35（0.10, 0.60）分相关，并与个体内K6≥5的概率高出3.5-4.6个百分点相关。这些个体内K6差异在所有性别和家庭组中均为正值（0.20-0.63分），但估计不精确。对于其他频率，个体内差异为0.03-0.20分。结论 每月居家办公2-3次或每周一次，以及每周2-3次，与更高的心理困扰相关，无论在个体间还是个体内均如此。对有时居家办公的员工的支持应综合考虑居家办公频率及其工作和家庭状况。</p>

<h3>失眠与睡眠和抑郁及焦虑的遗传重叠：一项基因组结构方程模型研究</h3>
<span class="paper-item__meta">medRxiv / 2026-10-23 / Sakiroglu, M. A.</span>
<p>失眠、抑郁和焦虑共同发生并共享遗传易感性，但遗传相关无法表明该易感性是分布在整个睡眠领域，还是集中于失眠——失眠是抑郁和广泛性焦虑障碍的一项诊断标准。我们对十项全基因组关联研究应用了基因组结构方程模型，拟合了一个包含睡眠、内化（抑郁和焦虑）、精神病-双相和代谢易感性的四因子模型。仅通过因子相关连接睡眠和内化领域的模型不可接受，我们在同一决策规则下比较了每种可修复该模型的一参数连接：领域-wide连接、失眠特异性交叉载荷，以及代表共享诊断内容的残差协方差，其中三种可接受。失眠交叉载荷的拟合优于唯一可接受的领域-wide替代方案（{Delta}AIC = 13.8；在500次蒙特卡洛抽样中98.6%更优），也优于共享内容（{Delta}AIC = 96.9），而将其置于精神病-双相或代谢易感性上则不可接受。在该模型下，失眠通路承载了56.3%的睡眠-内化协方差（95% CI 45.6-67.0%）。第二条睡眠通路改善了拟合（{Delta}AIC = -33.3），但在三个睡眠指标下其位置无法识别，且在等效模型间失眠占比范围为0%至127.0%。在变异水平上，校正后没有内化先导变异偏离抑郁-焦虑比例性，内化先导变异在FinnGen中重复，存在部分样本重叠，而睡眠先导变异则未重复（60.4%；P = 0.17）。重叠的集中程度需要更精细的睡眠表型来确定。在单连接模型中，失眠是重叠位置的最佳支持。</p>

<h3>GLP-1受体激动剂（GLP-1RAs）治疗烟草和酒精依赖：随机对照试验的系统综述与荟萃分析</h3>
<span class="paper-item__meta">medRxiv / 2026-10-23 / Taylor, G.</span>
<p>背景 胰高血糖素样肽-1受体激动剂（GLP-1RAs）可能减少烟草和酒精使用。我们综合了随机对照试验（RCT）中关于吸烟和酒精结局的证据，包括为其他临床目的开展的试验中报告的次要结局。方法 我们检索了MEDLINE、Embase、PsycINFO、Web of Science、CENTRAL、PubMed以及注册库，纳入从建库至2026年8月18日比较GLP-1RAs与安慰剂的RCT。吸烟和酒精结局采用随机效应荟萃分析进行综合。我们使用RoB-2评估偏倚风险（RoB），并使用推荐意见分级评估、制定与评价（GRADE）方法评估证据确定性。结果 共纳入14项试验，涉及1149名参与者；其中13项纳入荟萃分析。在14项试验中，8项招募的参与者未寻求烟草或酒精治疗。其余6项招募了寻求治疗的参与者：3项针对烟草，3项针对酒精。8项试验报告了吸烟相关结局，11项报告了酒精结局，5项同时报告两者。随访时间为6至60周。所有4项吸烟相关合并估计均倾向于GLP-1RAs，尽管所有95%CI均包含无差异，且与结局的升高和降低均相容；例如，戒烟，OR 1.39（95%CI，0.77至2.53，k=3）。将分析限制于司美格鲁肽试验显示每日吸烟支数（CPD）减少（SMD=-0.10，95%CI：-0.16至-0.04；k=3）。跨药物汇总，合并估计倾向于GLP-1RAs对无酒精天数的改善（SMD=0.35，95%CI：0.12至0.59，k=3）。仅司美格鲁肽试验的合并估计也倾向于治疗对酒精消耗量（克/天；SMD=-0.56，95%CI：-0.82至-0.30；k=2）、渴求（SMD=-0.60，95%CI：-0.91至-0.29；k=2）、每个饮酒日的饮酒量（SMD=-0.59，95%CI：-0.86至-0.32；k=3）、每个日历日的饮酒量（SMD=-0.48，95%CI：-0.87至-0.09；k=2）和重度饮酒天数（SMD=-0.45，95%CI：-0.85至-0.06；k=3）以及无酒精天数（SMD=0.41，95%CI：0.09至0.73；k=2）的改善。在41项评估结果中，2项为低偏倚风险，31项存在一些担忧，8项为高偏倚风险；1项结局的证据确定性为中等，4项为低，8项为极低。解释 GLP-1RAs可能减少酒精消耗和CPD，其中司美格鲁肽的证据最为明确。这些发现应结合大多数证据为低至极低确定性这一背景来理解。需要更大规模的试验来确定具有临床意义的获益和持续戒断。</p>
