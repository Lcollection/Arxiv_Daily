<h3>自主量子测量与代理式人工智能</h3>
<span class="paper-item__meta">arXiv / 2026-10-28 / Eunbi Rha</span>
<p>量子材料展现出多样的电子与功能现象，但其表征需要大量实验专业知识、迭代决策以及难以记录和转移的实验室积累知识。在此，我们提出Quantum Agent（QUANTA），一种用于自主量子材料表征的智能体人工智能（AI）框架。以广泛采用的物理性质测量系统（PPMS）作为实验平台，QUANTA将基于科学文献、实验方案和先前测量数据的检索增强与用于实验规划、故障排除和数据解读的专用智能体相结合。一个独立的确定性控制层对仪器操作进行验证。在传入数据的引导下，QUANTA评估测量质量、修订实验计划并选择后续测量。我们通过拓扑Weyl半金属TaP的输运测量以及对磁性材料Co2MnGa中非线性响应的研究展示了这些能力。这些结果确立了QUANTA作为证据驱动、安全防护和闭环量子材料表征的通用框架。</p>

<h3>使用生成流网络发现多样且逼真的金融尾部风险</h3>
<span class="paper-item__meta">arXiv / 2026-10-28 / Adir Serruya</span>
<p>准确建模罕见且高影响的金融事件对于稳健的风险管理至关重要。基于采样的技术，如序列马尔可夫链蒙特卡洛（SMCMC），能够生成多样化情景，但对高风险区域的探索效率低下；而深度强化学习（DRL）则收敛于狭窄的情景集合，限制了多样性。我们提出GRID，利用生成流网络（GFlowNets）——一种按奖励比例抽取对象的采样器——来系统性地生成多样化且逼真的金融尾部风险情景。GRID在连续GFlowNets的基础上，引入了一种灵活的混合策略架构，针对高维、序列化的宏观金融数据采用变量特定的分布族，并结合合理性约束以保持生成轨迹的逼真性。一个核心的实际优势是对奖励代理不完美的鲁棒性：由于GFlowNets是按比例采样而非最大化，即使预言机的样本外准确率较低——这是金融预测中不可避免的现实——它们仍能保持广泛的探索性。在三次真实世界危机中，GRID在情景多样性、逼真性和尾部风险覆盖方面优于RL和MCMC基线，而针对预言机架构和分布族的消融实验为噪声奖励下连续GFlowNet的行为提供了实用见解。</p>

<h3>随机化什么很重要：低数据分子生成中体积、轴和表示的对照研究</h3>
<span class="paper-item__meta">arXiv / 2026-10-28 / Neerav Kaushal</span>
<p>化学语言模型在小数据集上训练时可能难以生成新分子，此时模型可能只是复现训练样本，而非学习到有用的生成分布。随机化SMILES增强改变了原子遍历顺序，而基于序列连接的片段嵌入（SAFE）还允许片段块的顺序发生变化。这些不同的表示变异来源如何影响低数据分子生成尚未得到清晰研究。本文使用1,000个种子分子训练一个自回归序列模型，在递增的语料规模下比较规范SAFE与随机化SAFE，分离SAFE随机化的原子顺序轴与片段顺序轴，并在逐分子匹配的训练语料上比较完全随机化SAFE与随机化SMILES。研究得出三项发现。第一，仅对SAFE进行随机化即可将新分子的真实产率提高450倍以上，使一个仅复现训练集的模型转变为实用的分子生成器。第二，两个随机化轴共同作用而非简单相加：仅原子顺序达到两个轴同时变化时真实产率的十分之一，仅片段顺序达到七分之一，而两者同时变化的效果是二者单独贡献之和的四倍。第三，在匹配语料规模和计算量下，随机化SAFE的真实产率是随机化SMILES的2.8倍。Welch检验结合Games-Howell事后比较解决了主要结局上的所有差异。因此，在低数据情形下，随机化什么而不仅仅是随机化多少，决定了增强是产生新分子还是仅仅产生训练集的新拼写。</p>

<h3>通过模型课程发现越狱方法</h3>
<span class="paper-item__meta">arXiv / 2026-10-28 / Michał Burzyński</span>
<p>自动化越狱发现旨在寻找能够诱导经过安全训练的语言模型产生被禁止行为的提示，帮助开发者在部署前识别漏洞。一类方法使用强化学习训练一个调查者模型，使其生成能够从目标模型诱导出指定行为的提示。然而，直接针对经过安全训练的目标进行训练是困难的，因为几乎所有提示都会被拒绝，导致调查者只能获得稀疏的奖励信号。先前的工作通过倾向性边界（PRBO）来解决这一问题，该方法通过从一个更顺从的目标中采样回复来估计代理奖励，然后根据这些回复在原始目标下出现的可能性进行调整。我们引入了模型课程（CoM），这是一种替代方法，它针对目标的一系列修改版本训练调查者，从容易表现出指定行为的版本逐步过渡到原始目标。对于越狱发现，训练从很少拒绝有害请求的目标版本开始，一旦调查者能够可靠地从当前版本诱导出该行为，就推进到下一个更难的版本。我们在涉及CBRN材料、爆炸物和非法药物的诱导任务上评估了CoM，使用了两个开放权重目标：gemma-4-31b-it和gpt-oss-120b。我们与PRBO以及在没有课程的情况下直接对原始目标进行训练进行了比较。当调查者被训练来诱导单一行为时，CoM比任一基线都更可靠地找到成功的越狱。当同时训练多种行为时，CoM训练的调查者能够诱导出留出的行为，尽管PRBO训练的调查者取得了更高的成功率。我们的结果表明，对目标模型采用简单的课程为解决稀有行为诱导中的稀疏奖励问题提供了一种有前景的方法。</p>

<h3>超越区域记忆：用于视频喉镜中声带定位的局部点跟踪</h3>
<span class="paper-item__meta">arXiv / 2026-10-28 / Huayu Wang</span>
<p>在急诊视频喉镜检查中，可靠地定位声带在视觉上仍然具有挑战性，原因包括组织快速变形、镜面高光和器械遮挡。我们提出了局部点跟踪（Local Point Tracking，LPT），这是一个稳健的框架，结合了单帧检测器、局部点传播和无状态掩码细化。LPT遵循“先定位、后吸附”的流程。首先，单帧语义检测器生成稀疏锚点，LPT在其中初始化局部查询点（默认由SAM支持，并以规则网格作为回退方案）。点传播模块在检测器漏检的帧中跟踪这些点，并根据其几何形状恢复时序边界框。其次，由于由点推导出的边界框在可见边界周围可能较为松散，框吸附步骤将选定的框细化到目标边界。这种分解将时序状态保存在局部点坐标中，而不是有状态的掩码或全区域表示中，同时空间细化模块处理单帧边界精度，而不会将掩码误差反馈到时序记忆中。在两个不同数据集上的大量评估表明，我们提出的LPT方法在现有基线方法中取得了较强的整体性能，在两个数据集上均获得了最佳的mAP_50、成功AUC和漏检率。此外，消融研究证实，点跟踪主要增强了时序跟踪的稳健性，而框吸附细化有效提高了边界紧致度。</p>

<h3>利用眼动追踪评估AI生成视频的视觉真实感</h3>
<span class="paper-item__meta">arXiv / 2026-10-28 / Danqing Shi</span>
<p>迄今为止，对AI生成视频的人工评估一直依赖于显式的人类反馈，例如判断或评分。尽管这些信号捕捉到了观看者得出的结论，却无法提供对导致这些结论的感知过程的洞见。本文研究眼动追踪作为一种补充性的人工评估信号用于AI生成视频。我们针对最新生成模型生成的视频开展了两次视觉图灵测试（VTT）实验，共有90名参与者，参与者在实验中观看每个视频两次后给出反馈。在两次实验中，我们在438个视频上收集了4,286次有效的眼动追踪试验。我们的分析表明，注视模式提供了与显式人类反馈相一致的信息性评估信号。基于这些发现，我们提出了首个计算方法GazeEval，用于从眼动追踪数据预测AI生成视频的感知视觉真实感。该方法在预测中达到71.3%的准确率，提供了证据表明眼动追踪数据携带了关于人们如何评估视频的信息性信号。我们发布了研究数据，以支持关于眼动追踪用于评估AI生成视频的进一步研究。</p>

<h3>CopyLoop：通过上下文复制和浅层筛选实现快速循环Transformer解码</h3>
<span class="paper-item__meta">arXiv / 2026-10-28 / Wenyu Du</span>
<p>循环Transformer通过重复应用共享块来提升计算容量，但其循环深度使得传统的全深度解码变得昂贵。现有投机流水线通过在不同深度处理连续token位置来加速生成，但通常受限于顺序解码开销。我们提出CopyLoop，一种免训练的解码算法，将低成本上下文复制提案与浅层筛选和连续循环调度相结合。CopyLoop并非逐步生成，而是从重复上下文中提出多token后缀。随后在浅层循环深度上提前评估这些后缀，以高效过滤错误分支，在较早块仍在向全深度验证推进时并发处理较新的块。我们在来自Ouro、Raven和Huginn系列的六个模型检查点上评估CopyLoop，涵盖代码生成和多步数学推理。CopyLoop在Base模型上相比全深度自回归解码实现2.98倍至10.70倍的解码加速，在Thinking模型上实现2.74倍至3.52倍的加速，在所有评估任务上持续优于或接近所有竞争基线。此外，消融研究证实了浅层筛选与连续调度之间的强协同效应，而我们的分析表明CopyLoop仅需轻量级模型校准，并在具有可复用上下文的更长生成中产生更大加速。</p>

<h3>UnEZ：一种用于红移和谱线强度估计的全无监督自模板神经网络</h3>
<span class="paper-item__meta">arXiv / 2026-10-28 / Asha Abd</span>
<p>随着光谱巡天规模的扩大，估算金属丰度、恒星形成率和红移等星系属性在计算上变得愈发繁琐。估算此类属性的方法依赖于模板光谱或精选的红移星表，而这些无法代表大规模巡天中所见天体的多样性。我们提出UnEZ，一种完全无监督、融入物理信息的机器学习模型，能够在没有任何先验红移或谱线强度标签的情况下预测光谱红移和谱线强度。编码器预测发射线和吸收线的振幅/宽度，固定的确定性解码器构建唯一的模板、估计红移、红移置信曲线和光谱模型。由于斯隆数字巡天（SDSS）第18次数据发布具有庞大的数据集和经过充分验证的红移星表可作为独立基准，UnEZ在该数据上进行了测试。尽管缺乏模板、谱线强度标签或红移标签，UnEZ的性能仍可与现代红移估计算法相竞争。在SNR &gt; 10时，UnEZ的离群率为0.459%，归一化中位绝对偏差（NMAD）为$1.237 \times 10^{-4}$。在SNR &gt; 3时，UnEZ的离群率为3.89%，NMAD为$1.471 \times 10^{-4}$。此外，我们展示了如何将UnEZ的谱线强度和红移预测用于各种目的，例如构建传统红移估计算法所需的模板光谱。UnEZ说明了完全无监督的神经网络如何能够让红移及其他星系属性从光谱本身自然涌现，提供了一种可扩展到未来巡天需求的无模板、无标签方法。</p>

<h3>精准定位关键转折点：数据分析决策重要性的DECIDE框架</h3>
<span class="paper-item__meta">arXiv / 2026-10-28 / Zachary T. Rewolinski</span>
<p>在数据科学生命周期中，人为判断会影响从数据得出的结论。独立分析人员面对相同数据时常常做出不同选择，导致结果出现往往不可接受的变异，并加剧了各科学学科中持续存在的可重复性危机。智能体工具的快速采用有可能放大这一危机。为解决这种变异，已有若干方法被开发出来，它们遵循相同策略：在不同分析决策组合下重复分析，并检查结果的分布。示例包括多宇宙分析、规格曲线分析和效应振动。更广泛地说，可预测性-可计算性-稳定性框架评估数据科学生命周期中有记录的判断如何影响结论，其中可预测性作为一种现实检验，确认模型捕捉到了信号。这些方法都会产生一个“多宇宙”对象。虽然结果分布反映了结论的整体变异性，但估计每个单独决策的影响需要额外工具。一种常见启发式方法是训练一个模型从这些决策预测结果，并将其系数或特征重要性视为每个决策影响的代理。尽管该策略在某些情况下可能有效，但它假设模型被正确设定并能准确预测结果，而我们表明这并非总是如此。在这项工作中，我们引入DECIDE，一个无模型框架，它从合理决策空间中的实际结果量化每个决策的重要性，在设计上避免可预测性问题。我们通过将DECIDE应用于真实世界多宇宙分析来证明其有效性。我们进一步提供了据我们所知首个多宇宙的正式定义。</p>

<h3>奖励改变预测性空间地图的使用和结构</h3>
<span class="paper-item__meta">bioRxiv / 2026-10-29 / Oza, S.</span>
<p>奖励相关的变化在海马位置细胞活动中可能反映的是对既有空间地图的不同使用方式，或是重塑地图的可塑性。我们在一个双通路模型中分离了这些贡献：一个循环网络学习预测感觉输入并发展出空间表征，而一个强化学习控制器将该表征与明确的目标信号结合以指导行为。在学习前后重放相同的轨迹隔离出了表征可塑性。目标导向行为强烈地将位置野集中在奖励附近，而表征的变化较小且更为多变。奖励接近性教学信号使这些变化更大且更一致，而当循环可塑性受到限制时，这种变化被强烈减弱。在奖励重新定位后，目标相关的方向调谐比位置野组织适应得更充分，而撤除奖励和接近性教学则逆转了习得的位置野集中。因此，奖励通过可分离的机制影响预测性空间地图：目标信息改变既有地图的使用方式，而奖励相关的教学信号则重塑地图本身。我们的结果为未来实验提供了一个具体框架，以厘清奖励信息、可塑性和行为如何共同塑造海马活动。</p>

<h3>长期睡眠和失眠与不同人群中全球认知功能下降相关</h3>
<span class="paper-item__meta">medRxiv / 2026-10-29 / Wyss, A. B.</span>
<p>背景：尽管睡眠障碍通常与认知功能下降相关，但各研究对睡眠状况和认知功能的定义差异很大。因此，我们在多项研究中评估了睡眠的共识定义与认知结局之间的关联。方法：在三项队列研究（HCHS/SOL、MESA和ARIC，N=11,563）的基线访视中确定了共识睡眠测量指标：短睡眠和长睡眠（[&amp;le;]6小时和[&amp;ge;]9小时）、失眠（妇女健康倡议失眠评定量表[&amp;ge;]10或3个问题[&amp;ge;]6）、日间嗜睡（Epworth嗜睡量表[&amp;ge;]11）和阻塞性睡眠呼吸暂停（OSA，呼吸暂停-低通气指数[&amp;ge;]15）。在每项研究的基线访视和随访访视中确定认知测量指标，并用于计算统一结局：基线整体认知功能（GCF）、基线至随访期间GCF的变化、基线时GCF较差（低于中位数[&amp;ge;]1SD），以及随访时新发GCF较差。研究特异性分析根据需要对年龄、性别、中心、教育程度、种族/民族、APOE4和认知评估语言进行了调整。结果在各研究间进行荟萃分析。结果：长睡眠在各队列中一致地与较低的基线GCF相关（{beta}=-0.19，SE=0.03，p=3.78x10-14，FDR p=7.56x10-13，p-异质性=0.78），并与基线GCF较差的几率增加相关（OR=1.77，95% CI=1.49-2.09，p=2.96x10-11，FDR p=2.96x10-10，p-异质性=0.22）。失眠也提示性地与较低的基线GCF相关（{beta}=-0.051，SE=0.02，p=0.01，FDR p=0.07，p-异质性=0.005），并与基线GCF较差的几率增加相关（OR=1.22，95% CI=1.06-1.41，p=6.76x10-3，FDR p=0.05，p-异质性=0.03）。睡眠测量指标与认知功能变化无关。讨论：在三个大型多种族队列中，长睡眠和失眠与统一横断面GCF的关联表明，认知功能可能与不同的睡眠表型相关。</p>

<h3>自闭症个体中不同类别抗抑郁药相关自杀事件的风险比较：一项新使用者活性对照队列研究</h3>
<span class="paper-item__meta">medRxiv / 2026-10-29 / Jiang, C.</span>
<p>引言关于自闭症个体中不同抗抑郁药治疗与自杀相关结局的比较证据有限。我们研究了在自闭症谱系个体中启动抗抑郁药治疗后，抗抑郁药治疗类别与自杀相关事件（SREs）之间的关联。方法我们使用全国性Truveta电子健康记录数据库开展了一项回顾性新使用者、活性对照队列研究。在自闭症谱系诊断后启动抗抑郁药治疗的自闭症个体，按初始治疗分类为选择性5-羟色胺再摄取抑制剂（SSRI）、非典型抗抑郁药、5-羟色胺-去甲肾上腺素再摄取抑制剂（SNRI）或三环类抗抑郁药（TCA）。采用成对倾向评分重叠加权平衡基线特征，并使用加权Cox比例风险模型估计治疗期间随访中与SREs的关联。结果在42,441名启动抗抑郁药治疗的自闭症个体中，与SSRIs相比，非典型抗抑郁药（风险比[HR]，0.787；95%置信区间[CI]，0.632-0.979）和TCAs（HR，0.487；95%CI，0.263-0.902）与较低的观察到的SRE风险相关，而SNRIs未观察到明显差异（HR，0.948；95%CI，0.651-1.381）。在具体药物分析中，与SSRIs相比，曲唑酮与较低的观察到的SRE风险相关，而安非他酮或米氮平未观察到明显差异。探索性年龄分层分析提示，在18岁以下个体中，非典型抗抑郁药相对于SSRIs的风险较低，但效应修饰的证据在年龄的不同替代设定中并不一致。讨论在启动抗抑郁药治疗的自闭症个体中，观察到的SRE风险在某些抗抑郁药治疗比较中存在差异。非典型抗抑郁药的类别层面关联在其各具体药物中并未一致观察到，年龄相关差异值得进一步研究。通俗摘要自闭症患者常接受抗抑郁药治疗，但关于不同种类抗抑郁药在减少自杀相关事件发生方面是否具有不同效果，所知甚少。在这项大型真实世界研究中，我们比较了自闭症个体中几种常用抗抑郁药治疗，发现某些治疗组观察到的自杀相关事件发生率低于其他组，尽管这些发现应谨慎解读，因为治疗选择可能反映患者之间的差异，而这些差异无法在健康记录中被完全测量。这些发现可能有助于为未来关于自闭症患者抗抑郁药治疗安全性的研究提供信息。</p>
