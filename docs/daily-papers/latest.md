<h3>带可迁移学习价值模型的预算子集选择</h3>
<span class="paper-item__meta">arXiv / 2026-11-20 / Jade Lejeune Herman</span>
<p>子集选择是机器学习、统计学和组合优化中的一项基础任务，其应用涵盖主动学习、波段选择、输入选择和实验设计。一个子集的效用取决于仅在选择之后才揭示的信息（如标签或响应），以及所选候选之间的交互作用。现有方法以特定于应用的方式将价值估计与冗余控制相结合，这限制了它们在其他领域中的使用。本文提出了一种名为“基于学习价值估计与搜索的子集获取”（SALVES）的框架，该框架将子集选择分解为两个组成部分。首先，在隐藏信息已知的任务上通过监督学习训练一个价值模型。在新任务上，该模型预测每个候选将为当前选择增加的效用。其次，一个选择步骤根据这些预测来选取子集，通常采用模拟退火并辅以惩罚冗余的多样性项。该价值模型可迁移至新类别、预训练网络、数据集和传感器，并可从合成数据迁移至真实数据。在四个应用中，SALVES平均而言达到或超过了特定于应用的基线方法。在达到同等精度的情况下，它所需的波段数量大幅减少，并且在单个基线方法失效的输入选择场景中仍保持可靠性。</p>

<h3>RoSci：探索科学视觉语言模型的鲁棒性</h3>
<span class="paper-item__meta">arXiv / 2026-11-20 / Junying Wang</span>
<p>视觉语言模型（VLMs）的最新进展推动了科学任务的显著进步。然而，这些模型通常被假设为面对完整且准确的信息，忽视了野外场景中错误/缺失信息带来的挑战。为填补这一空白，我们引入了科学模型鲁棒性的概念，其定义模型在面对信息错误（不一致性）或信息丢失（不充分性）时检测异常、评估可解性并执行自校准的能力。具体而言，我们提出了RoSci-Bench，一个包含1，220个样本的诊断基准，采用种子-变体策略覆盖六种退化类型。为解决VLM的脆弱性，我们进一步提出了RoSci-Agent，一个采用解析-验证-决策流水线在推理前审查前提的框架。被评估的VLMs有时会回答前提无效或不完整的问题。RoSci-Agent取得了比被评估的独立VLMs更高的整体鲁棒性得分。RoSci-Bench为多模态推理社区提供了一个共同的测试，用于判断模型何时回答、请求澄清或拒绝一个科学问题。</p>

<p>人们越来越多地将AI代理作为扩展的异步工作流的一部分来协同工作。在这些情境中，对信息的共享访问并不保证共享的行动基础：目标、计划和角色可能持续存在，但其当前意义会发生变化。我们引入协调连续性这一概念，即协作者在工作推进过程中维持可用的相互依赖行动基础的程度。基于对协作工作的研究，以及两项定性团队研究和来自我们自己基于仓库环境的反思性案例，我们提出了一个包含三个要素的框架：协作工作的持久表征；支持在当下解释表征的相对协调属性；以及能够理解和改变表征状态的交互机制。我们使用“构建—行动—漂移—重建”的启发式方法和“后果性时刻”的概念来描述何时可能需要重建。我们提出了对协作式AI基础设施的八项设计启示。</p>

<h3>视觉语言模型能合成可执行的游戏程序吗？</h3>
<span class="paper-item__meta">arXiv / 2026-11-20 / Yao Tong</span>
<p>近期视觉语言模型（VLM）的进展使多模态智能体具备了日益强大的视觉感知与长程推理能力，使得基于VLM的自主游戏游玩成为可行。现有的游戏基准主要评估智能体能否在不同场景和游戏中根据当前视觉状态选择合适动作。然而，大多数基准采用逐步交互范式，即在每次动作前将当前视觉观察发送给智能体。在实际部署中，该范式带来两个根本性局限：游戏循环必须等待模型推理，使实时交互不切实际；重复调用VLM产生高昂成本。因此，我们提出PlayScriptBench，一个基于脚本的游戏基准，评估VLM能否从游戏状态合成可执行的游戏游玩程序。该设定联合评估视觉 grounding、对游戏动态的理解、长程战略推理以及可执行程序合成，为游戏游玩智能体提供更全面的评估。为支持对当前通用VLM进行更可处理的评估，我们进一步引入四阶段流水线——探索、感知、API构建与策略组合——将控制器合成分解为游戏探索、状态感知、接口构建与战略控制，使智能体能够逐步构建可执行程序。在涵盖4个类别的16款游戏上的实验表明，即使强大的VLM在我们的基准上也表现不佳，揭示了被动视觉游戏理解与可执行闭环游戏控制之间的显著差距。这些结果确立了基于脚本的控制器合成作为评估基于VLM的游戏游玩智能体的一个互补方向。</p>

<h3>通过请求本地令牌路由实现的平均深度可变执行</h3>
<span class="paper-item__meta">arXiv / 2026-11-20 / Pengjie Zheng</span>
<p>层跳过可以降低大语言模型的推理成本，但请求预算并未规定如何在生成的 token 之间分配层执行。我们引入 \method{}，它允许 token 执行不同数量的层，同时使每个请求的平均执行深度匹配一个连续预算。在每个路由层，路由器读取当前 token 状态及其请求的预算，并决定是否执行 Transformer 块。跳过该块的 token 通过一个轻量级残差适配器，并且在该层不写入任何键/值（K/V）条目。单个检查点可在同一批次中服务具有不同预算的请求。在三种 LLaMA 主干、六项质量指标和 13 种预算下，AVERT 在 234 次比较中有 206 次为最佳或并列最佳。在单预算和混合预算批次中，每个请求的平均绝对预算误差至多为 1.15 个百分点。当按预算对请求分组导致批次填充不足时，混合预算可将每输出 token 的解码时间（TPOT）降低 4.3--21.2%。</p>

<h3>AutoOntologyBench：面向智能体知识工程的基于任务的基准测试</h3>
<span class="paper-item__meta">arXiv / 2026-11-20 / Minye Shao</span>
<p>基础模型智能体正日益从软件工程扩展到自主科学研究，而在这一领域中，获取和整合领域知识仍然是一项关键挑战。近期的产业进展越来越多地采用知识图谱和基于本体的语义层，将异构知识组织为可复用的表示形式。我们提出疑问：自主智能体能否构建本体以帮助其解决真实任务，并且这些本体相较于其他知识表示形式是否能带来可衡量的收益？现有基准孤立地评估本体的正确性或智能体的任务成功率，使得自主获取知识的价值悬而未决。因此，我们推出 AutoOntologyBench，这是一个以任务为基础的基准，包含 19,947 个经审核的任务，这些任务基于 7 个领域中 18 个真实世界知识源，并采用源生验证。AutoOntologyBench 涵盖应用、修复、组织与构建，在匹配的知识表示下比较了九个前沿模型智能体。在检索之上叠加智能体构建的本体可带来 6.1 个百分点的任务成功率提升，但仍落后于专家推导的参考标准 13.0 个百分点，从而将自主知识获取确定为可扩展科学研究的瓶颈。代码与资源见 https://github.com/VinyehShaw/AutoOntologyBench。</p>

<h3>爱丽丝和鲍勃会梦见神谕吗？一厢情愿的密码分析</h3>
<span class="paper-item__meta">arXiv / 2026-11-20 / Guoxiao Liu</span>
<p>两千年来，攻与防锻造了密码学的安全边界。工具自动化了计算与搜索，而人类驱动着发现。基础模型如今标志着从自动化计算向智能科学发现的转变。由于密码分析建立在精确的数学定义和可立即执行的真理之上，它为自主智能提供了一个试验场，使其能够超越依赖稀缺人类注意力的安全模式，并探索超出人类工作记忆的结构。无引导的模型会在两个相反的陷阱之间停滞：权威幻觉，即当先前文献宣称某条路径被阻断时便放弃；以及推理幻觉，即产生微妙且无法验证的缺陷。封闭平台和通用智能体循环进一步阻碍了持续的开放探究。我们提出“愿望式密码分析”，一种与框架无关的方法论，它将针对根深蒂固假设的建设性乐观与针对错误的盲化、零导入验证相结合。智能体首先在配置的算力内压缩缩减规模的理论，使实时见证自动证明其数学正确性。随后它们协同适配原语、算法和硬件，并沿参数阶梯攀升至高层数理论。在仅需目标和算力、极少人类干预的情况下，该范式应用于前沿开放权重和专有模型，在Keccak（SHA-3）和AES上产生了新颖的攻击技术和十三项可验证的实际结果。这些包括破解一个开放十五年的公开挑战并弥合长期存在的实际差距，同时发布了一个早期预览的开源工作台（agent-framework）。将Kerckhoffs原则延伸至AI时代，我们设想一个Open Oracle，一种开放且可审计的公共基础设施，使密码学家得以解放出来，去制定安全目标、挑战假设、提炼理论并协同设计具有韧性的标准。</p>

<h3>基于车载相机与透视校正的路面病害定量测量</h3>
<span class="paper-item__meta">arXiv / 2026-11-20 / Sike Wang</span>
<p>利用图像数据正成为公路管理机构自动评估路面状况的重要方法。然而，大多数研究侧重于提高检测精度，而非获得定量测量结果，例如路面病害的长度或面积。尽管现场相机标定可以提供此类测量，但对于从不同车辆采集的大量车载图像而言并不现实。本研究开发了一种无需现场相机标定、可直接从车载相机图像中定量测量路面病害的方法。首先基于车道检测识别出一个四边形感兴趣区域，并用于构建透视变换矩阵以进行图像校正。随后利用图像中道路标线的比例和指定尺度进行尺寸校正，这也使得能够估计所选区域的实际宽度。校正后的图像随后通过目标检测算法处理，以获得定量的病害测量结果。所提出的方法能够以最少的人工投入，对同一车辆相机采集的图像高效地进行透视校正。测得的路面修补长度与路面摩擦数据呈现一致的趋势。本研究仅利用图像信息对车辆相机进行标定，从而无需额外的现场实验即可实现定量路面病害检测。该方法为处理大量车载相机数据提供了实用解决方案，尤其是随着网联汽车产生越来越多未经标定的道路图像。</p>

<h3>一种用于在助听器中选择环境自适应个性化增益的切换机制</h3>
<span class="paper-item__meta">arXiv / 2026-11-20 / Nafisa Zarrin Tasnim</span>
<p>个性化放大增益已被证明比处方增益更受助听器用户青睐。由于偏好设置可能随背景音频环境而变化，本文提出一种切换机制或系统，能够针对当前背景音频环境自动选择个性化增益。为防止前景语音干扰背景环境分析，设计了一种单类语音活动检测器，用于从混有噪声的语音中识别语音活动。通过一致性检查来区分前景语音与背景语音，同时将嘈杂背景语音保留为感兴趣的背景环境，因为助听器用户在嘈杂背景中理解语音往往存在困难。随后，采用一种结合贝叶斯变化点检测与先前 encountered 环境记忆的在线发现方法，对不含前景语音的声音片段进行分析。该发现方法能够检测变化、识别回归环境并发现新环境，且无需预先设定环境数量。实验结果表明，在覆盖36种背景噪声类型的八组语音/背景语料对上，三种子平均宏平均F1分数达到了85.53%至91.98%。此外，该发现方法在两族测试流上分别取得了0.91和0.96的调整兰德指数。在将语音与助听器用户常遇到的四种背景音频环境组合而成的音频流的同录音回归条件下，该切换机制在105次环境变化后选择了正确的个性化增益配置文件，在每次回归时均召回了存储的增益配置文件，且未发生任何错误增益配置文件的切换。</p>

<h3>面向交互式过程分析与优化的认知型智能体AI框架</h3>
<span class="paper-item__meta">arXiv / 2026-11-20 / Trung Ngoc Trinha</span>
<p>复杂多变量过程分析与优化需要协同访问仿真、结构化数据、机器学习（ML）、优化和科学文献，而这些资源往往分散在彼此割裂的软件工具中。我们提出了一种认知代理式人工智能框架（CAAF），能够在既有流程表中通过自然语言提示实现交互式、迭代式的过程研究。遵循 harness 工程原则，CAAF 将任务解释、规划、知识综合和上下文管理分配给大语言模型，同时将数值计算委托给专用工具。专用提供程序连接数据库、科学文档检索、机器学习辅助的贝叶斯优化（BO）以及 COCO 过程仿真。该框架在乙酸甲酯生产上进行了演示。在连续提示的引导下，一名工程师探索了多变量关系，执行了 4,000 次 BO 迭代以最大化碳转化率（C-Yield）并最小化比能耗成本（C-SEC），细化了操作边界，并通过过程仿真验证了选定的候选方案。在受限域内对 16 个候选方案进行重新仿真，结果与 ML 预测高度一致，C-Yield 的平均绝对误差为 0.0085（0.85 个百分点）。经 COCO 验证的 BO 所得最高 C-Yield 为 0.921，而初始数据集约为 0.81，提升了约 11 个百分点。CAAF 还能检测并报告未收敛的仿真，排除无效输出，并继续后续评估。结果表明，人类引导的代理式协调如何能够在固定过程拓扑下，将工程工具结合起来进行迭代分析与优化，并进行严格的基于仿真的验证。</p>
