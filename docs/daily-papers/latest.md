<h3>单分子荧光显微镜中的定位精度</h3>
<span class="paper-item__meta">bioRxiv / 2026-10-16 / Chapman, K. B.</span>
<p>在显微镜焦平面内确定单个荧光团位置的两种常用方法，要么依赖于荧光团在相机上产生的荧光图案的质心，要么如MINFLUX中所实现的那样，通过空间受控的照明最小值来瞄准荧光团的坐标。在这两种方法中，都已达到（亚）纳米级的定位精度，但对其准确度，即所得坐标与其真值之间的偏差，却知之甚少。在此，我们报告了对这两种策略所提供准确度的理论与实验比较。我们量化了基于相机的定位中存在的显著系统误差，这些误差源于两个难以控制的参数之间的相互作用：荧光团在空间中的取向及其相对于焦平面的轴向偏离（离焦）。例如，在焦点周围{+/-}120 nm的轴向范围内，通过基于相机的定位测得的纳米抗体上两个荧光团之间的中位距离变化达26.5 nm。在相同条件下，一台商用MINFLUX系统给出的距离中位变化为1.4 nm，表明准确度提高了一个数量级。通过减小照明最小值所瞄准的坐标与荧光团之间的平均距离，MINFLUX定位的准确度可以进一步提高到（亚）埃水平。由于它为绘制荧光团及其距离提供了无与伦比的精度和准确度，我们认为坐标靶向定位对于在亚10 nm水平上研究标记细胞以及探索标记生物分子的结构和构象变化至关重要。</p>

<h3>靶向TMPRSS2-ERG融合驱动的前列腺癌：新型HBS-α-螺旋模拟物的应用</h3>
<span class="paper-item__meta">bioRxiv / 2026-10-16 / Kundu, S.</span>
<p>雄激素受体（AR）反应性基因TMPRSS2与ERG之间的基因融合发生在大约50%的前列腺癌（PCa）中，从而通过异常的ERG表达促进肿瘤发生。靶向转录因子-DNA界面的治疗仍然是一项艰巨的挑战，这主要归因于靶标结合过程中肽折叠相关的熵惩罚。在此，我们描述了针对ERG-DNA识别界面的氢键替代物（HBS）约束的α-螺旋模拟物的结构导向设计和临床前评估。ERG-DNA复合物的结构分析揭示，DNA结合诱导识别螺旋H4从约2.5个螺旋圈伸长至4.0个螺旋圈。为了稳定生物活性构象，我们引入了一个N端HBS大环，引入D363E和S366E突变以增强DNA结合和结构稳定性，并添加了双重NLS-TAT标签以促进细胞递送。生化和细胞实验表明，先导化合物ERG螺旋模拟物竞争性抑制ERG与ETS基序的结合，破坏ERG与AR及其他辅因子的关联，从而导致ERG转录活性受到抑制。染色质免疫沉淀-qPCR证实，经典靶基因调控区域处ERG的占据减少，伴随ERG驱动的转录程序下调。ERG螺旋模拟物还降低了ERG阳性PCa细胞的增殖、迁移和侵袭。在TMPRSS2-ERG阳性PCa的小鼠异种移植模型中，全身性ERG螺旋模拟物治疗抑制了肿瘤生长，未出现明显毒性，与指定对照肽相比，Ki-67表达降低。总体而言，我们的研究结果支持HBS约束的ERG螺旋模拟物作为靶向ERG驱动型PCa的合理策略，值得进一步的治疗优化。</p>

<h3>第二相冷冻驯化机制的阐明：植物在冰冻条件下通过光合作用积累糖分</h3>
<span class="paper-item__meta">bioRxiv / 2026-10-16 / Sugita, K.</span>
<p>越冬植物分两个阶段增强其抗冻能力：第一阶段称为冷驯化，在低温条件下发生，随后是在零下温度中进行的第二阶段驯化。我们此前的研究表明，第二阶段冷冻驯化是将冷驯化的拟南芥在光照下暴露于-2°C并伴随胞外冰形成，通过一条需要光合电子传递的途径赋予最高的抗冻能力（LT50低于-20°C），且可能独立于CBF-COR途径。然而，光照如何增强冷冻植物的抗冻能力仍不清楚。在此，我们开发了一个系统，用于测量处于冷冻状态的完整植株的叶绿素荧光，并发现冷冻叶片中PSII保留了显著的光化学能力（Fv/Fm）。比较转录组学显示，光照下的第二阶段冷冻驯化诱导了参与淀粉、蔗糖和半乳糖代谢的基因。与此一致，可溶性糖（主要是蔗糖、葡萄糖和果糖）积累到约为冷驯化植株中水平8倍的浓度，且总糖含量与抗冻能力高度相关。这种积累被光合电子传递抑制剂DCMU所抑制。这些结果表明，冷冻植物中光合活性得以维持，并供应糖类，这些糖类可能有助于在第二阶段驯化期间获得抗冻能力，其水平超过第一阶段冷驯化所达到的程度，揭示了一种此前未被认识到的植物冬季生存策略机制。</p>

<h3>C3气体交换分析将C3-C4中间型叶片中的维管束鞘再固定解读为负的日间呼吸</h3>
<span class="paper-item__meta">bioRxiv / 2026-10-16 / Yazar, E.</span>
<p>C3-C4中间型（C2）植物在维管束鞘细胞中脱羧光呼吸甘氨酸，Rubisco在此重新固定部分释放的CO2，然而研究者却用为C3叶片建立的方法分析其气体交换。我校准了von Caemmerer的C3-C4模型，使其拟合已发表的C3和C2 Flaveria及其近缘种在36°C下的补偿点和Laisk测量值，并以实验者的方式分析所得叶片数据。在其真实Rubisco动力学和叶肉导度下，Farquhar-von Caemmerer-Berry模型拟合紧密描述了其CO2响应，但给出的白天呼吸（Rd）为-5.4 mol m-2 s-1，而真实值为1.2，并将最大羧化速率和电子传递速率分别低估了12%和11%。Rd亏缺等于叶肉CO2等于光呼吸补偿点（{Gamma}*）时的净维管束鞘CO2固定量，在每片叶片中误差均在5.3%以内。Laisk方法在叶肉校正后给出{Gamma}* = 42 bar，而真实值为65 bar，氧斜率法将Rubisco特异性高估了26-53%。已发表的两个C3-C4 Moricandia物种的曲线给出的Rd为-2.5 mol m-2 s-1，而其C3同属种为1.1。以相同方式拟合得到的Rd远低于C3近缘种，标志着维管束鞘重新固定，而非拟合失败。</p>

<h3>通过叶片生理和代谢的空间梯度解码植物与环境的相互作用</h3>
<span class="paper-item__meta">bioRxiv / 2026-10-16 / Perez Valverde, R.</span>
<p>肉质叶片以兼具光合作用、碳储存和水分缓冲功能而著称。然而，同一叶片轴线上不同部位的代谢对高温和干旱的响应可能存在差异。我们研究了CAM植物柱叶虎尾兰在三个实验阶段中的叶片组织含水量、光合性能和中心碳代谢的时空变化：（i）高温，（ii）高温与干旱复合胁迫，（iii）持续高温下复水。在正午对叶尖、中部和基部叶段取样，并在叶尖附近监测叶绿素荧光。干旱条件下基部组织的鲜重与干重比值显著下降，而叶尖组织仅在复水期间才出现显著下降，表明沿叶片轴线组织水分供应存在相当大的延迟。在高温与干旱复合胁迫期间，叶尖光系统II量子产率下降，蔗糖在高温暴露期间短暂积累，尤其是在中部和基部叶段。葡萄糖和果糖在干旱条件下达到峰值，复水后下降。柠檬酸在实验时间进程中下降，而叶尖苹果酸在复水阶段显著增加。叶绿素主要随叶片位置变化，而淀粉和延胡索酸未显示显著效应。神经网络分类表明，柠檬酸和蔗糖是区分处理阶段的主要贡献因子，而叶绿素在区分叶片位置方面最具信息量。总之，这些发现表明，叶片内部的生理和代谢梯度捕捉了植物与环境相互作用的互补维度，将空间结构化的叶片特征与动态胁迫响应区分开来。因此，整合空间分辨的代谢和生理图谱为识别CAM植物环境胁迫与恢复的生化特征提供了一种有前景的方法。</p>

<h3>生长细胞模型中蛋白质分配的 growth 成本</h3>
<span class="paper-item__meta">bioRxiv / 2026-10-16 / Szeliova, D.</span>
<p>微生物生长取决于细胞如何在相互竞争的功能之间分配其有限的蛋白质组。尽管许多蛋白质的表达水平接近最大化生长的水平，但偏离这些最优水平的情况很常见，并可能带来显著的适应度代价。对次优蛋白质分配的生长代价进行建模仍然具有挑战性，因为蛋白质表达通过多种相互作用的机制影响生长，包括生物合成需求、酶动力学以及细胞密度限制。在此，我们利用生长平衡分析（GBA）来分析这些效应，GBA 是一个非线性框架，可从基本细胞约束出发预测粗粒化微生物模型的稳态生长和生物量组成。对这些模型预测的最优生物量组成不仅包括蛋白质浓度，还包括通过非线性速率定律使酶达到饱和所需的反应物浓度，从而捕捉到比传统线性资源分配模型更复杂的资源权衡。利用这些 GBA 模型，我们计算了将单个蛋白质固定在次优水平时的最优生物量组成。由此得到的次优蛋白质分配与生长速率之间的关系与细菌中的定性实验模式一致，其生长效应取决于蛋白质功能（包括闲置蛋白质）、环境条件、毒性副产物以及替代反应。这些结果表明了一种实用且可处理的方法，用于对由次优蛋白质分配引起的生长代价进行建模，并为代谢工程和合成生物学中的预测建模提供了基础。</p>

<h3>一种Caspase介导的凋亡信号机制模型揭示了前列腺癌细胞中耐药性的调节因子</h3>
<span class="paper-item__meta">bioRxiv / 2026-10-16 / Mangrum, D. S.</span>
<p>抗癌药物耐药性仍然是有效治疗的主要障碍，因为内在和获得性耐药机制均可抑制凋亡性细胞死亡。去势抵抗性前列腺癌发病率的不断上升，凸显了对不依赖激素信号传导仍能保持有效的治疗策略的需求。在此，我们建立了一个简洁的、基于数据校准的常微分方程模型，用于描述前列腺癌中caspase介导的凋亡信号传导。该模型并非表征凋亡网络的完整复杂性，而是纳入了一组精简的关键凋亡调控因子，足以捕捉实验观察到的凋亡反应。模型参数利用三种促凋亡药物（Tocopheryloxybutyrate、Narciclasine和Celecoxib）的已发表数据进行了估计，并采用全局敏感性分析来识别治疗反应和耐药性的决定因素。该模型准确再现了实验观察结果，并揭示特定信号组分的变异性可导致对促凋亡药物治疗的反应产生显著差异。模拟确定了凋亡承诺的关键调控因子，预测了通过联合治疗可能克服耐药性的条件，并提示了癌细胞间异质性反应背后的候选机制。总之，这些发现表明，一个精简的机制框架能够生成关于凋亡药物反应的具有生物学意义的洞见，同时识别出关于治疗脆弱性的可检验假设。这项工作为研究耐药机制和指导未来实验研究建立了一个定量平台。</p>

<h3>儿童期创伤与伴精神病性症状及不伴精神病性症状的双相障碍中的皮层厚度：诊断分组与创伤亚型的影响</h3>
<span class="paper-item__meta">bioRxiv / 2026-10-16 / Chapagai, D.</span>
<p>摘要 背景 双相情感障碍影响约2-3%的人口，并与皮层异常相关，据报道伴有精神病的双相情感障碍（BDP）表现出更明显的变化。目前尚不清楚童年创伤是否与双相情感障碍各亚型（尤其是BDP）的皮层厚度差异相关。 方法 使用公开可用的PARDIP（精神病与情感研究领域及中间表型）数据集，我们检验了童年创伤是否与120名个体的皮层厚度差异相关：33名不伴精神病的双相情感障碍患者（BD；36%为男性），38名伴精神病的双相情感障碍患者（BDP；47%为男性），以及49名健康对照（HC；61%为男性）。参与者完成了童年创伤问卷简版（CTQ-SF），T1加权MRI扫描经FreeSurfer处理，以提取68个Desikan-Killiany区域的皮层厚度。线性混合效应模型检验了CTQ各亚型评分与皮层厚度之间的关联以及创伤与诊断的交互作用，并按照ENIGMA指南对药物类别和病程进行了敏感性分析。 结果 经多重检验校正后，未发现任何皮层厚度差异具有统计学意义。在名义水平上，BD相对于HC在扣带回、额叶和枕叶区域表现出厚度降低，而BDP相对于BD表现出颞上区厚度增加。性虐待在名义上与颞叶厚度降低相关。探索性创伤与诊断交互作用提示了区域和亚型特异性的模式，但未通过校正。经FDR校正后，药物类别和病程未显示出显著效应。 结论 这些探索性发现提示，童年创伤亚型与双相情感障碍中的皮层厚度之间存在名义上的、区域特异性的关联。然而，没有任何发现通过多重比较校正，因此应将其视为初步结果，并需要在更大样本中重复验证。</p>

<h3>用于追踪持续演化和重叠功能脑状态的Chronnectogram-ICA框架</h3>
<span class="paper-item__meta">bioRxiv / 2026-10-16 / Soleimani, N.</span>
<p>大脑动力学的离散状态模型已成为功能连接分析的主导范式，它将网络活动表示为固定的一组短暂重现状态之间的转移，同时通常假设这些状态本身不演化。我们引入了一个多层级时间连接图框架，该框架放宽了这一假设，并明确表示大脑动力学的高阶时间结构，即不同状态如何在时间上耦合与共同演化，以及每个状态的持续性。该方法将空间引导的独立成分分析（ICA）与个体化、状态引导的动态ICA相结合，以在共享表征空间中捕捉演化且重叠的连接模式。在具有已知真实值的模拟数据上的验证表明，该方法能够恢复离散状态方法无法看到的连续重叠和高阶耦合结构。将该框架应用于FBIRN数据集（151名精神分裂症患者，160名对照者）的静息态功能磁共振成像，结果揭示，同一对大脑状态在患者中向相反极端偏移，一些患者表现出强烈同步，另一些则表现出主动反耦合，造成连接模式的重新分布，而这是传统占用率指标无法看到的，从而提供了一个基础，使精神分裂症根据所采用的测量指标既可表现为高波动性，也可表现为低波动性。</p>

<h3>面包板神经科学：用简单电子电路探索神经元动力学与计算</h3>
<span class="paper-item__meta">bioRxiv / 2026-10-16 / Supple, J. A.</span>
<p>简单的电子电路提供了一种直观的方式来探索神经元信号传导和计算背后的电学原理。本文介绍了一系列实验，使用廉价且易于获取的元件，在免焊接面包板上组装，以研究被动膜特性和模拟神经计算。一个电阻-电容膜模型展示了膜电阻、电容和兴奋性电导如何决定响应幅度以及充电和放电时间常数。多个输入展示了亚线性求和和分流抑制。通过轴向电阻连接膜区室再现了空间衰减和时间延迟。随后我们构建了一个初级运动检测器，以展示简单的电学操作如何产生对视觉运动的方向选择性响应。总之，这种方法为探索神经元生物物理学提供了一个易于使用且灵活的平台，使学生能够将数学描述与可观察的电学行为联系起来，同时培养实用电子技能并创造性地参与自己实验的设计。</p>

<h3>埃塞俄比亚南部沃莱塔地区某三级医院慢性病患者住院负担及相关因素：一项横断面研究</h3>
<span class="paper-item__meta">medRxiv / 2026-10-16 / Koyra, H. C.</span>
<p>背景 慢性病是全球疾病、残疾和死亡的主要原因，在中低收入国家负担尤为沉重。住院是慢性病管理中的一个关键结局，反映了疾病严重程度、治疗失败和医疗资源利用情况。然而，关于埃塞俄比亚慢性病患者住院负担及其相关因素的数据有限。本研究旨在确定埃塞俄比亚南部沃莱塔地区一家三级医院就诊的慢性病患者住院率及其相关因素。方法 于2022年11月至12月在沃莱塔索多大学综合专科医院慢性随访门诊就诊的321名慢性病患者中开展了一项基于医疗机构的横断面研究。采用连续招募方式，并追踪唯一病历号以防止重复招募。通过结构化问卷和病历审查收集数据。采用负二项回归确定与住院率相关的因素，报告发病率比（IRR）和95%置信区间（CI）。p值&lt;0.05被认为具有统计学意义。结果 在321名参与者中，66%报告在治疗期间至少住院一次，平均每名患者住院1.70±1.81次。停药是最常记录的住院原因（39.5%），其次是疾病并发症（22.3%）和感染（11.7%）。多病共存普遍存在，大多数（59.8%）患有2-3种疾病，平均每名患者患有2.40±1.02种慢性病。男性与较高的住院率相关，而规律体育锻炼与较低的住院次数相关。结论 本研究发现慢性病患者住院负担较高，停药是主要的记录原因。男性和规律体育锻炼与住院率显著相关，凸显了将用药依从性支持项目和结构化运动项目整合到常规慢性病护理中的必要性，以及采取性别敏感干预措施的需要。</p>

<h3>乳腺癌相关淋巴水肿中皮下剪切波速度异质性的像素级量化用于淋巴管阻塞分级</h3>

<p>目的：开发并验证像素数据分析（PDA），用于从保存的Holder优化弹性成像（HOE）弹性图中重建像素级剪切波速度（SWV），并确定全区域皮下异质性是否提供淋巴管阻塞的定量特征，与视觉高速度区域（HVA）计数和稀疏手动感兴趣区（ROI）采样进行比较。材料与方法：在这项横断面研究中，110名乳腺癌术后女性接受了淋巴闪烁显像和HOE检查，HOE是一种压力最小化采集框架，在保留常规采集的SWV信息的同时，还能揭示被手持采集所衰减的空间异常。重建验证使用了来自49张PACS检索图像的200对配对ROI，覆盖了几乎整个显示的SWV范围；可重复性评估基于6名参与者的96个匹配解剖部位，这些参与者接受了独立重新采集的HOE检查。PDA、视觉HVA计数和手动ROI采样在任务特定的共同完整病例队列中，对同一HOE采集的弹性图进行评估。结果：PDA在1.17 - 9.97 m/s范围内以接近零的误差重建了机器报告的SWV（平均差值，+0.0009 m/s；平均绝对误差，0.0075 m/s；95%一致性界限，-0.0202至+0.0221 m/s）。对于皮下方差，PDA的观察者间/观察者内组内相关系数分别为0.709/0.799，而手动ROI采样为0.178/0.560。在主要的无阻塞与部分阻塞比较中（n = 93），前臂合并PDA皮下方差比产生了观察到的最高曲线下面积（AUC，0.858；95%置信区间，0.771 - 0.946），相比之下视觉HVA计数为0.820，手动ROI采样为0.794。PDA的皮下方差比在所有三项比较中均为领先特征（AUC，0.858 - 0.878），包括部分与完全阻塞分级，在该分级中三种框架均显示出高区分度。结论：PDA能够从保存的HOE弹性图中准确重建像素级SWV，并实现对浅表SWE异质性的可重复全区域定量。皮下方差比是淋巴管阻塞比较中领先的PDA定量特征，在部分阻塞中尤其具有信息价值。该方法还可对兼容的存档弹性图进行回顾性定量再分析。</p>

<h3>护理实习生职业认同及其影响因素：社会支持与职业认同之间职业适应性的中介作用</h3>
<span class="paper-item__meta">medRxiv / 2026-10-16 / Zhao, Y.</span>
<p>目的：实习期是护生职业价值观形成的关键阶段。本研究旨在调查护理实习生职业认同的现状，分析社会支持、感知压力、心理弹性和生涯适应力对职业认同的影响，并探讨生涯适应力在社会支持与职业认同之间的中介作用，为提升职业认同和优化护理人才培养体系提供实证依据。方法：采用便利抽样法，选取2025年5月至7月泉州市某三级医院的407名护理实习生作为研究对象。采用一般资料问卷、社会支持量表、感知压力量表、心理弹性量表、护生职业认同问卷、生涯适应力量表及护士留职意愿问卷收集数据。使用SPSS 26.0进行信度分析、描述性分析、独立样本t检验、单因素方差分析、Pearson相关分析和多元线性回归分析。采用PROCESS宏检验中介效应。结果：护理实习生职业认同总分为（61.74±11.08），73.5%的护生职业认同处于中等水平。父母对护理的态度、选择专业的原因、个人对专业的态度和就业意愿在职业认同得分上差异有统计学意义（p&lt;0.05）。Pearson相关分析显示，职业认同与社会支持（r=0.474）、心理弹性（r=0.389）和生涯适应力（r=0.609）呈显著正相关（p&lt;0.01），与感知压力呈显著负相关（r=-0.378）（p&lt;0.01）。多元线性回归分析表明，生涯适应力（β=0.309，p&lt;0.001）和社会支持（β=0.383，p&lt;0.001）是职业认同的显著正向预测因素，而选择专业的原因（β=-3.603，p=0.001）和就业意愿（β=-7.116，p&lt;0.001）是显著负向预测因素。该模型解释了职业认同49.2%的变异。中介效应分析显示，生涯适应力在社会支持与职业认同之间起部分中介作用，中介效应值为0.288（95% CI：0.221-0.363），占总效应的40.2%。结论：护理实习生职业认同处于中等偏上水平。社会支持和生涯适应力是正向影响因素。生涯适应力在社会支持与职业认同之间起部分中介作用；社会支持通过增强生涯适应力间接提升职业认同。</p>

<h3>描述健康不平等而不失真：简单均值MAIHDA与随机效应MAIHDA</h3>
<span class="paper-item__meta">medRxiv / 2026-10-16 / Merlo, J.</span>
<p>个体异质性与歧视准确性的多层次分析（MAIHDA）通过三个组成部分描述健康不平等：（i）特定情境效应（SCE），（ii）一般情境效应（GCE），以及（iii）情境的歧视准确性。我们提出简单均值MAIHDA（S-MAIHDA），它直接从每个层级的观测个体估计该层级，无需分布假设。观测比例无论层级大小如何都是无偏的，其置信区间如实报告不确定性。S-MAIHDA在概率尺度上操作化这三个组成部分。SCE是原始和构成标准化的患病率，以及将每个观测层级患病率精确分解为一个参照值、其地区的绝对风险差（ARD）、其社会人口学层级在所有地区共有的ARD，以及地区对该ARD的修正。GCE是方差分配系数（VPC）、标准化情境ROC曲线下面积（coAUC*），后者允许跨结局比较，以及层级间不平等的情境结构化，表达为不平等的情境聚类、加性社会人口学差异，以及不平等的情境修正（CMI）。情境歧视准确性由情境ROC曲线下面积（coAUC）表示，以及在人群患病率作为可能干预阈值时的敏感性和特异性。由于其估计值就是观测数据本身，S-MAIHDA是典范性描述，而比较诊断量化了随机效应MAIHDA（RE-MAIHDA）——通常的实现方式——偏离它的程度：RE收缩将小层级拉向总体均值，可能掩盖分析所寻求揭示的不平等本身。每个指标都从按层级计数的表中计算，因此个体记录无需共享。该方法在smaihda Stata命令中实现，并在免费的Python和R代码中复现。我们用瑞典马尔默2006年登记数据的横断面分析（43,291名个体；300个地区-社会人口学层级）来说明S-MAIHDA，展示这三个组成部分如何区分两个对比鲜明的结局：精神药物使用，几乎纯粹是社会人口学的，在各地区间稳定，情境结构化较弱（VPC约4%，coAUC*约63%，CMI约0%）；以及选择私人全科医生，强烈具有地理性（VPC约11%，coAUC*约72%，CMI约17%），社会人口学差异在富裕地区被重塑和放大。RE-MAIHDA减弱了不平等。对于描述不平等而言，S-MAIHDA保留了数据所显示的内容。</p>

<h3>认知、生活方式与环境：量化身体生理与大脑的作用</h3>
<span class="paper-item__meta">medRxiv / 2026-10-16 / Buianova, I.</span>
<p>生活方式和环境因素日益被视为维持认知健康的可干预目标。然而，目前尚不清楚它们对认知功能的预测能力有多强，以及它们与认知的关联在多大程度上反映在大脑和身体指标中。我们对来自超过10,000名英国生物银行参与者的多模态数据应用机器学习，评估十二个生活方式和环境领域（涵盖体力活动、饮食、吸烟、饮酒、睡眠、性行为、电子设备使用和环境暴露）对认知的预测价值，包括单独和联合评估，并量化这些关联被身体和大脑所捕捉的程度。一个整合生活方式和环境领域的模型解释了认知方差的23%，r=0.48，与身体和大脑标志物相当。体力活动、饮食、饮酒、日照和当地环境是最强的预测因素。一个整合三种神经影像模态的复合大脑标志物解释了生活方式-认知关联的57.7%，而一个涵盖九个生理系统的复合身体标志物解释了47.8%。生活方式、环境、身体和大脑共同捕捉了92.6%的年龄相关认知变异。因此，整合生活方式和环境因素能够在英国生物银行队列中稳健地预测认知，且这种关联的很大一部分反映在大脑和身体健康中。然而，这些发现对更广泛人群的普遍适用性仍需进一步评估。</p>

<h3>瑞典长读长基因组测序的国家生态系统：整合群体基因组学与罕见病诊断</h3>
<span class="paper-item__meta">medRxiv / 2026-10-16 / Ameur, A.</span>
<p>为评估长读长基因组测序（lrGS）的临床实施，并建立支持其在诊断中应用所需的人群参考资源，我们整合了两项互补性计划：瑞典基因组计划（GoS），即瑞典对欧洲基因组计划（GoE）的贡献，以及瑞典基因组医学-罕见病（GMS-RD）长读长测序试点。GoS首批发布的576名个体提供了群体尺度的遗传和表观遗传变异图谱。在485名GMS-RD先证者中，161名（33.2%）获得分子诊断，其中lrGS在40名（24.8%）中提供了额外临床价值。作为一线检测，lrGS本可避免至少42次后续分析，并在7.2%的先证者中避免额外一轮检测，从而降低成本和患者负担。通过整合群体与临床长读长基因组学，瑞典建立了用于基因组研究和临床诊断的国家生态系统。我们的发现支持lrGS的临床实施，并提供了一个可扩展的国家协作模式。</p>

<h3>用于临床试验终点预测和前瞻性评估的inClinico智能体</h3>
<span class="paper-item__meta">medRxiv / 2026-10-16 / Chen, J.</span>
<p>临床试验药物开发中的高流失率带来了巨大的临床和经济负担，但前瞻性预测单个试验能否达到其主要终点仍然具有挑战性。在此，我们提出一个机器学习系统，可预测I-IV期临床试验的成功率，并分别对以疗效为主要终点和以安全性/毒性为主要终点的研究进行建模。为防止前视偏差和结局泄漏，模型基于注册时特征进行训练，包括靶点和作用机制的先例、药物模态和新颖性、试验设计和运营特征，以及冻结的文献衍生靶点选择嵌入。每个预测都会产生一个介于0到1之间的连续预测试验指数（PTI），反映成功概率。在2021年或之后启动的试验测试集上，疗效模型的受试者工作特征曲线下面积（AUROC）达到0.828（95% CI 0.812-0.845；n = 2,347），安全性/毒性模型达到0.809（95% CI 0.787-0.831；n = 1,485）。这些模型嵌入于inClinico Agent中，这是一个代理式AI系统，将前沿大型语言模型（LLM）与确定性评分引擎、检索工具和专门临床技能相结合。我们还引入了ClinBench，这是一个由inClinico Agent和五个前沿LLM评估的2,040项正在进行试验的前瞻性基准，为在试验完成时跟踪前瞻性预测准确性建立了无泄漏基础。</p>
